§0编写理念与融合结构

这不是三门课的拼盘，而是围绕一条红线重新组织的一门课：一个逻辑性质，总能在代数一侧找到一个自然对应，在拓扑一侧找到它的空间表现。三者讲的是同一件事的三种语言。

● 代数（Universal Algebra）

把「逻辑系统」压缩成一类代数。工具：同余、商、直积、子直积、自由代数、簇、同态。回答：这个逻辑的代数本质是什么？

● 拓扑（in & via Logic）

把「可能世界 + 可验证命题」看成空间与开集。工具：滤子、超滤子、紧致、连通、无点拓扑。回答：可验证性如何塑造空间？

● 逻辑（Universal Algebraic Logic）

把各种逻辑放进统一规范形式，定义其代数对应物，再证明桥定理。回答：性质如何在逻辑与代数之间来回搬运？

三条线在 「对偶 / 表示 / 桥定理」 处交汇 —— 这是全课的枢纽

贯穿全课的红线：「可验证性 → 开集 → 滤子 / 理论 → 同余 / 理想 → 代数对应物 → 桥定理」。 以天鹅例子起步：开集 = 可验证命题；再往上，紧致性在逻辑侧是「有限可满足即整体可满足」，在代数侧是「对超积封闭」，在拓扑侧是「每个超滤子收敛」——同一个定理，三副面孔。

三部分教材在课程中的角色

Bergman《Universal Algebra》（2011）— 代数主干教材，Part I 打地基，Part II 同余分配 / 算术 / Maltsev / 有限代数作为专题深度，保证「代数」这条线足够硬。

《在逻辑中并经由逻辑学习拓扑》（Aharoni–Almeida–Knudstorp，中译稿第 2–7 章）— 拓扑主干教材，自带认识论解释，是全课「融合」的黏合剂：开集/可验证、滤子/理论、紧致/完备、S4/内部算子。

Andréka–Gyenis–Németi–Sain《Universal Algebraic Logic》（2022）— 逻辑主干教材，提供规范形式、代数化方法、六座桥定理、八个案例与关系代数附录，是全课的「主线剧本」。

I共同基础：关系、序、闭包

三条线共用的语言。闭包算子这一讲是全课第一个融合点：它同时是代数中的生成子代数、拓扑中的闭包、逻辑中的后承算子。

集合、关系、函数、序

2 学时

代数逻辑
  • 集合、类、元组；Russell 悖论；二元关系、等价关系、函数
  • 序、序数、基数；序列；族的直接积；高阶关系
  • 一阶逻辑语法与语义速览（词项、公式、满足、模型）
融合接口：「三元组关系 ↔ 函数 ↔ 等价类」同时是后面同余关系、模态可达关系、商空间的共同前身。
来源：UAL Ch1 §1.1–1.6, §1.8；Bergman Ch2 §2.1
L02格、闭包系统与 Galois 连接 正文已就绪 · 深度讲

  • 偏序集、格、分配格与模格、完全格
  • 闭包算子、代数格；Galois 连接的定义与基本性质
  • 闭包系统：任意交封闭；生成闭包系统的标准方法
融合接口：闭包算子 C 三副面孔 —— 代数 Sg（生成子代数）、拓扑 cl（闭包）、逻辑 Cn（后承）。Galois 连接是 Stone 对偶的雏形。
来源：Bergman Ch2 §2.1–2.6；UAL §1.7；拓扑讲义 §2.4（内部/闭包算子）

代数线的主体，以 Bergman 为骨架、UAL Ch2 为补充。这一部分的每个概念后面都会在「代数化」中被用来表示某个逻辑。

III拓扑：用逻辑的眼光看空间

以中文讲义为主线，逐节落实其认识论解释。这里的每个拓扑概念都配一个逻辑读法，为第五部分的桥定理准备几何直觉。

L08

开集 = 可验证命题

2 学时
L08拓扑空间与认识论解释 正文已就绪
拓扑逻辑
  • 拓扑定义 (O1)(O2)(O3) 的认识论论证：可验证命题对任意析取、有限合取封闭
  • 天鹅例子：X = {a, b}，τ = {∅, X, {b}}；可验证 / 可证伪 / 不可判定
  • 命题 ↔ 真值集；∨ ↔ ∪，∧ ↔ ∩，¬ ↔ 补
融合接口：这是全课「翻译词典」的出发点：可验证命题 ↔ 开集；在 x 为真的可验证命题 ↔ x 的开邻域。
来源：拓扑讲义 Ch2 §2.1（含例 2.1.1、表 2.1）
L09基、子基与生成新拓扑 正文已就绪
拓扑逻辑
  • 基与子基的定义；用基/子基生成拓扑；拓扑的比较（细/粗）
  • 由子基生成：有限交再任意并；积拓扑、子空间拓扑、商拓扑
融合接口：基 = 一组基本可验证命题；子基通过「加强知识（有限合取）+ 弱化知识（析取）」生成全部可验证命题。
来源：拓扑讲义 Ch2 §2.2–2.3（含注 2.2.1）
L10闭集、邻域、闭包与内部算子 正文已就绪
拓扑代数
  • 闭集 = 可证伪命题；既不开也不闭的命题（「外面下雨」vs JFK 念头）
  • 邻域、闭包 cl、内部 int； Kuratowski 闭包公理
  • 内部算子作为模态 □、闭包作为 ◇ 的预告
融合接口：Kuratowski 闭包公理 ↔ 逻辑中的模态公理；内部算子是 S4 模态算子的拓扑实现（L25）。
来源：拓扑讲义 Ch2 §2.4；Bergman Ch2 §2.4（闭包算子）
L11连续映射、同胚、嵌入与商映射
拓扑逻辑
  • 连续性的开集定义与认识论定义：翻译「不增加知识」
  • 开映射 =「不丢失知识」的翻译；同胚、嵌入、商映射
  • 积空间、商空间的泛性质
融合接口：连续映射 ↔ 逻辑翻译的保真性；同胚 ↔ 两种逻辑的表达力等价（可相互定义）。
来源：拓扑讲义 Ch3 §3.1–3.2（含注 3.1.2、3.1.4）
L12分离公理：可区分性与滤子
拓扑逻辑
  • 认识论问题：能否验证两个模型不同？滤子基、滤子、主滤子、邻域滤子
  • 收敛、唯一收敛；T0 / T1 / T2 (Hausdorff) / 正则 / 正规
  • T0 的认识论意义：T0 才「可区分」；不可区分 ≍ 同余关系
融合接口：滤子 ↔ 理论；收敛滤子 ↔ 确定性理论；Hausdorff ↔ 每个理论至多一个模型。这是 L13 紧致性的前置。
来源：拓扑讲义 Ch4 §4.1–4.5；UAL §3.3.5（滤子性质）
L13素滤子、紧致性与紧致化
拓扑逻辑
  • 素滤子（ultrafilter）：极大真滤子；Tarski 素滤子定理
  • 紧致 = 每个开覆盖有有限子覆盖 ⇔ 每个素滤子收敛；闹钟例子
  • 局部紧、紧致 Hausdorff、Alexandroff 单点紧致化、Stone–Čech 紧致化
融合接口：紧致性 = 完备性（有限可满足 ⇒ 整体可满足）；素滤子 = 饱和理论；紧致化 = 给理论补上缺失的模型（L18 详证）。
来源：拓扑讲义 Ch5 §5.1–5.3（含命题 5.2.9、5.3.15）
L14连通性、全不连通与 Stone 空间
拓扑逻辑
  • 连通、道路连通；全不连通、全分离；孤立性与极端不连通
  • Stone 空间（紧致、Hausdorff、零维）与布尔代数的对偶预览
  • 极端不连通在完全信念逻辑中的用途预告
融合接口：零维 / 极端不连通空间是布尔代数与 Stone 对偶的几何形态；与 S4.2 及信念逻辑相连（L25）。
来源：拓扑讲义 Ch6 §6.1–6.3；Ch7「空间的模态逻辑」

IV代数化：把逻辑翻译成代数

UAL 第三章的主线剧本。把千差万别的逻辑放进统一规范形式，然后为每一个逻辑定义它的代数对应物。

逻辑代数
  • 逻辑的规范形式：语言、公式、语义、后承关系；语法与语义两要素
  • 大量例子：命题逻辑、模态逻辑、一阶逻辑的规范表示
  • 为什么需要规范形式：为了定义函数 Alg(L)
融合接口：规范形式把「逻辑」变成一个可代数化的对象；这是把各类逻辑纳入通用代数机器的入口。

L16代数对应物、代入性质与滤子性质
逻辑代数

  • 代入性质：语义代入、句法代入、条件代入；filtral 性质

V桥定理：全课核心

五座桥，每座都双向走：逻辑性质 ⇔ 代数性质，并在可能处补上拓扑对应。建议这一部分是课程高潮，投入最多学时。

B三条教学路线

参照 UAL 前言给出的三套课程方案，结合本讲义的融合结构，给出三种用法。

路线 A · 代数逻辑基础

13 周 · 每周 2 学时 · 面向逻辑/数学新生
  1. L01–L02 基础与闭包
  2. L03–L06 代数骨架（略去 Bergman Part II）
  3. L08–L14 拓扑的认识论速览
  4. L15–L17 代数化
  5. L18, L19–L22 桥定理
  6. L27–L29 三个经典案例

路线 B · 融合通论（推荐）

16 周 · 每周 2–3 学时 · 完整覆盖
  1. 第 1–4 周：L01–L07（基础 + 代数 + 闭包系统）
  2. 第 5–8 周：L08–L14（拓扑全套）
  3. 第 9–11 周：L15–L17 + L18–L22（代数化 + 桥）
  4. 第 12–13 周：L23–L26（对偶与表示）
  5. 第 14–15 周：L27–L30（案例工坊）
  6. 第 16 周：L31–L32（前沿与总结）

路线 C · 研究生专题研讨

一学期 · 每周 3 学时 · 需坚实泛代数与 FOL 基础
  1. 快速过 L01–L06（学生自读）
  2. 精读 L18–L22 全部桥定理及证明
  3. 精读 L07（Bergman Part II）与 L30
  4. 研讨 L23–L26 对偶与无点拓扑
  5. 选题报告：UAL Ch5 案例 + Ch6 推广
