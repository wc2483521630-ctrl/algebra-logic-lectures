2动机：四条路，一把刀

它解决什么问题

到 L16 为止，我们只走了一条路——UAL：先把逻辑做成四元组，再算代数影子，最后把逻辑性质翻成代数性质。这条路不是唯一的。Tarski 之后至少分出四条，都想做同一件事：给「逻辑」一个统一形状，好让定理能一次证明。

奇怪的是，它们彼此不像。AAL 的基本对象只有 ⟨F, ⊢⟩，连模型都不要；AMT 只谈句子和满足关系；机构论把一切都范畴化；UAL 则死死抱住意义函数 mng 不放。为什么会差这么多？

答案藏在「为了统一，你愿意丢掉什么」这个问题里。丢得越多，框架越轻、定理越漂亮；丢得越少，能处理的逻辑越丰富、越贴近真实的一阶逻辑。四种选择对应四种答案：

  • AAL 丢掉语义，只留后承 → 换来一套极其干净的演绎系统理论；
  • AMT 丢掉 mng，只留句子与满足 → 换来模型论性质的统一处理；
  • 机构论 再进一步范畴化 → 换来程序语言规范那一侧的工具；
  • UAL 什么都不丢，连开公式的意义都留 → 换来处理非替换形式的一阶逻辑的能力，代价是框架更重。

这一讲就是把这个交换说清楚。不是评优劣，是看清楚哪把刀切哪块肉。

3AAL：从演绎系统出发 O1

它解决什么问题

抽象代数逻辑（AAL）问的问题比 UAL 窄：如果只给你语法和后承关系，没有模型、没有意义函数，还能不能做代数化？答案是能，而且做出了一套极干净的理论。

它的基本对象叫演绎系统 ⟨F, ⊢⟩：F 是形式语言，⊢ 是后承运算。Tarski 要求 C(X) = {φ ∈ F : X ⊢ φ} 是代数闭包算子——这正是 L02 讲的那三公理，在这里第一次以「逻辑公理」的身份出现。

Łoś 与 Suszko 后来加了一条：替换不变性，AAL 叫 structurality。加上它，所有这样的后承都来自某个 Hilbert 型系统（公理 + 推导规则）。这一步把「闭包算子」和「证明系统」接上了。

演绎系统 AAL 的起点

一对 ⟨F, ⊢⟩，其中

C(X) = {φ ∈ F : X ⊢ φ}  是代数闭包算子（单调、扩张、幂等）

structural（结构）指 C 对替换不变：任意同态 h : F → F，X ⊢ φ ⟹ h(X) ⊢ h(φ)。这正是 L16 定义 3.3.9 的句法代入性质在后承层面的说法。

structural 的演绎系统叫 sentential logic（Font）。Blok–Pigozzi 定义：演绎系统可代数化，若它等价于某个唯一代数类 K 的等式理论，翻译用的正是 L16 定义 3.3.18 滤子性质里的那组项。

UAL 与 AAL：同源异向 UAL §3.4 开宗明义

同源：两条路都从 Tarski 出发，都提供「一般化的代数逻辑」，目标与方法都很像。

异向：UAL 可以看作向着一阶逻辑敞开、并把重心放在语义上的 AAL；也可以看作从柱形代数与关系代数理论中抽象出来的代数逻辑通论。

为什么 UAL 必须比 AAL 重？因为 FOL 比命题逻辑复杂得多（可判定 vs 不可判定）。UAL 的三个「重」处：

  • 代数化结果不止一个类，而是 Alg⊨ 与 Algm 两套；
  • Algm(L) 甚至不是抽象类——不对同构封闭，在弱 Beth 性质里这点很重要（L16、L20）；
  • 重心在开公式而非语句——给开公式赋意义的 mng 函数，在别的技术路线里根本不出现。
典型 · 经典命题逻辑

⟨F, ⊢⟩ 取所有命题公式与标准推导，C 是重言后承。它 structural（替换保真）、可代数化，唯一的 K 是布尔代数类 BA。AAL 与 UAL 在这里完全重合。

本质 · Łoś–Suszko 定理在干什么

它说「满足闭包公理 + 替换不变的后承」恰好是「由 Hilbert 型公理系统给出的后承」。这一步的意义是：你不必逐个检查逻辑，只要验证两条抽象性质，就知道它能被公理化。这就是 L02 闭包算子观点的第一次大胜。

边界 · AAL 丢掉的东西

演绎系统里 ⊢ 可以兼指语义后承（Remark 3.1.2 的伪模型构造），但 AAL 的主要应用是句法可推导性。一旦丢掉 M 与 mng，你就问不了「某个模型里这个开公式指什么」——而这正是 UAL 要保留的。

一个术语坑

UAL §3.3 里说「有滤子性质就叫 algebraizable」（§3.4 Remark 3.4.2 仍这么用），但定义 3.4.1 为了和 AAL 兼容，把它定义成「滤子性质 + 语义代入」。同一本书两个口径，读的时候要看上下文。本讲按定义 3.4.1。

Remark 3.4.2：可代数化能 weaken 到什么程度

Blok–Pigozzi 那边还有一连串更弱的性质，越弱越容易满足，能用的代数方法也越少。UAL 把它们平移到语义逻辑 Ls = ⟨F, M, mng, ⊨⟩ 上：

Ls protoalgebraic ⟺ 存在导出连接词集 ∆(φ,ψ) 使 ⊨ ∆(φ,φ) 且 M ⊨ ∆(φ,ψ) ⟹ (M ⊨ φ ⟺ M ⊨ ψ)

这条式子只读成一句话：∆ 至少能「检测」两个公式是否同真——它是滤子性质里 ∆i 的削弱版（不要求意义相等，只要求同真）。

在此基础上逐级加码：

  • equivalential：∆ 还满足滤子性质的条件 (1)（意义相等 ⟺ 所有 φ∆iψ 有效）；
  • weakly algebraizable：protoalgebraic + 滤子性质的条件 (2)（有一组 ε, δ）；
  • infinitely algebraizable：equivalential + weakly algebraizable，但 ∆, ε, δ 可以是无穷集；有限集时就是 algebraizable。
protoalgebraic ⟹ equivalential ⟹ algebraizable

UAL 本书只为 algebraizable 这一档展开机器，并邀请读者把 machinery 推广到更弱的两档。protoalgebraic 被认为是「还能用代数方法的最弱门槛」。

典型 · 命题逻辑站在阶梯顶端

经典命题逻辑 protoalgebraic、equivalential、algebraizable、structural、nice 全占。∆ = {↔}，ε = {⊤}，δ = {id}，一组有限的导出连接词把整条阶梯走完。

本质 · 阶梯为什么是「加法」而不是「分类」

每一级都在前一级上加一条具体要求：先要有 ∆ 能测同真，再要 ∆ 能测意义相等，再要有 ε, δ 把有效翻成等式。UAL 把 L16 那一大堆定义拆成可单独开关的旋钮，AAL 则给这些旋钮起了名字、排了序。两种风格互补。

边界 · 别把「nice」当成夸奖

nice 是 UAL 借来的技术术语，= 组合 + 滤子性质 + 句法代入。一阶逻辑连语义代入都没有，自然不 nice；但它无条件可代数化。「nice」在这里只是个标签，不是价值判断。另外注意 protoalgebraic 的 ∆ 可以是无穷集，UAL 正文的「algebraizable」要求有限——infinitely algebraizable 是单独一档。

5两个方向的等价定理 O3

它解决什么问题

两套框架都对「可代数化」下了定义，它们是一回事吗？UAL 给了双向定理：在各自合适的条件下，AAL 的可代数化演绎系统 ⟷ UAL 的可代数化语义逻辑。这保证你在 AAL 证的定理不会和 UAL 的打架。

UAL §3.4 · 双向等价 UAL ↔ AAL

方向一（UAL → AAL）。设 L 是 algebraizable、后承紧致（定义 4.1.1，L18 详讲）的语义逻辑。则 ⟨FL, ⊨L⟩ 总是 Blok–Pigozzi 意义下的 algebraizable 演绎系统，而且与它等价的唯一的 K 就是 Alg⊨(L)。

方向二（AAL → UAL）。若 ⟨F, ⊢⟩ 是 algebraizable 演绎系统，则由 Remark 3.1.2 的伪模型构造得到的 L⊢，总是 UAL 意义下 algebraizable、后承紧致的逻辑。

Font–Jansana 还指出：紧致性在这两个定义里都不重要——去掉它，等价仍然成立。UAL 这里加上，只是因为正文要在紧致语境里用。

唯一性那句最值钱：AAL 那边「唯一的 K」正是 UAL 算出来的 Alg⊨(L)。两套独立发展出的理论，指认了同一个代数类。

典型 · 命题逻辑的 BA

LS 后承紧致、algebraizable，Alg⊨(LS) = BA。AAL 那边从 ⟨F, ⊢⟩ 算出的唯一等价类也是 BA。两边对上了。

本质 · 为什么需要「唯一」

可代数化若允许一堆 K 都等价，翻译就没有标准答案。唯一性让「这个逻辑的代数」成为一个确定的对象，L18–L20 的桥才写得出来。Alg⊨(L) 凭什么配当这个唯一者？因为定理 3.3.5 保证它和语义侧只差 SP（L16）。

边界 · 紧致性的角色别搞反

UAL 方向一要求「后承紧致」，读者容易以为紧致性是可代数化的前提。Font–Jansana 的结果说不是：它是正文使用时的附加条件，不是定义的必要条件。L18 会把紧致性讲成一座独立的桥，别和这里的「可代数化」绑死。

6AMT：抽象模型论 O4

它解决什么问题

模型论那边问的是另一个问题：一阶逻辑有那么多性质（紧致、Löwenheim–Skolem、省略型……），哪些是「一阶逻辑」本身给的，哪些是具体语言给的？想回答，就得把「逻辑」抽象出来，让一阶逻辑只是其中一个实例。

AMT（Abstract Model Theory）的抽象逻辑是一对 ⟨L, ⊨L⟩：L 定义在经典签名 τ 上，L[τ] 是语句类，⊨L 是结构与语句之间的满足关系，并满足五条条件。

AMT 抽象逻辑 五条件 (i)–(v)
条件内容在 UAL 里的对应
(i) 扩张τ ⊆ σ ⟹ L[τ] ⊆ L[σ]子逻辑 / 签名扩张
(ii) 语言封闭M ⊨L φ ⟹ φ ∈ L[τM]mng 的定义域
(iii) 同构不变M ⊨ φ 且 M ≅ N ⟹ N ⊨ φ模型同构保持满足
(iv) 约化φ ∈ L[τ]、τ ⊆ τM 时 M ⊨ φ ⟺ M↾τ ⊨ φL16 Remark 3.3.30 的约化函数
(v) 改名重命名 ρ : τ → σ 时存在 φρ ∈ L[σ] 使 M ⊨ φ ⟺ Mρ ⊨ φρL16 定义 3.3.26 的同构副本

逐条看下来你会发现：这五条 UAL 的一般逻辑都有（或等价地有）。所以 UAL §3.4 直接下结论：

AMT ⊂ 一般逻辑 特例关系

抽象模型论是 UAL 一般逻辑的特例：签名类 Sig 取所有一阶签名，模型类取经典一阶模型。AMT 的每条抽象逻辑，都是一个一般逻辑。

差别在关注点：AMT 专心找表达力至少和 FOL 一样强的逻辑（如加入无穷量词、多数数量词）。它用一条额外条件刻画存在量词：

(q)  若 c ∈ τ，则对任意 φ ∈ L[τ] 存在 ψ ∈ L[τ−{c}]，使 M ⊨ ψ ⟺ (M,a) ⊨ φ 对某个 a ∈ M

读作：把变量当成一个额外的常元 c，存在量词就变成「在某个展开上成立」。这是模型论处理量词的标准手法。

典型 · 一阶逻辑本身

L = FOL，L[τ] 是 τ 上的一阶语句，⊨ 是 Tarski 满足关系。五条全满足，(q) 也满足——变量当常元的老手法。

本质 · AMT 与 UAL 的分工

两者都强调语义、都认真对待 FOL，但 AMT 不打算研究语义与代数的桥。它要的是「更强的逻辑各自有哪些模型论性质」。UAL 要的是「逻辑性质和代数性质怎么互译」。工具箱不同，对象可以重叠。

边界 · (q) 那招为什么在 UAL 里够用

(q) 把变量升级成常元，只在语句层面说话。可一旦要谈开公式的意义——比如 φ(x) 在模型里定义一个集合——你就需要 mng(φ, M) 这种东西。AMT 的 (q) 绕开了它，UAL 则正面接住它。这正是 UAL 后来能处理非替换形式一阶逻辑的本钱。

7机构论：范畴论版本 O5

它解决什么问题

机构论（Institutions Theory）是 AMT 的范畴论版本。它最初不是为逻辑基础做的，而是为程序语言规范提供统一框架（Burstall–Goguen）。同一个「签名—句子—模型—满足」结构，换一套范畴论语言重说一遍，就得到另一套工具。

UAL 的态度很明确：机构论强调一般逻辑里的范畴论侧面（本书把它压下去了），同时抑制了由 mng 表示的内涵侧面。

逻辑态射与签名范畴 从一般逻辑造范畴

设 P, P1 ∈ Sig。逻辑态射 h : LP → LP1 是一对 h = ⟨f, μ⟩：

  • f : FP → FP1 是公式代数的同态；
  • μ : MP1 → MP（注意反向）使一切交换：M ⊨ f(φ) ⟺ μ(M) ⊨ φ。

若 mng 也在场，μ 还要诱导出意义上的函数 μ+，使

mngμ(M)(φ) = μ+( mngM(f(φ)) )

f↾P 叫签名态射。以签名态射为箭头、Sig 为对象得范畴 Sign；以逻辑态射为箭头得范畴 Log。于是有函子 F : Sign → Log，P ↦ LP。

机构的构造 I(L) = ⟨Sign, fml, Mod, ⊨⟩

上面那个函子 F 几乎就是机构了，只差一味：在我们知道的所有应用里，MP 不只是一个类，而是一个范畴（本书压下了这个范畴侧面，但它确实在后方起作用）。设每个 MP 是范畴后，F 诱导出两个函子：

fml : Sign → Fmla,    Mod : Sign → Catop

于是 F(P) = ⟨fml(P), Mod(P), ⊨P⟩，四元组

I(L) = ⟨Sign, fml, Mod, ⊨⟩  就是机构，其中 ⊨ = ⟨⊨P : P ∈ Sign⟩

双向恢复：给一般逻辑 L 得机构 I(L)；给机构 I 得一般逻辑 L(I)，二者可互相还原（前提是 L(I) 里模型仍成范畴）。要百分之百严丝合缝，还得把 mng 也加进机构、把 MP 也做成范畴——UAL 说「看不出为什么不作此修正」。

机构论里 UAL 的「fml」写作 sen，正因为 mng 被抑制，意义被真值取代。应用到 FOL 时，注意力只能限制在语句（闭公式）上——开公式的意义比真值复杂得多。

典型 · 命题逻辑的机构

Sign 是命题字母集与改名，sen(P) 是公式，Mod(P) 是赋值，⊨ 是满足。四元组齐全，与 UAL 的一般逻辑一一对应。

本质 · 反向的 μ 是精髓

签名从 P 扩到 P1（公式变多），模型方向却从 P1 缩回 P（忘掉多余结构）。这就是 L16 Remark 3.3.30 的约化函数，只是换成了范畴论的说法。两条路线在这里握手。

边界 · sen 不是 fml

名字差别有实质内容：机构论只留真值，所以只能谈句子；UAL 留 mng，所以能谈开公式。量词在 IT 里和 AMT 一样，靠「变量当常元」的 (q) 式手法处理——再次绕开了开公式的意义。这不是缺陷，是选择：换了工具，就得换能问的问题。

8UAL 的特色与缺口 O6

它解决什么问题

比较完三条路，回到 UAL 自己。Preface 用一句话点出自家的定位：

UAL 的新意 = 为量词逻辑（尤其 FOL）处理其「非替换形式」而发展出成套方法

「非替换形式」是什么意思？就是不假设命题字母可以任意换成公式。L16 已经看到：一阶逻辑的语义代入失败，只有条件代入成立。多数统一框架在这里悄悄假设了强替换性，一阶逻辑就被挤出去；UAL 偏要正面处理它。

Preface 同时坦白一个缺口：多排序逻辑（many-sorted logics）尚未覆盖，这可能是 UAL 最重要的缺失方向。而多排序逻辑在把逻辑用于其他科学时越来越重要（Halvorson）。

典型 · 开公式的 mng

在 LFOL 里，mng(φ(x), M) 是满足 φ 的赋值之集（L15）。AAL 不问它、AMT 绕开它、机构论把它压成真值；只有 UAL 把它当一等公民。

本质 · 非替换形式为什么值钱

一阶逻辑里 r(x) 是一元、s(x,y) 是二元，替换会撞类型（L16 §5）。UAL 用条件代入接住这件事，代价是代数侧要用带定义关系的自由代数 Fr(K, P, ∼L)。框架重一点，换来的是「真的一阶逻辑」而不是「一阶逻辑的替换式简化版」。

边界 · 多排序缺口

Preface 说得很直白：UAL 最重要的缺失方向，或许就是多排序逻辑的处理。起点文献有 [66]、[192]，Halvorson [93] 谈它为何在跨学科应用中重要。本讲义到这里也停在同一处：我们能处理单排序的一阶逻辑，但把「多 sorts 的语言」做成四元组，还需另起炉灶。
