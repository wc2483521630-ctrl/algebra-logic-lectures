2动机：说得出的，和分得开的

它解决什么问题

前两座桥问的都是「整体性质」：有没有模型（L18）、能不能证明（L19）。这一问的是一个更细的问题——具体某样东西，语言能不能把它单独指出来？

拿群语言举例。群里有个元素只满足 x · x = x，它是单位元。一阶句子把单位元唯一地「说」出来了：任何群、任何满足这句子的元素，都只能是那个单位元。反过来，若给群加一个常元 c 但不加公理约束，c 就没被定义——不同模型里它指不同元素。可定义性问的就是：这个「说准了」能不能被形式化？

形式化之后，真正有意思的是它的三副面孔：

  • 语法：存在一个公式 φ(x)，在所有模型里恰好选出你要的东西（Beth 可定义性）。
  • 代数：某个自然同态是满射——语言的影子没有「漏掉」这个元素的像。
  • 拓扑：两个模型在共同语言下分得开（T0）；分不开就说明语言看不见它们的差别，自然也说不准。

三句话是同一句：「语言能定义，当且仅当语言能区分。」这一讲就是把这句翻来覆去证三遍。

先把话说清楚：可定义性不是「能命名」

① 能写个常元指它，不等于能定义它。加一个新常元 c 谁都能做；可定义性要求用已有语言写出公式，把 c 的取值逼死（Beth 定理：隐含可定义 ⟺ 显式可定义，§3）。

② 「分得开」依赖你选的语言。同一批模型，语言丰富时分得开，语言贫乏时可能分不开。可定义性是相对语言的性质，不是绝对性质。

3Beth 可定义性四版本 O1

定义 3.1（显式可定义）

设 Σ 是语言 𝓛 上的理论，R 是一个 n 元关系符号（不在 𝓛 里，或当作要定义的符号）。称 R 在 Σ 中显式可定义，若存在 𝓛-公式 φ(x₁,…,xn)（不含 R）使

Σ ⊨ ∀x̄  (R(x̄) ↔ φ(x̄))。

对函数符号 f，显式定义要求公式 ψ(x̄, y) 使 Σ ⊨ ∀x̄∀y  (f(x̄) = y ↔ ψ(x̄, y))。显式 = 有一把现成的尺子，量出来的外延就是它。

定义 3.2（隐含可定义）

称 R 在 Σ 中隐含可定义，若把 R 换成两个不同符号 R₁, R₂，则

Σ(R₁) ∪ Σ(R₂) ⊨ ∀x̄  (R₁(x̄) ↔ R₂(x̄))。

也就是说：任何两个模型，只要在其他部分一样，它们给 R 的解释就必须一样。隐含 = 没给尺子，但 Σ 已经把 R 的外延唯一逼出来了。

定理 3.3（Beth 可定义性定理）
R 在 Σ 中隐含可定义 ⟺ R 在 Σ 中显式可定义。

在一阶逻辑里，「被逼出来」和「说得出来」等价。这是本讲的第一根支柱：它把语义条件（所有模型一致）换成语法条件（存在公式）。证明用紧致性——L18 的桥在这里第一次兑现到可定义性上。

证明骨架。显式 ⟹ 隐含显然（同一把尺子量两次，结果一样）。反向用紧致性：若 R₁, R₂ 的解释在所有模型里一致，可把「R₁(x̄)」与「R₂(x̄)」的偏差用有限片段排除；Craig 插值（L21）给出一个 𝓛-公式夹在中间，就是所求的 φ。∎

注：Beth 定理与 Craig 插值定理等价（见 L21）。此处先给结论，完整证明待插值工具就绪。

定义 3.4（局部与弱可定义）
  • 在某模型 M 中（局部）可定义：存在公式 φ 使 RM = φM——只要求这一个模型里对上。
  • 弱可定义：允许公式带参数（常元或元素），即 φ(x̄, ā)。局部 + 带参数，是最宽松的版本。
  • 全局可定义：上面的定义 3.1/3.2，要求对 Σ 的所有模型成立。

四种版本按强度排：全局显式 = 全局隐含（Beth）⟹ 局部显式；弱版本最弱（多了参数这个自由度）。做题先问是哪种，混了就错。

典型例子

群的单位元。e(x) : x·x = x 显式定义单位元；隐含地，任何满足「存在唯一的 x 使 ∀y (x·y = y)」的解释都只能是真单位元。两种说法对上，Beth 在此最直观。

本质例子

为什么「隐含 ⟹ 显式」不显然。隐含说的是「任何两个模型给的解释一样」——这是关于所有模型整体的全称命题；显式说的是「存在一条公式」——这是关于语法对象的存在命题。它们凭什么相等？本质是紧致性 + 插值：整体一致性能被有限证据捕捉，而有限证据可以写成一条公式。L18 的发动机在这里第二次点火。

边界与误解

① Beth 定理对一阶逻辑成立，对某些弱逻辑失败。模态逻辑、直觉主义逻辑里显式与隐含可能分开。别当成普世真理。

② 「唯一」要量对所有模型，不是一个模型。在某模型里唯一，换个模型可能被别的东西满足——那是局部可定义，不是全局。

来源：UAL §4.3.1（Beth 可定义性四版本）；L18 紧致性；L21 Craig 插值（预告）。

4代数侧：同态的满射性 O2

从公式翻译到同余

把 L16 的 Fact 3.3.20(ii) 请出来。它说（在组合 + 条件 (ii) 下）：

M ⊨L Σ  ⟺  ker(mngM) ⊇ ∼Mod(Σ)。

左边是语义（模型满足理论），右边是代数（模型的同余比理论的同余更粗）。L16 说这是「L20 可定义性定理的雏形」，现在兑现。

关键在 ∼Mod(Σ)：它是所有满足 Σ 的模型共同认可的那些公式对——也就是「在共同语言里分不开的公式」。如果 Σ 已经把某个东西说死，那么在任何模型里，它的像不该随着模型乱跑。把这句翻成代数，就是某个自然同态必须满射。

定义 4.1（伴随同态）

设 F 是公式代数，∼Mod(Σ) 是理论同余，商 F/∼Mod(Σ) 是 L16 的概念代数。对模型 M，mngM 诱导出同态

hM : F/∼Mod(Σ) → mngM(F),    hM(φ/∼) = mngM(φ)。

由 ker(mngM) ⊇ ∼Mod(Σ)，这个同态良定义。它把「公式在理论下的类」送到「公式在这个模型里的值」。

命题 4.2（可定义的代数写法）

关系 R 在 Σ 中可定义，当且仅当对 Algm(Σ) 中每个模型，R 的外延落在伴随同态 hM 的像里——即 hM 对 R 那一部分是满射。

证明骨架。若 φ 显式定义 R，则 R = φM = hM(φ/∼) 在像里。反向：若每个模型里 R 的外延都在像里，取 φ/∼ 作其原像；Beth 定理保证这个原像与模型选择无关，于是 φ 全局定义 R。∎
「满射」为什么是这里的关键词

回想 L11：连续映射的核是「不可区分关系」，商映射把不可区分的点黏成一点。这里同理：hM 不满射，意味着模型的概念代数里有元素不是任何公式的值——语言里有「说不出」的东西。满射，意味着每个可见元素都有公式名字。所以「可定义 = 满射」不是比喻，是同一句话的两种写法。

来源：UAL §4.3.2–4.3.3；L16 Fact 3.3.20(ii)、Remark 3.3.4；L11 连续映射的核；L03 商代数。

5定理 4.3 系列：双向刻画 O3逻辑

定理 5.1（UAL 定理 4.3 系列，第三座桥）
R 在 Σ 中可定义 ⟺ 伴随同态 hM 满射（对 Algm(Σ) 中每个模型 M） ⟺ 模型在共同语言下 T0 可分。

这是本讲的高潮：语法（可定义）、代数（满射）、拓扑（可分）三者被钉成同一个命题。前两座桥是两端，这一座是三端。

两方向各用哪座桥
方向用的工具关键一步

满射 ⟹ 可定义Beth 定理（§3）+ 紧致性（L18）像点的原像给出公式，Beth 保证全局一致

和前两座的模板仍然一样：一边逻辑性质，一边代数性质，靠 L16 的翻译 + L04 的构造兑现。你已经见过第三遍了。

技术注解（可跳过）

上面在「一阶、有 Beth 性质」的熟悉情形写得干净。UAL 一般设定下，满射条件要对 Algm(L) 而不是 Alg⊨(L) 陈述——因为前者的元素是具体概念代数，保留了区分模型的信息（§8）。这一条正是本桥与前两座最不一样的地方。

6拓扑侧：不可区分、T0 与商空间 O4

从「核」到「不可区分关系」

L11 讲连续映射时说过：映射 f : X → Y 的核 ∼f（x ∼ y ⟺ f(x) = f(y)）是一个等价关系，把核相同的点黏起来得到商空间。这里把这个装置原样搬到模型上。

对模型类 K，定义不可区分关系：

M ≈ N  ⟺  对所有 𝓛-句子 σ，M ⊨ σ ⟺ N ⊨ σ。

也就是说：共同语言里的每句话，在 M 和 N 里真假一样——语言看不出它们有任何差别。这正是 L11 的核、L14 Stone 空间里「同一个点」的另一种说法。

命题 6.1（可分 = T0）

模型类 K 配 Spec 型拓扑后是 T0 的，当且仅当不可区分关系 ≈ 是恒等关系：M ≈ N ⟹ M = N。

L12 已经把 T0 讲透：不许有两个点对所有命题真值完全一致。现在读回来：语言能区分所有模型 ⟺ 语言能定义它们的差别 ⟺ 没有两个模型在共同语言里「长得一样」。

逻辑代数拓扑
隐含可定义hM 满射≈ 是恒等
有两个模型给 R 不同解释hM 不满射（像重合）存在 M ≈ N 但 M ≠ N
Beth 定理修好定义补上缺失的像点商掉不可区分关系，取 T0 化
商空间的泛性质：把分不开的点黏掉

L12/L03 的商构造在这里兑现。设 q : K → K/≈ 是商映射。泛性质说：任何从 K 出发、把 ≈-等价的点送到同一点的映射，都唯一地穿过 q。

翻成逻辑：任何「只依赖语言能看见的信息」的映射，都必须穿过商——因为 ≈-等价的模型在语言里本就无从分辨。K/≈ 就是语言的「可见世界」：把肉眼看不出差别的模型黏成一个点。T0 化 = 让语言把该分的都分开。

典型例子

命题逻辑的理论空间 2ω：两个指派若在每个公式上真值相同，它们就是同一个指派。≈ 是恒等，空间 T0（实际还是 Hausdorff、全不连通）。这就是语言把点分得最开的情形。

本质例子

取一个只有 ∀ 没有 = 的语言，或取 S5 模态语言：从任一世界出发能看到的都一样，于是所有世界 ≈-等价，商空间塌成一点。本质在于：不可区分不是模型的缺陷，是语言的分辨率问题——语言的分辨率越粗，商塌得越狠，能定义的东西越少。

边界与误解

① ≈ 是等价关系，不是偏序。「互相分不开」显然对称传递。别和 L12 的 Alexandroff 序 x ≤ y（知识包含）混——那个是预序，取它的反对称商才得到 T0。

② 「T0 可分」不等于「有公式区分」。T0 只保证拓扑开集能分开；要公式区分，还得开集是公式定义的（L18 §6 的 [φ]）。在 Stone 空间里两者恰好一致，因为开闭集基就是公式。换个空间就不一定。

来源：UAL §4.3.4；拓扑讲义 Ch4（T0、商空间泛性质）；L11 连续映射的核、L12 分离公理与 Alexandroff、L14 Stone 空间。

7应用：函数符号与群的例子 O5逻辑

例 7.1：群的单位元与逆元

在语言 {·} 里，群公理隐含定义了单位元 e：任何两个满足群公理、且各自指定了一个单位的模型，单位必须相同（e·e = e 且 e·x = x 唯一）。Beth 定理给出显式定义 e(x) : x·x = x。逆元同理可定义，但只依赖 ·——所以把 e、⁻¹ 当常元/函数符号放进语言是「冗余」的，它们能被定义。

代数读法：把 {·}-概念代数映到 {·, e, ⁻¹}-概念代数，这个同态是满射——因为 e, ⁻¹ 的外延都已在 {·} 的像里。

例 7.2：加法群里的零（局部 vs 全局）

在阿贝尔群语言 {+, 0} 里，0 由常元直接给出，当然可定义。若把 0 从语言里删掉，剩下的 {+} 仍隐含定义零（x + x = x）。但在某些模型里，一个元素可能只在局部被带参数的公式定义，换个模型就失效——这正是局部/全局、弱/强四个版本要分开的原因（§3）。

例 7.3：序的「极小元」不可全局定义

在偏序语言 {≤} 里，「极小元」不是全局可定义的：ℕ 有极小元 0，ℤ 没有极小元。不同模型对「有没有极小元」表态不同 → 语言没把它逼死 → 隐含可定义失败 → 自然也没有统一公式。代数侧：hM 在极小元那一部分不满射；拓扑侧：两个模型在 ≈ 下仍可分（因为 ≤ 本身可区分），但「极小元」这个概念不在语言的可见范围里。

使用说明书：判断可定义的三步
  1. 语法：试着写公式 φ 把外延逼死；写不出，先查隐含可定义（两个副本是否总一致）。
  2. 代数：看伴随同态 hM 在目标外延上是否满射。
  3. 拓扑：看两个候选模型能否被语言分开（≈ 是否恒等）。

三步结论总是一致——这就是桥的意思。

来源：UAL §4.3 应用例；群与偏序的标准可定义性事实；L16 概念代数。

8三座桥的差别与 Algm 为何不抽象类 O6

这一座为什么不一样

L18、L19 两座桥的代数侧都只用到 Alg⊨(L)——抽象类，对同构封闭，用类的封闭性质（超积、有限基）说话。L20 却改用 Algm(L)——具体代数类，不对同构封闭。L16 的 Remark 3.3.4 当时就预告：「尤其在可定义性理论里，Beth 性质正需要这一点」。现在说清为什么。

命题 8.1（为什么必须是具体代数）

可定义性问的是「这个模型里的这个外延能不能被公式说出」。同构副本虽然代数结构一样，但元素的身份变了。若把 Algm(L) 换成它的同构闭包，「哪个元素被定义」的信息就被抹掉了——而那正是问题本身。

Alg⊨(L)Algm(L)
成员抽象代数类型具体概念代数（模型给出的）
同构封闭是（按定义带 I）否（刻意）
用在哪座桥L18 紧致、L19 完全L20 可定义
关心的性质类的封闭性元素的身份、满射

一句话：类的性质看「形状」，可定义性看「身份」。形状可以对同构封闭，身份不行。

把这座桥记成一句话

「语言能定义」在代数里叫「同态满射」，在拓扑里叫「T0 分得开」，而把它们焊在一起的是「不可区分」这一个关系。

三座桥走完，你已经手里有三副词典：紧致、完全、可定义，各自在逻辑 / 代数 / 拓扑三侧的名字都能对上。下一讲 L21 走第四座桥——插值 ↔ 合并 / 超合并，那里会把 L18 用的紧致性、L19 用的有限证明、本讲用的可定义性同时请回来，是全书技术含量最高的一讲。
