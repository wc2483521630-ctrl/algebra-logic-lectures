2动机：可能的世界有没有几何 为什么先讲这个

Kripke 语义把「可能」画成点之间的箭头。拓扑语义把箭头抹掉，换成「哪些区域算得上是开放信息」。这不是换皮——它决定了你能问什么问题。

前面几讲我们一直在过桥：L18 把紧致性从逻辑译成超滤子，L19 把完全性译成代数，L20 把可定义性译成同态满射，L21 把插值译成合并，L22 把判定性译成有限基，L23 把布尔代数译成 Stone 空间，L24 把关系代数译成二元关系族。这一讲不一样：我们不再过桥，而是让拓扑直接当语义。

为什么值得这么做？看一个具体的差别。Kripke 框架里，「必然 p」意思是「p 在所有可及世界里真」——这是一条逐点的检查。拓扑里「必然 p」意思是「p 成立的区域包含一个开邻域」——这是一条整体的要求。后者多出来的东西叫稳定性：一旦你知道 p，你不仅此刻知道，还在一个邻域内都知道。知识要的是这个，不是「在别的可能世界里也真」。

一个能记住的画面

把 p 想成「今天下雨」这类可观察事实。□p 不是说「在所有平行宇宙里今天下雨」，而是说「有一个可验证的依据，使得在这个依据覆盖的整个区域内都下雨」。这个「依据」就是开集。◇p 则反过来说「现有信息排除不了 p」——这正是闭包 cl 的意思：把 p 能触及的边界都算进来。

这一讲的主线就一句：选什么空间类，就得到什么逻辑。所有空间都给 S4；预序（Alexandrov）空间刚好够给 S4 完全性；极端不连通空间给 S4.2，同时给强信念的 KD45。三个层次，三套空间，一条线。

3O1　拓扑语义：□ = int，◇ = cl O1

定义 拓扑模型与有效性

一个拓扑模型是三元组 M = ⟨X, τ, v⟩，其中 ⟨X, τ⟩ 是拓扑空间，v 给每个命题变元指定一个子集 v(p) ⊆ X。递归定义语义值（记 ⟦φ⟧）：

⟦p⟧ = v(p)　　⟦¬φ⟧ = X − ⟦φ⟧　　⟦φ ∧ ψ⟧ = ⟦φ⟧ ∩ ⟦ψ⟧
⟦□φ⟧ = int(⟦φ⟧)　　⟦◇φ⟧ = cl(⟦φ⟧) = X − int(X − ⟦φ⟧)

写 M, x ⊨ φ 当且仅当 x ∈ ⟦φ⟧；写 M ⊨ φ 当且仅当 ⟦φ⟧ = X；写 ⟨X, τ⟩ ⊨ φ 当且仅当对所有 v 都有 ⟨X, τ, v⟩ ⊨ φ。

注意：◊ 是 int 的对偶，不是独立原始算子

最后一行 ◇φ = ¬□¬φ 是把 ◇ 定义为 cl 的等式。在经典语义下 cl(A) = X − int(X − A)，所以两种写法完全重合。下面验证公理时只验 □，◇ 那侧由对偶自动得到。

命题 S4 的四条在任意拓扑空间成立
  1. （K） □(φ → ψ) → (□φ → □ψ)。翻译：int(−A ∪ B) ⊆ −int(A) ∪ int(B)。证明：取 x ∈ int(−A∪B)，若 x ∈ int(A)，则 int(A) 是含 x 的开集且包含于 A，于是它与 int(−A∪B) 的交是含 x 的开集，落在 B 里，故 x ∈ int(B)。
  2. （T） □φ → φ。翻译 int(A) ⊆ A——内部算子的定义，L10 第一条。
  3. （4） □φ → □□φ。翻译 int(A) ⊆ int(int(A))——幂等性，L10 第四条。
  4. （N） □⊤ = ⊤。翻译 int(X) = X。

再由 MP 与代入保持有效性，得 S4 的拓扑可靠性：S4 定理在所有拓扑空间有效。∎

口径：为什么 UAL 把 ◇ 当原始算子

L06 §7 与 L10 §7 都提醒过这件事，这里给完整理由。UAL 定义 2.8.6 的 BAO 要求算子对 ∨ 分配且把 0 送到 0（正规性）。拓扑里：

cl(A ∪ B) = cl(A) ∪ cl(B),　cl(∅) = ∅　　✓ 符合 UAL 的 (Dst) + (Nrm)
int(A ∩ B) = int(A) ∩ int(B),　int(X) = X　　✓ 但对 ∨ 只有 ⊆，不分配

所以把 ◇ = cl 当 UAL 的原始正规 BAO 算子最省事，□ = int 由补对偶 □A = −◇−A 得到，它满足的是「对 ∧ 分配、保顶」的对偶版公理。两种写法不矛盾——只是同一件事从 ∨ 侧还是 ∧ 侧说。若你直接说「BAO 分配 ∨」就忘了补这一句，会和拓扑内部的日常定义打架。

S5 在这里为什么难看

UAL 例 3.2.5 把 S5 写成 ◇φ 意为「存在某个世界使 φ 真」——这是把等价关系压平后的写法。在拓扑这边，要让 □ 满足 S5 的 ◇□p → □p（即 cl(int A) ⊆ A），对 A 开时就是 cl(A) ⊆ A，即每个开集都闭。空间必须极端不连通且开闭集稠密——离散空间可以，一般的拓扑空间不行。所以「模态 = 内部」只对 S4 这一族自然，别当成普遍真理。

4O2　S4 拓扑完备性：McKinsey–Tarski 完整证明 O2

L10 说「McKinsey–Tarski：S4 相对拓扑空间类完备，证明留给 L25」。现在兑现。路线分三段：先把预序框架看成一种拓扑，再搬来 S4 的典范模型，最后证明两种语义在 Alexandrov 空间上重合。

4.1Alexandrov 引理：预序就是拓扑

定义 Alexandrov 拓扑

给定预序 ⟨W, ≤⟩（自反且传递），令

U ⊆ W 是开集　⟺　∀x ∈ U ∀y ∈ W (x ≤ y ⟹ y ∈ U)

即开集 = 上集。易验任意并、有限交仍是上集，∅, W 是上集，所以这是拓扑，记作 τ≤，称为 Alexandrov 拓扑。

引理 4.1（转轴）

在 ⟨W, τ≤⟩ 中，对任意 A ⊆ W：

int(A) = { x ∈ W : ∀y (x ≤ y ⟹ y ∈ A) } =: □≤(A)

右边的 □≤ 正是预序框架上的 Kripke 必然算子。这就把 Kripke 语义装进了拓扑语义。

证明。

（⊆）设 x ∈ int(A)。取任意 y ≥ x。含 x 的最小上集是 ↑x = {z : x ≤ z}，它开且含 x，故 ↑x ⊆ A（内部是最大开子集），于是 y ∈ A。

（⊇）设对所有 y ≥ x 有 y ∈ A，即 ↑x ⊆ A。而 ↑x 是含 x 的开集，故 x ∈ int(A)。∎

别把引理用到所有拓扑空间上

引理 4.1 只对 Alexandrov 拓扑成立。一般拓扑空间的 int 不等于它在特殊化预序上的 Kripke □——例如 ℝ 的特殊化预序是恒等（T1），Kripke □ 会变成恒等算子，而实际的 int 不是。Alexandrov 恰好是「开集任意并仍开」这一条加强带来的：一般拓扑只对有限并封闭。

4.2S4 典范模型：把「证不出」变成「有一个点反例」

定义 S4 典范模型

令 Wc = 全体 S4-极大一致公式集（L19 Henkin 构造里已经用过这个概念）。定义

Γ ≤c Δ　⟺　{ φ : □φ ∈ Γ } ⊆ Δ

赋值 vc(p) = {Γ ∈ Wc : p ∈ Γ}，得模型 Mc = ⟨Wc, ≤c, vc⟩。

引理 4.2 ≤c 是预序
自反。

若 □φ ∈ Γ，由 T 公理 □φ → φ 与极大一致集对 MP 封闭，得 φ ∈ Γ。故 Γ ≤c Γ。

传递。设 Γ ≤c Δ 且 Δ ≤c Θ，要证 Γ ≤c Θ。取 □φ ∈ Γ。由 4 公理 □φ → □□φ 得 □□φ ∈ Γ，由 Γ ≤c Δ 的定义（把其中的 φ 取为 □φ）得 □φ ∈ Δ，再由 Δ ≤c Θ 得 φ ∈ Θ。故 Γ ≤c Θ。∎

引理 4.3（真值引理） Mc, Γ ⊨ φ ⟺ φ ∈ Γ

对公式结构归纳。命题变元、布尔连接词由 vc 定义与极大一致集的布尔封闭性直接得到。关键是 □ 那一步，分两个方向。

（⇐）设 □φ ∈ Γ。

取任意 Δ 使 Γ ≤c Δ。由定义得 φ ∈ Δ，由归纳假设 Mc, Δ ⊨ φ。故 Mc, Γ ⊨ □φ。

（⇒）设 □φ ∉ Γ。要找一个 Δ ≥c Γ 使 φ ∉ Δ。令

Γ− = { ψ : □ψ ∈ Γ }

则 φ ∉ Γ−。断言 Γ− ∪ {¬φ} 一致：反证，若它不一致，由演绎定理有 Γ− ⊢ φ，取有限个 ψ₁,…,ψn ∈ Γ− 使 ⊢ (ψ₁ ∧ … ∧ ψn) → φ。由必然化规则与 K 公理得 ⊢ □(ψ₁ ∧ … ∧ ψn) → □φ；又每个 □ψᵢ ∈ Γ，而 □ 对 ∧ 分配（K 与 4 可导出），故 □(ψ₁ ∧ … ∧ ψn) ∈ Γ，由 MP 得 □φ ∈ Γ，矛盾。

由 Lindenbaum 引理把 Γ− ∪ {¬φ} 扩成极大一致集 Δ。此时 Γ ≤c Δ（定义），且 ¬φ ∈ Δ 故 φ ∉ Δ。由归纳假设 Mc, Δ ⊭ φ，于是 Mc, Γ ⊭ □φ。∎

推论 S4 Kripke 完全性

若 ⊬S4 φ，则 {¬φ} 一致，扩成极大一致集 Γ。由真值引理 Mc, Γ ⊨ ¬φ，故 φ 不是 Kripke 有效的。∎

4.3合龙：拓扑完备性

定理 4.4（McKinsey–Tarski）

⊢S4 φ 当且仅当 φ 在所有拓扑空间的 int 语义下有效。

（⇒）

§3 已证的可靠性。

（⇐）设 ⊬S4 φ。取典范模型 Mc = ⟨Wc, ≤c, vc⟩ 与 Γ ∈ Wc 使 Mc, Γ ⊭ φ（推论 4.3）。在 Wc 上赋 Alexandrov 拓扑 τ≤c。由引理 4.1，对任意公式 ψ：

⟦□ψ⟧top = int(⟦ψ⟧top) = { Γ : ∀Δ ≥c Γ, Mc, Δ ⊨ ψ } = ⟦□ψ⟧Kripke

布尔情形显然，故对所有公式 ψ，拓扑语义值与 Kripke 语义值逐点相同。于是 Mc, Γ ⊭top φ，φ 非拓扑有效。逆否得证。∎

这一步到底用掉了什么

注意完全性方向只用到 Alexandrov 空间——一类很特殊的拓扑（任意并封闭）。所以 S4 的拓扑完全性其实是「Kripke 完全性 + 预序可以伪装成拓扑」两件事的合体。拓扑语义并没有比 Kripke 语义多给出 S4 的新定理，它多给的是提问的方式：下面问「哪类空间的逻辑是什么」时，Kripke 那边没有现成对应词。

5O3　S4.2：有向性 ⟺ 极端不连通 O3

L14 §8 已经证过「在拓扑语义下 .2 ⟺ 极端不连通」，并把「框架对应与完全性证明」明确推给本讲。现在补上框架侧，并把两边焊起来。

定义 Geach 公理 .2 与有向性
.2：　◇□p → □◇p　　（等价写法：◇□p → □◇□p）

框架 ⟨W, R⟩ 有向（也叫汇合），若

∀x ∀y ∀z ( xRy ∧ xRz ⟹ ∃w ( yRw ∧ zRw ) )

读法：从同一点看出去的两条路，最终能在某个世界汇合。这比「完全」弱——只要求有共同后继，不要求那个后继在所有路上唯一。

命题 5.1（框架对应，双向）
（有向 ⟹ .2 有效）

设 M, x ⊨ ◇□p，取 y 使 xRy 且 M, y ⊨ □p。要证 M, x ⊨ □◇p，即任取 xRz 证 M, z ⊨ ◇p。由有向性取 w 使 yRw 且 zRw；由 y ⊨ □p 得 w ⊨ p；由 zRw 得 z ⊨ ◇p。∎

（.2 有效 ⟹ 有向）反证。设 xRy、xRz 但 y, z 无共同后继。造模型：令 V(p) = { w : yRw }。则 y ⊨ □p（定义），所以 x ⊨ ◇□p；而对任意 zRw，w ∉ V(p)（否则 w 是共同后继），所以 z ⊭ ◇p，进而 x ⊭ □◇p。这与 .2 有效矛盾。∎

5.1把有向性翻译成空间

命题 5.2（有向预序 ⟺ 极端不连通，在 Alexandrov 空间上）

设 ⟨W, ≤⟩ 是预序，τ≤ 是开集 = 上集的 Alexandrov 拓扑。则

≤ 有向　⟺　⟨W, τ≤⟩ 极端不连通（每个开集的闭包仍开）
先算闭包。

在 τ≤ 中，cl(A) = ↓A = { x : ∃a ∈ A, x ≤ a }：因为含 x 的最小开集是 ↑x，而 x ∈ cl(A) ⟺ ↑x ∩ A ≠ ∅ ⟺ ∃a ∈ A (x ≤ a)。

（有向 ⟹ 极端不连通）取开集 U（上集），要证 ↓U 是上集。设 x ∈ ↓U、x ≤ x′，取 u ∈ U 使 x ≤ u。对 x 的两个上界 u 与 x′ 用有向性，得 w ≥ u 且 w ≥ x′。因 U 是上集且 u ∈ U，有 w ∈ U，于是 x′ ∈ ↓U。∎

（极端不连通 ⟹ 有向）设 x ≤ y、x ≤ z。取开集 U = ↑y。因 y ∈ ↑x ∩ ↑y，得 x ∈ cl(↑y)。由极端不连通，cl(↑y) 是开集（上集），又 x ≤ z，故 z ∈ cl(↑y)。按上面闭包公式，存在 w ∈ ↑y 使 z ≤ w，即 y ≤ w 且 z ≤ w——共同上界。∎

推 S4.2 的定理命题 5.1 双向命题 5.2 双向 + L14 §8 的拓扑证明

推论：S4.2 对极端不连通空间类完备。方向一：每个极端不连通 Alexandrov 空间的有向预序验证 .2，故 S4.2 可靠。方向二：若 ⊬S4.2 φ，取 S4.2 典范模型，其预序自反、传递、且由 .2 有效得有向（命题 5.1），赋 Alexandrov 拓扑后极端不连通（命题 5.2），由定理 4.4 的同型论证得拓扑反例。∎

一个必须钉死的边界

「极端不连通」在一般拓扑空间里不等于有向——因为一般空间的 int 不是任何预序上的 Kripke □（§4.1 的警告）。L14 §8 证明的是「.2 在拓扑语义下 ⟺ 极端不连通」，那是算子等式层面的对应，不需要 Alexandrov。本讲命题 5.2 是框架与空间之间的对应，只在 Alexandrov 里成立。两个结论都真，但说的不是同一件事，别混用。

来源：L14 §8（.2 ⟺ 极端不连通的拓扑证明、明确留给 L25 的框架对应）、UAL §2.8、拓扑讲义定义 6.3.7、例 6.3.10。

6O4　信念逻辑：B = ◇□ 与 KD45 O4

讲义 Ch7 只说了一句「极端不连通空间曾被用于完全信念逻辑」。这一句背后是 Stalnaker 的想法：信念就是「知识的认识可能性」——我相信 p，当且仅当 p 与我所知道的一切相容。把它写成算子，就是 B = ◇K。

6.1知识与信念：差一条 T，多两条自反思

S4（知识）与 KD45（信念）逐条对照
公理公式知识（S4）信念（KD45）
K□(p→q) → (□p → □q)✓✓（对 B 同样成立）
T / D□p → p　/　¬B⊥T：知道的一定真D：相信的不必真，但要一致
4□p → □□p✓ 正内省✓ Bp → BBp
5◇p → □◇p✗（S4 里不成立）✓ ¬Bp → B¬Bp 负内省

直觉差别：知识有 T（真理性），信念没有——我相信的事可以是假的；但信念比知识多一条 5（负内省）——我知道我不知道什么，我不知道我不相信什么。信念逻辑里，「一致」取代了「真」的位置。

6.2强信念的拓扑定义

定义 强信念（Stalnaker；文献）

在拓扑模型 M = ⟨X, τ, v⟩ 上，同时解释知识 K = int 与信念 B：

⟦Kφ⟧ = int(⟦φ⟧)　　⟦Bφ⟧ = cl(int(⟦φ⟧)) = ◇Kφ

第二个等式就是「信念 = 知识的认识可能性」：某件事与我的知识相容，当且仅当它触及了我已知区域的边界。这正是 L14 §8 翻译词典最后一行 cl(int(U)) 的严格化。

命题 6.1（在极端不连通空间上，B 满足 KD45）

先记一个由极端不连通性立刻得到的事实：对任意 A，C = cl(int A) 既开又闭——闭是闭包的定义，开是定义 6.3.7 用于开集 int A。因此 B 把任意集合送到开闭集。下面四条逐步验。

（D） B⊥ = ∅。

B(∅) = cl(int ∅) = cl(∅) = ∅。这条在任意空间成立。

（4） Bp → BBp。令 C = cl(int A)，已知 C 开闭。于是 int(C) = C 且 cl(C) = C，故 B(C) = cl(int C) = cl(C) = C。即 B 在极端不连通空间上幂等，B(B(A)) = B(A)，比 4 要求的还强。

（5） ¬Bp → B¬Bp。仍令 C = B(A) 开闭，则 −C 也开闭，故 B(−C) = cl(int(−C)) = cl(−C) = −C。即 B(¬B(A)) = ¬B(A)，负内省等式成立。

（K） B(A→B) ∩ B(A) ⊆ B(B)。记 D = cl(int(−A ∪ B))，由极端不连通 D 开。用一个拓扑小事实：若 O 开，则 O ∩ cl(X) ⊆ cl(O ∩ X)（取 y ∈ O ∩ cl(X)，O 是 y 的开邻域，故 O ∩ X ≠ ∅，即 y ∈ cl(O ∩ X)）。于是

D ∩ cl(int A) ⊆ cl( D ∩ int A )　（取 O = D, X = int A）
D ∩ int A ⊆ cl( int(−A∪B) ∩ int A ) = cl( int(A∩B) ) ⊆ cl(int B)

第二行用了「开集 D ⊇ int(−A∪B)」与 int(−A∪B) ∩ int A = int(A∩B)。两行串起来得 D ∩ B(A) ⊆ B(B)，即 K。

MP 与代入保持有效，故 KD45 在极端不连通空间上可靠。∎

定理 6.2（文献，非本教材）

KD45 关于极端不连通空间类在上述 B = cl ∘ int 语义下可靠且完全；更强地，把知识 K = int 与信念 B = cl ∘ int 放在一起，Stalnaker 的 KB 系统刻画极端不连通空间上的知识与信念，其知识片段恰是 S4.2、信念片段恰是 KD45。

出处：A. Baltag, N. Bezhanishvili, A. Özgün, S. Smets, The Topological Theory of Belief（ILLC 预印本 PP-2015-18，2015；正式版 J. Philosophical Logic 48(2), 2019）。这三本教材只给了「极端不连通 ↔ 完全信念逻辑」这一句方向性提示，定理号与完全性证明请查该文。

为什么 S4.2 与 KD45 会在同一类空间里碰头

因为它们用的是同一个空间条件，但检查的是不同的算子。S4.2 检查 K = int：它要 cl(int A) ⊆ int(cl A)，即 cl(int A) 开。KD45 检查 B = cl ∘ int：它同样要 cl(int A) 开闭（命题 6.1 全靠这一条）。「开集的闭包仍开」这一个空间性质，在知识这边读成 .2，在信念那边读成 4+5+一致性。这就是讲义 Ch7 那句话的全部内容。

6.3另一条路：导集语义及其麻烦

L14 表的另一行：τ = X − d(X − A)

L14 §8 还列了用导集 d 定义信念候补 τ(A) = X − d(X−A) 的读法，并指出在 T1 空间里有 τ(X−{x}) = X——每个主体都相信「实际世界并非如此」。这与 B = cl ∘ int 不同：后者在离散空间给 B(A) = A（信念退化为知识），前者却逼出反常识的结论。

Baltag 等人的工作比较了两条路，结论是 cl ∘ int 给出了 Stalnaker 强信念最一般的外延语义，导集语义在分离性较强时会退化。这也印证了 L14 那条译注：「修条件不等于修结论」。

6.4再往前一步：动态更新为什么要「遗传」

动态信念会破坏极端不连通（文献）

把「学到 φ」读成限制到子空间 [[φ]]（L13 的 Stone/紧致化视角下这是自然的），问题来了：极端不连通空间的子空间未必极端不连通。于是更新后的模型可能掉出语义类。

补救办法是改用遗传极端不连通空间：所有子空间都极端不连通。文献中证明：在此语义下 KD45 仍完全，而知识侧要升到 S4.3（线性预序），条件信念与更新算子也有完整公理化。

出处：同定理 6.2 的文献；超出本教材范围，这里只作为 L26 与动态逻辑的接口提示。

本讲来源：拓扑讲义 Ch7（「完全信念逻辑」方向）、Ch6 §6.3（定义 6.3.7、命题 6.3.8/6.3.9）；L14 §8。KD45/KB 的完全性为文献结果，已单独标注。

7O5　模态代数 ↔ 拓扑空间；学习理论的方向 O5

7.1代数侧：BAO 与 Jónsson–Tarski

三行对应（UAL §2.8）
逻辑代数拓扑
S4 的定理集S4-代数 = 满足 □x ≤ x、□x ≤ □□x 的正规 BAO任意空间的 ⟨𝓟(X), cl⟩
S4.2 的定理集再加 ◇□x ≤ □◇x极端不连通空间的 ⟨𝓟(X), cl⟩
KD45 的信念片段满足 D/4/5 等式的 BAO极端不连通空间上的 B = cl ∘ int
回指 L06：JT 定理 2.8.9 / 2.8.15

L06 §8 讲过：任何 BAO 都能嵌入一个完全原子的 BAO A+。本讲的拓扑完备性（定理 4.4）就是它的拓扑版本：

抽象 S4-代数 A　──JT──▶　完全原子 BAO A+　──原子当点──▶　Kripke 框架　──Alexandrov──▶　拓扑空间

「非定理必有反模型」= 「代数里不等于顶元的元素，在某个空间的开闭/幂集代数里能被区分开」。L06 说这是「把完备性问题变成嵌入问题」，本讲补上了最后一步：嵌入的目标可以取成拓扑空间。

与 L23 Stone 对偶的接口（预告 L26）

L23 把布尔代数对偶到 Stone 空间。BAO 多了一个算子，对偶空间就要多带一点结构：模态算子的关系对应、内部算子的特殊化序。Priestley 对偶给有序空间，Esakia 对偶给 Heyting 代数——L23 已标为预告，L26 会把这条对偶谱系补完。

7.2学习理论：教材给的是方向，不是定理

先把话说清楚

讲义 Ch7 关于学习理论只有一句展望：「拓扑语义与学习理论的许多联系，也不断为机器学习时代人工智能中的逻辑作用提供启发。」它没有给出任何定理或定义。下面给的是解释性联系，帮助你把本课程的工具用过去，不是教材结论。

能接得上的地方有两个。第一，□A = int(A) 就是「稳定可验证」：一个性质算得上被知道，要求它在某个开区域内一直成立——这正是学习理论里「猜想稳定下来」的形状。第二，◇A = cl(A) 就是「与全部已见数据相容」：闭包把极限点收进来，而极限点恰是数据序列可能收敛到的地方。

把 L13 的紧致化也请进来：βX 的额外点是「理想极限」。学习一个概念，往往就是在X 上给不出有限依据、只在 βX 里才收敛的情形。本讲能提供的只是这本词典；具体学习模型的形式化，不在这三本教材里。

来源：UAL 定义 2.8.6、定理 2.8.9/2.8.15；L06 §8；拓扑讲义 Ch7 末段（学习理论展望）。

8O6　三层例：典型 / 本质 / 边界 O6

典型例子 ℝ 与离散空间：S4 成立，.2 失败

取 A = (0,1) ⊆ ℝ：int(A) = A，cl(A) = [0,1]，于是

◇□A = cl(int A) = [0,1]　⊄　(0,1) = int(cl A) = □◇A

.2 失败，所以 ℝ 是 S4 模型而非 S4.2 模型。这也说明 ℝ 不极端不连通——cl((0,1)) = [0,1] 不开。离散空间是另一极端：int = cl = 恒等，S4/S4.2/S5 全部退化成立，B(A) = A——信念与知识合一，什么新信息都没有。

本质例子 βℕ：同时是 S4.2 与 KD45 的空间

L14 命题 6.3.9 证过 βX（X 离散）极端不连通，L14 例 6.2.9 证过它是 Stone 空间。两条叠起来：

βℕ = Ult(𝓟(ℕ))　　cl(int A) 开闭　　K = int 给 S4.2，B = cl∘int 给 KD45

这是本讲最重要的具体对象：它把 L06 的超滤子、L13 的紧致化、L14 的极端不连通、L23 的 Stone 对偶、本讲的信念语义全接在同一批点上。βℕ − ℕ 里的非主超滤子，正是「与所有有限信息相容、却不由任何自然数给出」的理想信念状态。

边界与误解 分离性一松，词就失去直觉

① 余有限拓扑（无限集 X）：每个非空开集闭包是 X，所以它极端不连通且连通（L14 例 6.3.10）——两个听上去相反的性质同时成立。原因是它非 Hausdorff。任何「极端 ⟹ 全不连通」的推论都要检查分离性。

② 有限空间：有限 Hausdorff 且极端不连通 ⟹ 离散。所以想看真正的 S4.2/KD45 语义，必须去无限空间；有限模型里 .2 与 S5 常常重合，会把差别抹平。

③ □ 作用在 𝓟(X) 上，不是只作用在 τ 上。若把公式只解释成开集，int 就是恒等，S4 结构整个消失。这是 L10 §7 已记过的坑。

来源：L14 例 6.2.9、命题 6.3.8/6.3.9、例 6.3.10；拓扑讲义定义 6.3.7；文献定理 6.2。
