2动机：为什么要给关系装上运算

从你已经会的三样东西走过来

命题逻辑的语义是「真值」，代数化后得到布尔代数；模态逻辑加上「必然」，代数化后得到带算子的布尔代数（L06 的 BAO）；现在轮到关系：把「有序对的集合」当作真值，逻辑里的连接词就变成关系运算。这条递进线是同一台机器换了输入：

真值 → 布尔代数 可能世界集合 → BAO（□ = 内部 / 闭包） 有序对集合 → 关系代数（◦ = 复合、⁻¹ = 逆、Id = 恒等）

为什么偏偏要研究二元关系？因为它同时出现在三个地方：关系数据库里一张表就是二元关系，查询就是复合与选择；程序语义里程序是「输入—输出」关系，顺序执行就是复合；模态与动态逻辑里可达关系是 Kripke 框架的骨架。Tarski 在 1940 年代做了一件大胆的事：不问「这些关系有什么性质」，而问「把关系当成数，能列出一套代数公理吗」。一旦列出来，就可以用泛代数的全部机器研究它——这正是本课程从 L01 到 L22 一直在练的手艺。

但这里埋着一个陷阱。公理是人写的等式，关系是具体存在的东西。人写的公理可能太宽：允许一些「满足公理、却根本不是任何关系族」的怪代数混进来。于是本讲的悬念是：

满足 Tarski 公理（RA）　=？　真的能由二元关系实现（RRA）

答案是不等于。而且这个「不等于」会一路传导到逻辑那一边，让箭头逻辑丢掉插值、Beth 和有限 Hilbert 系统。这就是本讲值得花两学时的理由：它是前面五座桥的第一批「结算单」。

3从零开始：二元关系的六个运算 O1

定义 二元关系

集合 U 上的二元关系是笛卡儿积 U × U 的子集。比如 U = {1,2,3}，那么「小于」关系是 {(1,2), (1,3), (2,3)}，「等于」关系是 {(1,1),(2,2),(3,3)}。关键：关系就是有序对的集合，没有别的神秘东西。

把 U 固定住，令 V = U × U（九个有序对）。下面六个运算都在这九个有序对上做。先固定两个关系作全程例子：

R = {(1,2), (2,3)}　　S = {(2,1), (3,2)}
六个运算 前四个是布尔运算，后两个是关系特有的
运算定义在本例中的结果
并 R ∪ S属于 R 或属于 S{(1,2),(2,3),(2,1),(3,2)}
交 R ∩ S两者都属于∅（这是导出运算：R∩S = −(−R ∪ −S)）
补 −RV − R，其余七个有序对九个有序对里去掉 (1,2),(2,3)
顶 V全体有序对 U × U九个有序对
复合 R ◦ S{(u,w) : ∃v, (u,v)∈R 且 (v,w)∈S}{(1,1),(2,2)}（见下面逐步算）
逆 R⁻¹{(v,u) : (u,v)∈R}{(2,1),(3,2)} = S
复合手算：为什么 R◦S = {(1,1),(2,2)}

复合的定义是「先走 R 再走 S，中间接点相同」。逐个检查：

  • 从 1 出发：R 只能到 2；S 从 2 能到 1。所以 (1,1) ∈ R◦S。
  • 从 2 出发：R 只能到 3；S 从 3 能到 2。所以 (2,2) ∈ R◦S。
  • 从 3 出发：R 哪儿也去不了，所以没有以 3 开头的复合对。

再看反方向：S◦R = {(2,3),(3,3)}（请自己按同样方法验一遍）。复合不交换！这是关系代数与布尔代数最不一样的地方，也是它难算的根源。

两个值得现在就记住的小事实

① 逆会把复合的顺序反过来：(R◦S)⁻¹ = S⁻¹◦R⁻¹。直观上，把一条「先 R 后 S」的路径倒着走，当然变成「先 S 的逆，后 R 的逆」。

② 复合对并分配：(R ∪ S)◦T = (R◦T) ∪ (S◦T)。因为「先走 R 或 S，再走 T」就是两种走法的并。这两条正是 L06 说关系代数是「正规 BAO」的原因。

一个最容易踩的坑：补是相对的

−R 永远是相对于顶元 V 的补，不是相对于整个 U × U（虽然本例里两者恰好相同）。下一节会看到，UAL 的具体关系代数允许 V 是 U × U 的某个子集——此时 −R = V − R，补的世界变小了。这个细节正是后面区分 BRA 与 RRA 的关键。

4具体关系代数 cBRA 与 BRA O1

定义 UAL 7.1.1 / 7.1.2

一个具体二元关系代数（cBRA）是形如

A = ⟨A, ∪, −, V, ◦, ⁻¹⟩

的代数，其中 A 是一族二元关系，V 是其中最大的那个（叫单位），五个运算分别是并、相对 V 的补、单位、复合、逆；而且 A 对这些运算封闭。「具体」的意思是：元素真的就是有序对集合。

一个二元关系代数（BRA）是某个 cBRA 的同构像，即 BRA = I cBRA（UAL 定义 7.1.2）。

这个定义其实由两块拼成

把 cBRA 拆开看，它同时是两样你已经很熟的东西：

⟨A, ∪, −, V⟩　是布尔代数（BA） ⟨A, ◦, ⁻¹⟩　　是对合半群（结合、有逆、逆逆归原） 两者共用同一个载体 A，并合成正规 BAO

这正是 L06 定理 6.5 那套「判别式簇 / BAO」的语言。UAL 在定义 7.1.2 后特意点出这一点：关系代数并不陌生，它就是「布尔代数 + 对合半群」焊在一起。你先前学的每一件 BAO 工具，在这里都能直接用。

定理 UAL 7.1.4 / 7.1.8 / 7.1.9
  1. 7.1.4：BRA 是等式类，即存在一族等式 E 使 BRA = Mod(E)。
  2. 7.1.8：BRA 不可有限公理化——没有有限多条等式能描出它。
  3. 7.1.9：Eq(BRA) 是递归可枚举但不可判定的。

证明路线用到了 L04 的子直表示、L07 的判别式簇：先证 BRA = SP Sir(BRA)，再证子直既约成员构成一个伪公理化类并有判别式项，最后得到等式类。第 7 讲学的 Jónsson 式技术，在这里第一次真正兑现。

UAL 自己的评价

教材在 §7.1 里写了一句很值得记住的话：只用 BRA 就能说明代数逻辑的大部分主要结果、思想与问题。换句话说，这一讲不是边角料——它是整个领域的浓缩样本。后面 L27 的案例「箭头逻辑」会把它接回逻辑主线。

5术语迷宫与 Tarski 公理 O2

先解决一个真正的麻烦：五个名字长得太像

UAL 这本书把关系代数分成五层，别的教材往往只讲其中两层。若不等读清楚，很容易以为自己在读同一件事。下面这张表是本讲的地图，建议你先记住它再往下走。

对照 五层术语（本讲地图）
名字全称怎么得到语言一句话
cBRA具体二元关系代数直接拿一族有序对集合∪,−,V,◦,⁻¹元素真的是关系
BRA二元关系代数I cBRA（同构像）同上换了个名字的具体物
ARABRA 的抽象逼近公理 (1)–(4)同上按规律写公理，不管是不是真关系
RA关系代数（Tarski）公理 (1)–(3) + (5) + (6)多一个 Id标准抽象公理类

读法：常见教材说「RA 是抽象的、RRA 是可表示的」，UAL 在这两层前面又加了三层（cBRA、BRA、ARA）来把「具体到抽象」的过程拆细。牢记一个包含链：RRA ⊆ BRA，而 RA ⊋ RRA。最后那个真包含是本讲的高潮。

定义 UAL 7.1.3：ARA 的四组公理（逐条讲人话）

(1) 布尔公理：交换、结合、x ∪ 1 = 1，加上一条缩写的补元律。作用只是保证 ⟨A,∪,−,1⟩ 是布尔代数——你已在 L01 见过。

(2) 对合半群公理：

(x ◦ y) ◦ z = x ◦ (y ◦ z)　　(x ◦ y)⁻¹ = y⁻¹ ◦ x⁻¹　　x⁻¹⁻¹ = x

三条分别说：复合可结合（走三段路不用管括号）、逆会反序（§3 的小事实①）、逆两次回到原样。§3 已经用手算验证过后两条。

(3) 正规 BAO 公理：

(x ∪ y) ◦ z = (x ◦ z) ∪ (y ◦ z)　　(x ∪ y)⁻¹ = x⁻¹ ∪ y⁻¹　　0 ◦ x = 0,　0⁻¹ = 0

两条分配 + 两条保底元。第一条是 §3 的小事实②；0 ◦ x = 0 说「空关系开头，走不出任何路」。

(4) 连接两半的桥：−(x⁻¹) = (−x)⁻¹（补与逆交换），以及 x ≤ 1 ◦ x、−(1 ◦ x) = 1 ◦ −(1 ◦ x)（说 x ↦ 1◦x 是补闭包算子，L02 的老朋友）。

关键：ARA 没有 Id，也没有三角形规则。它只抓住了「关系代数大概长什么样」，还留着口子。

定义 UAL 7.1.13：RA 在 ARA 上再加两条
(5)　x⁻¹ ◦ [−(x ◦ y)] ≤ −y (6)　Id ◦ x = x

(6) 好懂：Id 是复合的单位元。Id = {(u,u) : u ∈ U}，恒等关系接在任何关系前面都不改变它。UAL 特意指出这条在逻辑里对应 Leibniz 律：相等的东西不可区分。

(5) 是 Tarski 最有名的那条，下面单独拆。

验证公理 (5)：在具体关系里它为什么成立

要证 R⁻¹ ◦ (−(R◦S)) ⊆ −S。取左边任意一个有序对 (u,w)，按复合定义，存在某个 v 使

(u,v) ∈ R⁻¹　即　(v,u) ∈ R,　　且　　(v,w) ∉ R ◦ S.

现在反证 (u,w) ∈ S。那么 (v,u) ∈ R 且 (u,w) ∈ S，按复合定义就有 (v,w) ∈ R◦S——与上面第二条直接矛盾。所以 (u,w) ∉ S，即它在 −S 里。∎

这条公理的全部内容就是这个反证：「R 走一步到不了 S 的终点」这件事，与 R⁻¹ 和 S 的补相容。

公理 (5) 的另一种说法：三角形规则

UAL 指出 (5) 等价于下面这条更对称的 (5′) 三角形规则：

x ∩ (y ◦ z) = 0　当且仅当　y ∩ (x ◦ z⁻¹) = 0　当且仅当　z ∩ (y⁻¹ ◦ x) = 0.

把 x, y, z 想成三角形的三条边：y 是第一条边，z 是第二条，x 是合成后的第三条。x ∩ (y◦z) = 0 说「x 这条边不是由 y 接 z 走出来的」，也就是这个三角形不存在。另外两行只是把三条边换了个位置重新说一遍。三种说法等价，正是公理 (5) 的功劳。

一个常见的记号转换表

别的书里同一个东西常写成另一套符号，看到别慌：

UAL 的 ∪ 　= 常见教材的 ∨ 或 + UAL 的 ◦ 　= 常见教材的 ; UAL 的 ⁻¹ 　= 常见教材的 ⌣ 或 ˘ UAL 的 V / Id = 常见教材的 1 / 1′

6表示问题与 RRA O3

现在到了关键分岔。前面造的 RA 是按公理定义的类：只要满足等式就算成员。但我们还想要一个更严格的要求——它真的能由二元关系实现吗？这就是「表示」问题。

定义 setRRA 与 RRA（UAL §5.2、§7.1）
  • 集合关系代数 setRRA：形如 ⟨𝓟(U×U), ∪, −, V, ◦, ⁻¹, Id⟩ 的代数及其子代数，其中 V = U×U（方形单位），Id = {(u,u) : u∈U}。
  • 表示关系代数 RRA = SP setRRA：集合关系代数的子代数之积。等价地，A ∈ RRA 当且仅当存在集合 U 与单同态
    h : A → ⟨𝓟(U×U), ∪, −, ◦, ⁻¹, Id⟩
    保全部运算——也就是给 A 的每个元素找到一批真正的有序对，并且复合、逆、恒等都按真的关系运算对上。

「可表示」的意思非常朴素：这个抽象代数可以被实现成一个关系族。若做不到，它就是「假关系」——满足公理却不是任何真正的二元关系系统。

定理 UAL 7.1.10（RRA 的基本性质）

RRA 是不可有限公理化的判别式簇，其等式理论递归可枚举但不可判定。

这几条与 BRA 的 7.1.4 / 7.1.8 / 7.1.9 完全平行，证明也是照搬。请把它与 L22 对照：「不可有限公理化 ⇒ 没有有限完全且强可靠的 Hilbert 系统」，「r.e. + 不可判定 ⇒ 逻辑那边的有效式集算不出来」。

定理 UAL 7.1.11（Id 是唯一的额外门槛）

记 E₀ 为一组有限等式（逆与复合的交互、三角形规则、一条分配式）。则

Eq(BSR) ∪ E₀　　　　　　公理化 BRA Eq(BSR) ∪ E₀ ∪ {Id ◦ x = x}　　公理化 RRA.

这条定理信息量很大：从 BRA 走到 RRA，只需要补一条 Id◦x=x。教材的解读是——RRA 不可有限公理化的「全部罪魁」是复合运算 ◦；逆和恒等借助复合都可以有限地公理化。

回到 §3 的提醒：BRA 允许 V 是 U×U 的任意子集（相对化），而 Id◦x=x 强迫单位变成方形。所以「可表示」与「相对化」的差别，就卡在方不方形这一点上。

一个术语对照，免得读文献时迷路

常见教材里 setRRA 常被称为「完全可表示关系代数」，而 RRA 是它们的同构闭包与乘积闭包。UAL 的写法 RRA = SP setRRA 是把这件事压缩成一个式子：具体物 → 取子代数 → 取积，就得到整个可表示类。

7RA ≠ RRA：反例在哪里 O4

先用一个便宜的论证看出「一定有反例」

RA 是由有限多条等式（(1)–(3) + (5) + (6)）定义的，所以它有限可公理化。如果 RA = RRA，那么 RRA 也有限可公理化——这与定理 7.1.10 直接冲突。所以 RA 里必定有不能表示的元素，而且反例多到让 RRA 根本写不出有限公理。

这个论证只告诉我们「有」，没告诉我们「长什么样」。下面给出具体构造。

定义 Lyndon 代数（UAL §7.1）

一个有限 Lyndon 代数是满足以下条件的有限 RA：

  • Id 是一个原子；
  • 每个原子 a 满足 a⁻¹ = a 且 a ◦ a = a ∪ Id；
  • 任意两个不同的非 Id 原子 a, b 满足 a ◦ b = 1 − (a ∪ b)。

这是一套纯组合的配方：只要指定若干原子，复合表就被规则完全定死，不需要真的画出有序对。UAL 指出：这样的代数里无穷多个不可表示，也无穷多个可表示。最小的不可表示 RA 只有 16 个元素（McKenzie 发现）——小到可以手算，却已经不是任何关系的代数。

另一种造反例的办法：把可表示的「掰弯」

从一个可表示 RA 出发，用分裂或膨胀把某些原子的复合关系改掉，就能造出不可表示的 RA。UAL 还提到一个很有意思的证明路线：找无穷多个不可表示 RA，使它们的超滤子积反而可表示——由此推出 RRA 不可有限公理化。这里又看见了 L04 的超积和 L18 的紧致性。

定理 UAL 7.1.14（什么时候抽象就够用）

令 φ 与 ψ 为

φ = ∃xy (x⁻¹◦x ≤ Id ∧ y⁻¹◦y ≤ Id ∧ x⁻¹◦y = 1) ψ = ∀x∃y (x ≠ 0 → [0 ≠ y ∧ y ≤ x ∧ y⁻¹◦y ≤ Id]).

则对 Σ = {φ} 与 Σ = {ψ} 都有

RRA ∩ ModΣ = RA ∩ ModΣ.

满足 φ 的叫拟投射 RA（QRA），满足 ψ 的叫函数稠密 RA。好消息：这两类里，RA 与 RRA 重合——也就是说只要多满足一条这样简单的性质，抽象公理就够用了。教材特别注明：「每个 QRA 可表示」是 Tarski 的定理，Maddux 给过优雅的代数证明。

φ 到底在说什么（值得拆开看）

条件 x⁻¹◦x ≤ Id 的意思是：x 是部分函数——同一个起点不会通过 x 走到两个不同终点（把 §3 的复合定义代进去验一下就清楚）。而 x⁻¹◦y = 1 说这两条部分函数合起来铺满了整个方形：任意两点的组合都能被接上。于是 φ 在说「这个代数里有足够多的函数式关系，可以把每一对点定位出来」。这正是把抽象元素实现为真正关系所需要的坐标系统——Tarski 的表示构造就靠它起步。

一句话总结本节的立场

RA 是「便宜的近似」，RRA 是「昂贵但真实」。RA 有限公理化、好算；RRA 不可有限公理化、等式理论不可判定，但它是逻辑真正要的语义。两者的差距不是技术细节，而是逻辑本身的复杂度——下一节看得最清楚。

8箭头逻辑与五座桥的收束 O5O5

定义 UAL 5.2.1：箭头逻辑 LREL

连接词 {∧, ¬, ⊥, ◦, ⁻¹, Id}。一个模型的世界不是点，而是箭头：取 W = U × U，把 ⟨u,z⟩ 读作「从 u 到 z 的箭头」。赋值 v : P → 𝓟(W) 给每个变元一族箭头。三条新连接词的语义是：

  • M, ⟨u,z⟩ ⊨ φ◦ψ 当且仅当存在 x 使 M,⟨u,x⟩ ⊨ φ 且 M,⟨x,z⟩ ⊨ ψ——首尾相接的两支箭。
  • M, ⟨u,z⟩ ⊨ φ⁻¹ 当且仅当 M,⟨z,u⟩ ⊨ φ——把箭倒过来。
  • M, ⟨u,z⟩ ⊨ Id 当且仅当 z = u——原地不动的箭。

于是 mng(φ◦ψ) = mng(φ) ◦ mng(ψ)，mng(φ⁻¹) = mng(φ)⁻¹，mng(Id) 是恒等关系。语义就是 §3 的手算规则。有效式定义为 mng(φ) = W（在所有箭头上成立）。

历史小注（UAL 原文）

Tarski 在 1941 年定义 LREL，本意是给出第一个不可判定的命题逻辑。它虽然叫「命题逻辑」，复杂度却几乎追平一阶逻辑。这一句就解释了为什么它的代数对应物这么难。

命题 UAL 5.2.2（接回 L16）
Algm(LREL) = setRRA　　Alg⊨(LREL) = RRA.

请把这条与 L16 的区分对上：Algm 是具体语义代数的类（这里就是具体关系族），Alg⊨ 是抽象的类（对同构封闭）。从前者到后者要取 SP 闭包——正好是 RRA = SP setRRA。

教材还给出 LREL 的演绎项：⊤ ◦ φ₀ ◦ ⊤ → ⊤ ◦ φ₁ ◦ ⊤（⊤ 是全关系）。这正是 L19 讲过的「把带前提的后承折算成空前提后承」的那一招，只是这次用在箭头逻辑上。

这张表为什么是本讲的高潮

前面五讲我们一座一座地过桥，每次都问「这个性质在代数那边的对应物是什么」。现在把五座桥同时对准同一个逻辑，答案一目了然：紧致靠的是普遍机制（所以有），其余四样都卡在 RRA 这个代数类的复杂上（所以没有）。你在 L18–L22 学的不是五个孤立的定理，而是一套能一次性诊断一个逻辑的工具。

9接回 L23：三层例与融合图 O6O6

L23 的方法在这里遇到了新门槛

上一讲我们靠「取超滤子当点」把布尔代数变成 Stone 空间。表示关系代数时，Tarski 的原始想法如出一辙：把抽象元素送到「超滤子对」构成的某种关系上，让复合对应于路径拼接。但这里多了一道硬门槛——可表示要求关系真的活在方形 U × U 上，而 Stone 空间的点只是超滤子，不自带方形结构。这道门槛就是 Id◦x=x；它不一定能跨过去，于是才有了非可表示的 RA。

定理 7.1.14 的 QRA 正好是「跨得过去」的充分条件：那些代数里有足够多的部分函数关系，可以把超滤子对坐标化，从而铺出方形。L23 的机器没变，变的是我们要它交出的东西更严格了。

典型例子 手算能验完

U = {1,2,3}，A = 𝓟(U×U)（九个有序对的全部子集，共 2⁹ = 512 个元素）。这是最小的非平凡集合关系代数，R ∈ setRRA。§3 的 R◦S = {(1,1),(2,2)} 与 R⁻¹ = S 都在这个代数里，全部公理可以直接手算验证。有限情形是所有定义的试算场。

本质例子 代数与逻辑真的接上

箭头逻辑 LREL 的理论，按 L16 的方法商出 Lindenbaum–Tarski 代数，得到 setRRA 的成员；取 SP 闭包得到 RRA（命题 5.2.2）。逻辑 → 代数 → 逻辑这条闭环，在关系代数上走得最完整，也最残酷：它把 RRA 的所有坏性质（无插值、无 Beth、不可判定）一并传回逻辑。

边界例子 公理管不到的地方

16 个元素的最小非可表示 RA，以及无穷多个 Lyndon 代数。它们满足全部 Tarski 公理，却不是任何集合上的关系族。这类例子不是病态：RRA 不可有限公理化正是靠它们证明的。抽象公理与具体实现之间的这道裂缝，是本讲最该带走的印象。

  逻辑                     代数                       具体物
  ─────────────────      ─────────────────      ─────────────────
  箭头逻辑 LREL             RRA（可表示）             𝓟(U×U) 的子族
  φ ◦ ψ                    x ◦ y                     先走 x 再走 y
  φ⁻¹                      x⁻¹                       把箭倒过来
  Id                       Id                        ⟨u,u⟩
  可证 / 有效              等式成立                   关系恒等式

全讲一句话

关系代数 = 布尔代数 + 复合，表示问题 = 这些复合能不能真的画成路径。答案是不一定；而「不一定」这三个字的代数代价是 RA ⊋ RRA，逻辑代价是箭头逻辑没有插值。
