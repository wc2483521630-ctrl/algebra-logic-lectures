2动机：基本运算的暴政

在群论里，你以为群就是「一个集合带乘法、逆元、单位元」。但真正决定群的行为的，是所有由这几样东西造出来的表达式——xyx⁻¹, (xy)⁻¹z, x²y³… 基本运算只是生成器，不是本质。

一个思想实验

把同一个载体 A 装上不同的「基本运算」集合 F 与 G，但只要 F 和 G 生成同一个 clone——即能造出完全相同的所有运算——那么子代数、同余、直积这些结构全都一样。区分「基本」与「导出」是人为的；clone 才是那个不随人为选择而变的对象。

本讲前半段把这个洞见做成形式（§2–§3），后半段收获它的果实：同余的全新刻画（§4）、Maltsev 条件（§6）、簇之间的翻译（§7）。

3Clone：运算的闭包 O1

定义 5.1（Bergman 4.1）

集合 A 上的 clone 是 Op(A)（A 上所有有限元运算之集）的子集 C，满足：

  1. 含全部投影 pnk(x₁,…,xn)=xk；
  2. 对广义复合封闭：若 f∈C 是 m 元，g₁,…,gm∈C 都是 n 元，则 f(g₁,…,gm)∈C。

换句话说，clone 就是「把一些运算放在盒子里，允许你取投影、做复合，怎么也跑不出去」的闭包系统。

例子（Bergman 4.2）
  1. Op(A) 与 Proj(A)={pnk} 是最小与最大的 clone。
  2. ℚ 上形如 a₁x₁+⋯+anxn (ai∈ℤ) 的线性函数全体；加上常数项得仿射函数 clone。
  3. E(A)：所有幂等运算 f(x,…,x)=x；U(A)：所有本质一元运算。都是 clone。
定义 5.2（两个主角；Bergman 4.6）

对代数 A=⟨A,F⟩：

  • 项运算 clone Clo(A)=CloA(F)：由 F 生成的 clone，即 A 上所有项函数。它只含「用基本运算能表达的」。
  • 多项式运算 clone Pol(A)：由 F∪Op₀(A) 生成——除了基本运算，还允许把 A 的元素当常量参数硬塞进去。例如群里的 f(x)=axb 是多项式运算，一般不是项运算。

Clo(A)⊆Pol(A)，二者都是 clone（定理 4.3 给出生成方法：逐层加入投影与复合）。

为什么区分两者

Clo 对应「不使用参数的公式」，Pol 对应「允许用元素作参数的公式」。同余只需要 Clo 保持（L03 定义 3.4）；但刻画同余的等价条件会自然用到 Pol（§4 定理 4.16）。逻辑里的对应是：不使用参数的可定义性 vs 带参数可定义性，这条分界在模型论里极其重要。

来源：Bergman §4.1 定义 4.1、4.2、4.6，定理 4.3。

4不变关系与 Pol–Inv 对偶 O2

这是 L02 Galois 连接的一个最重要实例，只是两极换成了「运算」与「关系」。

定义 5.3（保持关系；Bergman 4.11）

f 是 n 元运算，θ 是 k 元关系。说 f 保持 θ（记 f:θ），若：把 n 个 θ 的元素排成矩阵，按列逐列作用 f，得到的一行仍在 θ 中。

x₁₁ x₁₂ … x₁k ∈ θ 按列作用 f x₂₁ x₂₂ … x₂k ∈ θ ↓ ⋮ ⋮ ⋮ ⋮ xₙ₁ xₙ₂ … xₙk ∈ θ ↓ ───────────────────────────────── f(x₁₁,…,xₙ₁) … f(x₁k,…,xₙk) ∈ θ
引理 4.12（一眼看穿）。f:θ 当且仅当 θ 是代数 ⟨Ak, fk⟩ 的子代数载体。把「保持」翻译成「对提升后的运算封闭」，定义立刻变轻。
定义 5.4（两个极性；Bergman 4.13）
R(F) = { σ∈Rel(A) : F:σ }　　F(Θ) = { g∈Op(A) : g:Θ }

R(F) 是被 F 守住的全部关系；F(Θ) 是守住 Θ 的全部运算，叫 polymorphisms（多态）。这就是 L02 定义 2.35 的 Galois 连接，两极是 Op(A) 与 Rel(A)，闭集满足 F=F(R(F))。

定理 5.5（Bergman 4.14）

对任意关系集 Θ，F(Θ) 是 clone。若 A 有限，则每个 clone 都形如 F(Θ)。

有限集上，「clone」与「Galois 闭的运算集」是同一件事——有限性把 clone 的形状完全交给关系去描述。比如偏序 ⟨P,≤⟩ 的保序运算 clone 就是 F(≤)。这正是 L02「闭包算子 ↔ 闭集格」对偶的又一次现身。

L02 的方法在这里复用

你不需要重新证明 Galois 连接的四条性质——L02 定理 2.35 已经给了。这里只做了一次「代入」：把那里的极性 ◮/◭ 换成这里的保持关系 R/F。这就是抽象的价值：一次证明，处处使用。 后面 L21 的 Pol–Inv 对偶、L16 的代数化可定义性，都还是同一台机器。

来源：Bergman §4.2 定义 4.11/4.13、引理 4.12、定理 4.14；L02 §7（Galois 连接）。

5同余的新刻画与生成 O3

定理 5.6（五个等价条件；Bergman 4.16）

设 θ 是 A 上的等价关系。以下等价：

(a) θ 是同余　⟺　(b) Clo(A):θ　⟺　(c) Pol(A):θ　⟺　(d) Pol₁(A):θ　⟺　(e) F(A):θ

其中 F(A) 是基本平移的全体：形如 f(a₁,…,ai−1,x,ai+1,…,an) 的一元运算（定义 4.15），即「只留一个空位、其余位置填死」。

证明思路。(a)⟺(b) 几乎是定义（Clo(A) 正是所有项函数）。(a)⇒(c)：由定理 4.14，F(θ) 是 clone；θ 自反给出常量运算保持它，θ 是同余给出基本运算保持它，故 Pol(A)⊆F(θ)。(e)⇒(a) 是漂亮的串行论证：对 aiθbi，逐坐标换元 gi(x)=f(b₁,…,bi−1,x,ai+1,…)，用基本平移保持 θ 再传递，得到 f(a)θf(b)。∎
为什么 (e) 最有用

检验同余时，(a) 要求验证所有 n 元基本运算；而 (e) 只要求验证一元的基本平移。对复杂运算（比如 n=10）这是巨大的简化。「多元相容」可以拆成一串「一元相容」——这是 Maltsev 风格的典型技巧。

定理 5.7（Maltsev 的生成同余构造；Bergman 4.17）

对任意 θ⊆A²，Cg(θ)（由 θ 生成的同余）等于所有满足下列条件的对 ⟨a,b⟩：存在 z₀,…,zn∈A，存在 ⟨xi,yi⟩∈θ，与基本平移的复合 fi∈F(A)*，使

a = z₀,　b = zn,　{zi, zi+1} = { fi(xi), fi(yi) }

读作：从 θ 中的一对点出发，用一元平移把它们搬到别处，再把一串这样的「跳跃」首尾相接，能连到的所有对，正好就是生成同余。这是 L03「Cg 是闭包算子」的具体展开——现在你知道它一步步怎么闭包了。

来源：Bergman §4.2 定理 4.16、4.17；定义 4.15。

6等式理论与全不变同余 O4逻辑

定义 5.8（全不变同余；Bergman 4.57）

同余 θ 叫全不变，若对任意自同态 f∈End(A)：

⟨a,b⟩∈θ ⟹ ⟨f(a),f(b)⟩∈θ

全体记作 Confi(A)。等价说法：Confi(A)=Con(A+)，其中 A+=⟨A, F∪End(A)⟩ 把自同态也当作基本运算。

命题 5.9（Bergman 4.58）

Confi(A) 是 Con(A) 的完全子格，且是代数格。

为什么等式理论 = 全不变同余

L04 项代数 Ft(X) 的元素是项。一个等式理论（一组对 V 成立的等式）就是项之间的一个等价关系；它同余（因为等式可代入），而且全不变（因为对项作代入就是自同态——把变量换成任意项）。「代入保持可证性」正是全不变性的定义。

于是研究「簇的等式公理」可以改研究 Ft 上的全不变同余。Bergman 定理 4.59 进一步说明：簇 V 在代数 A 上诱导的同余 λV 总是全不变的。用格论工具比直接用公理化更能操纵这件事。

逻辑侧的读法

全不变同余 ≍ 「在任意代入下封闭的理论」。逻辑里我们要求定理集对代入封闭（否则 ⊢φ 换成 ⊢φ[p/q] 会失效），这就是同一条性质。L06 的布尔代数滤子、L16 的 Leibniz 同余，都从这里长出来。

来源：Bergman §4.6 定义 4.57、命题 4.58、定理 4.59。

7Maltsev 条件 O5

这是泛代数最漂亮的结论之一：一个关于所有代数的同余性质，等价于某个一元项满足两条等式。

定义 5.10（同余可换）

同余 α,β 可换，若 α∘β = β∘α。代数 / 簇叫同余可换，若其任意两个同余可换。（注意 α∘β 一般只是关系；可换时它等于 α∨β。）

定理 5.11（Maltsev 定理，1954；Bergman 4.64）

对簇 V，以下等价：

  1. V 同余可换；
  2. 三生成自由代数 FV(3) 同余可换；
  3. 存在三元项 q(x,y,z) 使 V ⊨ q(x,y,y)≈x≈q(y,y,x)。
证明核心（(c)⇒(a)）。设 a α c β b。用 q 造链：
a = q(a,b,b) β q(a,c,b) α q(a,a,b) = b
第一等号用 q(x,y,y)=x；中间一步 b β c 让第 2 位变；再一步 a α c 让第 3 位变；末等号用 q(y,y,x)=x。于是 ⟨a,b⟩∈β∘α，得证。∎

(b)⇒(c) 是自由代数的反向魔术：在 F=FV(x,y,z) 中取 α=Cg(x,y), β=Cg(y,z)，则 ⟨x,z⟩∈α∘β=β∘α，故有 u 使 x β u α z；因 F 由三生成元生成，u=qF(x,y,z)。再用自由性把 x,y 一起映到 a、z 映到 b，就读出两条等式。

例子 · Maltsev 项长什么样
  • 群：q(x,y,z)=x·y⁻¹·z。验证 q(x,y,y)=x·y⁻¹·y=x，q(y,y,x)=y·y⁻¹·x=x。
  • 环：q(x,y,z)=x−y+z。
  • 拟群：q(x,y,z)=(x/(y\y))·(y\z)。
  • 反例：三元素链（以及任何非平凡格簇）不同余可换，因此没有 Maltsev 项。
什么是「Maltsev 条件」

定理 4.64 的模式——「某个全局结构性质 ⟺ 存在满足若干等式的项」——被称为 Maltsev 条件。它是泛代数的万能翻译器：把「簇的性质」翻译成「项的等式」，于是可以用逻辑/证明论工具研究结构。L07 讨论同余分配簇、算术簇时，会遇到一整串这样的条件（Jónsson 项、优先项、near-unanimity 项）。

来源：Bergman §4.7 定理 4.64 及其后讨论。

8簇之间的解释 O6

定义 5.12（解释；Bergman 4.76）

设 V 型为 ρ:F→ω，W 型为 σ:G→ω。

  • 严格解释：映射 D: F→Tσ(Xω)，把 V 的每个运算符号译成 W 语言的一个项（元数相符），且对每个 A∈W，用这些项解释出的代数 AD∈V。
  • 无谓解释：把 0 元符号换成取常值的 1 元项。
  • 解释：严格解释（可先做无谓解释）。

注意方向有点反：D 是「把 V 的符号译成 W 的项」，却给出一个从 W 到 V 的代数变换。因为翻译项，就是告诉你在 W-代数上怎么造出 V-结构。

例子（Bergman §4.8 开头）
  • 环忘掉乘法 → 阿贝尔群（reduct，删掉运算）。
  • 阿贝尔群上定义 x·y=0 → 环。
  • 群上定义 x/y=x·y⁻¹, x\y=x⁻¹·y → 拟群。
  • 布尔代数 ↔ 布尔环，两个互为逆的解释。
定义 5.13（项等价；Bergman 4.77）

V 与 W 项等价，若存在解释 D: V→W 与 E: W→V 使 AED=A、BDE=B。项等价的簇在泛代数意义下「是同一个」：子代数、积、自由代数全部对应。

定理 5.14（解释的刻画；Bergman 4.78）

对无 0 元符号的簇 V,W 与变换 T: W→V，以下等价：(1) T 来自某个解释；(2) T 保持载体（A 与 T(A) 同载体）且把同态送成同态。

融合：解释为「逻辑之间的翻译」铺路

把簇看作某个逻辑的代数对应物，簇之间的解释就是逻辑之间的解释（interpretability）：用 W 的语言定义 V 的连通词，把 V 的定理翻译成 W 的定理。L16 会看到，代数化的逻辑之间做解释，正对应这里的结构。项等价则对应「表达力相同」——比如布尔代数与布尔环，命题逻辑的两种代数外壳。

来源：Bergman §4.8 定义 4.76/4.77，定理 4.78；UAL §2.3（范畴语言）。

10习题（按学习目标编号）

  1. O1 验证 E(A)（幂等运算全体）是 clone：检查投影幂等、复合封闭。
  2. O1 对群 G，举例一个多项式运算但不是项运算（提示：用元素作参数的平移），并说明为何 Clo(G)⊆Pol(G)。
  3. O2 用引理 4.12 证明：偏序 ⟨P,≤⟩ 的保序运算集 F(≤) 是 clone。
  4. O2 对 A={0,1}，列出全部二元关系，计算 F(≤)（≤ 为通常序），并与 Op(A) 比较。
  5. O3 用定理 4.16(e) 证明：群的同余由单位元的正规子群决定（提示：基本平移 axb 保持等价关系 aN=bN）。
  6. O3 对 A=⟨{0,1,2}, f⟩（f 为一元后继模 3），取 θ={⟨0,1⟩}，用定理 4.17 构造 Cg(θ)。
  7. O4逻辑 说明为什么「等式理论对代入封闭」对应「同余全不变」：把代入 σ 看成项代数 Ft(X) 的自同态，验证定义 5.8。
  8. O5 验证 q(x,y,z)=x·y⁻¹·z 满足 Maltsev 等式，并用它把 a α c β b 改写成 β∘α 的见证。
  9. O5 证明三元素链不同余可换（提示：取 α=Cg(0,1), β=Cg(1,2)，验证 ⟨0,2⟩∈α∘β 但不在 β∘α）。
  10. O6 写出「布尔代数 → 布尔环」「布尔环 → 布尔代数」两个解释的项定义，并验证它们互为逆。
  11. O6 用定理 4.78 说明：为什么「环 → 单位群」不是解释（提示：载体变了）。
