2动机：一个不该缺失的世界

它解决什么问题

L12 结束时留下一个悬案：收敛是「逼近」，但逼不逼得到，不知道。滤子 𝔉 收敛到 x，要求 x 这个点在空间里已经存在。可如果这个空间本身缺了点呢？那么一个完美相容、越来越精确的知识状态，可能根本没有落点——不是我们没找到，而是那里什么都没有。

讲义用的例子极其朴素，但杀伤力很强。闹钟。

闹钟例子（讲义 §5.2 开头）

设想认识论图景由可数多个世界构成，第 n 个世界里闹钟在 n 秒后响。记这些世界为 x0, x1, x2, …。

考虑命题

Pn ：「闹钟将在超过 n 秒之后才响。」

世界集里 Pn 恰好是 {xm : m > n}。它是可证伪的：想推翻它，只需等到第 n 秒——如果那时响了，Pn 就假。所以 Pn 是闭集，它的补 {x0, …, xn} 是开集（可验证：「不超过 n 秒就响」在有限时间内就能确认）。

关键的一步：每一个 Pn 都是一致的。任取有限多个 Pn1, …, Pnk，取 N = max(n1,…,nk)，那么世界 xN+1（闹钟 N+1 秒后响）同时满足它们全部。所以

P0 ∩ P1 ∩ ⋯ ∩ PN ⊇ {xm : m > N} ≠ ∅

但整体不一致：

⋂n∈ω Pn = ∅

因为每个 xm 都有确定的响铃时间，都会在某一秒响，于是都被某个 Pn 排除掉（取 n ≥ m）。

「每一小批都相容，整体却不相容」——这就是紧致性失效的形状。而它失效的根源不是逻辑,而是空间里少了一个世界：那个闹钟坏了、永远不响的世界。

补上那一点

加一个世界 x∞：「闹钟永远不响。」一切立刻恢复正常。在新的世界集 X = {x0, x1, …} ∪ {x∞} 里，

⋂n∈ω Pn = {x∞}

非空。这个理论现在有模型了，而且模型唯一。而且那个「每一小批都相容」的族，正是以 x∞ 为唯一极限的那个素滤子的生成元。

后面 §7 会看到：这个「加一点」的操作有个正式名字——Alexandroff 一点紧致化。而它恰好是把 ω 补成 ω + 1。本讲剩下的所有技术内容，都是把这一件事说严谨、说完整、说到能算。

先把话说清楚：紧致性不是什么

刚接触时最容易走偏的两条：

① 紧致 ≠ 有界。在 ℝn 里「紧致 ⟺ 有界闭」是 Heine–Borel 定理的内容，它依赖 ℝn 的特殊结构。在一般拓扑空间里，有界这个概念甚至没有定义（没有度量就没有「界」）。所以不要拿有界性去理解紧致性。

② 紧致 ≠ 序列紧致。紧致说的是「每个开覆盖有有限子覆盖」，序列紧致说的是「每个序列有收敛子列」。在度量空间里两者等价（这是极有用的定理），但一般空间里都不等价。反例有 [0,1][0,1]（紧致但存在没有收敛子列的序列）和 ω1（序列紧致但不紧致）。把它们混为一谈，后面所有关于超滤子的讨论都看不懂——因为紧致性的正确定义用的是开覆盖，而不是序列。这也解释了为什么本讲要用滤子：滤子是序列的正确推广，它不需要可数性。

3素滤子与素滤子定理 O1O1O1

它解决什么问题

L12 的滤子刻画「相容的知识」：知识越多，集合越小，但绝不缩到空。可是「知识越多」到哪儿为止？一个滤子可能还能再加强——加进一条新事实而仍然相容。素滤子的要求是：加不动了。

换个说法：给定任何一条命题 U，一个饱和的知识状态必须对它表态——要么确定 U，要么确定 ¬U，不能悬着。这正是「理论完全」的集合版本。所以素滤子 = 饱和理论 = 完全理论。

定义 3.1（定义 5.1.1）

设 X 为集合，𝔉 为 X 上的滤子。若对任意 U, V ⊆ X，

U ∪ V ∈ 𝔉  ⟺  U ∈ 𝔉 或 V ∈ 𝔉

称 𝔉 为素滤子（prime filter）。这里是在整个幂集上讨论，因而也就是通常说的超滤子（ultrafilter）。

注意这个定义用的是并，不是交。这一点值得停一下。滤子本身对交封闭（U, V ∈ 𝔉 ⟹ U ∩ V ∈ 𝔉），那是「知识可以叠加」。素性说的是反方向的对偶：如果一条弱命题（并）被确定了，那么它的某一支必须已经被确定。

为什么这和对交封闭对偶？因为在布尔代数里 ¬(A ∪ B) = ¬A ∩ ¬B，并通过补运算互换。讲义把它放在幂集上，是因为在幂集布尔代数里「对并素」和「极大」恰好等价——但这句话不能推广到任何格，下面 §3 末尾会专门说这个坑。

引理 3.2（引理 5.1.2）

设 X 为集合。

  1. 若 (𝔊i)i∈I 是按包含关系全序排列的非空滤子链，则 ⋃i∈I 𝔊i 是滤子。
  2. 若 𝔉 为滤子，A ⊆ X 与每个 B ∈ 𝔉 相交，则
    𝔉 ⊕ A = { C ⊆ X : ∃B ∈ 𝔉, A ∩ B ⊆ C }
    是包含 𝔉 且含有 A 的最小滤子。
  3. 对任意 x ∈ X，{U ⊆ X : x ∈ U} 是素滤子。
  4. 对滤子 𝔉，下列条件等价：
    (a) 𝔉 素；
    (b) 𝔉 是极大的真滤子——任何严格包含它的 𝔉′ ⊆ 𝓟(X) − {∅} 都不再为滤子；
    (c) 对任意 U ⊆ X，U ∈ 𝔉 或 X − U ∈ 𝔉。
第 4 条为什么成立（这是本讲最要紧的等价）

(a) ⟹ (c)：取 U ∪ (X − U) = X ∈ 𝔉，由素性立刻得到 U ∈ 𝔉 或 X − U ∈ 𝔉。一步而已。

(c) ⟹ (b)：先注意要假设 𝔉 真，否则陈述无意义（𝓟(X) 满足 (c) 但不极大）。在真滤子前提下设 𝔉′ ⊋ 𝔉 为滤子，取 A ∈ 𝔉′ − 𝔉。由 (c)，X − A ∈ 𝔉 ⊆ 𝔉′，于是 ∅ = A ∩ (X − A) ∈ 𝔉′，𝔉′ 非真。故 𝔉 极大。

(b) ⟹ (a)：设 𝔉 极大真，U ∪ V ∈ 𝔉 而 U ∉ 𝔉，要证 V ∈ 𝔉。反设 U 与每个 B ∈ 𝔉 都相交，则由第 2 条 𝔉 ⊕ U 是滤子，它包含 𝔉 且含 U，故严格包含 𝔉；又因 U 与每个 B 相交，𝔉 ⊕ U 不含 ∅，是真滤子——与极大性矛盾。所以存在 B ∈ 𝔉 使 B ∩ U = ∅，即 B ⊆ X − U，向上封闭给出 X − U ∈ 𝔉。再由 U ∪ V ∈ 𝔉 与交封闭，

(U ∪ V) ∩ (X − U) = V − U ∈ 𝔉

而 V ⊇ V − U，故 V ∈ 𝔉。两路都通。 ∎

这个证明的结构值得留意：关键工具是第 2 条的「𝔉 ⊕ A」——给滤子强塞进一个集合 A 的最小方式。极大性论证的标准套路是「塞进去而仍然相容 ⟹ 不极大」。同一个套路在下面定理 3.3 的证明里再出现一次。

定理 3.3（定理 5.1.3，Tarski 素滤子定理）

设 𝔉 是集合 X 上的滤子基，则存在素滤子 𝔊 ⊇ 𝔉。

证明（Zorn）

取向上闭包即可把滤子基扩成滤子，故只需从滤子 𝔉 出发。考虑偏序集

𝒫 = { 𝔊 : 𝔊 是滤子且 𝔊 ⊇ 𝔉 }

以包含关系排序。任意非空链的并由引理 3.2 第 1 条仍为滤子且包含 𝔉；空链有上界 𝔉。于是 Zorn 引理给出极大元 𝔊。

下证 𝔊 素。设 U ∉ 𝔊 且 X − U ∉ 𝔊。目标是导出矛盾。

由 U ∉ 𝔊 及向上封闭，𝔊 中不可能有成员包含于 X − U。于是对每个 C ∈ 𝔊 都有 C ∩ U ≠ ∅，因为

C ∩ U = ∅  ⟹  C ⊆ X − U

由引理 3.2 第 2 条，𝔊 ⊕ U 是严格扩张 𝔊 的滤子，与 𝔊 的极大性矛盾。因此 U 与 X − U 必有一个在 𝔊 里，即 𝔊 素。 ∎

这条定理的地位

它等价于选择公理的一种弱形式（布尔素理想定理，BPI）。讲义在 Alexander 子基定理的脚注里明确说了这一点：「这个定理实质地使用了选择公理的一种弱形式，恰为上面的素滤子定理。」

所以本讲后面所有关于紧致性的结论，背后都站着同一个假设。这不是技术瑕疵，而是必然：紧致性定理（逻辑侧）、Tychonoff 定理（拓扑侧）、素理想定理（代数侧）三者都被证明与 BPI 等价。换句话说，下面 §9 要讲的那个「同一个定理」，连它对选择公理的依赖都是同一份。

典型例子

主超滤子：固定 x ∈ X，𝔘x = {U ⊆ X : x ∈ U}。它对每条命题表态：含 x 的都确定，不含 x 的都否定。这是「一个具体模型 x 所确定的全部事实」，也是引理 3.2 第 3 条说的那种。所有有限集上的超滤子都是主超滤子（练习 E1 会让你证明）。

本质例子

非主超滤子：在 ω 上，把余有限集族（Fréchet 滤子）扩成超滤子 𝔘。它不含任何有限集（因为补是余有限，在 𝔘 里，而 𝔘 真），所以不是任何 𝔘x。这类超滤子的存在性只能靠选择公理，写不出具体例子——这是它的本质特征。

为什么它是本质的：紧致性定理、Tychonoff 定理、非标准分析的超幂构造，全都需要非主超滤子。主超滤子什么都做不了——用它做超积只是取回某一个因子。所以「素滤子定理」的全部力量都在非主那一侧。

边界与误解

① 「素」和「极大」在一般格上不等价！这是最容易犯的错。在幂集布尔代数上它们碰巧等价（引理 3.2 第 4 条），在一般分配格里则「极大 ⟹ 素」成立而反之不一定。Bergman 的素理想定理（定理 2.41）说的是分配格上「分离理想与滤子」的素理想存在性，这是比超滤子更弱、更一般的结论。所以看到「素滤子」时先问：在哪个格上？

② 别把素性读成「对交封闭」。那是滤子公理。素性是反方向：U ∪ V ∈ 𝔉 ⟹ U ∈ 𝔉 或 V ∈ 𝔉。写成「对交封闭」是错的，写成「U ∪ V ∈ 𝔉 ⟹ U ∩ V ∈ 𝔉」也是错的（更弱，且几乎是废话，因为 U ∩ V ⊆ U ∪ V，由向上封闭自动成立）。

③ 素滤子定理不给出唯一性。一个真滤子通常能扩成很多个不同的素滤子。{𝔘 : 𝔘 ⊇ 𝔉} 这个集合本身的大小，正是 Stone 空间 βX 的「纤维」——§8 会用它构造 Stone–Čech 紧致化，L06 已经用它构造过 Stone 表示。这两处是同一件事。

4紧致性：开覆盖、基、子基 O2

它解决什么问题

「空间缺了点」这个话说得很有感觉，但没法直接算。要变成定理，必须翻译成只谈集合和开集的语言。翻译的产物就是开覆盖定义——它看起来跟「缺点」毫无关系，这是初学者最大的困惑来源。

先给一个桥梁式的说法，先记住它，§6 会证明：缺了点 ⟺ 有一个开集族覆盖了整个空间，但任取有限多个都盖不住。想一想闹钟例子：开集 Vn = {x0,…,xn}（「不超过 n 秒就响」）。这个族覆盖了所有 xm——每个 xm 都在 Vm 里。但它盖不住那个缺失的世界 x∞；而任何有限多个 Vn 的并还是某个 VN，也盖不住 x∞。「有限子覆盖盖不满」正是「缺的那个点」的指纹。

定义 4.1（定义 5.2.1、5.2.2）

设 A ⊆ X。若开集族 (Ui)i∈I 满足 A ⊆ ⋃i∈I Ui，称它为 A 的开覆盖。其中一个仍覆盖 A 的子族 (Uj)j∈J（J ⊆ I）称为子覆盖；若指标集 J 有限，称有限覆盖。

若 X 的每个开覆盖都有有限子覆盖，称 X 紧致（compact）。称 A ⊆ X 为紧致子集，若它配备子空间拓扑后紧致（定义 5.2.10）。

注意「每个」这个词的位置。紧致性是全称命题：要对所有开覆盖都成立。所以证明紧致要靠论证（对所有覆盖统一处理），否证紧致只要举一个反例覆盖。这个不对称决定了下面所有例子的写法。

例 4.2（例 5.2.3）

ℝ 不紧致。取开覆盖

{(k, k + 2) : k ∈ ℤ}

它覆盖 ℝ（每个 x 落在某个长 2 的开区间里）。但没有有限子覆盖。理由：设取了有限多个 k1 < ⋯ < kn，则它们的并是 (k1, kn + 2)——一个有界区间，不可能等于 ℝ。一句话：有限多个有界区间还是只有界那么多。

Baire 空间 ωω 不紧致。取 {C(⟨n⟩) : n ∈ ω}，即「第 0 位等于 n」这些柱集。它们覆盖 ωω（每个序列有第 0 位）。但移去任何一个成员都会留下无穷多个未被覆盖的点：去掉 C(⟨n⟩) 之后，所有第 0 位为 n 的序列全没了覆盖。所以任何真子族都不覆盖，当然更没有有限子覆盖。

这两个例子的对比很有教益

ℝ 的失败是「无界」型：覆盖成员各有各的位置，散得太开。Baire 空间的失败是「分支太多」型：一个无穷多的分叉，任何有限选择都漏掉无穷多支。

两种失败对应两种紧致化的补法。无界型补「无穷远」一点（ℝ → S1，Alexandroff）；而 ωω 这种 Cantor 型空间本身就有紧致版本（2ω 紧致，例 5.2.6），把 ω 换成 2 就把「无穷分支」压成「两个分支」——这提示紧致性和「分支宽度有界」有关。§8 的 Stone–Čech 紧致化会把这个直觉做成一般构造。

命题 4.3（命题 5.2.4，基判据）

设 ℬ 为 (X, τ) 的基。X 紧致，当且仅当每个由基本开集组成的覆盖都有有限子覆盖。

证明

正向显然：基本开集都是开集，基本开覆盖就是一个开覆盖，紧致性直接给有限子覆盖。

反向：设 X = ⋃i∈I Ui 为任意开覆盖。把每个 Ui 写成基本开集的并（基的定义），得

X = ⋃i∈I ⋃j∈Ji Vj

这整个族 {Vj} 是基本开覆盖，由假设可选出有限子覆盖 X = Vj0 ∪ ⋯ ∪ Vjk。为每个 Vjr 选一个包含它的原覆盖成员 Ui(r)（这要用选择公理，但只对有限多个，不需要 AC），即得原覆盖的有限子覆盖。∎

这条命题的价值是省事，不是深刻。它把「对所有开集」降级成「对所有基本开集」。因为基通常小得多，检查起来容易得多。下面 Cantor 空间的紧致性证明就是它的直接应用。

定理 4.4（定理 5.2.5，Alexander 子基定理）

设 𝒮 为 X 的子基。X 紧致，当且仅当每个由子基本开集组成的覆盖都有有限子覆盖。

注意差别：基判据几乎是平凡的（正向显然，反向一步展开）；子基版本则完全不平凡，因为子基成员是「粗糙的原料」，它们的有限交才构成基。这一步跳跃需要 Zorn 引理。

证明（讲义原证）

一向显然。反向反证：设每个子基本开覆盖都有有限子覆盖，但存在没有有限子覆盖的开覆盖 ℬ。

第一步：把 ℬ 撑到极大。用 Zorn 引理把它扩成具有「无有限子覆盖」这一性质的极大开覆盖 ℬ′：包含 ℬ 的这类开覆盖按包含排序，链的并仍覆盖 X；若并中有有限子覆盖，由链性这有限多个成员都属于链上某一个覆盖，矛盾。所以极大元存在。

第二步：ℬ′ ∩ 𝒮 不可能覆盖 X，否则依假设它有有限子覆盖，与 ℬ′ 的选择矛盾。于是可选取

x ∈ X − ⋃(ℬ′ ∩ 𝒮)

因为 ℬ′ 覆盖 X，存在 U ∈ ℬ′ 含 x。由子基定义，可选 V0,…,Vl ∈ 𝒮 使

x ∈ V0 ∩ ⋯ ∩ Vl ⊆ U

第三步：每个 Vi 都不在 ℬ′ 里。因为 x ∈ Vi ∈ 𝒮，而 x 的选法保证它不在任何 ℬ′ ∩ 𝒮 的成员里。由 ℬ′ 的极大性，ℬ′ ∪ {Vi} 必有有限子覆盖（否则它更大且无有限子覆盖，违反极大性），即对每个 i ≤ l，

X = C0i ∪ ⋯ ∪ Cnii ∪ Vi,   Cji ∈ ℬ′

第四步：把这些并起来。

X = ⋂i=0l (C0i ∪ ⋯ ∪ Cnii ∪ Vi)

展开这个交（分配律），每一项形如「从每个括号里挑一个」，得到

X ⊆ ⋃i=0l (C0i ∪ ⋯ ∪ Cnii) ∪ (V0 ∩ ⋯ ∩ Vl) ⊆ ⋃i=0l (C0i ∪ ⋯ ∪ Cnii) ∪ U

最后一步用了 V0 ∩ ⋯ ∩ Vl ⊆ U。而右边全是 ℬ′ 的成员——这就给出了 ℬ′ 的一个有限子覆盖，矛盾。 ∎

这个证明值得反复看。它是「极大性 + 有限交分配」这台机器的标准运转：先靠 Zorn 拿到一个「已经撑到底」的对象，再从「再加一个就崩」反推出它必然含有某些东西，最后用分配律把那些东西组合成有限覆盖。同样的结构在命题 5.2.9、在布尔代数的素理想定理、在逻辑的极大一致集构造里都会重复出现。

例 4.5（例 5.2.6，Cantor 空间紧致）

用基判据。设 2ω = ⋃s∈T C(s)，T ⊆ 2<ω。

反证：设没有有限子覆盖。则 C(∅) = 2ω 不能被有限多个覆盖成员盖住。关键的一步：因为 C(∅) = C(⟨0⟩) ∪ C(⟨1⟩)，这两个柱集中至少一个也不能被有限覆盖——否则两个都能，并起来就能。选它为 C(s0)。

归纳地：若 C(sn) 不能有限覆盖，则 C(sn⌢0) 或 C(sn⌢1) 中至少一个不能有限覆盖，据此选 sn+1。

得到无穷二进制序列 x = ⋃n sn，它的每个有限初段对应的柱集都不能被有限多个原覆盖成员覆盖。但原覆盖包含 x，所以 x ∈ C(s) 对某个 s ∈ T 成立。注意 C(s) 只要 x 的初段够长就在里面，所以 s 必是某个 sn 的延长——于是 C(sn) ⊆ C(s)，而 C(s) 本身就是一个覆盖成员，矛盾。∎

这个证明的形状极重要：「不能有限覆盖」这个否定性质沿着二分树往下传，一路传出一条无穷路径。无穷路径的存在（König 引理）就是紧致性的实质内容——反过来，紧致性的失败就等于「存在一棵无穷高的有限分支树没有无穷路径」。这是紧致性在组合层面的真身。

典型例子

有限空间都紧致。设 |X| = n，取任一开覆盖。对每个点 x 选一个含它的成员 Ux，那么 {Ux : x ∈ X} 至多 n 个，覆盖 X。故有限空间恒紧致。推论：紧致性与「大小」无关——有限空间可以很不紧致的样子（比如离散的两点空间），而 [0,1] 不可数却紧致。找紧致的反例不能靠数点数。

本质例子

[0,1] 紧致（Heine–Borel，习题 5.1 要求仿 Cantor 空间证明）。它的紧致性来自完备性 + 全有界，而完备性正是「缺的点都补上了」——ℝ 不紧致是因为两端缺点但不补，(0,1) 不紧致是因为两端都缺点，[0,1] 补上了。这就是为什么「紧致 = 完备性」这个直觉在最熟悉的空间里完全正确。

更本质的例子是 2ω（Cantor 空间）：它是所有紧致度量空间的原型——每个紧致度量空间都是它的连续像。而它的紧致性完全来自「二分树的无穷路径总存在」。

边界与误解

① 「紧致子集」不等于「紧致的空间里的子集」。定义 5.2.10 说的是配备子空间拓扑后本身紧致。(0,1) ⊆ [0,1] 是紧致空间里的子集，但不是紧致子集（它不紧致）——它的开覆盖 {(1/n, 1) : n ≥ 2} 在子空间拓扑下没有有限子覆盖。这正是 L09 子空间拓扑的重要性：紧致性是相对于拓扑说的，换个拓扑就换个答案。

② 紧致性不被子空间继承，也不被拓扑和保持。讲义明确说了「拓扑和一般不保持紧致性」。但闭子集继承（引理 5.2.11），连续像继承（命题 5.2.12），积继承（Tychonoff）。这三条构成了紧致性的「运算封闭性」清单，值得背下来：闭、连续像、积——都保；开子集、和、商？商保（命题 5.2.12 的推论），开子集绝不保。

③ 把「紧致」当成「闭 + 有界」是只对 ℝn 有效的记忆。在一般空间里，紧致蕴含闭（若空间 Hausdorff，定理 5.3.1 第 2 条），但「有界」无从谈起。反过来，闭 + 有界在非 ℝn 的空间里不蕴含紧致——比如在 ℓ2 的单位球是闭有界但不紧致。Heine–Borel 是 ℝn 的定理，不是紧致性的定义。

来源：拓扑讲义 §5.2（定义 5.2.1、定义 5.2.2、例 5.2.3 及脚注「但 [0,1] 紧致……这是 Heine–Borel 定理的一种形式」、命题 5.2.4、定理 5.2.5 及脚注「这个定理实质地使用了选择公理的一种弱形式，恰为上面的素滤子定理」、例 5.2.6、定义 5.2.10）。

5有限交性质与闭集版紧致性 O3O3

它解决什么问题

开覆盖版本好用，但每次都要「取补」才能连到逻辑——因为逻辑里说的是「一族命题相容」，不是「一族开集覆盖」。把它们直接对上，需要一个中间的翻译。翻译工具就是有限交性质。

而且这个翻译是纯机械的：开覆盖取补就是闭集族，有限子覆盖取补就是有限交非空。但它把「紧致性」从一个看起来像「覆盖」的条件，变成了一个看起来像「相容性」的条件。这才是它通向逻辑的那扇门。

定义 5.1（定义 5.2.7）

集合族 𝒮 ⊆ 𝓟(X) 具有有限交性质（finite intersection property，f.i.p.），若任意有限子族的交非空。

这就是 L12 命题 4.3 里的那个条件。同一个东西在三个地方出现：L12 用它判真滤子，这里用它判紧致性，Bergman 用它（FIP，定义 5.1）造超滤子。三处是同一个条件的三次使用。

补一句重要的边界：f.i.p. 是有限交非空，不是全体交非空。这两者的区别正是本讲的全部内容。{Pn : n ∈ ω} 在闹钟例子里有 f.i.p.（每有限交非空）但全体交为空。紧致性说的是「f.i.p. 升级成全体交非空」——它就是升级许可证。

引理 5.2（引理 5.2.8）

X 紧致，当且仅当每个具有有限交性质的闭集族 ℱ 都满足 ⋂ℱ ≠ ∅。

证明（并看清那个「取补」）

⟹：设 X 紧致，ℱ 为具 f.i.p. 的闭集族。反证设 ⋂ℱ = ∅。则由 De Morgan，

X = ⋃U∈ℱ (X − U)

注意每个 X − U 都开（因为 U 闭）——这就是为什么必须要求闭集族，而不是随便什么族。由紧致性取有限子覆盖 X = (X − U0) ∪ ⋯ ∪ (X − Un)，再取补得

∅ = U0 ∩ ⋯ ∩ Un

与 f.i.p. 矛盾。

⟸：设开覆盖 X = ⋃i∈I Ui 无有限子覆盖。令 ℱ = {X − Ui}，这是闭集族。任何有限交 (X − Ui0) ∩ ⋯ ∩ (X − Uin) = X − (Ui0 ∪ ⋯ ∪ Uin) ≠ ∅（因为有限并没覆盖 X），故 ℱ 有 f.i.p.。由假设 ⋂ℱ ≠ ∅，即存在 x 不属于任何 Ui，与覆盖矛盾。∎

整个证明就是两次 De Morgan。但请注意：开覆盖版和闭集版是同一个命题的两种写法，谁也不比谁深。那为什么两个都要？因为闭集版可以直接对上「相容」：闭集族 ℱ 有 f.i.p. = 「这族条件局部相容」，⋂ℱ ≠ ∅ = 「整体有解」。一句话，紧致性 = 局部相容 ⟹ 整体有解。

这句话的重要性，以及它的精确形状

「局部相容 ⟹ 整体有解」——这就是一阶逻辑紧致性定理。把闭集族换成公式集、把「交非空」换成「有模型」，命题一字不改。这个对应不是比喻，L18 会给正式的桥：理论的模型集是闭集（Mod(Γ) 在 Stone 空间里闭），f.i.p. 就是有限可满足性，于是引理 5.2 与紧致性定理是同一句话。

但要说清一个限定。这个等价要求「闭集族」这一环境：不能把「每个 f.i.p. 的开集族交非空」当紧致性，那是错的。比如 [0,1] 里 {(0, 1/n) : n} 是开集族，有 f.i.p.，但全体交是 ∅。开集族天然可以「逃向边界」，闭集族不能——所以紧致性才能止住这个逃逸。

典型例子

[0,1] 中取闭区间族 {[0, 1/n] : n ≥ 1}。任取有限个 n1,…,nk，交是 [0, 1/max]，非空。全体交是 {0} ≠ ∅。f.i.p. 成立，整体交非空，符合引理 5.2。

把它和开集版对照：把 [0, 1/n] 换成 (0, 1/n)，f.i.p. 照样成立（有限交是 (0, 1/max) ≠ ∅），但全体交是 ∅。差别只在端点 0 在不在里面——而这个端点正是闭区间「补」回来的那个点。这就是 §2 那句「缺了个点」的最简实例。

本质例子

闹钟例子，用闭集语言重写：Pn 是闭集（可证伪），f.i.p. 成立（有限交非空），全体交是空。所以「世界集 {x0,x1,…} 不紧致」这件事，在闭集语言里就一句话：有一个 f.i.p. 闭集族交空。

为什么这是本质例子：因为它同时说了三件事。① 紧致性的失败有具体内容（少了那个世界）；② 失败是可以修的（加上 x∞ 就好）；③ 修法有一般形式（§7、§8）。一个定义若能同时给出反例、修法、和一般理论，它就算讲透了。

边界与误解

① 「有 f.i.p.」不等于「两两相交」。f.i.p. 要求任意有限多个交非空，不是只有两个。教科书里的经典反例：三个集合 {1,2}, {2,3}, {1,3} 两两相交，三者交为空。所以两两相交推不出 f.i.p.，更强的要求才够。

② f.i.p. 是「存在」还是「全体」？定义说的是「任意有限子族的交非空」——这等价于「每个有限子族交非空」，而不等于「存在一个有限子族交非空」（后者是废话，只要族非空且成员非空就成立）。「任意」这两个字是本定义的全部力量。

③ 紧致性不能降级成「每两个闭集相交」。在 ℝ 里取三个闭集 {1,2}、{2,3}、{1,3}（有限集在 ℝ 中闭）。任取两个都相交，但三者交为空。这个族有「两两交」而没有 f.i.p.，所以它不被引理 5.2 管——ℝ 不紧致，正好允许这种事。要点：n 元族的相容性要检查到 n 元为止，「两两」只在 n = 2 时才够。

来源：拓扑讲义 §5.2（定义 5.2.7、引理 5.2.8 及证明）；Bergman 定义 5.1（FIP）；L12 命题 4.3。

6紧致 ⟺ 每个素滤子收敛 O4O4O4

它解决什么问题

现在到了本讲的核心。引理 5.2 说「紧致 = f.i.p. 闭集族交非空」，但这个说法还是不涉及逻辑。素滤子会是那个缺失的环节——因为素滤子同时是「知识状态的饱和」和「闭集族的相容」，它把两边焊在一起。

要证的定理一句话：「一个空间是紧致的，当且仅当每个素滤子都收敛。」注意这句话有多强：它不给具体极限，只保证存在。这正是紧致性的作用——它是一个存在性原理，不是构造性方法。

命题 6.1（命题 5.2.9）

X 紧致，当且仅当每个素滤子 𝔘 都在 X 中收敛。

证明（⟹，紧致 ⟹ 收敛）

设 X 紧致，𝔘 为素滤子。要造一个极限点 x。思路：把 𝔘 里所有闭成员拿出来，它们的交非空（f.i.p. + 紧致），交点就是答案。

令

𝔘cl = { C ∈ 𝔘 : C 闭 }

𝔘cl 有 f.i.p.：任取 C1,…,Cn ∈ 𝔘cl，它们的交仍在 𝔘（滤子对交封闭），而 𝔘 真（不含 ∅），故交非空。由紧致性与引理 5.2，⋂𝔘cl ≠ ∅。取其中一点 x。

下证 𝔘 收敛到 x。设 U 是 x 的任一开邻域。声称 U ∈ 𝔘。反设 U ∉ 𝔘。由素性（引理 3.2 第 4 条 (c)），X − U ∈ 𝔘。而 X − U 是闭集（U 开），所以 X − U ∈ 𝔘cl，从而 x ∈ X − U，即 x ∉ U——与 U 是 x 的邻域矛盾。

因此每个开邻域都在 𝔘 里，由 L12 §5 定义 5.2（收敛），𝔘 收敛到 x。 ∎

这一步的结构值得单独记下来：

素性 → 「不在 𝔘 里就在补里」→ 补集是闭的 → 补集属于 𝔘cl → x 在补集里 → 矛盾

素性在这里的作用精确到位：它把「U 不在 𝔘 里」这句没有办法用的话，变成了「X − U 在 𝔘 里」这句可以直接用的话。没有素性，𝔘cl 那一步就没有任何信息可用。

证明（⟸，收敛 ⟹ 紧致）

反证。设所有素滤子都收敛，但存在开覆盖 X = ⋃i∈I Ui 无有限子覆盖。

第一步：造一个 f.i.p. 的族。考虑

E = { (X − Ui0) ∩ ⋯ ∩ (X − Uin) : {i0,…,in} ⊆ I 有限 }

即有限多个覆盖成员的补之交。因为有限并没覆盖 X，每个这样的集合非空；它包含空交（取 n = −1 时约定为 X）；且对交封闭。所以 E 是滤子基。

第二步：扩成素滤子。由素滤子定理（定理 3.3），存在素滤子 𝔘 ⊇ E。由假设，𝔘 收敛到某点 x。

第三步：逼出矛盾。因为 Ui 覆盖 X，选 i 使 x ∈ Ui。收敛性给出 V ∈ 𝔘 满足 V ⊆ Ui（这是 L12 收敛定义的形式：𝔘 含一个落在邻域内的成员）。但 X − Ui ∈ E ⊆ 𝔘，于是

∅ = V ∩ (X − Ui) ∈ 𝔘

与 𝔘 是真滤子矛盾。∎

注意两个方向用了完全不同的工具：

  • ⟹ 用紧致性 + 素性（素滤子已有的性质，去造极限点）；
  • ⟸ 用素滤子定理 + 收敛（用 AC 造出一个素滤子，再用收敛性打倒反设）。

所以这条定理的证明成本不对称：一个方向是「分析」，另一个方向是「综合 + 选择公理」。这也解释了为什么它跟 BPI 等价——反方向就是 BPI 的直接应用。

这条定理为什么是本讲的高潮

把三副面孔摆在一起：

领域同一句话的写法
拓扑紧致：每个开覆盖有有限子覆盖；等价地每个素滤子收敛
逻辑紧致性定理：每个有限可满足的理论整体可满足
代数簇对超积封闭（UAL 定理 4.1.5）；每个真滤子可扩成超滤子

它们不是「类似」，是同一个定理在不同范畴里的像。§9 的融合接口会把这张表做实。此处先指出一个具体接口：

「每个素滤子收敛」 ⟷ 「每个理论有模型」。给定理论 Γ，把它的证明闭包 Cn(Γ) 取出来——它是一个滤子（L02 讲过 Cn 是闭包算子，其对偶就是滤子）。若 Γ 有限可满足，则 Cn(Γ) 是真滤子；扩成素滤子 𝔘（= 完全理论，对每条公式表态）；命题 6.1 说 𝔘 收敛到某个模型 x；而「𝔘 收敛到 x」正是「x 满足 𝔘 里所有公式」，于是 x ⊨ Γ。整条链：有限可满足 → 真滤子 → 素滤子 → 收敛 → 有模型。中间那一步「素滤子 → 收敛」就是紧致性，就是命题 6.1。

典型例子

[0,1] 紧致，故每个素滤子收敛。取滤子基 {[0, 1/n] : n ≥ 1}（有 f.i.p.，因为有限交是 [0, 1/max]），扩成素滤子 𝔘。

它的极限是几？看 𝔘cl：含所有 [0,1/n]，交为 {0}，由命题 6.1 的证明，极限就是 0。所以极限点被 𝔘cl 完全钉死了。

但 𝔘 本身未必是主超滤子。若 𝔘 是主超滤子 𝔘x，则 {x} ∈ 𝔘，而 [0,1/n] ∈ 𝔘 迫使 x ∈ [0,1/n] 对一切 n 成立，即 x = 0。所以要造非主的，只需让 A = {1/n : n ≥ 1} 也进 𝔘——它满足 0 ∉ A，且与每个 [0,1/n] 相交（交含 1/n），故相容，可以扩。此时 {0} ∉ 𝔘，𝔘 ≠ 𝔘0，于是 𝔘 非主。

这个例子的教益：极限唯一（在 [0,1] 这种 Hausdorff 空间里）并不要求滤子唯一。无穷多个不同的素滤子可以收敛到同一个点——它们是同一个点的不同「逼近方式」。这正是 §8 里 βX 的「纤维」概念，也是 L06 Stone 表示里同一个素滤子既当点又当理论的原因。

本质例子

βω：ω 上所有素滤子构成的空间（拓扑见 §8）。βω 紧致，且每个素滤子都收敛——收敛到「它自己」。这句话听起来循环，实际上提示了 Stone–Čech 紧致化的本质：紧致化就是把「素滤子」本身当点，让每个素滤子收敛到自己。

为什么这是本质例子：它展示了命题 6.1 的构造性反面。一般情形下命题 6.1 只给存在性，不给构造。但 βω 里极限恰好就是那个素滤子——空间的点与素滤子一一对应。这是「紧致化」这件事的最干净形态：把缺的点直接定义为「缺的那个极限」。§7 的 Alexandroff 是另一个极端（只补一点），§8 是最大补法。三者对照，才看得清「补多少点」这件事的真正自由度。

边界与误解

① 把「每个素滤子收敛」误读成「每个滤子收敛」。错得很厉害。[0,1] 紧致，但平凡滤子 {X}（只用 X 一个集合生成的滤子……严格说是 {X} 的向上闭包，也就是 {X} 本身）不收敛：它要收敛到 x，就得让 x 的每个邻域都在 {X} 里——也就是 x 唯一的邻域是 X 本身，即 x 属于每个非空开集。[0,1] 里没有这样的点（Sierpiński 空间里那个开点倒是符合）。

根源在于「不收敛」的两个原因被混起来了。平凡滤子不收敛，是因为它的成员太粗（X 太肥，塞不进任何真邻域）；而命题 6.1 关心的是「成员够细但落点不存在」。素滤子保证了对每条命题表态，所以「粗」的问题不存在了，剩下的只是「有没有落点」——这才是紧致性管的事。所以命题 6.1 必须限定「素」。

② 把「每个素滤子至多收敛一点」和命题 6.1 混起来。「至多一点」是 T2（L12 §6 定理 6.2）；「至少一点」才是紧致。两者独立、可以分别失败。合起来才是分析里那句「极限存在且唯一」。这是本讲与 L12 的分工，必须分清。

③ 以为命题 6.1 能用来「算」极限。它不能。它只保证存在。真要算极限得用 𝔘cl 的交（如上面典型例子），而那需要知道 𝔘 里有哪些闭集——通常很难。命题 6.1 的正确用法是判紧致性（用它证不紧致最容易：造一个不收敛的素滤子）和做存在性论证。

7紧致 Hausdorff、局部紧与 Alexandroff 紧致化 O5

它解决什么问题

命题 6.1 只给了「极限存在」。L12 给了「极限至多一个」。两个条件分开看都不够用，合起来才是分析的做法。问题是：紧致和 T2 能不能同时满足？会不会互相排斥？

不但不排斥，而且配合得极好。定理 5.3.1 说：紧致 + Hausdorff 会额外赠送三个性质——正规性、闭 = 紧致、连续双射即同胚。这三个都是「免费」得到的，代价只是同时假设紧致和 T2。所以这两个条件在数学里几乎总是成对出现，简称「紧 Hausdorff」。

定理 7.1（定理 5.3.1）

若 X 紧致且 Hausdorff，则：

  1. X 正规；
  2. 紧致子集恰为闭子集；
  3. 紧致 Hausdorff 空间之间的连续双射是同胚。
三个证明的骨架，以及它们共同的招法

(1) 正规性。设 E, F 不交闭集。在紧致空间里闭集紧致（这正是 (2) 的一个方向，引理 5.2.11），故 E, F 都紧致。固定 x ∈ E，对每个 y ∈ F 取不交开邻域 Ux,y ∋ x、Vx,y ∋ y（这里用了 T2）。F 紧致，故 {Vx,y} 有有限子覆盖 Vx,y0,…,Vx,yn。令

Vx = Vx,y0 ∪ ⋯ ∪ Vx,yn,   Ux = Ux,y0 ∩ ⋯ ∩ Ux,yn

则 F ⊆ Vx、x ∈ Ux、且 Ux ∩ Vx = ∅。现在让 x 跑遍 E：{Ux} 覆盖紧致集 E，取有限子覆盖 Ux0,…,Uxm，令

U = Ux0 ∪ ⋯ ∪ Uxm,   V = Vx0 ∩ ⋯ ∩ Vxm

则 E ⊆ U、F ⊆ V、U ∩ V = ∅。正规。

注意那个「两次取有限」的结构：先对 F 取并（覆盖它），对 x 取交（保住 x）；再对 E 取并，对 F 取交。两次都是「覆盖方取并、被保住方取交」，并且两次都靠紧致性把无穷降成有限。这个双重紧致技巧是紧 Hausdorff 空间里最常用的招法，值得记住形状。

(2) 紧致 ⟺ 闭。一个方向是引理 5.2.11：紧致空间的闭子集紧致（用「⋃Vi ∪ (X − A)」这个开覆盖）。反方向：设 A 紧致、x ∉ A，对每个 y ∈ A 取不交开集 Uy ∋ x、Vy ∋ y。A 紧致，有限多个 Vy0,…,Vyn 覆盖 A，故 Uy0 ∩ ⋯ ∩ Uyn 是 x 的开邻域且与 A 不交。于是 X − A 开，A 闭。

讲义在这里加了一句关键的注：「注意这一步只需环境空间 Hausdorff。」不需要紧致性。所以精确的陈述是：在 Hausdorff 空间里，紧致子集必闭。反方向需要紧致：在紧致空间里，闭子集必紧致。两句话的前提不同，别混成一句「紧致 = 闭」。

(3) 连续双射即同胚。设 f : X → Y 连续双射，X 紧致、Y Hausdorff。若 U 在 X 中闭，则 U 紧致（(2) 的紧致侧），f[U] 紧致（命题 5.2.12，连续像保紧致），故在 Y 中闭（(2) 的 Hausdorff 侧）。所以 f 是闭映射；连续双射 + 闭映射 = 同胚。 ∎

这条的实用价值极高。L11 讲同胚时，验证同胚要同时验 f 连续和 f−1 连续，两件事都很麻烦。现在只要「X 紧致 + Y Hausdorff + f 连续双射」，逆连续性白送。这是 L11 §6 那个「四格表」里最值钱的一格，也是「紧致 Hausdorff」几乎总成对出现的原因之一。

存在性 + 唯一性，正式合成

把 L12 与 L13 拼起来：

X 紧致 + Hausdorff  ⟹  每个素滤子恰收敛到唯一一点

存在由命题 6.1（紧致），唯一由 L12 §6 定理 6.2（T2）。这就是分析里那句「极限存在且唯一」在一般拓扑里的版本。

为什么这件事值得大书特书：在 ℝ 里我们从来不觉得「极限存在」是个问题——因为它紧致化过（ℝ ∪ {±∞} 或 S1）。但一般的逼近过程（迭代、逼近序列、模型构造）里，「收敛到哪」常常是核心难点。紧致性把这件事从「构造」降级成「验证」——你不需要指出极限是什么，只要证明所在空间紧致。这是数学里最划算的交易之一。

定义 7.2（定义 5.3.2、5.3.4、5.3.6）

设 f : X → Y 连续。若 f[X] 在 Y 中稠密（cl f[X] = Y），称 (Y, f) 为 X 的拓扑扩张。进一步：

  • 若 Y 紧致，称为紧致化（compactification）；
  • 若 f 是到其像的同胚且 X 不紧致，称为真扩张（proper extension）；
  • 若还满足 Y 紧致、f[X] 在 Y 中开，称为强紧致化。

Hausdorff 空间 X 称为局部紧致，若每个 x ∈ X 都有一个紧致邻域。

讲义在这里有一句非常诚实的提醒：「这一组术语并非统一标准，不同作者的约定差异很大。」（原文定义 5.3.2 的脚注。）而中译本的译注还纠正了原稿两处：「真扩张」处的 f 应是到其像的同胚（否则非紧致 X 无法被紧致化）；命题 5.3.3 原稿漏写 Hausdorff（「嵌入某个紧致空间」本身不蕴含 Tychonoff，例如任何非 T1 的有限空间已紧致）。读这一节务必以定义为准，别信记忆里的术语。

命题 7.3（定义 5.3.4 + 命题 5.3.5，Alexandroff 一点紧致化）

令 X* = X ∪ {∞}（∞ ∉ X）。规定 U ⊆ X* 开，当且仅当

U 在 X 中开，  或者   U = (X − C) ∪ {∞}，其中 C 是 X 中的紧致闭子集

若 X 不紧致，则 (X*, i) 是 X 的强紧致化（i 为包含映射）。常记为 α(X)。

证明

拓扑合法性（讲义略，这里补）：∅ 与 X* 都开（∅ 在 X 中开；X* = (X − ∅) ∪ {∞}，而 ∅ 紧致闭）。对有限交：两类开集的交仍是两类（U1 ∩ ((X−C) ∪ {∞}) = (U1 − C) ∪ {∞} 若 ∞ ∈ U1，此时 U1 形如 (X−C1)∪{∞}，交为 (X − (C1 ∪ C)) ∪ {∞}，而两个紧致闭集之并紧致闭）。细节可以自己补，关键是「紧致闭」这个条件恰好对有限并封闭。

i 是拓扑嵌入且 X 在 X* 中开：按定义，X 中开集在 X* 中开，故 i 是开嵌入。

X 稠密：若 U ∋ ∞ 开，则 U ≠ {∞}——否则 X − C = ∅，即 C = X，与「X 不紧致」矛盾。所以 U ∩ X ≠ ∅。（这里就是「不紧致」这个假设唯一的用处，也是最漂亮的一处。）

紧致：取 X* 的开覆盖。某个成员含 ∞，故为 (X − C) ∪ {∞}，C 紧致。其余成员在 C 上诱导开覆盖（每个与 C 相交的部分是 C 的相对开集），由 C 紧致选有限多个覆盖 C，连同该成员便覆盖 X*。 ∎

例 7.4（α(ω)，图 5.1 的构造）

取离散的 ω = {0,1,2,…}。它 Hausdorff 但不紧致（单点集族是开覆盖，无有限子覆盖）。加一点 ∞，开集是：ω 的任意子集，以及含 ∞ 的余有限集（因为 ω 离散时「紧致 ⟺ 有限」，故 C 就是有限集）。

所得空间 α(ω) 就是图 5.1 那个：0, 1, 2, …, ∞。它紧致且 Hausdorff。（讲义说「请验证」——这里给一句话：任意开覆盖中取一个含 ∞ 的成员，它漏掉有限多个点，逐个补上即可。Hausdorff 见命题 7.5。）

注意它和序数的关系：α(ω) 正是序数 ω + 1 带序拓扑。而 α(ℝ) ≅ S1——这在 §8 结尾会再提，它是「两种紧致化分别是最小与最大」这句话里「最小」的例子。

命题 7.5（命题 5.3.7）

若 X Hausdorff 且不紧致，则 α(X) Hausdorff，当且仅当 X 局部紧致。

证明见习题 5.8（讲义原话），思路值得先说：

⟸：要分开 ∞ 与 x ∈ X。局部紧给 x 一个紧致邻域 K。在 Hausdorff 空间里可以取 K 闭（把 K 换成 cl K，紧致空间里紧致集闭…这里需要 K 紧致 + 环境 Hausdorff ⟹ cl K = K，故 K 闭）。于是 (X − K) ∪ {∞} 是 ∞ 的开邻域，与 int K ∋ x 不交。关键：局部紧致保证了「x 有一个离开 ∞ 的余地」。

⟹：若 α(X) Hausdorff，则 ∞ 与 x 有分离的开邻域 U ∋ ∞、V ∋ x。写 U = (X − C) ∪ {∞}，C 紧致闭。则 clX V ⊆ C（因为 V ∩ (X − C) = ∅）。而 C 紧致，闭子集 cl V 也紧致，故 cl V 是 x 的紧致邻域。局部紧。∎

这条命题说明了 Alexandroff 的局限：它「补得最少」，但补得少就未必补得好。讲义紧接着给出反例的伏笔：即使 X 正规，α(X) 也可能非 Hausdorff（习题 5.7 的 Arens–Fort 空间）。所以「补一点」这条最省事的路，只对局部紧空间可靠。

反例：Arens–Fort 空间（习题 5.7）

令 X = ℕ2（平面第一象限的格点）。规定 U ⊆ X 开，当且仅当满足下列之一：

  • (0,0) ∉ U（U 不碰原点）；
  • (0,0) ∈ U，且除有限多个 m 外，U 包含每行 {(m,n) : n ∈ ω} 中除有限多个外的全部点。

习题要求证明：(1) 它正规；(2) α(X) 不 Hausdorff。提示是「证明紧致闭子集只能包含有限多个不同于 (0,0) 的点」。

为什么这个反例值得单独看：它把「正规」和「局部紧」这两件事彻底分开了。L12 的阶梯里正规是比 T2 更强的条件，人的直觉是「正规 + 补一点 ⟹ 还是 Hausdorff」。Arens–Fort 把这个直觉打碎：(0,0) 这个点的邻域必须是「几乎所有行的几乎所有点」，它太肥了，肥到任何紧致集都装不下它的邻域，于是 (0,0) 没有紧致邻域，不局部紧，而 ∞ 就无法与它分开。

教益：紧致性的「局部版本」（局部紧）与分离性的「全局版本」（正规）互不蕴含。这是 L12 阶梯图之外的第四种独立性，值得记进反例库。

典型例子

α(ℝ) ≅ S1（圆周）。把 ℝ 的「两端」接到同一个点 ∞：t ↦ e2πit/(1+|t|) 之类。因为 ℝ 局部紧 Hausdorff，α(ℝ) 也 Hausdorff。这就是 L11-alt 里那个贯穿映射 π : ℝ → S1 的拓扑背景。

α((0,1)) ≅ [0,1]：两端各补一点？不，只补一点。因为 (0,1) ≅ ℝ，一点紧致化是圆周。要得到 [0,1] 得补两个点——「补几点」由「空间有几个『逃逸方向』」决定，不是由「差几个端点」决定。ℝ 有两个逃逸方向（±∞），可在一点紧致化里并成一个；[0,1] 是「不并」的版本（两点紧致化）。

本质例子

α(ω) = ω+1。它的本质性在于它就是 §2 闹钟例子的解：x∞ 就是 ∞，而那个「每一秒都往后推」的理论正好收敛到它。

为什么这是本质的：它展示了紧致化的认识论含义——补上的点 = 相容但没有实现的理论。这个含义在 §8 的 Stone–Čech 里会被推到极致：那里补的不是一个点，而是每一个这样的理论各补一个点。

边界与误解

① 以为一点紧致化总能得到 Hausdorff。错，命题 7.5 说需要局部紧，Arens–Fort 是反例。更常见的误解是「正规 ⟹ 局部紧」——两者毫无关系。

② 把 α(X) 和 βX 搞混。讲义最后说得极清楚：对局部紧 Hausdorff 空间，这两种紧致化分别是最小和最大的。最小 = α（只补必要的那一点点），最大 = β（把所有可能的极限都补上）。中间还可能有许多：讲义给的例子是

S1 ≤ [0,1] ≤ βℝ

而这三个的大小关系不是「子空间包含」——讲义有脚注纠正：「紧致化的标准偏序实际由固定原空间的连续满射（支配关系）定义，不宜理解为一般子空间嵌入。」这是个非常容易错的地方：S1 不是 [0,1] 的子空间，但 [0,1] 是 S1 的商（把两端粘起来）。

③ 以为「紧致化」必须保持 T2。定义 5.3.2 只要求 Y 紧致，没要求 Hausdorff。所以 α 在某些空间上给出非 Hausdorff 的结果，仍然符合定义。要 Hausdorff 得额外要求，那就引出 §8 的 β。

8Stone–Čech 紧致化 O6O6

它解决什么问题

Alexandroff 只补一个点，省事但不够：它只对局部紧空间保证 Hausdorff，而且它把所有的「无穷远方向」硬粘成一个点。如果空间有完全不同的若干种逃逸方式（比如 ω 上有无穷多种本质不同的「趋于无穷」的方式——每个非主超滤子一种），一点紧致化会把它们全糊在一起，丢掉了信息。

那就不糊：每一种逃逸方式各补一个点。这就是 Stone–Čech 紧致化 βX。它的定义方式很优雅——不说「补哪些点」，只说「它必须满足什么」（泛性质），然后证明这样东西存在且唯一。

定义 8.1（定义 5.3.8）

设 X 为拓扑空间。若 Y 紧致 Hausdorff，i : X → Y 连续且像稠密，并满足下述泛性质：对任意紧致 Hausdorff 空间 Z 及连续映射 f : X → Z，存在唯一连续映射 f̄ : Y → Z，使 f̄ = f ◦ i，

则称 (Y, i) 为 X 的 Stone–Čech 紧致化，通常记为 βX。

i X ──────────► Y = βX ╲ │ ╲ │ f̄ （存在且唯一） f ╲ │ ╲ ▼ ╲──────► Z 紧致 Hausdorff

把它读成一句话：从 X 出发到任何紧致 Hausdorff 空间的映射，都能唯一地「穿过」βX。换句话说，βX 是所有紧致 Hausdorff 扩张里「最自由」的那个——它能模拟任何别的扩张。「最大」这个词就是这个意思。

为什么「唯一」几乎是白送的

设 (Y, i)、(Y′, i′) 都满足定义。则由泛性质有连续映射 a : Y → Y′、b : Y′ → Y，满足

a ◦ i = i′,    b ◦ i′ = i

从而 b ◦ a ◦ i = i = idY ◦ i。b ◦ a 和 idY 都是「使 f̄ ◦ i = i 的连续映射」，由唯一性 b ◦ a = idY；同理 a ◦ b = idY′。故两个空间同胚。所以「在同胚意义下唯一」。

这个论证是范本。凡是靠泛性质定义的构造，唯一性都这么证：造两个方向的映射，证明复合等于恒等，全部靠「唯一性」这一句。L02 的 Galois 连接、L05 的自由代数、L11 的商拓扑泛性质，都是同一个套路。

例 8.2（例 5.3.9，βω）

对离散空间 ω，βω 可以取为 ω 上所有素滤子的集合，基本开集为

φ(U) = { 𝔘 ∈ βω : U ∈ 𝔘 },    U ⊆ ω

（讲义用 φ(U) 记号；等价地，φ(U) 就是「含有 U 的那些素滤子」。）可以证明该空间紧致 Hausdorff，并具有紧致化泛性质。更一般地，对任意离散空间 X，其 Stone–Čech 紧致化均可取为 X 上素滤子的空间，拓扑基同上。

这个构造极为漂亮，值得停下来看它说了什么。

  • 点 = 素滤子 = 完全理论。（§3 的翻译表）
  • 基本开集 φ(U) = 「确定 U 的那些理论」。注意这和 L08 的开集认识论读法完全一致：φ(U) 是「可验证 U 成立」这件事。
  • 原空间 ω 嵌进去的方式：n ↦ 𝔘n（主超滤子）。这些是「有具体模型的理论」，稠密——因为任何 φ(U)（U ≠ ∅）都含某个 𝔘n（取 n ∈ U）。
  • 补上的点 = 非主超滤子 = 相容但没有具体模型的理论。这就是 §2 闹钟例子里那个「闹钟永远不响」的世界的一般化。

而这正是 L06 的 Stone 表示！L06 里布尔代数 A 的 Stone 空间是「A 上超滤子的集合」，拓扑由 {𝔘 : a ∈ 𝔘} 生成。同一个构造，两个名字：在布尔代数上看叫「Stone 空间」，在离散空间上看叫「Stone–Čech 紧致化」。更精确地说：βX 就是幂集布尔代数 𝓟(X) 的 Stone 空间。（见练习 E12。）

一般构造为什么需要 [0,1]

上面那个「素滤子空间」的构造只对离散（或零维）空间直接可用。一般拓扑空间没有「素滤子 ↔ 点」这种一一对应（因为 𝓟(X) 太大了，素滤子会多到分不清）。一般构造换了个思路：用连续函数当坐标。

核心是评价映射：

iX : X → [0,1]C(X),    iX(x)(f) = f(x)

其中 C(X) 是所有连续映射 X → [0,1] 的集合，右边配积拓扑。即 x 对应一个函数：把每个 f 送到 f(x)。

为什么这样做？因为 [0,1]C(X) 由 Tychonoff 定理紧致（定理 5.2.13），由命题 4.3.5 Hausdorff。于是「目标空间」自动是紧 Hausdorff 的，我们只要把 X 塞进去，再取闭包。

令

K(X) = cl iX[X] ⊆ [0,1]C(X)

它是紧致空间的闭子空间，故紧致且 Hausdorff；iX[X] 在 K(X) 中稠密（按定义）。所以 (K(X), iX) 是紧致 Hausdorff 扩张。命题 5.3.15 断言它满足泛性质，从而是 Stone–Čech 紧致化。

命题 8.3（引理 5.3.10–5.3.14 + 命题 5.3.15）

对任意拓扑空间 X，(K(X), iX) 是 X 的 Stone–Čech 紧致化。

四块拼图（讲义原证，此处给出骨架与每块的作用）

① 引理 5.3.10（分离不同映射）：设 X, Y 紧致 Hausdorff，f, g : X → Y 不同的连续映射，则存在连续 h : Y → [0,1] 使 h ◦ f ≠ h ◦ g。作用：保证「映射不同」可以被 [0,1] 值的函数看出来——这是为什么坐标只取 [0,1] 就够。

② 引理 5.3.12（iX 连续）：只需检查子基本开集的原像。设 f ∈ C(X)，O ⊆ [0,1] 开，U = pf−1[O]，则

iX−1[U] = {x : iX(x)(f) ∈ O} = f−1[O]

因 f 连续而开。作用：评价映射是连续嵌入的候选。

③ 引理 5.3.13（紧致 Hausdorff 时 X ≅ iX[X]）：先用 Urysohn 引理（L12 §8）证 iX 单射：若 x ≠ y，有连续 f : X → [0,1] 使 f(x)=0, f(y)=1，故 iX(x)(f) ≠ iX(y)(f)。再由 X 紧致、iX[X] Hausdorff，定理 7.1 第 3 条给出 iX 是同胚到其像。作用：紧致 Hausdorff 空间不丢东西（βX = X）。

④ 引理 5.3.14 + 命题 5.3.15（泛性质）：设 Z 紧致 Hausdorff，m : X → Z 连续。定义

m̂ : [0,1]C(X) → [0,1]C(Z),    m̂(g)(f) = g(f ◦ m)

则 m̂ 连续，且 m̂ ◦ iX = iZ ◦ m，特别地 m̂[iX[X]] ⊆ iZ[Z]。由连续性与 ③，

m̂[K(X)] = m̂[cl iX[X]] ⊆ cl m̂[iX[X]] ⊆ cl iZ[Z] = iZ[Z]

（最后一步因紧致集 iZ[Z] 在 Hausdorff 空间中闭。）因此可以定义

m̄ = iZ−1 ◦ m̂ ↾ K(X) : K(X) → Z

并有 m̄ ◦ iX = m。唯一性：若另有连续 l 使 l ◦ iX = m，则 l 与 m̄ 在稠密子集 iX[X] 上一致；因 Z Hausdorff，由「两个连续映射在稠密集上一致则处处一致」得 l = m̄（讲义指出这就是习题 4.2 的结论）。 ∎

整条证明的骨架，一句话：把「β 的存在」化归成「[0,1] 的 Tychonoff 紧致性」。所有麻烦都推给积空间——而积的紧致性正是 Alexander 子基定理（Zorn + 分配律）撑起来的。所以整条链的底部还是素滤子定理。没有一处是免费的。

命题 8.4（命题 5.3.16）
  1. βX 与 X 经自然映射相同，当且仅当 X 紧致 Hausdorff；
  2. X 是 Tychonoff 空间，当且仅当自然映射 i : X → βX 是拓扑嵌入；
  3. 对非紧致的 Tychonoff 空间 X，i[X] 在 βX 中开，当且仅当 X 局部紧致。

这三条把 β 与 L12 的整个分离阶梯对上：β 只对 Tychonoff 空间是「好的」嵌入。原稿两处被译注纠正：第 2 项原文写「真扩张」但真扩张还要求非紧致，须排除紧致情形；第 3 项原文还要求 X 正规，这个要求并非必要。读文献时注意这类修订。

讲义接着给出一个极有趣的对象：余部 βX − X。当 X Tychonoff 且局部紧时它是闭集，因而本身紧致，具有丰富的拓扑与集合论结构。尤其 βω − ω 可识别为 ω 上非主素滤子的集合，与组合集合论、力迫法、代数乘积的对偶都有特殊联系（超出本课程范围）。

典型例子

β(0,1] 与 β(0,1)：注意 (0,1] 局部紧，故 β(0,1] − (0,1] 是闭的、紧的；而 (0,1) 不局部紧。但最干净的典型例子是 X 紧致时：βX = X（命题 8.4 第 1 条）。此时什么都没补，泛性质退化成「f̄ = f」——一个平凡的恒等，但它是整个理论的锚点：紧致 Hausdorff 空间不需要紧致化。

实践上最有用的典型例子：βω。它 不可度量、基数 22ℵ0、不含任何非平凡的收敛序列。这几个性质合起来说明：βω 是一个「只能靠滤子理解」的空间——序列在它里面完全失效。这直接印证了 §4 那条警告：紧致性不能用序列来理解。

本质例子

讲义结尾的那条链：

α(ℝ) = S1  ≤  [0,1]  ≤  βℝ

这是「最小、中间、最大」三种紧致化的完整样本，而且全在同一个空间 ℝ 上。读法：

  • S1：只补一点，把 +∞ 和 −∞ 粘成一个。最少的信息保留。
  • [0,1]：补两点，两端分开。保留了「往哪边跑」这个信息。
  • βℝ：补到极致，每一种「趋于无穷的方式」（= 每个非主素滤子，每个「渐近行为」）各补一点。基数远大于 2ℵ0。

为什么这是本质例子：它把「紧致化有多少自由度」这件事变成了可数的三个样本。每一个都对应一种「你认为什么信息重要」的判断——只要 S1（够用就好），要方向 [0,1]，要全部渐近行为 βℝ。这不是数学技巧的差别，是建模需求的差别。

边界与误解

① 把「βX 最大」读成「βX 包含所有其它紧致化作为子空间」。错。讲义脚注明确纠正过：紧致化的偏序由「固定原空间的连续满射」（支配关系）定义，不是子空间包含。[0,1] 不是 βℝ 的子空间；正确的说法是存在连续满射 βℝ → [0,1] 固定在 ℝ 上（由泛性质取 Z = [0,1]、f = 某个嵌入即得）。「最大」= 「能满射到所有别人」，不是「包含所有别人」。

② 以为 βX 总能嵌入 X。命题 8.4 第 2 条说得很清楚：只有 Tychonoff 空间才行。而且讲义脚注还指出原稿的漏洞：「X 能拓扑嵌入某个紧致空间」本身不蕴含 Tychonoff——任何非 T1 的有限空间已经紧致，却是自己的紧致化，谈不上「嵌入到 Hausdorff 里去」。所以命题 5.3.3 的原文漏了 Hausdorff 这个词。

③ 以为 βX − X 总是闭的。讲义脚注特别纠正：原稿对任意 Tychonoff 空间都声称余部闭，这不成立；闭性需要 X 在 βX 中开，即局部紧致条件。这是「余部拓扑」讨论里最基本的坑。

④ 把「β 存在」当成构造性的。它的存在性证明用了 Zorn 引理（通过 Tychonoff 定理），没有任何算法能给出 βℝ 的具体点。βω − ω 上的很多问题（比如它的齐性）是集合论的独立命题。所以 β 的正确用法是「存在性论证」，不是计算。

闹钟例子在逻辑侧长什么样

回到 §2 的 Pn。在逻辑侧写成一阶理论：语言含常元 c 和谓词「t > n」，理论

Γ = { c > 0, c > 1, c > 2, … }

每个有限子集都有模型（取 c 足够大）。但 Γ 在 ℕ 里没有模型——没有自然数比所有自然数都大。所以「ℕ 不是紧致的」这件事，就是「Γ 在 ℕ 里没有模型」。

但一阶逻辑的紧致性定理说 Γ 有模型。矛盾吗？不矛盾——模型不在 ℕ 里，在某个非标准模型里。那个模型含一个「无穷大元素」c，它正对应拓扑侧补上的 x∞。非标准分析就是在这个非标准模型里做微积分。

所以「紧致化」在逻辑侧的名字是「添补非标准元素」。Alexandroff 补一点；Stone–Čech 补全部；一阶逻辑的紧致性定理补「所有需要的」——三者是同一种操作在不同精度下的版本。

但有一个反讽必须说

讲义在 §5.2 开头说紧致性是「空间的某种完备性」，因为「它强制某些点存在」。而 §2 的闹钟例子恰恰说明：一个空间可以不紧致，就是因为缺了点。那么「完备性」这个词用在这里，跟度量空间的完备性是一回事吗？

在最熟悉的情形里是。ℝ 完备 ⟺ ℝ 的每个柯西序列收敛；而 ℝ 不紧致，它的紧致化 [−∞,+∞] 是完备的。(0,1) 不完备，[0,1] 完备。但一般情形下不是：度量完备性说的是「柯西序列收敛」（一个可数条件），紧致性说的是「每个素滤子收敛」（一个任意条件）。紧致 ⟹ 完备永远成立；反过来需要「全有界」。

所以准确的对应是：紧致性 = 完备性 + 全有界。而「全有界」在逻辑侧对应的是语言的可数性/有限性条件——这就是为什么紧致性定理对任意语言成立，而「完备性 + 全有界 ⟹ 紧致」只在度量空间里成立。这个区别在 L18、L19 会再出现，先记住：把紧致当完备性用是可以的，但要知道你多用了什么。

收束与本讲之后

一句话总结整讲：紧致性 = 「局部相容 ⟹ 整体有解」；素滤子是那个把局部升成整体的工具；紧致化是「升级失败时打补丁」。

L14 会转向另一个方向：连通性。那里问的问题不再关于「缺不缺」，而是关于「断没断」——能不能把一个空间劈成两块不交的非空开集。而 Stone 空间（全不连通 + 紧致 Hausdorff）会成为 L14 的主角，把 S4.2 与信念逻辑接进来。紧致性这根接力棒会一路传下去：L14 的 Stone 空间是紧致的，L18 的完备性定理靠紧致性，L23 的关系代数对偶里又是紧致性。
