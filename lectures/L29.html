0概念清单与依赖关系 先摆牌

本讲新概念（八个，按依赖排序）
  1. 非标准语义：模型不再是通常的关系结构，而是更抽象、或带额外约束的对象；公式不变，模型类一换，逻辑全变（L15「旋钮二」的正式登场）。
  2. 抽象模型 ⟨A, RM⟩：A 是简单柱体代数，解释成 A 的元素——把「模型」直接读作「可能的概念代数」。
  3. 可采纳赋值集 W：变量依赖语义里只允许 W ⊆ ⁿM 里的取值；W = ⁿM 是标准模型，其余非标准。
  4. 相对化柱体集合代数 Crsn：把 Csn 的相对化到 W 的版本；变量依赖逻辑的代数对应物。
  5. 排序函数 ρ : R → ω：每个关系符号有固定元数；有它叫排序版，没有它叫无排序版。
  6. 条件可代数化：只有加上一组条件 S(ρ) 才组合、才代入；比可代数化弱一档。
  7. 图式不完全性：每个实例都可证、整条图式却没有统一证明——排序版 Gödel 完全性与它并存，正是本讲最微妙处。
  8. 反变原理：模型类越大，有效式越少；靠 Mod 与 Th 的 Galois 连接（L02）支配全讲。

2为什么要拧语义；一条反变原理 O1

前四讲我们一直换代数：BA、RRA、CAn、RCAn，看同一台桥机器跑出什么结果。这一讲反过来——代数工具不动，专换模型类，看逻辑的脾气怎么变。这是 L15 说的旋钮二，UAL 在这里把它拧了四下。

原理 反变：模型类越大，有效式越少

设逻辑 L = ⟨F, M, mng, ⊨⟩，有效式集 E(M) = {φ ∈ F : 对所有 M ∈ M，M ⊨ φ}。若 M ⊆ M′，则

M′ ⊆ M　⟹　E(M) ⊆ E(M′).

为什么反着走？有效式要「对所有模型成立」。模型越多，要通过的检查越多，能活下来的公式越少。把模型类放大，等于把有效式集收紧。这就是 L02 的 Galois 连接 Mod ⊣ Th 在起作用：M 与 Th(M) 反向对应。

直觉 · 这一讲所有「治疗」的共同机制

前面几讲的老毛病——没有 Hilbert 系统、不可判定、没有 Beth——都不是公式的错，是模型类选得太「规矩」造成的。把模型类放宽一点，多塞进一些「怪模型」，有些公式就不再有效，逻辑就变弱；而变弱之后，恰好能把原先卡住的性质捞回来。

这事听起来像作弊：把定理删掉就「完全」了。但下面四个案例会说明，它一点也不廉价——每放回一样东西，都要付另一样东西作代价。UAL 把四笔账摆在同一张表（Table 5.1）上，本讲最后一节就读这张表。

典型 · 反变在眼前发生

UAL §5.5 给了一个两变量公式，说的是「若 R 的定义域至多一个元素，则 R 等于它的定义域乘值域」。它在通常语义 L2 里有效，在抽象模型语义 La2 里不再有效——因为抽象模型里 R 的解释是柱体代数里的一个元素，不再是一批有序对，「定义域」「值域」这些概念没有通常意义。模型类一放宽，这条定理就掉了。

变量依赖侧同理：∃v₀(v₀ = v₁) 在通常语义里是重言式，在变量依赖语义里不是——因为可采纳赋值集 W 可能根本不含任何让 v₀ 与 v₁ 相等的赋值。

别把「模型多」与「表达力强」搞混

扩大模型类之后，有效式变少，逻辑变弱；但可表达的公式集一点没变（四案例的公式集全是同一套 FnR 或其 ω 维版本）。变的只是「哪些公式算对」。判断一个改动是好是坏，必须同时看公式侧和模型侧——这正是四元组 ⟨F, M, mng, ⊨⟩ 把两样都写出来的原因（L15）。

3案例 5：非标准语义 Lnan 与「概念代数」 O2

这个语义来自 Leon Henkin。招数很激进：既然 Ln 缺 Hilbert 系统是因为模型类太「实」，那干脆把模型改成抽象的柱体代数——让模型自己就是「概念的系统」。

定义 5.5.1（带抽象模型的 FOL，n 变元）

语言与 Ln 完全相同：原子公式 R(v₀,…,vn−1)，连接词 ∧, ¬, ⊥, vi=vj, ∃vi。模型类换成

Mna,R = {⟨A, RM⟩R∈R : A ∈ CAn 是简单的，且 RM ∈ A}.

意义函数是从公式代数 FnR 到 A 的唯一同态，在原子上满足 mngM(R)=RM、mngM(vi=vj)=dAij，并且

mngM(∃viφ) = ci(mngM(φ)),　mngM(φ∧ψ) = mngM(φ) ∧ mngM(ψ),

否定与 ⊥ 照常；M ⊨a φ 当且仅当 mngM(φ)=1A。

直觉 · 「模型 = 可能的概念代数」

在通常语义里，一个模型给出一批关系，公式的含义是「满足它的赋值集合」；含义全体组成可定义关系的代数。把这个代数直接拿来当模型，就是 Henkin 的想法：模型不必先有「点」，只要有一套能演算的概念就行。

注意「简单」这个要求：CAn 里只有 0 与 1 两个同余的代数。它保证 mngM(φ)=1 这个真值判据不会退化——在一个有非平凡同余的代数里，「等于顶元」与「在商里等于顶元」不是一回事。

命题 5.5.2

Lann 对所有 n < ω 都是可代数化的一般逻辑，且

Algm(Lann) = simpleCAn,　　Alg⊨(Lann) = CAn.
四步走一遍 L27 的流程。
  1. 规范形式。公式代数 FnR 就是自由 CAn，因为柱体算子 ci 与对角线 dij 已把量词与等号代数化。
  2. Algm。模型的意义函数值域恰是简单 CAn，同态核给出全部「模型可见」的同余，故 Algm = simpleCAn。
  3. Alg⊨。有效等式由所有简单代数决定；CAn 是 SP(simpleCAn)（每个代数是简单代数的子直积），故闭包是全部 CAn。
  4. 桥搬运。CAn 是簇、有 ⊢n 这套强完全系统，逐条搬到逻辑侧。
搬出来的性质（UAL §5.5 原文逐条）
  • 强完全的 Hilbert 系统 ⊢n，因而紧致。这正是换语义要治的病：L28 说 Ln 没有有限 Hilbert 系统，Lann 把模型放宽后就有了。
  • La2：Beth 有、有限代数性质有、可判定；重言式公式代数无限但原子。「原子」是个漂亮的细节：原子公式对应原子元素，理论仍可逐点分解。
  • n > 2：三条全反。无 Beth、无有限代数性质、不可判定；而且 n ≥ 3 时可以在里面建集合论，于是重言式公式代数非原子。
代价在哪儿

换来 Hilbert 系统，付出的代价是 n ≥ 2 丢 Beth、n ≥ 3 丢可判定。为什么会这样？Beth 与可判定各走各的桥（L20、L22）：Beth 要看 simpleCAn 里满射是否满，n≥2 时失败；可判定要看自由代数是否原子、理论是否有限基，n≥3 时集合论可解释，全崩。修好完全性桥，不等于修好所有桥。

4案例 6：变量依赖 Lnvd 与「可采纳赋值」 O3

这个语义来自 István Németi，是 guarded fragment 的源头之一。招数正相反：不动代数的抽象性，而是给赋值设卡——只允许某些赋值算数。结果把不可判定性治好了。

定义 5.6.1（变量依赖 FOL，n 变元）

公式集与 Ln 相同。模型是三元组 ⟨M, RM, W⟩：其中 RM ⊆ ⁿM，而

W ⊆ ⁿM　称为可采纳赋值集。

真值定义里唯一但致命的改动在存在量词：

M ⊨ ∃vi φ[h]　⟺　存在 h′ ∈ W，h 与 h′ 至多在 i 处不同，且 M ⊨ φ[h′].

注意关键：h′ 必须在 W 里。原本可以独立挑一个值 a，现在这个 a 与其余赋值的搭配必须「可采纳」。W = ⁿM 的模型叫标准模型，其余叫非标准。

整体有效性：M ⊨vd,n φ 当且仅当对所有 h ∈ W 有 M ⊨ φ[h]；意义函数 mngM(φ) = {h ∈ W : M ⊨ φ[h]}。

直觉 · 把「依赖」编码进 W

「变量依赖」说的是：给 vi 选什么值，可能依赖于别的变量现在取什么值。把这种依赖一次性写进 W——W 本身就是一批「允许同时出现」的赋值——就把依赖逻辑变成了普通逻辑加一个约束。这是相对化技术：从 Csn 相对化到任意 n 元关系 W，得到 Crsn。

顺带一提，它也是 guarded fragment 的亲戚：量词不再是「全宇宙随便挑」，而是「在一个已给定的关系里挑」——这正是 guarded 的精神。

命题 5.6.2

Lvdn 对所有 n < ω 都是可代数化的一般逻辑，且

Algm(Lvdn) = Crsn,　　Alg⊨(Lvdn) = ICrsn.

这里 Crsn 是 n 维相对化柱体集合代数：把 Csn 的顶元从整个 ⁿM 换成 W，柱体算子相应相对化。

Crsn 的代数性质（UAL §5.6 原文六条）
  1. n ≠ 1 时是簇；n ≥ 2 时不是判别式簇。
  2. 等式理论可判定——这是本案例的金矿。
  3. 有有限代数性质与有限基性质：非有效式可以用有限模型当场反证。
  4. n ≥ 3 不可有限公理化，但有一条漂亮的无限公理模式。
  5. 有超合并性质，故满射必满（L21 的桥）。
  6. 自由 Crsn 非原子。
搬到逻辑侧（n ≥ 3）
  • 可判定；非有效式可由有限模型反证。
  • 紧致；但没有有限强完全可靠推理系统——有的只是一条「有限模式、无限多条公理」的 Hilbert 式系统。（对照：Lan 有有限系统却不可判定；两者刚好互补。）
  • 插值有、Beth 有（靠超合并与满射满）。
  • 有弱 Gödel 不完全性，重言式公式代数非原子（靠自由代数非原子）。
直觉 · 两种「非标准」治的是两种不同的病
语义怎么改模型治好了什么代价
Lann模型换成抽象概念代数（放宽）有限 Hilbert 系统、强完全Beth（n≥2）、可判定（n≥3）
Lvdn给赋值加可采纳约束（换种类）可判定、Beth、插值有限 Hilbert 系统

这一对照是全讲最值钱的一格：它证明 L18（紧致＝存在性）与 L19（Hilbert＝生成性）确实是两件事——一个逻辑可以紧致却没有有限证明系统（Lvd），也可以有有限证明系统却不可判定（Lan）。当初把它们分成两座桥，在这里得到回报。

边界 · 不是所有有效式都能救回来

排除一部分非标准模型能找回有效式：要求 W 是所谓的 Dn-单元或 Gn-单元，就能恢复很多重言式且仍可判定。但恢复不了全部：量词交换图式 ∃vi∃vjφ ↔ ∃vj∃viφ 在变量依赖版里无效，而且很难（也许不可能）在保持可判定的前提下靠约束 W 的形状把它找回来。「驯服」一个逻辑是有极限的。

5案例 7：排序版 FOL 与 Gödel 完全性 O4

前面六个案例都是「有限变元」的有限语言。现在放到 ω 个变元，看真正的日常一阶逻辑。这里出现全讲最反直觉的事实：Gödel 完全性成立的版本，恰恰不是代入性的版本。

定义 §5.7（排序版 LrankedFOL）

连接词 Cω = {∧, ¬, ⊥, ∃vi, vi=vj : i,j < ω}。给一个排序函数 ρ : R → ω（ρ(R) 是关系符号 R 的元数），原子公式是 R(v₀,…,vρ(R)−1)——变量序由 ρ 定死，简写为 R。

模型 ⟨M, RM⟩，其中 RM 是 ρ(R) 元关系；意义函数

mngM(R) = {h ∈ ωM : h↾ρ(R) ∈ RM},　M ⊨ φ ⟺ mngM(φ) = ωM.

为了让它成为一般逻辑，签名取 SigFOL = {Dom(ρ) : ρ 是到 ω 的显式函数}。为什么非要「显式」？否则 {(R,2)} 与 {(R,3)} 是两个签名，并起来 {(R,2),(R,3)} 却不是——一般逻辑要求签名对并可封闭（L17 的机构论也在意这件事）。

命题 5.7.1

LrankedFOL 是条件可代数化的一般逻辑，不是可代数化的，并且

Algm(LrankedFOL) = Csfω,　　Alg⊨(LrankedFOL) = Lfω.

这里 Csfω 是 ω 维局部有限正则柱体集合代数，Lfω 是 ω 维局部有限柱体代数。

「条件」二字从哪来？

组合性、滤子性质都直接成立。代入则要加一组条件：

S(ρ) = {R ↔ ∃vi R : ρ(R) ≤ i}.

意思是：如果 R 的元数不超过 i，那么多量化一个用不到的变量不改变含义。有这组等式，代入性质才成立（命题 3.3.33(iii)），所以只能叫「条件可代数化」。

边界 · 它确实不是代入性的

取 n 元关系符号 R，令 φ 为 v₀=v₁ ∧ ⋯ ∧ v₀=vn。那么

⊨ R → ∀vn R,　　但　　⊭ φ → ∀vn φ.

原子公式的元数固定，不能随便拿一个复杂公式的含义来当它——这就是非代入性的根源：原子只能取「有限固定元数」的含义，而公式的含义可以是任意大的有限元数。下一案例专门修这个。

Alg⊨ = Lfω 的证明骨架（教材用了四步）。
  1. 左边包含关系直接；反向要证 S Alg⊨ = Alg⊨，再证 Lfω ⊆ SPC Csfω。
  2. 任取 B ∈ Lfω，写成子直不可约代数 Ai 的积。每个 Ai 是 B 的同态像，故仍在 Lfω；子直不可约的 Lfω 是简单的。
  3. 代数方法证明 simple Lfω ⊆ I Csfω，于是 B 嵌进 ∏ Ai（Ai ∈ Csfω）。
  4. 取其中的有限维元素做成子代数 C：对每个 a 取上界 na，造显式函数 ρ，用同态 f 映到 C ∈ SP Algm，且核包含 S(ρ)。于是 C ∈ Alg⊨，而 B ⊆ C。

这四步值得走一遍：它示范了代数侧怎么用「子直积 → 简单 → 表示」把逻辑的语义闭包算到底，L23 的 Stone 表示也是这个套路。

其他搬到逻辑侧的性质
  • 紧致（定理 4.1.9 + Lfω 的代数性质）。
  • 满射必满：反向走 Beth 定理 + 桥定理 4.3.19，从逻辑搬回代数；这是 L20 那座桥反过来用。
  • 有模型的拼补性质与单元素签名。
推理系统 ⊢ρ 与 Gödel 完全性

加公理模式 (R0) R → ∀vi R（当 ρ(R) ≤ i），记成 Axρ；然后

⊢ρ = {⟨Σ, φ⟩ : Σ ∪ Axρ ⊢ω φ,　Σ ∪ {φ} ⊆ LρFOL}.

即在非排序系统的推理里允许使用 Axρ 作为额外前提。

定理 5.7.2（Gödel 完全性）

对 LρFOL 的每个公式 φ：

⊨ φ　⟺　⊢ρ φ.

证明（教材原文四行，这里拆开）。

  1. 设 ≡ = {(φ,ψ) : ⊢ρ φ ↔ ψ}，F = Fρ/≡。由定理 5.4.6(i)，F ∈ CAω。
  2. F 由有限维元素生成（因为 Rng(ρ) ⊆ ω），故 F ∈ Lfω。
  3. 若 ⊬ρ φ，则 Fρ/≡ ⊭ φ = 1，于是 Lfω ⊭ φ = 1（因为 F ∈ Lfω）。
  4. 由命题 5.7.1 与定理 3.3.5 得 Lfω ⊆ SP Csfω，故 Csfω ⊭ φ = 1，即 ⊭ φ。反向（可靠）显然。
全讲最微妙的一格：图式不完全性

存在有效图式 Φ，满足 ⊨ Φ 却 ⊬ρ Φ。这跟 Gödel 完全性矛盾吗？不矛盾——区别在「逐个」与「统一」：

  • 由定理 5.7.2，Φ 的每个实例都是 ⊢ρ 可证的。
  • 但这些证明因实例而异。虽然有一个统一的「因」Φ 使它们有效，却给不出一个统一的 ⊢ρ 证明。
  • 根源：排序版与非排序版 Lω 的图式语言相同、有效图式也相同（推论 4.2.6，因为 Eq(Lfω) = Eq(RCAω)），⊢ρ 与 ⊢ω 可证的图式也相同。非排序版的图式不完全就这样传了过来。

补救：用定理 7.3.9(i) Dcω ⊆ RCAω，给语言加一族全新变量 wi（不出现在老公式里），并加公理说明它们对老公式无影响，得到 ⊢ρ+；它对公式图式强完全。又是「借变量」——L28 的定理 5.4.7 在这里换了一件衣服重现。

6案例 8：无排序版 FOL 与不紧致反例 O5

无排序版由 Henkin–Tarski 引入。它把上一案例的「补丁」ρ 直接删掉：关系符号的元数不写在语言里，交给模型决定。结果代入性修好了，紧致性与 Beth 却塌了。

定义 §5.8（无排序版 LrfFOL）

原子公式仍是关系符号 R 本身，但没有 ρ 告诉它几元。模型

MR = {⟨M, RM⟩R∈R : (∀R ∈ R)(∃n ∈ ω) RM ⊆ nM},

即每个 RM 是某个有限元数上的关系，元数由模型现场给。意义函数

mngM(R) = {h ∈ ωM : h↾n ∈ RM 对某个 n}.
命题 5.8.1

LrfFOL 是可代数化的一般逻辑（这次没有「条件」二字），且

Algm(LrfFOL) = Csfω,　　Alg⊨(LrfFOL) = SP Lfω.

注：教材这里第二个等式误印成 Algm；由 SP Csfω = SP Lfω 可知应为 Alg⊨，本讲按正确写法。

为什么代入性这次成立？因为 MngR = Hom(FR, Csfω)：原子符号的元数不固定，它可以取任意有限元公式的含义——上一案例那个「固定元数」的枷锁去掉了。

不紧致的漂亮反例（教材用三行，这里逐步走）。

取任意一个关系符号 R，令

Σ = {¬(R ↔ ∃vi R) : i < ω}.
  1. 先看每条公式在说什么。R → ∃viR 总有效（L28 的柱体公理）；反向 ∃viR → R 成立，当且仅当 R 的含义不依赖第 i 个变量。
  2. 所以 ¬(R ↔ ∃viR) 在说：「R 确实依赖第 i 个变量」。
  3. 有限子集可满足。给定 {i₁,…,ik}，取模型让 RM 是 m 元关系（m > max ij），且真的依赖这 k 个变量。可行。
  4. 整体不可满足。任何模型里 RM 只有某个固定有限元数 m；对一切 i ≥ m，R 不依赖 vi，于是 R ↔ ∃viR 成立，Σ 那条公式失败。

结论：LrfFOL 不紧致。由定理 4.1.6 反向读出代数事实 SP Csfω ≠ Up SP Csfω——这是逻辑直觉帮代数挣来的结果，教材特意点出这一点。

弱 Beth 也失败（教材的反例，讲清直觉）

取关系符号 R, S，令 π(i)R 表示「把 R 的前两个变元交换」的公式（教材用 ∃vi(vi=v₀ ∧ ∃v₀(v₀=v₁ ∧ ∃v₁(v₁=vi ∧ R))) 写出来）。考虑

Σ = {∀v₀∀v₁((∃viR ↔ R) → (S ↔ π(i)R)) : i ≥ 2}.

当 R 不依赖第 i 个变量时，π(i)R 的含义就是「交换 R 前两个变元」，而且与选哪个 i 无关。所以 Σ 是「S 由 R 强隐含定义」的一组句子。但没有显式定义：任给公式 φ，取 n 严格大于 φ 中出现的最大变元指标，在 M = n × n 上造一个特制的 RM（按 ai(0)=i 与 Σ ai(1) ≡ 0 (mod n) 规则），可验证 φ 的含义不等于 Σ 所规定的 S。

代数回响：SP Lfω 中满射不满，而 Lfω 中满射满（上一案例）。同一个 Beth 桥，在两个代数类上给出相反答案——又一次「逻辑帮代数」。

推论 5.8.2（非有限图式公理化）

若 ⟨Ax, Ru⟩ 定义了对 LrfFOL 强可靠且弱完全的推理系统 ⊢，则 Ax 与 Ru 必须涉及无穷多个公式变元。Lω 同样。依据是定理 7.3.4：RCAn 不是有限图式可公理化的。

这不推翻 Gödel——口径要钉死

读者容易觉得推论 5.8.2 与 Gödel 完全性冲突。不冲突：Gödel 定理 5.7.2 只对排序版 LrankedFOL 成立，对 LrfFOL 不成立。两个版本的本质差别是：

LrankedFOL 不是代入性的；　LrfFOL 是代入性的.

教材的原话更狠：已知的结构化一阶逻辑版本里，没有一个能让 Gödel 完全性成立——除了少数靠加新连接词绕开推论 5.8.2 的构造（[190] 等）。代入性与完全性在这里是鱼与熊掌。

三版 FOL 的同与异
版本有效图式可容许规则有效性判定Gödel 完全
非排序 Lω三者相同三者相同，且可容许图式集递归可枚举不可判定（定理 7.3.3 + 4.2.5 + 4.5.2）无

无排序 Lrf无

「相同」的理由是一条代数等式：SP Up Csfω = RCAω = Alg⊨(Lω)。三版代数化后的形式共享同样的准等式，故有效图式与可容许规则一致（定理 4.2.5）。形式一样，脾气不同——差别全在「算不算模型」。

直觉 · 读这张表的三个心得
  1. 紧致几乎永远有。六个案例里只有无排序版不紧致。紧致是「有限片段相容就有模型」的存在性承诺（L18），只要模型类还容纳得下超积极限，它就在。无排序版丢紧致，是因为「关系的元数」这件事本身可以是无穷的。
  2. Beth、插值、可判定各走各的桥。L2 可判定却无 Beth；Lvd 三者全有却无有限 Hilbert；Lan 有 Hilbert 却无 Beth。三座桥的前提互不相同，所以出现「东边晴西边雨」是常态，不是矛盾。
  3. 代数对应物决定一切。同一个公式集，Algm 从 {2} 换到 setRRA、simpleCAn、Crsn、Csfω，桥定理读出的性质就全变。L27 的四步流程不是比喻，是真的机器。
「没有免费午餐」的精确说法

每换一次语义，都是在有效式集与桥定理的前提之间做交易：

  • 放宽模型 → 有效式减少 → 可能捞回 Hilbert 系统（Lan），代价是 Beth 与可判定。
  • 给赋值设卡 → 有效式减少 → 捞回可判定与 Beth（Lvd），代价是有限 Hilbert 系统。
  • 加排序信息 → 捞回 Gödel 完全性（Lranked），代价是代入性与图式完全性。
  • 删排序信息 → 捞回代入性（Lrf），代价是紧致、Beth 与完全性。

一句话收束这一篇：桥定理告诉你「若代数有性质 P，则逻辑有性质 Q」；它从不承诺你能同时把 P 全占齐。案例工坊教的就是挑哪几座桥过。

8三层例：典型 / 本质 / 边界 理解检验

典型 L2 与 La2：一对照就看明白

两个逻辑的公式集一模一样，模型类不同：L2 用通常关系模型，La2 用简单 CA2 当模型。结果：La2 多了一个强完全 Hilbert 系统，仍有 Beth 与可判定，重言式公式代数无限却原子。这是「放宽模型捞回完全性」最干净的一例——代价小到几乎看不出来。但一到 n ≥ 3，同样操作就付出不可判定的代价，说明便宜是小维数的运气。

本质 Lvdn：相对化是「驯服逻辑」的通用技术

把 Csn 的顶元从整个 ⁿM 换成任意 n 元关系 W，得到 Crsn；逻辑上就是「量词只能在可采纳赋值里挑值」。这一步的本质不是「加限制」，而是「换顶元」——格还是那个格，1 换了，所有运算跟着相对化。它同时解释了三件事：为什么可判定（代数理论可判）、为什么有插值（有超合并）、为什么没有有限 Hilbert 系统（不可有限公理化）。一个动作，三个后果，全由桥定理读出。它还连着 guarded fragment 与 L26 的 locale：相对化与局部化是同一个念头的不同外衣。

边界 LrfFOL：把「元数」交给模型会怎样

去掉 ρ 之后，原子符号可以先是二元、后在另一个模型里是三元——公式本身不说。这救回了代入性（原子可取任意有限元公式的含义），却让公式集 {¬(R ↔ ∃viR)} 变成一个漂亮的不紧致反例：每个模型里 R 的元数是有穷的，但模型之间可以任意大，于是「每个有限片段都能满足、整体不能」。这条反例和上一条「捞回代入性」是同一个改动的两面——元数不固定既是药也是毒。再往边界站一步：若要求 W 是 Dn-单元或 Gn-单元，能找回不少重言式且保持可判定，但量词交换图式始终找不回来。驯服有极限，这是本讲的最后一道边界。
