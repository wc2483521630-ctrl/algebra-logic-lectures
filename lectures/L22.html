2动机：五个「有限」不是一回事

它解决什么问题

前面四座桥换了四种眼镜看同一个逻辑：有模型吗、能证明吗、能定义吗、能插值吗。这一问第五个、也是最有现实味道的问题：给定一句话，机器能不能在有限步内告诉我它对不对？

一听就有一堆「有限」冒出来，它们长得像、其实完全不同。先把它们分开，这一讲就不会乱：

「有限」说的是什么在哪一讲
有限证明每份证明是有限长的对象L19：给紧致性、给 r.e.
有限公理化 / 有限基公理或等式的条数有限L19 / L07：可存储的数据
有限模型 / 有限代数结构本身的元素个数有限本讲 O3：反例的落脚点
有限步终止算法对每个输入都停机本讲 O1：可判定的定义
有限个条件翻译出有限多条等式要同时检验本讲 O2：搬运可判定性的关键

最常犯的错是把「公理写得下」当成「机器算得出」。一阶逻辑的公理就写得下，有效性却算不出（Church）。本章最后两节，一半在讲「算得出」的代数条件，一半在讲「算不出」为什么反而是一种可以代数化的性质。

3可判定与递归可枚举 O1

先把算法这个词说精确。以下都是教材给出的直观说法，再由 Church 论题支撑：递归函数、图灵机可计算、各种合理的形式化，定义的都是同一个概念。

定义 3.1（可判定 / 递归可枚举）

设 A 是对象集合 H 的子集。

  • A 可判定（可计算）：存在算法，对任意 h ∈ H，在有限步后回答 h ∈ A 还是 h ∉ A。
  • A 递归可枚举（r.e. / 半可判定 / 图灵可识别）：存在算法，若 h ∈ A 则有限步后指出这一点；若 h ∉ A 则可能永远不指出。等价说法：有算法把 A 的成员逐个列成一张表（可以无穷长、可以永不停）。

注意两个定义的差别只在「否」的那一侧：可判定要求「是」与「否」都能在有限步给出；r.e. 只要求「是」能给出。

例 3.2（教材给的例子）
  • 可判定：空集、全集、任何有限集或余有限集、素数集；命题逻辑的有效式集（在全体命题公式中）。
  • r.e. 但不可判定：一阶逻辑的有效式集。由完全性定理，有效的公式能被证明枚举出来；由 Church 定理，没有一个算法能判定任意公式是否有效。
  • 连 r.e. 都不是：真算术（标准自然数模型里所有真的句子），Tarski 的不可定义性定理。
命题 3.3（判别法）

设 H 可判定（在逻辑里就是「公式的语法可判定」），则

A 可判定　⟺　A 是 r.e. 且 H − A 也是 r.e.
证明（分两步，一步一个方向）。

第 1 步（⇒）：设有判定算法 D。因 H 可判定，可把 H 的对象排成一个有效序列 h₁, h₂, h₃, …。造枚举 A 的程序：依次取 hn，用 D 测，回答「是」就输出它。造枚举补集的程序：同样的循环，回答「否」就输出。这里用到 D 对每个输入都停机——否则循环会卡住，两个枚举都造不出来。

第 2 步（⇐）：设 EA 枚举 A，E¬A 枚举补集。对输入 h，交错运行这两个程序：跑 EA 一步、跑 E¬A 一步、再各跑一步……因为 h 必在且只在一个集合里，它终会在某一条输出流里出现。出现在 EA 就答「是」，出现在 E¬A 就答「否」。∎

定义 3.4（逻辑的可判定；UAL 4.5.1）

逻辑 L = ⟨FL, ML, mngL, ⊨L⟩ 可判定，若它的有效式集

ThL(ML) = CsqL(∅) = { φ ∈ FL : ⊨L φ }

是 FL 的可判定子集。同理说 L 的有效式 r.e.，指这个集合是 r.e.。

为什么先定义集合，再定义「逻辑可判定」

因为可判定性本来就是集合的性质：给一个集合，问「判断归属」的算法存不存在。逻辑只是提供了「哪个集合」——有效式集 CsqL(∅)。把这两层分开，后面才能把问题原封不动搬到代数的等式集合上（§4）。

典型例子

命题逻辑可判定。给公式 φ，列出它出现的 n 个变元的所有 2n 个真值指派，逐个算 φ 的值。全真则有效，否则反例就是一个指派。这就是「两个半判定并行」的最简单样子：真值表从两头把答案夹住。

本质例子

为什么 r.e. 不够？一阶逻辑有效式是 r.e.：不断跑证明搜索，有效式终会被证出。但无效式呢？没有通用办法知道「还要找多久」——搜索可能永远不停。r.e. 只给了「是」那半边，缺「否」那半边；可判定 = 两半边都齐。下面所有技术（fmp、fap）本质上都是在补另外半边。

边界与误解

「判定」不等于「快速判定」。可判定只要求有限步终止，不要求步数少。真值表算法的步数是指数的，仍然是判定算法。复杂度是另一个问题，本讲不碰。

来源：UAL §4.5 开头关于可判定与 r.e. 的讨论及定义 4.5.1；命题 3.3 是教材所述「A 可判定 ⟺ A 与补集都 r.e.」的展开证明。

4定理 4.5.2 的完整展开 O2代数

这一节把教材那句「由推论 3.3.25 直接得出」拆开。要拆它，先得弄清推论 3.3.25 到底给了什么。

推论 3.3.25（UAL；翻译机制）

设 L 是 nice 逻辑（合成、有滤子性质、有语法替换性质）。按定义 3.3.18 取定翻译项 εj, δj（j < m）与 Δi（i < n）。则：

  1. 对任意公式 φ：
    ⊨L φ　⟺　Algm(L) ⊨ εj(φ) = δj(φ)　对每个 j < m.
  2. 对任意等式 τ = τ′：
    Algm(L) ⊨ τ = τ′　⟺　⊨L τ Δi τ′　对每个 i < n.

而且这两条对 Alg⊨(L) 也成立：因为二者有相同的准等式理论。

第 0 步：翻译项是什么，为什么它能搬运「可判定」

UAL 的代数化给每台逻辑配了一本双语词典，而且是有限本：

  • 公式 φ ⟶ m 个等式 ε0(φ)=δ0(φ), …, εm−1(φ)=δm−1(φ)；「φ 有效」等于「这 m 个等式都成立」。
  • 等式 τ = τ′ ⟶ n 个公式 τ Δ0 τ′, …, τ Δn−1 τ′；「等式成立」等于「这 n 个公式都有效」。

关键不在翻译存在，而在翻译可计算：εj, δj, Δi 是由逻辑的连接词表固定的有限个模式，给定 φ 或 τ = τ′，机械地代入就得到结果。m 与 n 都固定且有限，于是「同时检验 m 个条件」总能在有限步内做完。这两点合起来，才是「可判定性可以从逻辑搬到代数」的全部本钱。

举个具体的：命题逻辑里 m = n = 1，ε₁(φ) = φ，δ₁(φ) = 1，τ Δ₁ τ′ = τ ↔ τ′。推论 3.3.25 说的就是「φ 有效 ⟺ 在布尔代数里 φ = 1」，你早就用过，只是没意识到它有个名字。

定理 4.5.2

设 L 是 nice 逻辑。则

  1. L 可判定 ⟺ Alg⊨(L) 的等式理论可判定。
  2. L 的有效式 r.e. ⟺ Alg⊨(L) 的等式理论 r.e.
证明（四个小步，两个方向各两步；先做 (i)）。

第 1 步（假设 L 可判定，证等式理论可判定）。输入是一个等式 e : τ = τ′，要判断 Alg⊨(L) ⊨ e 是否成立。

① 用翻译项算出 n 个公式 τ Δi τ′（i < n）——机械操作，有限步。

② 对这 n 个公式逐个调用 L 的判定算法，问它们是否有效。

③ 由推论 3.3.25(2) 的 Alg⊨ 版，Alg⊨(L) ⊨ τ = τ′ ⟺ ⊨L τ Δi τ′ 对所有 i < n。所以：全部回答「是」就输出「成立」，只要有一个回答「否」就输出「不成立」。

④ n 有限，每步算法都停机，故整个过程有限步终止。∎

第 2 步（假设等式理论可判定，证 L 可判定）。输入是公式 φ，要判断 ⊨L φ。

① 用翻译项算出 m 个等式 εj(φ) = δj(φ)（j < m）。

② 逐个调用等式理论的判定算法。

③ 由推论 3.3.25(1) 的 Alg⊨ 版，⊨L φ ⟺ Alg⊨(L) ⊨ εj(φ) = δj(φ) 对所有 j < m。全「是」则有效。

④ m 有限，有限步终止。∎

第 3、4 步（(ii) 的 r.e. 版本）。把上面的「判定算法」换成「半判定过程」即可：

③′ 需要用到一条可计算性的小事实：有限个 r.e. 集的交仍 r.e. 做法是并排跑这 m（或 n）个枚举程序，只有当一个对象在每一条输出流里都出现过，才把它输出。每个「是」终会各自到达，全部到达在有限步内完成。

④′ 于是：有效式 r.e. ⟹ 逐条跑半判定、用上面的并行交得到「等式成立」的半判定 ⟹ 等式理论 r.e.；反向同理。∎

一处必须说清：为什么用 Alg⊨，不用 Algm

L20、L21 反复强调 Algm(L) 不对同构封闭、可定义性非它不可。这里为什么换成了 Alg⊨(L)？因为本问的是等式理论，而定理 3.3.36 给出 Alg⊨(L) = SP Algm(L)：抽象类是具体类的子代数与直积的闭包。等式在 S 与 P 下都保持（Birkhoff，L04），所以两个类满足完全相同的等式，等式理论是同一个集合。换成抽象类的好处是它是拟簇、结构整齐；坏处（丢掉模型身份）在这里无关紧要，因为我们不问可定义了。

典型例子

命题逻辑。m = n = 1，翻译退化为「有效 ⟺ 等于 1」。命题逻辑有效式可判定（真值表），于是布尔代数的等式理论可判定（在有限多个变元生成的自由布尔代数里检验）。两边其实是同一个算法。

本质例子

搬运可判定性的机制不是「有个翻译」而是「翻译可计算 + 只有有限多条」。若推论 3.3.25 里的 m 或 n 是无穷，第 1 步就要检验无穷多个条件，算法不再保证停机。定理 4.5.2 真正依赖的是「有限多」这三个字。

边界与误解

nice 这个条件不能随便丢。推论 3.3.25 要求合成、滤子性质、语法替换性质。逻辑若不 nice，双语词典可能不成立，定理 4.5.2 的搬运就会断。做题时先检查逻辑是否 nice。

来源：UAL 定理 4.5.2 与推论 3.3.25、定理 3.3.36；L16 关于 Algm 与 Alg⊨ 的区分；命题 3.3 的「有限个 r.e. 集之交 r.e.」。

5有限模型 / 有限代数性质 O3

定理 4.5.2 把「逻辑可判定」搬到「等式理论可判定」，但没说等式理论凭什么可判定。这一节补上另外半边算法。

定义 5.1（fmp；UAL 4.5.3）

逻辑 L 有有限模型性质，若对任意公式 φ：

⊨L φ　⟺　对所有有限 M ∈ ML，M ⊨L φ.

说人话：要否定一个有效式，有限反例就够。

定义 5.2（fap；UAL 4.5.5）

nice 逻辑 L 有有限代数性质，若对任意等式 e：

Alg⊨(L) ⊨ e　⟺　对所有有限 A ∈ Algm(L)，A ⊨ e.

注意教材特意说明：逻辑可以有 fap 而没有 fmp——因为模型未必有「底集」这个东西，有限模型性质要求的前提更强。

命题 5.3（UAL 练习 4.5.4 / 4.5.6，写出完整证明）

设 L nice 且有效式 r.e.（等价地，由 4.5.2，等式理论 r.e.）。

  1. 若 L 有 fmp，则 L 可判定。
  2. 若 L 有 fap，则 L 可判定。
证明（只写 (2)，(1) 把「等式 / 有限代数」换成「公式 / 有限模型」，逐字一样）。

目标：判定等式 e 是否属于 Eq(Alg⊨(L))。按命题 3.3 的判别法，只要造出「是」与「否」两个半判定。

第 1 步（「是」的半判定，来自 r.e.）。等式理论 r.e.，有枚举程序列出所有成立等式。输入 e，跑这个枚举，若 e 出现就答「成立」。这一步完全不需要 fap。

第 2 步（「否」的半判定，来自 fap）。这里要拆出两个隐含前提，教材把它们写在练习的语境里，我们明说：

① 有限代数 A ∈ Algm(L) 可以有效枚举（每个有限代数有有限的描述，按描述的长度排）；

② 给定有限代数 A 与等式 e，判断 A ⊨ e 是有限步可检验的——穷举 A 中所有的赋值（|A|k 个，k 是变元数），逐个计算等式两端。

于是造程序：枚举所有有限代数 A ∈ Algm(L)，对每个用 ② 检验 A ⊨ e；一旦找到某个 A 使 A ⊭ e，就答「不成立」，并把这个 A 作为反例输出。

第 3 步（fap 保证这个程序对「否」一定停下）。若 Alg⊨(L) ⊭ e，由 fap 的逆否命题，存在有限 A ∈ Algm(L) 使 A ⊭ e。第 2 步的枚举终会遇到它。没有 fap，这个反例可能只存在于无穷代数里，程序就永远找下去。

第 4 步（并行）。交错运行第 1 步与第 2 步。e 要么成立（第 1 步终停），要么不成立（第 2 步终停），二者必居其一且不会同时。由命题 3.3，等式理论可判定。∎

这一节的灵魂：fap 是「反例有限化」

把证明倒过来看：r.e. 给了「对」的枚举，fap 说「错」也一定有个有限证人。一个性质如果对与错都有有限证人，就能被算法两头夹住。一阶逻辑为什么不可判定？因为它有 r.e.（完全性定理给证明枚举），却没有 fmp——有的理论只有无穷模型。Church 的不可判定性在这里换了个角度重新出现：不是「证明搜不到」，而是「反例无处落脚」。

典型例子

命题逻辑有 fmp。任一非有效公式 φ，取它出现的有限个变元上的真值表，必有一个指派使它为假——有限反例就在眼前。配合 r.e.（证明搜索）得到可判定，这就是真值表算法的理论版本。

本质例子

模态 S5 有 fmp：非有效的模态公式能在有限 Kripke 框架里被否证。而有些模态逻辑没有 fmp——它们的反例框架必须无穷。于是「有没有 fmp」直接分裂出「可判定 / 不可判定」两大片逻辑。教材 §4.5 的大量练习就是在逐台逻辑验这件事。

边界与误解

① 「有限反例存在」还不够，要能找到。证明第 2 步用了两个可计算性前提（有限代数可枚举、有限检验可计算）。若一个逻辑的有限模型类虽然存在却不可有效枚举，fmp 也换不来算法。

② fmp 与 fap 不互推。fmp 是关于模型的，fap 是关于代数的；教材明确说 fap 可以在模型没有底集时仍成立。别把两者当同义词。

来源：UAL 定义 4.5.3、4.5.5 与练习 4.5.4、4.5.6；命题 3.3；L18 紧致性（无穷模型存在的对偶背景）。

6有限基问题与判定性 O4逻辑

大纲要求「从代数簇的有限基问题看逻辑的可判定性」。这一节把这条线拉直，并把最容易混的几件事分开。

定义 6.1（有限基；Bergman §5.4）

簇 V 有有限基，若存在有限等式集 E 使 V = Mod(E)；等价地，V 的等式理论由有限条等式生成。一个代数 A 有限基，指 Var(A) 有限基。

有限基与可判定：既有联系，又不是一回事
有限基可判定
问的是公理/等式写得下吗算法存在吗
类型数据的有限性过程的终止性
能保证什么等式理论 r.e.（有限公理的推演是可枚举的）r.e. + 反例可判定
不能保证什么不能保证算法终止（一阶逻辑是活教材）不能保证公理写得下

关系是单向的：有限基 ⟹ r.e.，但 r.e. ⟹ 可判定还要再补 fap/fmp（§5）。所以「有限公理化」是走向「可判定」的第一步，不是最后一步。

例 6.2（非有限基的簇；Bergman 定理 5.28）

存在一个四元、有限型的群胚 A = ⟨A, ·⟩，使 Var(A) 不是有限基——无论写多少条等式，总还差一条。注意 A 本身是有限的：这又一次说明「有限代数」与「有限基」是两个完全不同的「有限」。这是 Birkhoff 提出的著名问题，答案是否定的。

例 6.3（有有限基的充分条件；L07 回指）

Bergman 定理 5.35 / 5.40（L07 §4）：若 V 有 DPSC 且 Vsi 有限可公理化，则 V 有限基；特别地，每个有限生成、同余分配、有限型的簇有限基。这里用的还是 Jónsson 引理把 Vsi 压进 HS(K) 那一步——L07 的工具在这里收账。

命题 6.4（本讲关心的方向）

对 nice 逻辑 L：

  1. L 有限公理化 ⟺ Alg⊨(L) 有限基。（靠 Birkhoff 翻译，L19 O5）
  2. L 有限公理化 ⟹ 有效式 r.e.；再若 L 有 fmp/fap ⟹ L 可判定。
  3. 反过来不成立：存在不可有限公理化但仍可判定的逻辑（UAL §7 案例里的相对化柱面代数 CrSn（n ≥ 2），等式理论可判定，却非有限公理化）。
第 2 条的三步推导。

① 有限公理化意味着只有有限条公理模式与有限条推理规则。枚举所有有限长的证明序列，逐个检查——这是有效枚举，所以定理集 r.e.。

② 有效式 r.e. ⟹（由 4.5.2(ii)）Alg⊨(L) 的等式理论 r.e.。

③ 若再有 fmp/fap，由命题 5.3，可判定。注意第二步与第三步分别用掉了推论 3.3.25 与有限反例，缺一不可。∎

典型例子

布尔代数、群、格、环都是有限基且可判定（在等式理论层面）。对应命题逻辑等有限公理化且可判定的逻辑。这些是「公理写得下、算法也算得出」两全的样板。

本质例子

一阶逻辑：公理写得下，算法算不出。它是有限公理化的（L19），有效式 r.e.（完全性定理），但没有 fmp，于是第 ③ 步断了。这件事把「有限公理化 ≠ 可判定」钉死在最核心的例子上。

边界与误解

非有限基 ≠ 不可判定。Bergman 5.28 的四元群胚生成的簇不是有限基，但 Var(A) 的等式理论仍可判定：A 有限，等式在 Var(A) 成立当且仅当在 A 成立，而有限代数上的等式可逐一赋值检验。「写不下」和「算不出」是两种独立的能力缺陷。

来源：Bergman §5.4（定义、定理 5.28、5.35/5.40）；UAL 4.5.2、L19 O5、L07 §4；UAL §7 关于 CrSn 的讨论（7.3.5 附近）。

7Gödel 不完全性的定义学 O5

现在进入第 4.6 节。先别急着证，先看定义为什么长这样——这一步跳过去，后面的证明就像变魔术。

为什么不说「Γ 不完全」，要说「Csq(Γ) 不可判定」

日常说法是「算术不完全：有真句子既证不出也否不掉」。这话得有「否定」才讲得通。但 UAL 的逻辑 L = ⟨F, M, mng, ⊨⟩ 可能压根没有否定连接词——那样「不完全」三个字就没有定义。

教材于是换成一个不依赖否定的说法：Γ 的后承集 CsqL(Γ) 可不可判定。在一阶逻辑里这两件事对得上：r.e. 且完全的理论必可判定（练习 4.6.4(1)，马上证），所以后承集不可判定 ⟹ 理论不完全。定义 4.6.1 用不可判定，是把「不完全」这个概念推广到没有否定的逻辑上去的血液。

但教材也提醒了反向不成立：代数闭域理论（任意特征）可判定却不完全。所以「可判定」比「完全」弱，别把两个词混用。

约定 4.6.2（五条前提）
  1. L 是结构逻辑（合成 + 两种替换性质）。
  2. L 含经典命题逻辑作片段，即 Alg⊨(L) 有布尔归约，用标准连接词。
  3. 布尔的 → 是演绎项。
  4. FL 可判定（公式的语法与字符串可机械识别）。
  5. 若 Γ ⊆ FL r.e.，则 CsqL(Γ) r.e.。
  6. 记号 Fr = F / ∼M 为 M 的 Lindenbaum–Tarski 代数。
定义 4.2.16（演绎项；回指 L19）

公式模式 Φ₁ ∇ Φ₂ 是 L 的演绎项，若对所有 Σ ⊆ FL、φ, ψ ∈ FL：

Σ ∪ {φ} ⊨L ψ　⟺　Σ ⊨L φ ∇ ψ.

命题逻辑取 ∇ = →，S5 取 Φ₁ → □Φ₂（UAL 4.2.17）。它就是把「多一条前提」折算成「一条公式」的语法装置，L19 的演绎定理在这里正式命名。本节的每个证明都会用到它。

定义 4.6.3（Gip / wGip）与 4.6.1（Gip⁺ / wGip⁺）
  • Gip：存在公式 φ，使对所有递归理论 Γ，若 φ ∈ Γ 且 Γ 一致，则 Γ 不完全且不可判定。
  • wGip：同上，但只要求对所有有限 Γ。
  • Gip⁺ / wGip⁺：只保留「CsqL(Γ) 不可判定」那一半，不提完全性。

显然 Gip ⟹ wGip、Gip ⟹ Gip⁺；反向一般不成立（教材引 [166] 定理 1.6(b) 给出反例）。

练习 4.6.4(1)（写出完整证明）

设 Γ r.e. 且完全，则 Γ 可判定（即 CsqL(Γ) 可判定）。

证明（又是一个「两半判定并行」，这一次的「否」半边靠否定与完全性）。

第 1 步（「是」半判定）。由约定 4.6.2(5)，Γ r.e. ⟹ CsqL(Γ) r.e.。枚举它，输入 ψ，一旦出现就答「ψ ∈ Csq」。

第 2 步（「否」半判定）。输入 ψ，在同一个枚举里改等 ¬ψ。由完全性，Γ ⊨ ψ 或 Γ ⊨ ¬ψ，必有一个终会出现。若 ¬ψ 先出现，则 ψ ∉ CsqL(Γ)——这里用到 Γ 一致：否则两者都成立，不能下结论。

第 3 步（一致性的处理）。若 Γ 不一致，则 CsqL(Γ) = FL，而 FL 可判定（约定 (4)），直接答「全是」。所以证明要分两支：不一致时平凡；一致时靠上面两步的并行。

第 4 步。两支覆盖所有情形，由命题 3.3 得 CsqL(Γ) 可判定。∎

这条练习是 Gip 定义的命脉

它说明：在一阶逻辑里，「完全」几乎等于「可判定」（r.e. 的前提下）。所以「有一个一致的递归理论，其后承不可判定」就自动推出「它不完全」——这正是 Gip 想抓住的东西。整节的定义学就靠这一条练习撑住。

命题 4.6.6（UAL；可判定 ⟹ 无 wGip⁺）

设 L 有演绎项 ∇（不要求满足约定 4.6.2）。若 L 可判定，则 L 没有 wGip⁺。

证明（教材原文很短，这里补上每一步的理由）。

第 1 步。L 可判定，即 CsqL(∅) 是递归集（定义 4.5.1）。

第 2 步（目标转换）。要否掉 wGip⁺，只需证明：对任意一致的 φ，CsqL(φ) 可判定——因为 wGip⁺ 要求「所有有限扩张都不可判定」，找到一个可判定的有限扩张（例如 {φ} 本身）就足以否证它。

第 3 步（用演绎项改写集合）。令 Σ = ∅，演绎项定义给出

CsqL(φ) = { ψ : φ ⊨L ψ } = { ψ : ⊨L φ ∇ ψ }.

第 4 步（可判定性转移）。映射 ψ ↦ φ ∇ ψ 是语法代入，可计算；CsqL(∅) 可判定；于是它的可计算前像 {ψ : ⊨ φ ∇ ψ} 也可判定：给定 ψ，算出 φ ∇ ψ，问判定器。∎

典型例子

命题逻辑没有 Gip。它可判定（真值表），由 4.6.6 连最弱的 wGip⁺ 都没有。「强到能编码算术」才有不完全性，命题逻辑不够强。

本质例子

演绎项在这里干什么？它把「带一条前提的后承」变成「空前提的后承」。可判定性本来只对 Csq(∅) 知道，演绎项把这份知识传递给每个 Csq(φ)。这是全讲第二次看到「语法折算」给算法帮忙（第一次是 §4 的翻译项）。

边界与误解

4.6.6 只否掉 wGip⁺，没否掉 wGip。因为 wGip 还要谈「不完全」，而这里没有假设约定 4.6.2 的布尔结构。下一节的 4.6.7 在更强前提下才把 Gip 一并否掉。

来源：UAL 定义 4.6.1/4.6.2/4.6.3、练习 4.6.4(1)、命题 4.6.6；定义 4.2.16 演绎项；L19 演绎定理。

8定理 4.6.6 / 4.6.7 / 4.6.8 完整证明 O6逻辑

这一节是全讲的高潮：先证「可判定 ⟹ 无 Gip」，再证「wGip ⟺ 自由代数非原子」。两处都逐步展开，含教材的两个断言。

定理 4.6.7（UAL；可判定 ⟹ 无 Gip）

设 L 满足约定 4.6.2。若 L 可判定，则 L 没有 Gip。

证明（教材给了一个递归构造，这里把每一步为什么可行写全）。

第 1 步（目标）。要否掉 Gip，就要证明：任意一致公式 φ 都能扩张成一个递归的、完全的理论 Γ。由练习 4.6.4(1)，这样的 Γ 自动可判定，于是 φ 不可能见证 Gip。

第 2 步（枚举）。FL 可判定（约定 4.6.2(4)），所以公式可有效枚举成 {φi : i ∈ ω}。

第 3 步（逐步扩张）。令 Γ₀ = {φ}，递归定义

Γn+1 = Γn ∪ {φn}　若 Γn ⊭L ¬φn;　否则 Γn ∪ {¬φn}.

第 4 步（每一步可判定，这是构造的核心）。判断「Γn ⊨ ¬φn」是否可行？Γn 有限，把它合取成一个公式 γn = ∧Γn，反复用演绎项得 Γn ⊨ ¬φn ⟺ ⊨ γn → ¬φn。右侧是 CsqL(∅) 的归属判定问题，而 L 可判定。所以每一步的选择是算法可做的，整个 Γ 是递归构造出来的。

第 5 步（完全）。每个 φi 在第 i+1 步被决定：要么它自己被加入，要么 ¬φi 被加入。故 Γ = ⋃n Γn 完全。

第 6 步（一致与递归）。每步只加入与已有部分相容的一侧，一致性归纳保持；Γ 作为公式集是递归的（给定 ψ，找到其编号，模拟到第 i+1 步即可判定它是否被加入）。

第 7 步（收尾）。Γ r.e. 且完全，由 4.6.4(1) 可判定。所以任意一致 φ 都有完全的可判定扩张，没有公式能见证 Gip。∎

定理 4.6.8（UAL；wGip ⟺ Fr 非原子）

设 L 满足约定 4.6.2，Fr = F / ∼M 是其 Lindenbaum–Tarski 代数。则

L 有 wGip　⟺　Fr 不是原子代数.
先搭翻译枢纽：四行等价是整个证明的转轴

由命题 3.3.38，Fr 是 Alg⊨(L) 的自由代数，二者有相同等式理论。布尔序 ≤ 是等式，于是对任意公式 φ, ψ：

Fr ⊨ φ ≤ ψ　⟺　Alg⊨(L) ⊨ φ ≤ ψ　⟺　⊨L φ → ψ　⟺　φ ⊨L ψ.

四行逐一读：① 自由代数的等式理论 = 类的等式理论；② 等式翻译回公式（推论 3.3.25）；③ 演绎项把带前提的后承折成无条件有效式。「公式 φ 后承 ψ」从此可以读成「代数里 φ/∼ ≤ ψ/∼」——证明就在代数里做。

再记一条：τ/∼ 是原子，指它非零且对任意 ψ，τ/∼ ≤ ψ/∼ 或 τ/∼ ≤ ¬ψ/∼。把 ≤ 翻译成后承，这条就是说「τ 能决定每个公式的真假」——也就是一个完全理论。定理 4.6.8 的全部内容，就是把这句话的两个方向走一遍。

方向一（⇒）：wGip ⟹ Fr 非原子（含断言 4.6.9、4.6.10）。

第 1 步。设 φ 见证 wGip：任何含 φ 的有限一致 Γ 都使 CsqL(Γ) 不可判定。φ 一致，故 φ/∼ ≠ 0。

第 2 步（反设）。假设 φ/∼ 下面有原子 τ/∼：即 τ/∼ ≤ φ/∼（翻译回来是 τ ⊨ φ），且 τ/∼ ≠ 0。令 Γ = {τ, φ}——有限、含 φ、一致（因 τ/∼ ≠ 0）。

第 3 步（断言 4.6.9：Γ 完全）。任取 ψ。因 τ/∼ 是原子，τ/∼ ≤ ψ/∼ 或 τ/∼ ≤ ¬ψ/∼。用翻译枢纽读作 τ ⊨ ψ 或 τ ⊨ ¬ψ。又 τ ⊨ φ，所以 Γ ⊨ ψ 或 Γ ⊨ ¬ψ。完全性得证。

第 4 步（断言 4.6.10：CsqL(Γ) 可判定）。① 由约定 4.6.2(5)，Γ 有限故 r.e.，所以 CsqL(Γ) r.e.。② 由完全性与一致性，教材写下一个干净的等式：

F − CsqL(Γ) = { ¬ψ : ψ ∈ CsqL(Γ) }.

两边互证：若 ψ ∉ Csq，完全性给 Γ ⊨ ¬ψ，故 ¬ψ ∈ Csq，于是 ψ 属于右边；若 ¬ψ ∈ Csq，一致性保证 ψ ∉ Csq，于是 ψ 属于左边。③ 右边是 r.e.（枚举 Csq 再逐项加否定），故补集 r.e.。④ FL 可判定，由命题 3.3，CsqL(Γ) 可判定。可判定性得证。

第 5 步（矛盾）。Γ = {τ, φ} 是含 φ 的有限一致理论，其后承集却可判定——与 φ 见证 wGip 矛盾。故 φ/∼ 下没有原子；而 φ/∼ ≠ 0，所以 Fr 不是原子代数。∎

方向二（⇐）：Fr 非原子 ⟹ wGip（教材只证「不存在有限完全扩张」，这一步要看清）。

第 1 步。Fr 非原子，即存在非零元素 φ/∼ 其下没有原子。取这个 φ（一致）。

第 2 步（目标）。按 wGip 的定义，要证：任何含 φ 的有限一致理论都不完全。教材采用反证：假设存在有限、完全、含 φ 的一致扩张 Γ。

第 3 步（造一个原子）。因 Γ 有限，令 τ = ∧Γ（有限合取）。逐条验证 τ/∼ 是原子：

① τ/∼ ≤ φ/∼：因 φ ∈ Γ，合取蕴含每一项。

② τ/∼ ≠ 0：因 Γ 一致。

③ 对任意 ψ，由 Γ 完全，Γ ⊨ ψ 或 Γ ⊨ ¬ψ，即 ⊨ τ → ψ 或 ⊨ τ → ¬ψ（演绎项），即 τ/∼ ≤ ψ/∼ 或 τ/∼ ≤ ¬ψ/∼。这正是原子的判据。

第 4 步（矛盾）。τ/∼ 是 φ/∼ 下面的原子，与第 1 步「其下无原子」矛盾。所以不存在有限完全扩张，φ 见证 wGip。∎

教材原注 4.6.11

方向 (⇒) 用 wGip⁺ 也能过（因为只用到「不可判定」那一半）；只有方向 (⇐) 真正需要「完全」这个概念。记住这个不对称：从逻辑到代数便宜，从代数回到逻辑贵。

应用 8.1（教材 §4.6 应用段，逐条读）
  1. LS（经典命题逻辑）可判定 ⟹ 由 4.6.7 无 Gip。
  2. LPS（P 为原子公式集）：其重言式代数 Fr 是 |P| 生成的自由布尔代数。P 有限时 Fr 有限、原子；P 无限时 Fr 无原子。由定理 4.6.8，LPS 有 wGip ⟺ P 无限。（注：教材原文此处一行印作「P 有限时当且仅当有 wGip」，但与紧随其后的解释及定理 4.6.8 矛盾，是明显的笔误；按「wGip ⟺ Fr 非原子」应为 P 无限。）这说明 wGip 确实严格弱于 Gip：它可判定（无 Gip）却有 wGip。
  3. S5 情形完全类似。
  4. L×（Tarski 1941 定义的不可判定命题逻辑，即 L(RA)）：Tarski 在其中解释一阶逻辑，解释保持 wGip，故 L× 有 wGip。「命题逻辑也可能很强」这件事，在 1941 年是休克式的发现。
  5. 定理 4.6.13：若 0 < k < ω、n ≥ 3，则 Frk RA、Frk CAn、Frk SC3、Frk Df3 都不是原子。这些是非平凡的代数结果，却是拿一阶逻辑的 Gödel 不完全性经桥定理 4.6.8 换来的——本讲标题「代数侧面」落到实处。
  6. CrSn：等式理论可判定，但 k 生成自由代数非原子（Khaled），于是对应逻辑可判定却有 wGip，且由 4.6.6 知它没有演绎项。全是代数方法得出的逻辑结论。

来源：UAL 定理 4.6.6/4.6.7/4.6.8、断言 4.6.9/4.6.10、注 4.6.11、应用段与定理 4.6.13；命题 3.3.38（Fr 自由性）；L14 原子与孤立点。

桥逻辑问题代数对应物主发动机

把五座桥压成一句方法论

译过去 → 用代数解 → 译回来。

「译过去」靠的是代数化那本双语词典（推论 3.3.25）：逻辑性质变成等式理论、同态、合并、原子性。「用代数解」靠的是代数自己的工具：超积、自由代数、同余格、Jónsson 引理、Stone 表示。「译回来」靠反向翻译，把代数结论读回逻辑。

这一讲把这个套路用到了极致，也把它用出了边界。可判定性这一桥需要的最关键燃料是「有限」——有限个翻译条件、有限反例、有限基。一旦逻辑强到能编码算术，有限性守不住，不完全性就出来了，而它在代数上恰好表现为「自由代数没有原子」。六座桥到这里合龙：逻辑的每一种「好性质」，都能在代数里找到一个对应的结构性质；逻辑的每一种「坏性质」，也是。

下一讲 L23 进入第六篇「对偶与表示」，从 Stone 对偶开始——那是把这一路用到的「点 = 超滤子 / 同态」机制集中起来，看它如何同时支撑 Stone 对偶、模态语义与 locale 理论。
