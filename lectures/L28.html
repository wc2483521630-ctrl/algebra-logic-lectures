2O1　为什么要数变量个数；两个案例的差别 O1

一阶逻辑我们熟：变量随便用多少个。代数逻辑偏要问「只给 n 个变量会怎样」。这不是刁难——它逼出了一阶逻辑内部一整条精细结构，而且这条结构正好被代数侧完整镜像。

2.1变量是资源

把变量当有限资源看，很多熟悉的事立刻改观：

  • 公式 ∃x∃y∃z R(x,y,z) 要 3 个变量；只给 2 个就写不出来——除非你用「换名复用」的技巧，但那恰恰需要等号帮忙。
  • 证明也吃资源：一条 n 变量公式的证明，可能中途需要第 n+1 个变量当临时中转站。「证明能用几个变量」于是成了一个独立于「公式用了几个变量」的问题。
  • 代数侧同步：n 个变量 ↔ n 维柱体代数。变量数的每一次增减，都对应一个代数操作（neat reduct）。
一句话点破

有限变元片段不是「一阶逻辑的残缺版」，是把变量当刻度切开的一族逻辑。每一档有自己的代数、自己的完全性、自己的判定性。这条刻度在 n=2 处断裂。

2.2两个案例差在哪

UAL 这一节摆了两个片段，看上去只差一点，结果天差地别：

案例 3：L′n（带替换）案例 4：Ln（正式片段）
原子公式R(x₀,…,xn−1)，变量可任意排列只留 R(v₀,…,vn−1)
替换白送（原子里直接写）用 ∃ 与 = 表达出来
结局n≥2 连条件代入都不满足，不可代数化所有 n 都可代数化，桥全部开放

这是「语法多给一点反而更坏」的绝佳例子。你以为把替换直接放进原子是方便，结果它让原子公式的意义互相牵连，破坏了语义代入性质，机器直接停摆。UAL 在这里给的反例值得逐行读，下一节细看。

来源：UAL §5.3 开头与末尾讨论、§5.4 开头，Tarski 观察（量词加等号可表达替换）。

3O1　案例 3：带替换片段 L′n 与那个反例 O1

先说清定义，再读反例。反例是本讲第一个技术高潮，我一步一步拆，不跳过任何一行。

定义 5.3.1（FOL，n 变量，带替换原子公式）
  • 变量 Vn = {vi : i < n}；关系符号集 R 任意。
  • 原子公式 P = {R(x₀,…,xn−1) : R ∈ R, x₀,…,xn−1 ∈ Vn}——注意变量可以任意取、可重复。
  • 联结词 {∧, ¬, ⊥, vi = vj, ∃vi : i,j < n}。
  • 模型 MRn = {⟨M, RM⟩R∈R : M ≠ ∅, RM ⊆ nM}。
  • 赋值 h ∈ nM；M ⊨ ∃vi φ[h] 当且仅当存在 h′ ∈ nM 与 h 至多在 i 处不同、且 M ⊨ φ[h′]。「至多在 i 处不同」正是量词的标准约束。
  • 意义函数 mngM(φ) = {h ∈ nM : M ⊨ φ[h]}——文献里叫「φ 在 M 中定义的关系」，所以 mng(M) 是 M 中 n 变量可定义关系的代数。

第 1 步走流程：UAL 命题 5.3.2 说 L′n 是一般逻辑且有滤子性质，理由是两行等式：

mng(M, φ) = mng(M, ψ)　⟺　M ⊨ ∀v₀…∀vn−1(φ ↔ ψ) mng(M, φ) = mng(M, ¬⊥)　⟺　M ⊨ φ.

第一行是 ∆₀ 的候选（公式等价 ⟺ 意义相等），第二行是 ε/δ 的候选。滤子性质过了。但语义代入性质过不了。

反例一：替换把公式搞乱 UAL 命题 5.3.2 证明

取 p = R(v₀,v₁)、q = R(v₀,v₀)。可以验证：

⊨n q ↔ ∃v₁(v₁ = v₀ ∧ p)，　但　⊭n p ↔ ∃v₁(v₁ = v₀ ∧ p).

怎么读：式一把「把第二个位置换成第一个」的效果用 ∃v₁(v₁=v₀ ∧ p) 写出来了——这正是 Tarski 观察在起作用。式二说同样的表达式不等于 p 本身，因为 p 里两个位置是独立的，而右边强行把它们绑成相等。替换改了关系的结构，不是换个名字那么简单。

UAL 还给一个对称版本：取 p = R(v₀,v₁)、q = R(v₁,v₀)，则 ⊨n ∃v₁ p ↔ ∃v₁(v₁=v₀ ∧ ∃v₀ q) 而右边对 q 不成立。两个方向都坏，说明这不是个别公式的毛病。

反例二：五元模 5——条件代入也救不了 n = 2 的完整反例

上面的反例只打了「语法代入」。更强的是：哪怕退一步只要条件语义代入，也不行。UAL 给的构造是这样的：

  1. 取 R = {R, S}，模型 M 的底集是 5 = {0,1,2,3,4}。
  2. RM = {⟨u,v⟩ : v = u+1 mod 5}（五边形的「下一顶点」），SM = {⟨u,v⟩ : v = u+2 mod 5}（「隔一个顶点」）。
  3. 于是 mngM(R(v₁,v₀)) = {⟨u,v⟩ : v = u+4 mod 5}，mngM(S(v₁,v₀)) = {⟨u,v⟩ : v = u+3 mod 5}——掉头把 +1 变 +4、+2 变 +3。
  4. 造同态 h：在 R(v₀,v₁)、S(v₀,v₁) 上与 mngM 一致，但故意对调 R(v₁,v₀) 与 S(v₁,v₀) 的像：h(R(v₁,v₀)) = mngM(S(v₁,v₀))、h(S(v₁,v₀)) = mngM(R(v₁,v₀))。
  5. 于是 ker(h) = ker(mngM)（核相同，条件代入要求的正是这个），但 h 不是任何模型的意义函数——因为任何真模型的意义函数必须保持「掉头」这个结构：R 掉头得到 +4，不可能突然变成 +3。

这个反例的直觉：意义函数不只是保布尔结构，它还得尊重「变量位置」这个几何。同态只看到代数结构，看不到几何；把两个「掉头关系」对调，代数上无懈可击，语义上却根本不存在这样的模型。条件代入要求核相同就能找到模型，这里核相同却找不到——桥断了。

后果：L′0 就是经典命题逻辑，L′1 基本就是 S5（都能代数化）；但 n ≥ 2 时 L′n 不是语法代入、不是语义代入、甚至不是条件代入，因而不可代数化，六座桥全部关闭。它的代数对应物 UAL 记作 Rdca Psen 与 Rdca RPEAn（多相等代数的柱体约化），但桥定理用不上它们。

UAL 给的解法

「原子白送替换」这条路走不通，退回来：只把 R(v₀,…,vn−1) 当原子，替换式 R(x₀,…) 当成复合公式造出来。两条路：一条用 Tarski 观察（量词加等号），一条把替换直接当联结词加进来。案例 4 走的是第一条。

来源：UAL 定义 5.3.1、命题 5.3.2 全文、§5.3 末段、Tarski [207][209]。

4O2　案例 4：正式片段 Ln 与柱体代数对应 O2

只改一处：原子公式只留固定变量序 R(v₀,…,vn−1)，简写为 R。联结词、模型、意义函数都不变（L15 已见过这个四元组）。这一改，机器全开。

定义（正式 n 变量片段 Ln，n ≤ ω）

与 L′n 唯一差别：原子公式集就是 R 本身，即只保留 R(v₀,…,vn−1)（n 无限时是 R(v₀,…,vi,…)i<n）。UAL 叫它「完全受限的一阶语言」：「受限」指变量序固定，「完全」指每个关系符号的元数都是 n。其余完全照旧。

「受限」不是缺陷：L15 §边界例子里我提醒过「不允许写 r(v₁,…)」，当时说可以用量词和等号表达出替换效果——现在你知道这句话的依据就是 Tarski 观察，而且 L′n 的反例正好说明「不这么绕就会坏」。

命题 5.4.1：Ln 可代数化，且 Algm(Ln) = Csn、Alg⊨(Ln) = RCAn
第 1 步：语义代入。

组合性照旧；Mng = Hom(FR, Csn)，由命题 3.3.32 得语义代入性质。注意这和 L′n 的关键差别：一旦原子固定，意义函数必须保「位置」，不再出现五元模 5 那种对调。

第 2 步：滤子性质。

取 ε = φ₀、δ = ⊤、∆ = (φ₀ ↔ φ₁)，与 LC 同形。于是可代数化。

第 3 步：代数对应物。

Algᵐ(LRn) 恰是 |R|-生成的 Csn（n 维柱体集合代数），故 Algᵐ(Ln) = Csn。再由定理 3.3.36(ii) 与 RCAn = SP Csn，得 Alg⊨(Ln) = RCAn。∎

三层代数对照（把 L24 的词典搬过来）
层次关系代数侧（L24/L27）柱体代数侧（本讲）
具体集合代数setRRACsn（n 维柱体集合代数）
可表示抽象代数RRA = SP setRRARCAn = SP Csn
纯抽象公理代数RA（Tarski 公理）CAn（柱体公理）

同样的鸿沟：CAn ⊋ RCAn 对 n≥3（L22 定理 4.6.13 说 Frk CAn 非原子，就是这条鸿沟的后果）。

5O3　n = 2 分水岭：可判定与不可判定两侧 O3

UAL 原文一句话点破：RCAn 的基本性质，「n ≥ 3 时很像 RRA，n < 3 时更像 BA」。于是 L27 那张对照表在这里被复制成两半。先摊开代数性质。

5.1RCAn 的性质清单

按 n 分段（UAL §5.4 原文列出）
  • 所有 n ≤ ω：RCAn = SP setRCAn 是簇；n 有限时是判别簇，RCAω 不是。
  • n ≤ 2：等式理论有限公理化且可判定；RCAn (n≤1) 有超合并；但 RCA₂ 中满射不满。
  • 3 ≤ n ≤ ω：不可有限公理化、等式理论不可判定、集合论可解释进等式理论；满射不满，故无超合并。

6O4　两套演绎关系 ⊢n 与 ⊢n,m O4

这是本讲最独特的一节：别的逻辑只有一种「可证」，这里有两种，而且第二种要向更高的维度借变量。先把两套系统摆清楚，再问它们各自证明了什么。

6.1⊢n：关在 n 变量里的 Hilbert 系统

定义 5.4.4(i)（⊢n 的公理与规则）

导出联结词：∀vi φ = ¬∃vi ¬φ、φ → ψ = ¬(¬φ ∧ ψ)。公理模式 Axn（对一切 i,j,k < n）：

  1. χ，χ 是命题重言式（即 L₀ 的有效公式模式）。
  2. ∀vi(φ → ψ) → (∀vi φ → ∀vi ψ)
  3. ∀vi φ → φ
  4. ∀vi∀vj φ → ∀vj∀vi φ
  5. ∀vi φ → ∀vi∀vi φ
  6. ∃vi φ → ∀vi∃vi φ
  7. vi = vi
  8. vi = vj → (vi = vk → vj = vk)
  9. ∃vi(vi = vj)
  10. vi = vj → ∀vk(vi = vj)，若 k ≠ i,j
  11. vi = vj → (φ → ∀vi(vi = vj → φ))，若 i ≠ j

规则 Run：分离（MP）φ, φ → ψ / ψ 与推广 φ / ∀vi φ（i < n）。

最后一条公理最难，单独说人话

vi = vj → (φ → ∀vi(vi = vj → φ)) 是替换公理：若 vi 与 vj 相等，且 φ 成立，那么把 φ 里 vi 换成 vj 后仍成立。这正是案例 3 说「替换要靠等号表达」的落实——它现在是公理，不是免费的原子操作。前面几条管量词，这条管等号与替换的交互，是 n 变量片段的脊梁。

UAL 提醒两个技术细节：n 无限时公理有无穷多条（每个 i 一条），n 有限时可把第一条的无穷多命题重言式换成一个有限的 L₀ 公理系统，从而 Axn 有限；此外 ⊢n 也可由机械翻译 CAn 公理得到——和 L27 里从 BA 公理翻译出 LC 的 Hilbert 系统完全同一招。

6.2⊢n,m：向 m 变量借力

定义 5.4.4(ii)（m 变量可证）

设 n ≤ m ≤ ω。在高维公式集 FRm 里加一组公理

(R)　R → ∀vi R　（n ≤ i < m，R ∈ R），

然后定义 ⊢n,m = {⟨Σ, φ⟩ : Σ ∪ Axnm ⊢m φ，Σ ∪ {φ} ⊆ FRn}——即「在 m 维系统里证明，但前提与结论都落在 n 维语言里」。

直觉：新变量 vn,…,vm−1 是临时的。公理 (R) 说：关系符号 R 不依赖这些新变量（对新变量全称封闭仍成立）。于是你可以用额外的维度做中转推理，最后结论仍落回原来的 n 变量公式。「证明用了几个变量」和「公式用了几个变量」就此分离。

⊢n,m 不是 Hilbert 系统（这个区别要紧）

UAL 特意说：⊢n 由 Hilbert 系统给出，⊢n,m 不是（m>n 时）。原因是它的证明会用到 Fm 里的公式，超出了 n 维语言；要把它写成只允许 n 维公式的系统，就得牺牲强可靠性（见 §8 末 UAL 说明）。「多变量证明」是一种元层面的可证关系，不是 n 语言内部的形式系统。

两套系统都强可靠（UAL 明说「易于验证」）。但完备性差别巨大——下一节用三栏对应一次看清。

7O5　三栏对应与「多变量拯救证明」 O5

这是全讲最漂亮的一页：三个概念——n 变量内可证、借 m 变量可证、语义有效——分别精确对应三个代数等式判定问题。桥在这里不是比喻，是一一对应的翻译表。

定理 5.4.6：三栏对应（n 任意序数，n ≤ m）
(i)　⊢n φ　⟺　CAn ⊨ φ = 1 (ii)　⊢n,m φ　⟺　SNrn CAm ⊨ φ = 1 (iii)　⊨n φ　⟺　RCAn ⊨ φ = 1

其中 SNrn CAm 是 CAm 的 neat reduct：把 m 维代数「削」掉多余维度，只留 n 维结构（UAL §7.3，定理 7.3.9）。三行分别来自 Henkin–Monk–Tarski 经典教材 [97] 的推论 4.3.26、定理 4.3.25、定理 4.3.17。

这张表怎么读

每一栏都是一座桥，把「逻辑里的一句话」翻译成「代数里的一个等式」：

  • ⊢n → CAn：⊢n 的公理就是 CAn 的公理，所以「n 变量内可证」=「在所有抽象柱体代数里等于 1」。注意是 CAn，不是 RCAn——抽象系统管的是公理，不管可表示性。
  • ⊢n,m → SNrn CAm：借 m 变量证明，对应的是「m 维代数削成 n 维」后的类。借高维 = 在更大的代数里算完再削回来。
  • ⊨n → RCAn：语义有效对应可表示代数。这是 L16 的命题 3.3.20 在片段上的版本。

三栏按包含关系排成一条链：CAn ⊇ SNrn CAn+1 ⊇ … ⊇ RCAn（代数类越大，等式理论越弱、可证的东西越少），于是逻辑侧 ⊢n ⊆ ⊢n,n+1 ⊆ … ⊆ ⊨n。中间那些「借变量」正是把这条链填满的台阶。

推论 5.4.7：多变量完全性
  1. ⊢n,n+ω 对 Ln 强完备（对所有 n）。
  2. 若 m < ω，⊢n,n+m 对 Ln 连弱完备都不是。
  3. 对任意 φ ∈ Ln：⊨n φ ⟺ ⊢n,n+m φ 对某个有限 m 成立。
  4. 对任意 n,m < ω：存在有效的 n 变量公式，不能用 m 变量证明；但每个有效 n 变量公式，都存在某个 m 使它 m 变量可证。
为什么成立：把定理 5.4.6 与定理 7.3.9 接起来。

关键代数等式是 RCAn = SNrn CAn+ω（定理 7.3.9）。于是对任意有效式：

⊨n φ　⟺　RCAn ⊨ φ = 1　⟺　SNrn CAn+ω ⊨ φ = 1　⟺　⊢n,n+ω φ.

最后一步是 (ii)。强完备性对有限 n 还要用 Ln 紧致 + 有演绎定理（对 n ≥ ω 用 [97, 4.3.23(ii)] 另证）。(3) 的「某个有限 m」来自 ⊢n,n+ω 的定义：证明是有限对象，只会用到有限多个额外变量。这是一处典型的「紧致性在背后干活」：无穷多变量够用，是因为每个具体证明只需有限多。

本讲的主题句

n 变量公式的证明可能需要超过 n 个变量；但只要允许借任意多个（有限个）变量，完备性就回来了。定理 5.4.2 说「关在 n 里不完备」，推论 5.4.7 说「开门借变量就完备」。两句合起来才完整。

推论还顺带覆盖普通一阶逻辑：n 变量公式在 Ln 中有效当且仅当在通常 FOL 中有效；而任意一阶公式都有某个 Ln 里的正常形。有限变元片段不是旁支，它是一阶逻辑按变量数切出的骨架。

来源：UAL 定理 5.4.6、推论 5.4.7 及证明、定理 7.3.9（RCAn = SNrn CAn+ω）、[97] 4.3.17/4.3.23/4.3.25/4.3.26。

8O6　演绎能力的严格阶梯 O6

既然「借变量」有用，自然问：多借一个变量，能力涨多少？定理 5.4.8 给出完整答案，而且答案在 n=2 处再次显出特殊性。

定理 5.4.8（演绎能力）
  1. 若 1 < n < ω，⊢n ≠ (⊢n+1 限制到 Ln)：存在 n 变量公式，⊢n 证不出，⊢n+1 证得出。
  2. 若 n ≤ 1，对任意 n 变量公式与 m ≥ n，⊢n φ ⟺ ⊢m φ。0、1 变量处，多给变量毫无帮助。
  3. 若 3 ≤ n ≤ m < ω，⊢n,m ≠ ⊢n,m+1：存在 3 变量公式，用 m 变量证不出、用 m+1 变量证得出。每多借一个变量，能力都真涨。
  4. n = 2 时 ⊢2 ≠ ⊢2,3 = ⊢2,m（一切 m ≥ 3）。2 变量处，借到 3 个就到顶了。
  5. 若 n ≤ 1，⊢n = ⊢n,m 对一切 m ≥ n。
五条一句话记法

0、1 变量：借变量无用（ii、v）。2 变量：借一次到位（iv）。3 变量以上：无底洞，每借一个涨一级（i、iii）。这条阶梯和 §5 的可判定性分水岭是同一件事的两种说法——(iv) 背后是 CA₂ ≠ SNr₂ CA₃ = RCA₂ = SNr₂ CAω：2 维处「削一次」就已经得到全部可表示代数，所以借到 3 个变量就饱和了；3 维以上 SNrn CAm 随 m 严格下降，永远追不上 RCAn，所以每多借一个都在逼近但永不抵达。

(i) 的证明为什么这么短（UAL 原文只两行）。

由 [97, 2.6.14]：存在 CAn 的等式 e，使 CAn ⊭ e 而 CAn+1 ⊨ e。可设 e 是 φ = 1 形。于是定理 5.4.6(i) 直接给 ⊬n φ 而 ⊢n+1 φ。整个证明论结论是从一条代数等式搬过来的——这就是四步流程第 4 步的威力。(ii)(v) 同理，用 CAn = RCAn = SNrn CAn+m（n≤1）；(iv) 用上面那条 CA₂ 的链。

一个必须承认的边界

推论 5.4.7(i) 的 ⊢n,n+ω 是强完备的，但它的证明用了不在 Ln 里的公式。如果你坚持证明里只许出现 n 变量公式，文献里确实有完备系统（[201]、[151]、[157]、[158]），但它们共同牺牲强可靠性。这不是品味问题，是定理 5.4.2 的硬性结论：n>2 时强可靠 + 强完备的 Hilbert 系统根本不存在。「证明只能用 n 变量」和「证明可靠且完备」两者不可兼得。

来源：UAL 定理 5.4.8 及证明、注 5.4.9、[97] 2.6.8/2.6.9/2.6.14/2.6.42/3.2.65、[104][103]。

9三层例：典型 / 本质 / 边界 三层例

典型 · L₂ 是能亲手算的那一档
二元关系上的两个变量 L₂ 与 RRA 的第一课

取 R 一个二元关系符号，L₂ 的原子就是 R（代表 R(v₀,v₁)）。公式 ∃v₀ R 表示「某点指向当前点」，∃v₁ R 表示「当前点指向某点」——两个变量刚好够写出关系代数的逆与复合。这就是 L27 里 LREL 的方形语义在片段里的影子，也是为什么 L₂ 的代数 RCA₂ 与关系代数贴得最近。

本质 · L′₂ 的五元模 5 反例
原子多给一点，桥就塌 §3 反例二的浓缩

同样的 5 个点，R 是 +1、S 是 +2。在 L′₂ 里 R(v₁,v₀) 与 S(v₁,v₀) 是合法原子，于是可以在同态里对调它们的像而核不变。在 L₂ 里这两个公式根本不是原子，必须用 ∃ 与 = 从 R, S 造出来，一造就被结构锁死，对调不再可能。同一个模型，两种语法，一个可代数化一个不可——语法不是包装纸。

边界 · 无穷变量 Lω 与「借变量」的极限
两处别越界 n=ω 的演绎定理；n finite 的公理有限性
  • Lω 紧致但没有演绎定理。推论 5.4.7(i) 对 n ≥ ω 的强完备性要用 [97, 4.3.23(ii)] 另证，不能照搬有限 n 的「紧致 + 演绎定理」路线。「变量无穷多」和「公式有限长」是两回事，别混。
  • n 有限时 Axn 才能压成有限。注 5.4.5(1) 说要把无穷多条命题重言式公理换成一个有限的 L₀ 系统；n=ω 时做不到。这直接呼应定理 5.4.2：有限公理化是 Hilbert 系统能拿到的前提。
