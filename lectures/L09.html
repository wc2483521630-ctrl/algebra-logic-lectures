2动机：为什么不想列出全部开集

L08 里每个拓扑都是直接列出整个 τ。这在两三个点上是小事，在 ℝ 上就荒唐了——开集的集合族有多少？多到没法写下来。讲义说得很直白：直接指定全部开集「有时这很繁琐，实际工作中通常只指定一个可以生成整个拓扑的子族」。

它解决什么问题

它解决的是「怎么用有限的信息规定无限的结构」。这不是偷懒，而是 L02 闭包系统的老套路：闭集族由生成元决定，闭包算子由「补到最小封闭」算出。这里同理——指定一族「基本可验证命题」，让 (O2)(O3) 两条封闭条件自动补齐其余。你要做的只是验证生成元够不够、生成的拓扑是不是你要的。

认识论上更顺：一个认识主体未必能一口气列出所有可验证命题，但他手里总有若干基本检查手段（「测温度」「看颜色」「查这一段序列」）。复杂的可验证命题就是这些基本检查的组合。基和子基就是把「基本检查手段」形式化。

来源：拓扑讲义第 249–250 行、§2.2 开头。

3基：基本可验证命题 O1

它解决什么问题

基回答「哪些可验证命题算基本」。定义只有一句话，但要用它干活得会两件事：一是验证某族确实是基（每个开集都能由它拼出），二是用基去检验两个拓扑是否相等——因为只需检查基本开集，不用遍历全部开集。

定义 3.1（拓扑讲义定义 2.2.4）

设 ⟨X, τ⟩ 为拓扑空间。若每个 U ∈ τ 都可写成

U = ⋃i∈I Vi，其中 (Vi)i∈I ⊆ 𝓑

就称 𝓑 ⊆ τ 为 τ 的一个基。元素叫基本开集。约定：ℝ 上以开区间为基；空并 = ∅。

讲义点明三个关系：τ 是对任意并封闭的基；把子基对有限交封闭就得到基；但基本身不必对交封闭（脚注 3）。

典型例子

实直线 ℝ 上所有开区间 (x,y) 构成 Euclidean 拓扑的基（例 2.2.7）。U ⊆ ℝ 开当且仅当 ∀z ∈ U ∃x,y 使 x < z < y 且 (x,y) ⊆ U——这就是微积分里「开集」的老定义，现在知道它只是「区间的任意并」罢了。

本质例子

Cantor 空间 2ω（例 2.2.8）：对有限二进制序列 s，令柱集 C(s) = {x ∈ 2ω : s ⊴ x}（x 以 s 为初段）。柱集构成基，因为两个柱集之交或为空、或仍是柱集（讲义脚注提醒：不相容初段的交为空，严格说要把 ∅ 加进基，或用脚注 4 的局部条件）。认识论读法极漂亮：一次只检查有限长前缀，就能验证一个命题——柱集就是「有限信息可验证」的形式化。L09 后面证明它等于可数个离散二点集的积。

边界与误解

别把「基」误认成必须对交封闭。开区间对交封闭（交还是开区间），但一般基不保证这点；讲义脚注 3 专门提醒。真正的分界是：基只需能拼出全部开集；若还想从它直接生成拓扑（不事先有 τ），才需要命题 2.2.5 的覆盖 + 二元交封闭条件。这两个角色别混。

来源：拓扑讲义定义 2.2.4、脚注 2/3、例 2.2.7、例 2.2.8。

4子基与生成唯一拓扑 O2

它解决什么问题

基有时还是太大——开区间已经够多，柱集也一大堆。子基再退一步：只给最原始的检查手段，连交封闭都不要求。然后问一个关键问题：随便给一族子集 𝓒，能不能唯一地造出一个拓扑以它为子基？命题 2.2.5 说能，而且给出了配方——这就是本讲的生成机。

定义 4.1（拓扑讲义定义 2.2.4 后半）

若 𝓢 ⊆ τ 中元素的全部有限交所成族构成 τ 的一个基，就称 𝓢 为一个子基。约定空交为全集：⋂V∈∅V = X，逻辑上空合取为 ⊤（脚注 2）。

命题 4.2（拓扑讲义命题 2.2.5，生成机）
  1. 设 𝓒 ⊆ 𝓟(X)。存在唯一的 X 上拓扑以 𝓒 为子基。配方：先把 𝓒 对有限交封闭，再把所得族对任意并封闭。
  2. 若进一步 (1) 𝓒 覆盖 X（⋃𝓒 = X），且 (2) 𝓒 对二元交封闭，则存在唯一的以 𝓒 为基的拓扑。配方：直接对 𝓒 取任意并。

讲义脚注 4：条件 (2) 可弱化为局部条件——若 x ∈ U1 ∩ U2，U1,U2 ∈ 𝓒，则存在 U3 ∈ 𝓒 使 x ∈ U3 ⊆ U1 ∩ U2。这是「在每点附近够用即可」的版本，Cantor 柱集用的就是它。

认识论读法（讲义注 2.2.1）

τ 是全部可验证命题；基 𝓑 是一组基本可验证命题，其余命题靠弱化推理（对基本命题取析取 = 任意并）得到。子基则是更原始的命题：先加强知识（有限合取 = 有限交），再弱化知识（析取 = 任意并），两步合起来生成全部可验证命题。一句话：有限交 + 任意并 = 加强 + 弱化 = 子基生成机。

典型例子

讲义例 2.2.6 的四世界模型：X = {a,b,c,d}，按「乌鸦黑 / 不黑」「天鹅白 / 不白」分成四格。只指定子基 𝓢 = {{c,d}, {b,d}}（即「有非白天鹅」与「有非黑乌鸦」），先取有限交（得 {d}），再取任意并，生成 τ = {∅, X, {c,d}, {b,d}, {d}, {b,c,d}}——恰好是全部可验证命题。两条基本检查手段，生成了六个命题。

本质例子

一般积拓扑（§7）是子基生成机的真正用武之地：给 ∏i∈IXi 的子基取「只在第 i 个坐标受限」的集合 πi−1(U)，有限交后就是「有限多个坐标受限」，任意并补齐全部开集。没有子基，一般积拓扑的定义会笨重得多。这正说明命题 2.2.5 不是纸面练习，而是构造工具。

边界与误解

第一条配方对任意 𝓒 都成立——哪怕 𝓒 不覆盖 X、不交封闭。比如 𝓒 = {{a}} 在 X={a,b} 上生成的拓扑是 {∅,{a},X}（别忘了空交给 X）。别误以为「生成基」必须满足第二条的覆盖条件——那条只对「以 𝓒 为基」成立。两个配方、两套条件，分清哪条配哪个。

来源：拓扑讲义定义 2.2.4、命题 2.2.5 及脚注 2/4、注 2.2.1、例 2.2.6。

5拓扑比较：细 / 粗与知识多寡 O3O3

它解决什么问题

同一个 X 上可以装不同的拓扑，L08 末尾已经列了五种。现在要给「哪个更大」一个名字和判定法。认识论上这问的是：哪个框架能验证更多命题。而直接比较两个拓扑的全部开集太累，得靠基来判。

定义 5.1（拓扑讲义定义 2.2.9）

设 τ, τ′ 是 X 上的拓扑。若 τ ⊆ τ′，称 τ 比 τ′ 粗，τ′ 比 τ 细。细 = 开集更多 = 可验证命题更多 = 知识更多。

引理 5.2（拓扑讲义引理 2.2.10）

设 𝓑τ, 𝓑τ′ 分别为 τ, τ′ 的基。则 τ ⊆ τ′ 当且仅当：对任意 x ∈ X 及含 x 的 τ-基本开集 U，存在 U′ ∈ 𝓑τ′ 使 x ∈ U′ ⊆ U。

证明机关：(⇒) U ∈ τ′ 故是若干 𝓑τ′ 元素之并，含 x 的那块即所求。(⇐) 对 U ∈ τ 的每个点 x 取 U′x，则 U = ⋃x∈UU′x ∈ τ′。「逐点找小块」是比较拓扑的标准手法，后面连续映射也用它。

典型例子

例 2.2.11：形如 (l, ∞) 的集合覆盖 ℝ 且对二元交封闭，故生成拓扑 τF。由引理 2.2.10，τF ⊊ τE（Euclidean 拓扑）：包含是因为 x ∈ (l,∞) 时 x ∈ (l, x+1) ⊆ (l,∞)；严格是因为 0 ∈ (−1,1) 却找不到 l 使 0 ∈ (l,∞) ⊆ (−1,1)。

本质例子

L08 的五种拓扑现在能排成一条知识阶梯：τ平凡 ⊆ τAlexandroff ⊆ ⋯ ⊆ τ离散。两端是「什么都验证不了」与「什么都验证得了」。商拓扑（§8）则往粗的方向走——把世界认同后，有些命题不再可分。比较拓扑就是比较认识框架的分辨力。

边界与误解

「细」不等于「更好」。太细的拓扑（离散）里每个单点都可验证，但「归纳问题」那种结构性信息也消失了——一切都是并集，没有需要推理的封闭条件。反过来 τF ⊊ τE 的严格性证明里，关键词是「每点附近」：引理 5.2 的条件逐点检查，不能改成「存在一个 U′ 覆盖整个 U」——后者要求太强，会把很多真包含判成假。

来源：拓扑讲义定义 2.2.9、引理 2.2.10 及证明、例 2.2.11。

6子空间：限制论域 O4

它解决什么问题

认识世界集 X 里我们常常只关心一个子集 S（比如只看有理数、只看 [0,1] 区间）。子空间拓扑回答：把论域限制到 S 后，哪些命题还算可验证？最自然的答案是：原来可验证的命题，限制到 S 上仍然可验证。

定义 6.1（拓扑讲义定义 2.3.1、引理 2.3.2）

设 ⟨X,τ⟩ 为拓扑空间，S ⊆ X。S 上的子空间拓扑为 τS = {U ∩ S : U ∈ τ}。

若 𝓑 是 τ 的基，则 𝓑S = {U ∩ S : U ∈ 𝓑} 是 τS 的基（引理 2.3.2）。另一个好用的性质（命题 2.3.5）：先取积再取子空间，与先分别取子空间再取积，结果相同——两个构造可交换。

典型例子

ℤ ⊆ ℝ 取子空间拓扑：对 n ∈ ℤ，开区间 (n−½, n+½) 与 ℤ 相交得 {n}，故每个单点开，ℤ 离散（讲义第 388–391 行）。同一个 ℝ，限制到不同子集会得到完全不同的认识框架。

本质例子

讲义在 ℤ 之后立刻问：ℚ ⊆ ℝ 作为子空间也离散吗？答案是不。这个对比是本讲最值得停下来的地方：ℤ 的点彼此隔开（有不相交邻域），ℚ 的点却处处稠密——任何两个有理数之间还有有理数，单个有理数无法用开区间单独圈出。同一个「取交」定义，在离散子集与稠密子集上给出相反结果；这正是子空间概念的本质：它继承的是原空间的分辨结构，不是人为指定。

边界与误解

别以为「在 X 中开的集合，限制到 S 后仍开」这句话反过来说也行。S 中开集一定是 U ∩ S，但 S 本身作为 S 的子集总是开（取 U = X），而 S 在 X 中未必开。另外，讲义特别提醒：把 [0,1] 嵌入 ℝ 是拓扑嵌入，但其像在 ℝ 中并不开（第 949 行）——嵌入管的是同胚到像，不管像是否开。

来源：拓扑讲义定义 2.3.1、引理 2.3.2、命题 2.3.5、第 388–392 行、第 949 行。

7积拓扑：联合观察与有限坐标 O5

它解决什么问题

若一个世界由多个坐标描述（多个传感器、多个命题变元、多个坐标 x1,…,xn），把各坐标的拓扑简单相乘会出问题。积拓扑回答：「联合检查」的合法基本手段是什么？答案藏在子基里——一次只查一个坐标，有限次联合查有限个坐标。

定义 7.1（拓扑讲义定义 2.3.4、2.3.8、引理 2.3.6）
  1. 有限积：X × Y 上积拓扑以所有 U0 × U1 为基本开集，其中 U0, U1 分别开。若 𝓑X, 𝓑Y 是基，则 {U × V : U ∈ 𝓑X, V ∈ 𝓑Y} 是积拓扑的基（引理 2.3.6）。
  2. 一般积：设 (Xi)i∈I 为拓扑空间族。在 ∏i∈IXi 上，U = ∏i∈IUi 为基本开集，当且仅当 (1) 每个 Ui 在 Xi 中开；(2) 除有限多个坐标外 Ui = Xi。等价地，以「仅一个坐标受限、其余为 Xi」的集合为子基本开集（命题 2.2.5 生成机）。

讲义特别强调：这不是说任意无穷多个开集的积都开。有限坐标限制对许多性质在积下的保持至关重要。

典型例子

例 2.3.7：ℝn 上以 n 维开球为基得到通常拓扑，它等于 n 个标准实直线的积拓扑。证明用引理 2.2.10 双向包含：球内找开矩形、矩形内找小球（取到各边距离的最小值 ε）。这是多元微积分「开集 = 开矩形并」的严格版本。

本质例子

例 2.3.9：Cantor 空间 2ω 等于可数多个离散二点集 2={0,1} 的积拓扑。柱集 C(s)（有限前缀 s）恰是「只有前 m+1 个坐标受限、其余任意」的积基本开集：C(s) = {x0} × ⋯ × {xm} × ∏n>m{0,1}。「有限坐标限制」与「有限前缀可验证」是同一件事——这把 §3 的柱集基和 §7 的积拓扑接上了，也是后面 Cantor 空间紧致性（L18）与 S4 语义（L25）的舞台。

边界与误解

最大的坑是把一般积误当有限积：若允许无穷多坐标受限，∏n∈ω{0} 这样的集合会变成开集，而它在 2ω 里是单点——于是 Cantor 空间会变离散，紧致性等一堆性质全崩。讲义明确说「这不是说任意无穷多个开集的积都开」。另一个小边界：若 I = ∅，空积是单点集，整套定义仍自洽（留给习题）。

来源：拓扑讲义定义 2.3.4、命题 2.3.5、引理 2.3.6、例 2.3.7、定义 2.3.8、例 2.3.9。

8拓扑和与商拓扑：并置与认同 O6

它解决什么问题

最后两种构造走两个相反方向：拓扑和把几个认识框架并置（不交流、各自为政）；商拓扑把某些世界认同（宣布它们不可区分）。一个做加法，一个做除法，却都用生成机或原像定义规规矩矩地造出拓扑。

定义 8.1（拓扑讲义定义 2.3.10、3.2.5）
  1. 拓扑和：空间族 (Xi)i∈I 的拓扑和是不交并 ⨆i∈IXi，配备：U 开当且仅当每个切片 U(i) = {a ∈ Xi : (a,i) ∈ U} 在 Xi 中开。若 𝓑i 是 Xi 的基，把各分量的基本开集放进不交并即得拓扑和的一个基（引理 2.3.11）。
  2. 商拓扑：设 ∼ 是 X 上的等价关系，q : X → X/∼ 为自然投影 q(x) = [x]∼。X/∼ 上定义：U 开当且仅当 q−1[U] 在 X 中开。配备此拓扑后 q 是商映射（定义 3.2.1、3.2.5）。
典型例子

商拓扑的经典例子：在 I = [0,1] 上令 x ∼ y ⟺ x=y 或 {x,y}={0,1}。商空间 I/∼ 把端点粘合成圆，与 S1 的子空间拓扑同胚（例 3.2.6）。讲义还给了 Möbius 带（例 3.2.7）：先子空间、再积、再商，三步给出正确的几何结构。

本质例子

认识论读法才是重点。商 = 宣布某些世界不可区分：若 x ∼ y，则任何在商空间中可验证的命题都无法分开 x 与 y——因为 q−1[U] 开意味着若含 [x] 就整块含 [y]。这与 L01 的等价关系、L03 的商代数是同一个动作的三种面貌：按不可区分性做商。商拓扑的「U 开 ⟺ 原像开」正是「商上的命题可验证 ⟺ 拉回后可验证」。

边界与误解

商映射必满射且连续，但不一定开、也不一定闭（引理 3.2.3 只给了部分逆：(2.q) 满射连续开 ⟹ 商，(3.q) 满射连续闭 ⟹ 商；注 3.2.1 提醒反向不成立）。构造商拓扑时别偷懒直接说「开集的像开」——那会得到更强的条件，可能造出错误的拓扑。拓扑和这边：不交并的「不交」是字面意思，若两分量有公共点必须先标记成不同副本，否则切片定义会打架。

10习题（按目标编号）

  1. O1 证明 {(a,b) : a < b} ∪ {∅} 是 ℝ 上某拓扑的基，并写出该拓扑。它和 Euclidean 拓扑相同吗？
  2. O1 举一个基不对交封闭的例子（提示：想想 ℝ2 上的开矩形与开圆盘的关系），说明为什么这不妨碍它生成拓扑。
  3. O2 对 X = {a,b,c}、𝓒 = {{a,b},{b,c}}，用命题 2.2.5 的配方写出以 𝓒 为子基的唯一拓扑，列出全部开集。
  4. O2 验证讲义例 2.2.6：从 𝓢 = {{c,d},{b,d}} 出发，先取有限交、再取任意并，确认得到的正是 τ = {∅,X,{c,d},{b,d},{d},{b,c,d}}。
  5. O3 用引理 2.2.10 证明 τF ⊊ τE（例 2.2.11），并指出严格性证明里「找不到 l」这一步用到了 (−1,1) 的什么性质。
  6. O3 把 ℝ 上「形如 (−∞, l)」生成的拓扑记为 τL，比较 τL 与 τF 的粗细，并从「能验证什么」的角度解释结论。
  7. O4 详细证明 ℚ ⊆ ℝ 的子空间拓扑不离散：对任意 q ∈ ℚ 与含 q 的开区间 U，说明 U ∩ ℚ ≠ {q}。
  8. O4 证明命题 2.3.5 的可交换性：写出两边的基，用集合等式 (UX × UY) ∩ (SX × SY) = (UX ∩ SX) × (UY ∩ SY) 完成论证。
  9. O5 证明引理 2.3.6：若 𝓑X, 𝓑Y 是基，则 {U × V : U ∈ 𝓑X, V ∈ 𝓑Y} 是积拓扑的基。
  10. O5 说明为什么一般积要求「除有限多个坐标外 Ui = Xi」：若允许无穷多坐标受限，证明 2ω 会变成离散空间，并指出这会破坏哪个后续性质（提示：L18 紧致）。
  11. O5 证明例 2.3.9 的另一半：每个柱集 C(s) 是积基本开集；并解释空序列 s 对应的柱集是什么。
  12. O6 验证定义 3.2.5 的两件事：(a) U 开当且仅当 q−1[U] 开确实给出拓扑；(b) 配备此拓扑后 q 是商映射。
  13. O6 从认识论角度解释商拓扑：若 x ∼ y，证明任何商空间中的开集 U 都不能只含 [x] 而不含 [y]（其实二者是同一个点），并说明这与 L03 商代数的「按不可区分性认同」如何对应。
