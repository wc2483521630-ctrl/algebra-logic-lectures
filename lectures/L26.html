2O1　哲学动机：点到底是什么 O1

这一讲最该先问的不是「locale 怎么定义」，而是「为什么有人愿意不要点」。答案有三层，一层比一层硬。

2.1第一层：我们能观察到的从来不是点

先回到你从第 1 讲就带着的东西。L01 把逻辑定义为四元组 L = ⟨F, M, mng, ⊨⟩，其中 mng 把公式送到「模型上的真值集合」。L02 你学了闭包算子与 Galois 连接，看见「理论」和「模型」是一对极性。L08 你学了邻域滤子，那天我写过一句话：「不必真有点，一个滤子就能当作一个可能世界。」L10 你把开集格 τ 和 S4 的 □=int 对上。L23 你终于看见点 = 超滤子 = 同态到 2。

把这条线索连起来读，会发现一个一直在发生却没被点破的事实：我们从来没有直接把握过点，我们把握的一直是「哪些命题在点里成立」。点是我们从这些信息里反推出来的。L23 的反推用的工具是超滤子；这一讲问的是：如果反推这一步根本不做呢？

Vickers 的那句判词

Steven Vickers 在《Topology via Logic》(1989) 的序言里说得相当不客气：传统点集拓扑的动机是「先从欧氏空间抽象到度量空间，然后出于一个并不明显的理由，把开集的性质抽出来」。他的主张是：把这些公理不当集合论读，当逻辑读——拓扑就是有限观察的逻辑。

具体对应是 Smyth (1983) 与 Abramsky (1987) 那批工作的口号：开集 = 半可判定性质——存在有效方法能在有限步内验证它，但未必能否证它。「程序停下来了」是半可判定的；「程序永不停止」不是。两个半可判定性质可以同时验证（交），一族半可判定性质只要有一个被验证就验证（并）。拓扑公理不是天上掉下来的集合论约定，是「可验证性」这个概念的运算规则。

这就把 L02 的闭包算子、L10 的内部算子、L25 的 □=int 全部收进一个更基本的出发点：先有可验证的命题，后有它们描述的世界。点是这个世界的可选重构，不是它的地基。

2.2第二层：点太贵——构造性与选择公理

L23 证明 Stone 表示时用了 Zorn 引理（Bergman 定理 2.41 素理想定理）把滤子扩张成超滤子。L13 证明紧致 ⇔ 超滤子收敛时也用了非主超滤子。「点存在」这件事，在很多情形下是靠选择公理买的。如果你在构造性数学里工作，或在一个 topos 里工作，这笔钱未必付得起。

更细的麻烦是 Vickers 后来反复讲的「变体集合」问题：你想研究一族随参数 z 变化的空间 X(z)，很自然地想给每个 z 配一个点集。可有些变体空间没有令人满意的点集表示——你硬要做，得到的点集不是「集合」。点集定义在这里不是不方便，是不成立。

无点拓扑的做法是：把每个开集 U 不当成点的集合，而当成一个逻辑性质「x ∈ U」——至于 x 是什么、有多少，先不管。原先靠「知道点是什么」才隐含成立的那些关系，现在显式写成逻辑公理。于是你得到一个理论，点则定义成这个理论的模型。Vickers 一语中的：无点空间就是一个几何理论，它的点就是模型的集合。

为什么这比「省点事」重要

构造性数学里最著名的胜利之一：经典 Tychonoff 定理（任意积的紧致性）依赖选择公理，但 locale 版本的 Tychonoff 可以构造性地证明。同类的还有 Heine–Borel 定理。换掉点，换掉的不是表述，是定理的证明强度。这正是 L18 紧致桥在无点世界里的回响：紧致性本来就该是「有限观察能覆盖整体」这种构造性说法，而不是「每个超滤子收敛」这种非构造性说法。

2.3第三层：有些几何本来就没有点

如果你的物理图景在普朗克尺度上没有光滑流形、没有点事件，那么以点集为地基的几何就不是「近似」，而是用错了语言。Isham 与 Butterfield 的 topos 方案、量子引力中的位置 locale，走的都是这条路：把观测量（可问的问题）放在 frame 里，空间由它们生成，点只是可选的模型。

还有一个更贴近本课程的例子。你在 L06 见过无原子的布尔代数：𝓟(ℕ)/fin 没有原子，它的 Stone 空间 βℕ − ℕ 里的点不是任何自然数。L23 你学会把这些点叫「非主超滤子」。今天换一个看法：那些点之所以存在，是因为我们允许自己用选择公理把「余有限滤子」扩张到底。locale 视角问的是：如果不做这个扩张，𝓟(ℕ)/fin 自己作为格，还描述了一个几何对象吗？描述了——而且描述得更省。这就是「代数方法比点集方法更广」的意思，也是拓扑讲义 Ch7 那段话的重心。

2.4一次本体论换向

本体论在前，还是认识论在前

把两种做法并排看，哲学立场就出来了：

点集拓扑Locale 理论
起点一批点（可能世界、实体）一批可验证命题（观察、事实）
顺序本体论先于认识论认识论先于本体论
开集是什么点的集合命题（半可判定性质）
点是什么给定的、基本的推出来的、可选的（理论的模型）
亲近的逻辑经典逻辑直觉主义逻辑 / 几何逻辑

维特根斯坦《逻辑哲学论》开头两句放在这里几乎就是注脚：「世界是一切实际情况。世界是事实的总体，不是事物的总体。」点集拓扑从「事物」起，locale 从「事实」起。这一讲的整个技术展开，都是在这句哲学判断底下发生的。

3O2　Frame 与 locale：把开集格抽出来 O2

哲学立场定了，技术就顺了：把开集族从「点的集合」升级成「抽象命题」，然后只保留它作为可验证命题必须满足的运算规则。

3.1从开集格到 frame

定义 Frame（标准文献；拓扑讲义 Ch7 只给「完备 Heyting 代数」的说法）

一个 frame 是一个完备格 F = ⟨F, ∧, ∨, 0, 1⟩，满足有限交对任意并分配：

a ∧ ⋁i ∈ I bi = ⋁i ∈ I (a ∧ bi)　　（任意指标集 I，包括空集）

frame 同态 h : F → G 是保有限交（含顶元）与任意并（含底元）的映射。

原型：任何拓扑空间 X 的开集格 Ω(X) = ⟨τ, ∩, ∪, ∅, X⟩ 是 frame——任意并封闭、有限交封闭、交对并分配，都是拓扑公理加集合运算的直接后果。

那条分配律凭什么挑中它

回到「可验证性」读法。设 a 是「观察到 a」，bi 是一族观察。那么：

  • ⋁i bi = 「至少一个 bi 被验证」——这仍然是可验证的：只要给出那个 i 和它的证据就行。任意析取都允许，这是半可判定性的关键特征。
  • a ∧ b = 「a 与 b 都被验证」——有限个证据拼起来就行，所以有限合取允许；无穷合取要同时给出无穷多证据，一般做不到。
  • 分配律 a ∧ ⋁i bi = ⋁i (a ∧ bi) 说的是：「先看到 a，再看到某个 bi」等价于「看到某个「a 与 bi 同时成立」的证据」——正是观察能拼合的意思。

所以 frame 公理不是拓扑公理的代数伪装，它是可观察性本身的逻辑。教材说的「几何逻辑」就是这套「有限 ∧ + 任意 ∨」的逻辑。

分配律不是免费的：一个反例

取向量空间 V 的子空间格（按包含排序）。它是完备格：任意并是生成子空间，任意交是集合交。但不满足 frame 分配律。取 V = ℝ²，a = x 轴，b₁ = y 轴，b₂ = 对角线 y = x。则 b₁ ∨ b₂ = ℝ²，故 a ∧ (b₁ ∨ b₂) = a；但 a ∧ b₁ = 0、a ∧ b₂ = 0，故右边 = 0。子空间格不是 frame——「同时可验证」在量子式的叠加结构里不按经典分配律走。这也提示了为什么量子逻辑要用正交模格而不是 frame。

3.2Locale = Frameop：方向为什么必须反

定义 Locale

Locale 的范畴 Loc 定义为 Frameop：locale 就是 frame（记号上区分，写 ΩX 表示 locale X 对应的 frame），但从 X 到 Y 的连续映射 f : X → Y 定义为 frame 同态 f* : ΩY → ΩX。

方向反，是因为观察只能拉回

你在 L23 已经见过同一件事：Stone 对偶里 BAop ≃ Stone，连续映射 f : X → Y 给同态 f*(V) = f−1(V)。这里一模一样。给你一台显微镜（f：载玻片 → 屏幕），你在屏幕上做一个观察 V，等于在载玻片上做了观察 f−1(V)。观察天然沿映射反向搬运，所以 frame 同态的方向必须和连续映射相反。

这不是别扭，是情报：连续的真定义就是「拉回保有限观察」。显微镜像（观察到 V）能翻译回载玻片上的观察（f−1(V)），而且这个翻译保持「同时」与「或者」。这条思路后来直接长成 topos 理论里几何态射的定义。

两套记号，别混
这边（locale）那边（frame）为什么
积 X × Y余积 ΩX ⊗ ΩY范畴取反，积变余积
子 localeframe 的商同上
连续映射 f同态 f*拉回方向

4O3　点 = 完全素滤子；sober 与 sobrification O3

L23 说「点 = 超滤子」。现在要把这句话升级成 frame 版本，而且必须升级对——因为这里藏着一个特别容易讲错、又特别有教益的区别。

4.1素滤子 vs 完全素滤子：量词的位置又要人命

定义 两种素性

设 F ⊆ A 是 frame（或有界格）上的滤子（L02 三条：上闭、有限交封闭、含顶）。

  • F 素：若 a ∨ b ∈ F，则 a ∈ F 或 b ∈ F。有限析取。
  • F 完全素：若 ⋁i ∈ I ai ∈ F，则存在 i ∈ I 使 ai ∈ F。任意析取。

在有限布尔代数上两者显然等价。在什么条件下一般也等价？这就是下面的关键例子。

L23 的「超滤子 = 点」不是 locale 的「点」

取 A = 𝓟(ℕ)，把它当 frame（并 = 集合并，交 = 集合交）。它是离散空间 ℕ 的开集格。取任一非主超滤子 U（L13/L14 里 βℕ − ℕ 的点）。它是素滤子：这没问题是 L23 证过的。

但它不是完全素滤子。证明只需一行：令 an = {n}，则 ⋁n an = ℕ ∈ U，但没有任何 {n} ∈ U——否则 U 就是主超滤子了。量词一从「两个」换成「任意一族」，非主超滤子全军覆没。

于是 pt(𝓟(ℕ)) = ℕ（只有主超滤子给出的点），而 L23 的 Stone 空间 Ult(𝓟(ℕ)) = βℕ 多出一大片。这不是矛盾，是两个不同对象的开集格不同：𝓟(ℕ) 是 ℕ 的开集格（也是 βℕ 的开闭格，不是全部开集格）。βℕ 的开集格更大，它的完全素滤子确实给回 βℕ 的全部点，因为 βℕ 是 Stone 空间、从而 sober（下面会证）。记住这句话：Stone 对偶用超滤子，locale 用完全素滤子；在无穷并出现时二者分道扬镳。

4.2点的空间 pt(F)

定义 pt(F) 与 Ω ⊣ pt

对 frame F，令 pt(F) = 全体完全素滤子。对 a ∈ F，令

φ(a) = { p ∈ pt(F) : a ∈ p }

这些 φ(a) 构成 pt(F) 的一个拓扑（交对有限、并对任意还是由完全素性保证——验一下：p ∈ φ(⋁ai) ⟺ ⋁ai ∈ p ⟺ ∃i (ai ∈ p) ⟺ p ∈ ⋃φ(ai)）。这就得到一个函子 pt : Frameop → Top。

反方向就是 Ω : Top → Frameop：X ↦ Ω(X)，连续 f ↦ f−1。这两者构成伴随 Ω ⊣ pt（Johnstone、Piccinini–Pultr）。

4.3Sober：可见的都在，且不重影

定义 Sober 空间

拓扑空间 X sober，若每个不可约闭集 C（C ⊆ U ∪ V 且 U, V 开 ⟹ C ⊆ U 或 C ⊆ V）都是某个点的闭包 cl{x}，且这个点唯一。

等价说法：每个完全素滤子都是某点的邻域滤子，且该点唯一。白话：你从开集能认出来的「位置」，在空间里真的有一个点；而且只有一个。有个俏皮记法：sober 就是「看见的都在，而且不重影」。

命题 sober 判定与例子（标准文献）
  1. sober ⟹ T0；Hausdorff ⟹ sober。所以要找非 sober 例子，得往分离性弱的地方去。
  2. 伴随 Ω ⊣ pt 的单位 η : X → pt(ΩX) 把 x 送到邻域滤子；η 是同胚 ⟺ X sober。
  3. 限制到 sober 空间与 spatial frame（§5），Ω 与 pt 给出范畴等价 Sob ≃ SFrmop。
  4. L23 回指：每个 Stone 空间是紧 Hausdorff，故 sober。Stone 对偶完美地待在 sober 世界里——这就是为什么 L23 没遇到任何「点不够」的麻烦。
例 4.4（老朋友回来）余有限拓扑非 sober

取无限集 X 上的余有限拓扑（L14 例 6.3.10：连通且极端不连通、T1 但非 Hausdorff）。它的闭集只有有限集与 X。整个 X 是闭集，而且不可约（两个真闭子集都是有限的，有限集的并不能覆盖无限集 X）。

但 X 不是任何点的闭包：在 T1 空间里 cl{x} = {x}，而 X 无限。于是 X 不可约闭，却没有泛点——非 sober。这个例子你 L14 见过两次（极端不连通的边界例、T1 导集麻烦），现在第三次出场，角色是「点不够」的标本。

sobrification 怎么修：给 X 添一个点 ∞，规定含 ∞ 的开集是 {∞} ∪ (X − F)（F 有限）。新空间里 cl{∞} = X，泛点有了，sober。这是一个「理想点」——和 L13 用 Stone–Čech 紧致化补点、L19 Henkin 构造补见证常元，是同一个动作的第三次出现。

例 4.5（L25 回来）Alexandrov 空间一般非 sober

L25 §4 把预序 ≤ 赋成「开集 = 上集」的 Alexandrov 拓扑。Vickers 指出：这类偏序集一般非 sober。理由一眼可见：定向集 D 的上界集合（理想完备化要补的东西）对应一个「不可约闭集」，而原偏序集里未必有点实现它的上确界。

补法：作理想完备化——把所有定向理想当成新点。这正是 L25 里 Kripke 语义能装进拓扑语义的代价：Alexandrov 空间为了「任意并封闭」多给了太多开集，点反而不够用了。把这例子和 L25 §4.1 的警告并读，会看见无点视角并不是在挑刺，而是在指出一个真实的结构缺口。

「locale 天生 sober」是什么意思

因为 locale 的定义里就没有任何多余的点——它的点按定义就是完全素滤子，即「从开集能认出来的位置」。所以 pt(ΩX) ≅ X 对 locale 自动成立（在适当意义下）。非 sober 是点集空间的病，不是 locale 的病。这也解释了为什么范畴论者偏爱 locale：他们把「拓扑自然的空间」直接定义成 sober 的，其余的视为携带了拓扑看不见的冗余信息。

来源：Johnstone《Stone Spaces》Ch II §1–2；Piccinini–Pultr《Frames and Locales》Ch II；Vickers《Some constructive roads to Tychonoff》§0.1.2、Vickers 研究主页；L23 Stone 表示、L14 例 6.3.10、L25 §4.1。

5O4　空间性、子 locale 与「locale 不是空间的翻版」 O4

到这一步很容易以为 locale 只是点集空间的另一种写法。这一节专门拆掉这个误会：有 frame 点不够（非空间），有 locale 算出来的子对象和积跟空间里的不是一回事。差别正是新几何的内容，不是技术瑕疵。

定义 Spatial frame

frame F 空间（spatial），若它的元素能被点分开：

∀a ≠ b ∈ F,　∃p ∈ pt(F) 使 a ∈ p, b ∉ p（或反过来）

等价说法：每个元素都是「素元」的并。判定定理：单位 η : X → pt(ΩX) 是同胚 ⟺ X sober；ε : F → Ω(pt F) 是同构 ⟺ F spatial。两者合起来给等价 Sob ≃ SFrmop（§4.3）。

非空间 frame 是真实存在的

不满足上面条件的 frame 叫非空间——它有开集结构，但「点」不足以来区分这些开集。存在性是标准结果（Johnstone《Stone Spaces》Ch II §2 给系统例子；Banaschewski、Isbell 有经典构造）。

这里不硬塞一个复杂构造，只把判定机制说透：如果有两个不同的 a, b，使得每个完全素滤子要么同时含它们、要么同时不含，点就永远分不开这对开集。此时 Ω(pt F) ⊊ F，从点回看丢了信息。L23 的 Stone 对偶从不遇到这事，因为布尔代数的超滤子总能分开不等元素（那是定理 2.43 的内容）；无穷分配律一进来，情况就变了——这正是「frame 比布尔代数强」要付出的对价。

哲学上值得停一下：如果当年拓扑学是从 frame 起步的，我们大概会把非空间 frame 当作正常几何对象，而不会觉得它「没有点、不像空间」。「像不像空间」是历史习惯，不是数学性质。

5.1子 locale = frame 的商（方向反的后果）

三条与点集直觉冲突的事实（标准文献）
  1. 子 locale 对应 frame 的商，不是子 frame。因为 Loc = Frameop，单态变满态。
  2. 任意多个稠密子 locale 的交仍稠密。点集空间里完全不对：在 ℝ 中 ℚ 与 ℝ−ℚ 都稠密，交是空的。locale 里不可能出现两个稠密子对象"互相躲开"——这深刻改变了「子集」的几何意义。
  3. locale 的积不必是空间积。对 sober 空间 X, Y，Ω(X ×Top Y) 与 ΩX ⊗ ΩY（locale 积）一般不同；当其中一个因子局部紧时一致。这是 Johnstone《Stone Spaces》的经典定理。

为什么第 2 条会发生：子 locale 不是「挑一批点」，而是「在 frame 上加一层约束」；稠密意味着约束不改变可观察的真值。两个这样的约束叠加，仍然不改变真值——所以交还稠密。你一旦用点去想「稠密 = 到处有点」，这条定理就显得诡异；用观察去想，它几乎是必然的。

这一节真正想说的

locale 不是点集空间的「优化版」，而是另一个范畴，它和空间只在 sober/spatial 的交集上吻合。范畴不同，意味着「子对象」「积」「稠密」这些词都要重新定义。你在 L23 已经历过一次同样的转向（BAop ≃ Stone 时，商代数 ↔ 闭子空间、子代数 ↔ 连续满像，方向全反）；这次只是把同一课重上一遍，但对象更大。

来源：Johnstone《Stone Spaces》Ch II §2、Piccinini–Pultr《Frames and Locales》Ch II；稠密交与积的定理见 HandWiki「Locale」条目综述；L23 对偶词典回指。

6O5　way-below、紧 locale 与连续格（L13 的深化） O5

L13 把紧致性讲成「每个开覆盖有有限子覆盖」，又讲成「每个超滤子收敛」，再讲成「完备性」。这一节用 frame 的语言把它说成第三个样子：1 ≪ 1。三个说法是同一件事在不同范畴里的影子。

定义 way-below（紧包含）

在完备格 L 上，a ≪ b 读作「a 紧包含于 b」，若对任意定向集 D ⊆ L（非空、每两个元素有共同上界）：

b ≤ ⋁D　⟹　∃d ∈ D (a ≤ d)

L 是连续格，若每个元素都是紧包含于它的元素的定向并：b = ⋁{a : a ≪ b}。若可取「紧元」（满足 a ≪ a）为基，称代数格。

≪ 到底在说什么

把 a ≪ b 读成「b 的成立只靠有限信息就能保证 a」。定向集 D 是一步步增长、彼此相容的观察序列；⋁D 是它们的极限。如果 a 在极限里成立却永远不在某一步里成立，那 a 需要「无穷多观察」才能确认——不是有限可验证的。a ≪ b 排除这种情况。

在拓扑空间里，K ≪ U 对紧集 K 与开集 U 恰好成立：任何递增开覆盖 U 都能抽有限子覆盖。「紧」这个字就是从这里长出来的。

定理 6.1（紧 locale 的两种刻画，逐步证）

对 frame F，以下等价：

(i) 1 ≪ 1；　(ii) 若 ⋁i ∈ I ai = 1，则存在有限 J ⊆ I 使 ⋁j ∈ J aj = 1

满足者称紧 locale（frame 意义下的紧）。

（i ⟹ ii）

设 ⋁i ai = 1。令 D = { ⋁j ∈ J aj : J ⊆ I 有限 }。这是定向集（两个有限集的并仍有限，给出共同上界），且 ⋁D = 1。由 1 ≪ 1 得存在 d ∈ D 使 1 ≤ d，这个 d 就是有限子覆盖。

（ii ⟹ i）设 D 定向且 ⋁D = 1。把 D 本身看成覆盖，由 (ii) 取有限 d₁,…,dn ∈ D 使 d₁ ∨ … ∨ dn = 1。由定向性，存在 d ∈ D 同时≥所有 dᵢ，于是 d = 1。这正是 1 ≪ 1（取 a = 1）。∎

L13 / L18 的三重回指
讲次紧的写法用的机器
L13每个开覆盖有有限子覆盖 ⟺ 每个超滤子收敛素滤子 / 紧致化
L18有限可满足 ⟹ 整体可满足超积 + Łoś
L26（本讲）1 ≪ 1 ⟺ 覆盖有有限子覆盖定向集 / way-below

三种写法都抓住同一件事：无穷信息能被有限信息兑现。L18 的超滤子写法靠选择公理，本讲的 ≪ 写法是构造性的——这就是 Vickers 能构造性证明 locale Tychonoff 的原因（§2.2）。

定理 6.2（局部紧 locale，标准文献）

locale X 局部紧，若 frame ΩX 是连续格。并且：

  • 局部紧 locale 必空间（Johnstone）；
  • 局部紧 locale 范畴 ≃ 局部紧 sober 空间范畴。

这是无点拓扑最漂亮的成果之一：在局部紧这个天然条件下，两个范畴严丝合缝。L13 的 βX、L14 的 Stone 空间、L25 的极端不连通空间，全部落在这个等价里面。

来源：way-below 与连续格见 Johnstone《Stone Spaces》Ch VII、Abramsky–Jung《Domain Theory》；紧 locale 刻画与局部紧等价见 HandWiki「Locale」综述与 Piccinini–Pultr。L13/L18 回指。

7O6　Heyting 代数与直觉主义（L02 的深化） O6

现在接上教材里最实在的一块：Bergman 定义 3.30 与例 3.31。拓扑讲义说「locale 的开集结构形成完备 Heyting 代数」——这句话到底是什么意思，为什么它和直觉主义逻辑绑在一起。

7.1从伪补到相对伪补

定义 Bergman 3.30（伪补）

有界分配格 L 中，b 是 a 的伪补，若对所有 x ∈ L：

x ∧ a = 0　⟺　x ≤ b

即 b 是与 a 不相交的最大元素，记作 a*。每个元素都有伪补的有界分配格称伪补格。

Bergman 例 3.31(3)：开集格是伪补格

设 ⟨X, τ⟩ 是拓扑空间，Ω = ⟨τ, ∩, ∪, ∅, X⟩ 是有界分配格。对开集 A：

A* = (X − A)° = int(X − A)

即「A 的补的内部」是 A 在开集格中的伪补。

验证三条。

（1）它是开集，由定义。（2）A ∩ int(X−A) ⊆ A ∩ (X−A) = ∅。（3）若 B 开且 B ∩ A = ∅，则 B ⊆ X−A，而 B 开，故 B ⊆ int(X−A)。∎

定义 Heyting 代数（相对伪补）

有界格 H 是 Heyting 代数，若对每对 a, b 存在元素 a → b，满足伴随条件：

c ∧ a ≤ b　⟺　c ≤ a → b　　对所有 c ∈ H

即「a → b」是使 c ∧ a ≤ b 成立的最大 c。否定定义为 ¬a = a → 0，于是 ¬a 恰是 Bergman 的伪补 a*。

在 frame 中，由于有任意并，a → b 可以显式造出来：

a → b = ⋁ { c ∈ F : c ∧ a ≤ b }

这就是拓扑讲义「完备 Heyting 代数」那句话的精确内容：frame 的无限分配律保证这个并真能满足伴随条件。反过来说，一个 frame 忘掉无限分配律，只剩有限分配与这个 →，就是 Heyting 代数。

7.2开集格上的蕴涵与排中律的失败

命题 开集格的 Heyting 结构

在 Ω(X) 中：

A → B = int( (X − A) ∪ B )　　¬A = int(X − A)
验证伴随。

C ∩ A ⊆ B ⟺ C ⊆ (X−A) ∪ B；因 C 开，这又等价于 C ⊆ int((X−A) ∪ B)。正是伴随条件。∎

手算：排中律在 ℝ 里坏在哪

取 A = (0,1) ⊆ ℝ：

¬A = int( ℝ − (0,1) ) = int( (−∞,0] ∪ [1,∞) ) = (−∞,0) ∪ (1,∞)

注意端点 0 和 1 被内部算子丢掉了——任何含 0 的开区间都伸进 (0,1)。于是

A ∨ ¬A = (0,1) ∪ (−∞,0) ∪ (1,∞) = ℝ − {0,1}　⊊　ℝ

排中律 A ∨ ¬A = 1 失败。但双否定成立：¬¬A = int( ℝ − ((−∞,0) ∪ (1,∞)) ) = int([0,1]) = (0,1) = A。这个具体计算把「直觉主义为什么不是排版错误」钉死了：它描述的是「可验证」而非「真或假」。

与布尔代数的准确关系

布尔代数是 Heyting 代数的特例：在 BA 里 a → b = ¬a ∨ b，因为补运算真存在。判别条件是

Heyting 代数满足排中律（∀a, a ∨ ¬a = 1）　⟺　它是布尔代数

所以「 Heyting 比 Boole 弱」不是缺点，而是允许的语义更多：开集格、上集格、连续格都是 Heyting 而不是 Boole。L23 的 Stone 对偶只对 Boole 成立；要覆盖 Heyting，得换 Esakia 空间（§9）。

7.3¬¬ 是闭包算子：L02 的第三次出场

命题 在 Heyting 代数中，j(a) = ¬¬a 是闭包算子

扩张。a ≤ ¬¬a：直觉主义定理，代数证明为 a ∧ ¬a = 0，由伴随得 a ≤ ¬¬a。

单调。a ≤ b ⟹ ¬b ≤ ¬a ⟹ ¬¬a ≤ ¬¬b，两次用反序性。

幂等。先证三重否定 ¬¬¬a = ¬a：一方面，由扩张用于 a 得 a ≤ ¬¬a，反序推出 ¬¬¬a ≤ ¬a；另一方面，把扩张用于 ¬a 得 ¬a ≤ ¬¬¬a。两式合起来即相等。现在令 b = ¬a 代入，得 ¬¬¬(¬a) = ¬(¬a)，即 ¬¬¬¬a = ¬¬a。∎

这件事为什么值得单独说

你在 L02 第一次见闭包算子时，例子是「生成子代数」和「逻辑后承」。L10 见第三次，是拓扑 cl。这里是第四次：直觉主义的双否定。同一个抽象结构反复出现，本身就说明你当时抓对了东西。而且这次有个漂亮解释：¬¬ 把「a 不可反驳」变成一种新的「弱真」——从「有证据」到「没有反证」，正是一次闭包。

来源：Bergman 定义 3.30、例 3.31(1)(2)(3)；拓扑讲义 Ch7「完备 Heyting 代数」；frame 中 → 的显式构造与三重否定定理见 Johnstone《Stone Spaces》。L02/L10 回指。

8O7　Gödel 翻译与模态伴侣（L25 的深化） O7

上一讲你学了 S4 与它的拓扑语义。这一节要告诉你一件会让前面所有东西突然串起来的事：S4 就是直觉主义逻辑的模态影子。这不是比喻，是一个精确的同构级别的结果。

定义 Gödel–McKinsey–Tarski 翻译

把直觉主义公式 φ 译成模态公式 T(φ)：

T(p) = □p　（p 为命题变元）　　T(⊥) = ⊥
T(φ ∧ ψ) = T(φ) ∧ T(ψ)　　T(φ ∨ ψ) = T(φ) ∨ T(ψ)
T(φ → ψ) = □( T(φ) → T(ψ) )

由于 ¬φ := φ → ⊥，立刻有 T(¬φ) = □¬T(φ)。直觉主义的否定被译成「必然非」——和你上一讲刚学的 □ = int 严丝合缝：开集格里的 ¬A = int(X−A) = □(X−A)。

定理 Gödel (1933) 提出，McKinsey–Tarski (1948) 证明
IPC ⊢ φ　⟺　S4 ⊢ T(φ)

翻译是嵌入，不只是单向保真。这条定理是「模态伴侣」理论的基石。

哲学上这说的是什么

直觉主义的口号是「真 = 可证」。但「可证」在纯句法上不好给语义。Gödel 的招数是：在经典模态语言里找一个算子来扮演「已有证明/已被验证」——那就是 □。于是：

  • p（直觉主义：有 p 的证明）译成 □p（模态：在稳定区域内 p 成立）。
  • φ → ψ（有从 φ 到 ψ 的构造）译成 □(Tφ → Tψ)——蕴含本身也要是可验证的。
  • ¬φ（有从 φ 到假的构造）译成 □¬Tφ——否定 = 必然非。

为什么必须是 S4 而不是 K？因为「可验证」必须是自反思的：已经被验证的，可以验证「它已被验证」（对应 4： □p → □□p）；而且被验证的一定真（对应 T： □p → p）。L25 §3 给 S4 的四条公理，在这里获得了认识论解释：它们就是「证明」这个概念必须满足的条件。

8.1语义侧：Alexandrov 空间就是直觉主义 Kripke 模型

把 L25 的预序和直觉主义的偏序对齐

直觉主义 Kripke 模型是偏序 ⟨P, ≤⟩ 加一个上集赋值；w ⊨ φ → ψ ⟺ ∀v ≥ w (v ⊨ φ ⟹ v ⊨ ψ)。L25 §4 的 Alexandrov 模型是预序 ⟨W, ≤⟩ 加上集拓扑，int(A) = {x : ↑x ⊆ A}。

于是对上集 A, B：

int( (X−A) ∪ B ) = { x : ∀y ≥ x ( y ∈ A ⟹ y ∈ B ) }

右边逐字就是直觉主义 Kripke 的蕴含条件。也就是说：L25 的 □=int 装进 Alexandrov 空间后，与直觉主义 Kripke 语义是同一个语义。预序商掉等价类（x ~ y ⟺ x ≤ y ≤ x）就是偏序——这正是 Gödel 翻译在模型层面的形状。

9.1从 Priestley 到 Esakia

定义 Priestley 空间 → Esakia 空间

Priestley 空间：紧序拓扑 ⟨X, τ, ≤⟩，满足若 x ≰ y，则存在开闭集 U 使 x ∈ U, y ∉ U（Priestley 分离；Bergman 定理 2.46 后的评论已预告）。

Esakia 空间：满足额外条件的 Priestley 空间——

对任意开闭集 C，其下集 ↓C = { x : ∃c ∈ C, x ≤ c } 仍是开闭集

等价地：每个 ↑x 闭、且 ↓C 开闭。这个条件正是「蕴涵要在对偶代数里活着」所需的。

修正 L23 的一句简写

L23 §9 预告 Esakia 空间时写成「每个点的开上邻域含一个开闭上集条件」。那是为了不打断当期节奏的直观说法，精确条件应如上：开闭集的下集仍开闭。两句话的直觉相通（都关乎「开闭集在序操作下不跑出去」），但写证明时必须用后一句。Esakia 条件的等价形式还有：↑cl(A) = cl(↑A) 对所有 A 成立。

9.2对偶定理与关键公式

定理 Esakia 对偶（1974/1985；标准文献）

范畴 HA（Heyting 代数与同态）与 Esa（Esakia 空间与连续有界态射）对偶等价：

  • 对 H ∈ HA：点 = H 的素滤子，序 = 包含，φ(a) = {x : a ∈ x} 生成拓扑。
  • H ≅ 该空间的开闭上集格（交并照常）。
  • 蕴涵在空间侧的公式为
U → V = X − ↓(U − V)

这个公式值得盯住。布尔情形（L23）的补是集合差；Heyting 情形的蕴涵要额外做一次下集 ↓，因为「a → b 在滤子 x 里」涉及的是沿序往上所有滤子的行为。多出来的 ↓ 就是直觉主义比经典逻辑多出来的那点结构。

与 §7 的拓扑 Heyting 公式如何并存

§7 给的是 A → B = int((X−A) ∪ B)（开集格内部）；这里是 U → V = X − ↓(U − V)（Esakia 空间的开闭上集）。二者不冲突：前者在开集格上算，后者在素滤子空间上算，经由 a ↦ φ(a) 对上。在 Alexandrov 模型里，§8.1 已验证前者逐字等于直觉主义 Kripke 的蕴含条件；后者是同一条件在紧化了的对偶空间上的写法。序的方向由「素滤子按包含排序」的约定决定——照文献照抄即可，别凭直觉把 ↓ 改成 ↑。

一座桥回到 L25：内部代数

L25 的 S4 代数（拓扑布尔代数 = 布尔代数加内部算子）有个标准事实：它的「开元素」（□a = a 的元素）构成一个 Heyting 代数，而且每个 Heyting 代数都能这样得到。

翻译成人话：你上一讲学的 □ = int，把布尔代数切成两半——开元素那半不满足排中律，正好是直觉主义逻辑的代数；整个代数加上 □，则是 S4 的代数。Gödel 翻译（§8）在代数侧说的就是这件事。McKinsey–Tarski (1944) 是这个观察的源头，Esakia 给了它的空间对偶，Blok–Esakia 把它升成格同构。

10三层例：典型 / 本质 / 边界 O1–O8 总检验

典型例子 ℝ 的开集格：Heyting 而非 Boole

Ω(ℝ) 是 frame，也是 Heyting 代数，不是布尔代数——§7.2 已经手算过 (0,1) ∨ ¬(0,1) ≠ ℝ。同时 ℝ Hausdorff ⟹ sober（§4.3），所以 pt(Ω(ℝ)) ≅ ℝ，没有点不够的问题。这是「无点方法在普通空间上完全不改变结果」的样板：你熟悉的每个好空间都在这一格。

本质例子 βℕ 与非空间 frame：无点视角真正出手的地方

βℕ 你已经遇过四次：L13 紧致化、L14 极端不连通、L23 Ult(𝓟(ℕ))、L25 S4.2/KD45 的样板。这里第五次：它是紧 Hausdorff 从而 sober 的空间，pt(Ω(βℕ)) ≅ βℕ；而 𝓟(ℕ) 作为 frame 的点只有主超滤子（§4.1）。两个 frame 的区别（𝓟(ℕ) vs Ω(βℕ)）正好量出了「开闭集格」与「全部开集格」的差距。

非空间 frame 则是另一类本质例子：开集结构完备、分配律齐全，但点分开不了元素。它说明 locale 范畴真比空间范畴大，不是同一对象的换名。

边界与误解 三个「点不够」的现场

① 余有限拓扑（L14 老朋友）：T1、连通、极端不连通，但非 sober——不可约闭集是整个 X，没有泛点；sobrification 添一个 ∞ 修好。② Alexandrov 空间（L25）：预序的开集 = 上集，一般非 sober，补法是理想完备化。③ 非主超滤子是 L23 的点、不是 locale 的点（§4.1）——这个最容易讲错，量词位置一变身份就变。

三例一起记：点集空间里「点」总是有的，但可能不够（①②）或太多（③）；locale 把这些纠葛一次性定义干净。

给你的读法建议

这一讲的每个结论单独看都不难，难的是它们同时改变三个坐标：本体论（点还是事实）、逻辑（经典还是直觉主义）、范畴（空间还是 locale）。如果读完只记住「frame 是完备 Heyting 代数」，那还只是了解；记住「你一直在用可验证命题工作，点是后来补上的」，才算理解。
