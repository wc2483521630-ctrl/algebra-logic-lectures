本讲新概念（八个，按依赖排序）
  1. 准等式：等式之间的蕴涵 (σ₁=ρ₁ ∧ ⋯ ∧ σₙ=ρₙ) → σ₀=ρ₀；代数的「推理规则」，也是逻辑可容许规则的原型。

  5. 子直既约的透明化：Sir(HSPK) = Sir(SUpK)，且每个成员单；推论 2.7.8 + 练习 2.7.4(1)。

2为什么拿它收尾；两种「难」 O1

UAL 前言的「Teaching the book」列了十三周泛代数课程，最后一写的是：Selected applications from section 7.1。前面十二周造了同余、子直积、超积、自由代数、布尔代数、判别式簇、BAO；这一周不造新工具，只把判别式簇开到关系代数上，看它能挣来什么。

直觉 · 「难」有两种，判别式项只治其中一种

描述一类代数有两种方式。用等式（如 x ∪ y = y ∪ x）得到的是簇，算子 HSP 封闭、自由代数存在、Birkhoff 定理可用；用准等式（如「若 x·y = 0 则 y·x = 0」）得到的是准簇，只有 SPPU 封闭，工具箱小一圈。

关系代数的抽象公理天然带这种「若…则…」：例如 x 是函数当且仅当 x−1 ◦ x ≤ Id 这类条件。于是问题变成：能不能把准等式改写成等式，让准簇升格为簇？判别式项就是干这件事的——它能在代数内部实现「if-then-else」，于是「若前提成立则结论成立」可以被写成一条永远成立的等式。

回顾 L06 定义 6.4 = UAL 定义 2.7.1/2.7.2

集合 A 上的判别式函数

τ(x, y, z, u) = z　若 x = y；　τ(x, y, z, u) = u　若 x ≠ y.

若一族代数 K 有公共判别式项 τ，则 HSPK 叫判别式簇。有布尔缩并时，判别式项等价于开关项 c(x)（x=0 取 0、否则取 1），两者互定义：

τ(x, y, z, u) = [−c(x ⊕ y) ∩ z] ∪ [c(x ⊕ y) ∩ u],　　c(x) = τ(x, 0, 0, 1).

这里 ⊕ 是对称差。三元版本 t(x,y,z) = τ(x,y,z,x) 与四元版互定义：τ(x,y,z,u) = t(t(x,y,z), t(x,y,u), z)。

典型 · 判别式项的第一后果：所有成员都单

设 R 是 A 上非恒等同余，取 u R v 且 u ≠ v。对任意 a, b：

a = τ(u, u, a, b)　R　τ(u, v, a, b) = b.

于是 R = A×A——有判别式项的代数是单的（练习 2.7.4(1)）。这一行是本章的发动机：它让子直既约成员和「全关系代数」划上等号（O4 的引理 7.1.6），也让 BA 成为最小例子（定理 2.7.3：2 有判别式项且 BA = HSP{2}）。

别以为判别式簇万能

下一讲之前先把边界钉死：群簇没有判别式项（判别式项逼出单性，而 ℤ 不单）；RCAω 不是判别式簇；ICrsn（n ≥ 2）也不是。判别式簇是一把好用的钥匙，不是万能钥匙——它恰好能开关系代数这一扇门。

3核心引擎：准等式压成等式 O2

这是全讲最关键的一节，也是最容易被掠过的一节。教材把命题 2.7.6 的证明写得紧凑，这里按 L22 的规矩逐步拆开，不跳关键细节。读完这一节，后面所有「判别式簇的威力」都只是套用。

记号 准等式与长度

准等式形如

q:　(σ₁ = ρ₁ ∧ ⋯ ∧ σₙ = ρₙ) → σ₀ = ρ₀.

左边等式的个数 n 叫 length(q)；n = 0 时它就是普通等式。记 q′: (σ₂=ρ₂ ∧ ⋯ ∧ σₙ=ρₙ) → σ₀=ρ₀，于是 length(q′) = n−1，并且

q　等价于　σ₁ = ρ₁ → q′.
命题 2.7.6

设 K 有判别式项 τ。则对任意准等式 q，存在一个等式 e(q)，使得

(i)　K ⊨ e(q) ↔ q　　(ii)　HSPK ⊨ e(q) → q.

注意两侧的分工：(i) 在 K 上双向等价，(ii) 在整个簇里只保「等式推出准等式」这一个方向——这个不对称正是证明的关窍。

证明 · 对 length(q) 归纳。
  1. 基步 n = 0。 q 本身就是等式，取 e(q) = q，两条显然。
  2. 归纳假设。对所有 q′ 且 length(q′) < n，存在等式 σ = ρ 使
    K ⊨ (σ = ρ) ↔ q′　且　HSPK ⊨ (σ = ρ) → q′.　　(2.27)
  3. 关键构造。令
    e(q)　:=　τ(σ₁, ρ₁, σ, ρ) = ρ.
    先读懂这个项：若 σ₁ = ρ₁，判别式返回第三参 σ，于是 e(q) 说的是 σ = ρ（归纳假设里 q′ 的替身）；若 σ₁ ≠ ρ₁，返回第四参 ρ，于是 e(q) 自动成立。「前提不成立时等式平凡成立」——if-then-else 把蕴涵伪装成了全称等式。
  4. 证 (2.28)：K ⊨ q → e(q)。取 A ∈ K 与任意赋值 ā。反证：设 A ⊨ ¬e(q)[ā]，即 τ(σ₁,ρ₁,σ,ρ) ≠ ρ。判别式只在第四种情形给出不同于第三参的值，故必有
    A ⊨ σ₁ = ρ₁[ā]　　(2.30)　　且　　A ⊨ σ ≠ ρ[ā].
    由后一件与 (2.27) 的第一半（K ⊨ (σ=ρ) ↔ q′）得 A ⊭ q′[ā]。再合上 (2.30)，正是 A ⊭ q[ā]。于是 A ⊨ ¬e(q) → ¬q，即 q → e(q) 在 K 成立。
  5. 证 (2.32)：HSPK ⊨ ¬q → ¬e(q)。取 A ∈ HSPK、任意 ā，设 A ⊭ q[ā]。因为 q 等价于 σ₁=ρ₁ → q′，所以
    A ⊨ σ₁ = ρ₁[ā]　　且　　A ⊭ q′[ā].
    由 (2.27) 的第二半 HSPK ⊨ (σ=ρ) → q′ 逆否，得 A ⊨ σ ≠ ρ[ā]。于是判别式给出 τ(σ₁,ρ₁,σ,ρ) = σ ≠ ρ，即 A ⊭ e(q)[ā]。这就是 ¬q → ¬e(q)。
  6. 合起来。(2.28) 给出 (i) 的左半 q → e(q)；(2.32) 限制到 K ⊆ HSPK 给出 K ⊨ e(q) → q，与 (2.28) 合成 (i) 的双向；而 (2.32) 本身正是 (ii) 的逆否写法。□
直觉 · 为什么两侧不对称

在 K 里，「σ=ρ」和「q′」完全等价（归纳假设上半），所以 e(q) 和 q 可以互推。出了 K 到了 HSPK，等式被 HSP 保持、q′ 未必，我们只剩「σ=ρ → q′」这一个方向（归纳假设下半），恰好够证明「e(q) → q」。归纳假设两半各管一边的证明——教材的紧凑写法把这件事藏起来了。

本质 · 开关项版 e(q) 长什么样

若 K 有布尔缩并，用 c 写更直观。条件「所有 σᵢ=ρᵢ 且 σ₀≠ρ₀」不可能发生，写成恒等式就是

−c(σ₁ ⊕ ρ₁) ∩ ⋯ ∩ −c(σₙ ⊕ ρₙ)　≤　−c(σ₀ ⊕ ρ₀).

左边非空当且仅当每个 σᵢ=ρᵢ；此时右边要求 σ₀=ρ₀。这正是教材脚注 8 给出的显式 e(q)。它也是 O5 里「半群准等式 → 关系代数等式」那一幕的主角。

4结构定理：HSPK = SPUpK 与子直既约 O3

命题 2.7.6 的回报立刻兑现。它把「准等式类」变成「等式类」，于是 Birkhoff 机器可以开动。

定理 2.7.5

设 K 有判别式项，则

HSPK = SPUpK.

教材特意注明：此证明走模型论路线、更直观，思路来自 Johan van Benthem；标准泛代数教材多用计算式证明。

证明 · 两步夹击。
  1. 先证 HSPK ⊨ Qeq(K)。取 q ∈ Qeq(K)（在 K 成立的准等式）。由命题 2.7.6(i)，有等式 e(q) 使 K ⊨ e(q) ↔ q，特别地 K ⊨ e(q)。等式被 H、S、P 保持，故 HSPK ⊨ e(q)。再用命题 2.7.6(ii)：HSPK ⊨ e(q) → q，得 HSPK ⊨ q。
  2. 于是
    HSPK ⊆ Mod Qeq(K) = SPUpK,
    后一个等号是准簇刻画（定理 2.4.12）。
  3. 反向 SPUpK ⊆ HSPK。用练习 2.2.79 的算子包含：Up ⊆ HP、PH ⊆ HP、SH ⊆ HS、PP = P。于是 SPUpK ⊆ SPHPK ⊆ HSPK。□
直觉 · 这一等式到底省了什么

簇的定义要求 HSP 三个算子全封闭，其中 H（同态像）最难对付。判别式簇告诉你：H 是冗余的——任何同态像都藏在某个超积的子代数里。这一句话有两个后果：一是表示定理变简单（只需造超积），二是子直既约成员可以精确定位。

推论 2.7.8

设 K 有判别式项。则

  1. K 含于某个判别式簇；
  2. Sir(HSPK) = Sir(SUpK)：簇的子直既约成员恰是 K 的超积的子代数里的那些。
为什么成立。

判别式性质可写成全称一阶句子 ∀x,y,z,u[(x ≠ y ⇒ τ = u) ∧ (x = y ⇒ τ = z)]，全称句被 S 与 Up 保持（Łoś，L04），所以 SUpK 仍有判别式项。取 A ∈ Sir(HSPK)，由定理 2.7.5 A ∈ SP(UpK)；子直既约迫使它已在 SUpK 里。反向：有判别式项的代数是单的（O1），单的当然子直既约，故 SUpK ⊆ Sir(HSPK)。□

「公共」二字不能丢

推论 2.7.8(i) 说的是：只要 K 有一个共同的判别式项，它就自动落进判别式簇 HSPK。若每个成员各有各的判别式项、却不是同一个项，整个论证从命题 2.7.6 起就垮了——因为压缩 e(q) 用的必须是同一个 τ。这也是 O4 里「引理 7.1.6 必须证明 Sir(BRA) 有公共开关项 1◦x◦1」的原因。

5主案例：BRA 是簇 O4

前面的抽象机器现在落到具体对象上。目标：证明布尔关系代数的抽象公理类其实是等式类，即 BRA 是簇（定理 7.1.4）。教材的证明分三段，恰好对应上一节的三件工具。

定义 §7.1 · BRA 与 setBRA

记 R(U × U) 为集合 U 上全关系代数 ⟨P(U×U), ∪, −, 1, ◦, ⁻¹⟩（布尔运算 + 关系复合 + 逆）。则

BRA = SP{ R(U × U) : U 是集合 },　　setBRA = S{ R(U × U) : U 是非空集合 }.

于是 BRA = SP setBRA。教材从这一节起确立了一个统一的造类套路：先定义「最简单」的集合代数（顶元是 U×U×⋯×U 的那一个），再取所有直积的全部子代数。柱体代数、多代数依样画葫芦。

引理 7.1.5（结构分解）

BRA 对直积、子代数封闭；A ∈ BRA 可分解为若干 R(Ui×Ui) 的直积的子代数，且每个 A 的顶元是等价关系，其等价块 Ui 两两不交。

教材 Figure 7.3 给出三层结构：关系层 R（元素是 A ⊆ P(U×U)）→ 对层 P（元素是 ⟨u,v⟩）→ 集合层 S（元素是 u），由 ε（属于）与投影 p₀,p₁ 连接。同构 Q 逐层保运算：Q(1M) = U×U、Q(a ◦M b) = Q(a) ◦ Q(b)、Q(a−1) = Q(a)−1。

引理 7.1.6（子直既约 = 全关系代数；有公共判别式项）
Sir(BRA) = IS{ R(U × U) : U 非空 },　且 Sir(BRA) 有判别式项.

判别式项从哪来？在全关系代数里取

c(x) = 1 ◦ x ◦ 1.

若 x = ∅，则 c(x) = ∅；若 x 非空，取 ⟨a,b⟩ ∈ x，对任意 ⟨u,v⟩ 有 ⟨u,a⟩ ◦ ⟨a,b⟩ ◦ ⟨b,v⟩ = ⟨u,v⟩，故 c(x) = U×U = 1。这就是开关项。反向包含靠 O1 那一行：x R y, x ≠ y ⇒ a = τ(x,x,a,b) R τ(x,y,a,b) = b，有判别式项者必单，单者必子直既约。

引理 7.1.7（伪公理化 ⇒ 对超积封闭）

Sir(BRA) 是伪公理化类。

定义：K = RdU Mod(Σ)——把 K 的语言扩张到 L，在 L 中写一组一阶句子 Σ，再用一元关系符号 U 圈出论域并缩回原语言。这里 L 是三排序语言 S, P, R（集合 / 对 / 关系），带 p₀,p₁ : P → S、ε ⊆ P×R，正好把 Figure 7.3 的三层结构一阶化。伪公理化类对超积封闭（Łoś 定理直接给），这正是定理 2.7.5 里 Up 所需的条件。

教材脚注 6 的另一条路（值得知道）

也可以直接算：若 F 是 I 上超滤子，F(U) 表示 R(U×U)，则

∏F F(Ui)　≅　F(∏ Ui / F),　　a/F ↦ { ⟨u/F, v/F⟩ : {i : ⟨ui, vi⟩ ∈ ai} ∈ F }.

教材选了伪公理化路线，理由是它揭示了「真正的原因」：「具体的」代数通常就是伪公理化的——具体意味着有未编码进运算的额外结构，而额外结构在同构下会消失。这句话对理解 L23 Stone 对偶、L24 关系代数同样有用。

定理 7.1.4 · BRA 是等式类（四步收束）
  1. 令 K = Sir(BRA)。引理 7.1.6 给 K = SK 且 K 有判别式项；引理 7.1.7 给 K = UpK。于是 K = SUpK。
  2. 由定理 2.7.5，SPUpK 是等式类；再由定理 2.4.11，等式类就是 HSP 封闭的类。
  3. 由引理 7.1.5，SPUpK = SPK = SP Sir(BRA) = BRA。
  4. 故 BRA 是等式类。□

教材结语：「我们还证明了 BRA 是一个判别式簇。」并且指出同一套技术对柱体代数、多代数也有效。

直觉 · 为什么说这是「代数的 Birkhoff 时刻」

回想 L04 的 Birkhoff 定理 V = HSP：它把「可由等式公理化」与「对 HSP 封闭」等同起来。定理 7.1.4 做的是同一件事的升级版：先证明一个天然类（关系代数的抽象模型）有判别式项，再用 HSP = SPUp 把「看起来只能用准等式描述」的类洗成簇。没有判别式项，第一步就无处下手；有了它，Birkhoff 机器立刻启动。

6代价：不可有限公理化与不可判定 O5

知道 BRA 是簇之后，立刻问两个更狠的问题：能给它有限多条等式吗？能判定一条等式是否成立吗？两个答案都是否定的——而第二个否定，正是判别式簇的又一次兑现。

定理 7.1.8（Monk）

BRA 不可有限公理化：不存在有限的一阶公式集 Σ 使 BRA = Mod(Σ)。

定理 7.1.9

Eq(BRA) 递归可枚举但不可判定。

r.e. 的一半（三行）。

由引理 7.1.5，一条等式在 BRA 成立当且仅当在 Sir(BRA) 成立；由引理 7.1.7 的证明，Sir(BRA) = RdU Mod(Σ)，其中 Σ 是有限一阶句子集。由一阶逻辑完全性定理，有限理论的结论递归可枚举，故 Eq(BRA) r.e.。

不可判定的一半（两步解释 —— 全讲最漂亮的搬运）。
  1. 第一步 (∗)：半群的准等式理论可以搬进 BRA。「关于 ◦ 的准等式在所有半群成立，当且仅当它在 BRA 成立。」正向：半群都有结合律，而 BRA 的 ◦ 也结合。反向是关键：若准等式 q 在某个半群 ⟨S,·⟩ 失败，取该半群的 Cayley 表示——把 s 映到左乘变换 x ↦ s·x——得到嵌入 ⟨S,·⟩ ↪ ⟨P(S′×S′), ◦⟩，后者是某个 R(S′×S′) ∈ BRA 的缩并。q 在这个关系代数里也失败。半群的坏例子自动成为 BRA 的坏例子。
  2. 第二步 (∗∗)：BRA 里准等式等价于等式。这正是命题 2.7.6 + BRA 是判别式簇：对任意准等式 q 存在等式 e(q)，使 BRA ⊨ q ⇔ Sir(BRA) ⊨ q ⇔ Sir(BRA) ⊨ e(q) ⇔ BRA ⊨ e(q)。显式写法见 O2 的开关项公式。
  3. 合成。(∗) 把不可判定的半群准等式问题嵌入 BRA 的准等式问题，(∗∗) 再把后者嵌入 BRA 的等式问题。半群准等式理论不可判定，故 Eq(BRA) 不可判定。□
直觉 · 这是两个方向各走一次的典型

第一步是表示论干活（Cayley 嵌入把抽象半群变成具体关系）；第二步是判别式簇干活（把蕴涵改写成等式）。教材特意点出：这套「不可判定性证明」在代数逻辑里用途极广。对照 L29 的无排序版：那边是用逻辑反例帮代数得出 SP Csfω ≠ Up SP Csfω；这边是用代数工具帮逻辑得出等式理论不可判定。桥是双向的，两讲各演示了一次。

教材的定理 7.1.10 说：RRA 是不可有限公理化的判别式簇，等式理论递归可枚举但不可判定——证明是 7.1.4/7.1.8/7.1.9 的显然修改。三者按操作多少成链：

存在有限等式集 E₀（教材列出六条，如 (x ∪ y)−1 = x−1 ∪ y−1、(x ◦ y)−1 = y−1 ◦ x−1、x ◦ −(x−1 ◦ −y) ≤ y 等），使

直觉 · 不可有限公理化的「锅」全在 ◦ 上

教材的解读很干脆：正是 ◦ 太强，才造成不可有限公理化；一旦有了它，⁻¹ 与 Id 都能有限步补齐。这与 n 元柱体代数的情形正相反——那边各操作的强度是「均匀分摊」的。教材 Figure 7.4 把 ∪, −, 1, ◦, ⁻¹, Id 六个节点的全部连接画了出来：方框内是准簇而非簇，圆圈内除 BA 外都不可有限公理化。

开放问题与「可判定但难看」的公理集

教材脚注 13 给了一个漂亮的 Craig 式技巧：从 r.e. 枚举 E = {e(1), e(2), …} 出发，让 η(n) 是 e(n) 的 n 重合取，用判别式性质把 η(n) 在子直既约上等价的等式 ε(η(n)) 算出来，且能反算回去。于是 E′ = {ε(η(1)), ε(η(2)), …} 是可判定的公理集。代价是难看：Jónsson、Andréka 证明任何公理集都必须用任意多变元，且必须含 ∪, −, ◦ 全部符号。于是有了问题 7.1.12：

找出简单、数学上透明、可判定的等式集来公理化 BSR、BRA、RRA。教材说这是代数逻辑仍最重要的开放问题之一——而等式公理系统正是相应逻辑的推理系统（定理 4.2.5/4.2.6），所以这不只是美学问题。

7拨回逻辑；案例工坊九例收束 O6

最后一节把代数结论翻译回逻辑，并给第七篇结账。

桥：等式公理系统 ⇄ 推理系统（UAL 定理 4.2.5/4.2.6）
  • 一个准等式 q 对应一条推理规则「从前提等式得结论等式」；一个等式对应一条公理图式。
  • 簇有等式基 ⇔ 对应逻辑有可靠完全的 Hilbert 型系统；簇不可有限公理化 ⇔ 对应逻辑没有有限公理的推理系统（L19 桥之二）。
  • 等式理论可判定 ⇔ 对应逻辑的有效性可判定（L22 桥之五）。

于是定理 7.1.8/7.1.9 直接读成逻辑结论：与关系代数对应的逻辑，既没有有限公理系统，也没有判定算法——但它有一个 r.e. 的、甚至可判定的（虽然难看的）公理集。

判别式簇送给逻辑的三件礼物
  1. 规则可以改写成公理。命题 2.7.6 保证：只要代数对应物有判别式项，任意准等式规则都能压成一条等式公理。这是「有 Hilbert 系统」的代数根据。
  2. 模型类可以被精确列出。推论 2.7.8 把子直既约成员定位成 SUpK，L27 四步流程里「算 Alg⊨」这一步因此变得可操作（引理 7.1.5/7.1.7 就是这个套路）。
  3. 坏消息也能搬运。不可有限基、r.e. 不可判定这两块硬骨头，通过等式公理系统与推理系统的对应传给逻辑（定理 4.2.5）。判别式簇不只报喜。

8三层例：典型 / 本质 / 边界 理解检验

典型 BA：最小的判别式簇

2 上的布尔项 τ(x,y,z,u) = (x ∩ z) ∪ (−x ∩ u) 就是判别式（按 L06 的写法；等价地用对称差与开关项），而 BA = HSP{2}（定理 2.7.3）。整个判别式簇理论的最小实例，正是 L27 里 LC 的代数对应物。从它出发看 O2 的归纳：n=1 的准等式 (σ=ρ) → σ₀=ρ₀ 被压成 τ(σ,ρ,σ₀,ρ₀)=ρ₀——把「前提相等时结论相等」写成一条永远成立的等式。这是全讲最简单的压缩，也是理解后面所有压缩的模板。

本质 BRA：开关项 1◦x◦1 的几何

判别式项在关系代数里退化成一个极短的表达式：c(x) = 1 ◦ x ◦ 1。它的几何意义是「x 非空就吞噬整个宇宙」：只要 x 里有一对 ⟨a,b⟩，任意 ⟨u,v⟩ 都能经 a,b 中转，于是 c(x) 是全关系；x 空则什么都连不上。这个项同时干了三件事：证明成员单（引理 7.1.6）、把准等式压成等式（命题 2.7.6）、把半群准等式搬进等式理论（定理 7.1.9）。一个三行项撑起三个定理——这就是本讲想让你看见的「威力」的具体样子。

边界 不是判别式簇的那些类；可判定但难看的公理

把机器往旁边一试就碰壁：RCAω（L28 的有限变元片段极限）不是判别式簇，因为子直既约成员形形色色，找不到公共判别式项；ICrsn（n ≥ 2，L29 的变量依赖逻辑）也不是；群簇更不是（判别式项逼单，而 ℤ 不单）。所以 L29 里那些逻辑不能靠本讲的机器自动获得 Hilbert 系统——它们的问题出在别处，得换模型类来治。另一头是「可判定但难看」：Craig 技巧给出可判定的公理集 E′，但任何公理集都必须用无穷多变元。可判定与好看，在这里也是鱼与熊掌。
