0动机：为什么先讲这些

这一讲没有新定理，目的是把三本书共用的语言统一起来。代数、拓扑、逻辑三条线看似各说各话，底层其实都站在同一块地基上：集合、关系、函数、序。

直观

后面你会遇到三个长得很像的东西：代数里的同余关系（哪些元素「可视为相等」）、拓扑里的可达关系（哪个世界能走到哪个世界）、逻辑里的等价/代入（哪些公式可互换）。它们的定义都只是「集合 A 上的一个二元关系」。先把关系的语言讲清楚，后面每次遇到只是换一个名字。

还有一件更隐蔽的事：本课程的枢纽是闭包算子（L02），而闭包算子的最小例子就是天花板函数——一个从实数序到整数序的映射。序、函数、幂集这三样东西在这里第一次碰头。

如果你已经熟悉这些，可以只看 §融合接口，确认记号一致即可。

1集合、类、Russell 悖论

用 x ∈ A 表示「x 是 A 的元素」。A ⊆ B 表示「A 是 B 的子集」，即每个 A 的元素都是 B 的元素。幂集 𝒫(A)（Bergman 记作 Sb(A)）是 A 全体子集构成的集合。

定义 1.1

元组（有序 n 元组）写作 ⟨a₁,…,aₙ⟩，相等当且仅当逐坐标相等。笛卡尔积 A × B = {⟨a,b⟩ : a∈A, b∈B}。

例 · Russell 悖论（UAL 1.1.1）

「所有集合的集合」不存在。若存在这样的 V，则按分离公理 R = {x∈V : x∉x} 也是集合。问 R∈R 吗？若 R∈R，按 R 的定义 R∉R；若 R∉R，又满足定义故 R∈R。矛盾。

本讲义采取朴素的集合论立场：只谈我们实际用到的集合，不做公理化展开。遇到「所有……的集合」时，总把它限制在一个已经给定的全集 H 之内。

来源：UAL §1.1（定义 1.1.1 定理形式的 Russell 悖论）；Bergman Ch1。

2二元关系、等价关系、函数

定义 1.2

集合 A 上的二元关系是 R ⊆ A × A。写 aRb 表示 ⟨a,b⟩∈R。

R 是等价关系，若它满足：自反 aRa；对称 aRb ⇒ bRa；传递 aRb ∧ bRc ⇒ aRc。

等价关系把 A 切成互不相交的等价类 a/R = {b∈A : aRb}，全体等价类构成商集 A/R。映射 a ↦ a/R 称为自然投影。

直观 · 等价关系就是「决定忽略什么」

给 A 装一个等价关系，等于宣布「某些差别不算差别」。整数模 5 的等价关系忽略「相差几个 5」；代数里同余关系忽略「在运算下可否替换」；拓扑/模态里不可区分关系忽略「哪些世界用可验证命题分不开」。商集就是你忽略这些差别之后剩下的东西。

定义 1.3

函数 f : A → B 是满足「每个 a∈A 恰有一个像」的关系 f ⊆ A×B。单射、满射、双射如常。函数诱导出幂集上的两个映射：像 f[X] = {f(x):x∈X} 与原像 f⁻¹[Y] = {x:f(x)∈Y}。

融合接口

原像 f⁻¹ 是拓扑连续性的关键：映射 f : X→Y 连续，当且仅当 Y 的每个开集 V 的原像 f⁻¹[V] 在 X 中开（L11）。用中文讲义的说法，f⁻¹ 把「目标里的可验证命题」翻译成「源里的可验证命题」。一个纯集合论的记号，后来承担了「翻译」的全部重量。

来源：UAL §1.2（含练习 1.2.1 自由代表、1.2.2 划分）；中文拓扑讲义注 3.1.2。

3序、序数、基数

定义 1.4

集合 P 上的偏序 ≤ 满足自反、反对称、传递；⟨P,≤⟩ 称为偏序集（poset）。若任意两元素可比，称为全序。

对 S⊆P：u 是上界指 (∀s∈S) s≤u；最小上界（上确界、join）⋁S 是全体上界中的最小者；对偶地有下界与最大下界（meet）⋀S。

直观 · 「≤」到底在排什么

不要把它只读成「小于等于」。在数据里读成「信息量不超过」；在格论里读成「包含于」；在逻辑里读成「可推出」（φ ≤ ψ 表示 φ ⊢ ψ）；在闭包系统里读成「被包含于」。同一个符号承载「小 / 少 / 弱 / 特殊」这一族意思——这就是序能统一三条线的原因。

若每对元素都有 ⋁{a,b} 与 ⋀{a,b}，偏序集是格；若任意子集（含无穷集）都有上下确界，是完全格。幂集 ⟨𝒫(H),⊆⟩ 是完全格，⋁ 是并、⋀ 是交——这是 L02 的原型例子。

例 · 我们真正用得到的序数/基数

序数用来给「第 n 步」编号：有限序数 0,1,2,…、第一个无穷序数 ω。基数用来数「有多大」：ℵ₀（可数）、2^{ℵ₀}（连续统）。

本讲义只在两处认真用到它们：一是「代数闭包算子」要求「有限子集」（Z ⊆ᵩ X，L02）；一是「有限可满足 ⇒ 整体可满足」这类紧致性陈述（L18）中「有限」二字的分量。

来源：UAL §1.3；Bergman §2.1（特别是由「每个子集有上确界」推出完全格的命题 2.14）。

4序列、族的直接积、高阶关系

序列是从 ω（或其初段）出发的函数，写作 (aₙ)_{n∈ω}。集族由指标集 I 标记，写作 (Aᵢ)_{i∈I}。

定义 1.5

集族 (Aᵢ)_{i∈I} 的直接积 ∏_{i∈I} Aᵢ 是所有函数 f : I → ⋃_{i∈I} Aᵢ 的集合，且满足 f(i)∈Aᵢ。元素写作 (aᵢ)_{i∈I}，投影 πⱼ : ∏Aᵢ → Aⱼ 取第 j 个坐标。

直观 · 直接积是「并行世界」

把 I 想成代的「世界」或「部件」：∏Aᵢ 的一个点就是给每个世界各挑一个值。投影 πⱼ 是「只看第 j 个世界」。这个构造在 L04 会原样长成代数的直积，在 L10 长成超积（在直积上再按超滤子把世界「合并」），在拓扑里长成积拓扑。

高阶关系是 Aⁿ（n 元）或 Aᴵ（I 元）的子集。一元关系是集合，二元关系是上面讨论的对象，n 元关系是 UAL 第七章「关系代数」的舞台（L24）。

来源：UAL §1.4–1.6。

5一阶逻辑语法与语义速览

这里的记号在 L15「逻辑的规范形式」里会被推广到任意逻辑，请先记住它们的形状。

定义 1.6 · 语法

一阶语言由函数符号、关系符号、常量符号（带元数）组成。词项由变量、常量经函数符号递归生成；公式由原子式 R(t₁,…,tₙ) 经 ¬,∧,∨,→ 与量词 ∀,∃ 递归生成。变量在公式中出现若不在量词辖域内称为自由的；无自由变量的公式是句子。

定义 1.7 · 语义

一个模型 𝔐 = ⟨M, …⟩ 给出非空论域 M 及符号的解释。赋值 v 把变量映到 M。满足关系 𝔐 ⊨ φ[v] 按 Tarski 递归定义：𝔐 ⊨ ∀xφ[v] 当且仅当对所有 m∈M，𝔐 ⊨ φ[v(x↦m)]。

句子 φ 在模型中为真记作 𝔐 ⊨ φ。对理论 T（句子集），𝔐 ⊨ T 表示满足其中每句。后承关系：T ⊨ φ 当且仅当满足 T 的每个模型都满足 φ。

例 · 真值集（通向拓扑的桥）

固定模型 𝔐 与自由变量集 {x}，把公式 φ 映到它成立的赋值集合：

[[φ]] = { v : 𝔐 ⊨ φ[v] } ⊆ M

中文拓扑讲义 §2.1 正是从这里起步的：把 M（或更一般的世界集 X）看作认识世界，把 [[φ]] 看作命题 φ 的真值集，于是 [[φ∨ψ]] = [[φ]]∪[[ψ]]、[[φ∧ψ]] = [[φ]]∩[[ψ]]、[[¬φ]] = X∖[[φ]]。这三式在 L08 会变成开集公理的认识论论证。

融合接口 · 三个「⊨」的用法预告

符号 ⊨ 在全课出现三种形态，留意区分：𝔐 ⊨ φ（模型满足公式）、T ⊨ φ（语义后承）、以及 L18 中代数侧的 Alg⊨(L)（一个逻辑的「语义部分」的代数对应物）。UAL 的全名 Alg⊨ 就是在提醒你它来自后承关系。

来源：UAL §1.8；中文拓扑讲义 §2.1（例 2.1.1 天鹅例子）。

7习题

  1. 证明：若 R 是 A 上的等价关系，则等价类 a/R 两两不交且并为 A。（UAL 练习 1.2.2）
  2. 证明：对任意函数 f : A→B 与 X⊆A，有 X ⊆ f⁻¹[f[X]]；当 f 单射时取等。
  3. 验证：若把 ≤ 读成「可推出 ⊢」，则「⋁」对应析取、「⋀」对应合取。这个类比在 L21（Lindenbaum 代数）中会被严格实现。
  4. （预告 L02）在 𝒫(ℝ) 上定义 c(X)=X 的拓扑闭包。验证 X⊆c(X)、X⊆Y⇒c(X)⊆c(Y)、c(c(X))=c(X)。再问：c(X∪Y)=c(X)∪c(Y) 对吗？
