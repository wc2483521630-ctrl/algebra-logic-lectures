2动机：一个问不出来的问题

它解决什么问题

L08 把拓扑空间读成「模型集 X + 可验证命题族 τ」。那么自然要问：给你两个模型 x, y，你能验证它们不是同一个吗？

在普通逻辑里这不成问题——找一个在 x 成立、在 y 不成立的性质就行。但数学里往往没有这么便宜的事。讲义抬出的例子是连续统假设：ℵ1 = 2ℵ0 在 ZFC 中不可判定。你没法给出一个可验证命题 U 装住一个模型、另一个可验证命题 V 装住另一个，且证明 U ∩ V = ∅——因为「证明它们不交」这件事本身可能就做不到。

这就是本讲的起点：不是每个空间都能把点分开。能不能分开，是一个需要额外假设的性质。整讲就是把「分开」这件事按强度分级，并造一套工具（滤子）来测它。

注意一个易混点

经典逻辑里对模型 x 和命题 φ，总有「x ⊨ φ 或 x ⊭ φ」。但在直觉主义背景下，这两者未必有一个能被证明。按 L08 的认识论读法，「能验证 x 不满足 U」需要的是 x ∈ int(X − U)——注意是内部，不是补集。

这个区别很要紧：y ∉ U 只是「y 不在 U 里」，而「能验证 y 不满足 U」要求 X − U 含 y 的一个邻域。前者是集合事实，后者是认识论事实。T1 与 T0 的差别，正好卡在这两者之间。下面会看到这一点。

3拓扑可区分与 T0 O1O1

它解决什么问题

最弱的分开要求是什么？不是「用不交的开集分开」（那太强），也不是「一个含一个不含还要求能验证不含」（那也偏强），而是最朴素的一句：存在一个可验证命题，只装住其中一个。这就是 T0。它是「可区分」这件事的下限——低于 T0，就真的分不开了。

定义 3.1（定义 4.4.4）

若存在开集 U 使 x ∈ U、y ∉ U，或 y ∈ U、x ∉ U，称 x, y 拓扑可区分。若每对不同点都拓扑可区分，称 X 为 T0 空间。

注意那个「或」。方向不必固定：可以 U 只装 x，也可以只装 y，有一个方向就行。这个不对称正是 T0 弱于 T1 的地方——T1 要求两个方向同时成立。

对照：T1（定义 4.4.2）

若对每对不同点 x, y，存在开集 Ux 使 x ∈ Ux、y ∉ Ux，称 X 为 Fréchet 空间或 T1 空间。

把两个定义摆在一起看，差别只有一处：T1 要求「对每对 x,y」都能找到「含 x 不含 y」的开集——也就是两个方向都能做到；而 T0 只要有一个方向做到就算。T1 ⟹ T0，反之不成立。

讲义在这里插了一句关键的观察：y ∉ Ux 不意味着能验证 y 不满足 Ux，因为 X − Ux 未必开。要验证这一点，需 y ∈ int(X − Ux)。所以按认识论解释，Fréchet 条件尚且不足以确认两个模型彼此不同——这就是为什么讲义认为在带动念成分的情境里，真正值得关心的是 T0 而不是 T1。

定理 3.2（例 4.4.6，Kripke 框架的刻画）

对自反传递 Kripke 框架 𝔉 = (W, R)，赋 Alexandroff 拓扑：

  1. 诱导拓扑满足 T1，当且仅当 R 是恒等关系；
  2. 诱导拓扑满足 T0，当且仅当 R 为偏序（还满足反对称性）。

反过来，任意 T0 Alexandroff 空间都通过

x ≤ y  ⟺  ∀U 开,  x ∈ U ⟹ y ∈ U

诱导一个偏序 Kripke 框架。这个序可以读作「拥有更多知识」——y 在 x 之上，意味着凡是 x 能验证的 y 都能验证。

这条定理为什么漂亮

它把三个不同领域的东西焊在一起：拓扑的 T0 ⟷ 序论的反对称 ⟷ 认识论的「信息单调递增」。

取一个预序但不是偏序的框架（比如两点互相可达、互相不分），诱导出的拓扑里两点不可区分，于是不 T0。加了反对称之后，两点若互相「知道得不比对方少」，就只能是同一个点——这正是 T0 的定义在做的事：不许有两个点对所有命题的真值完全一致。

并且它说明了 L08 与 L06 的接口：Alexandroff 拓扑 ← 预序，双向翻译。T0 ⇔ 反对称，T1 ⇔ 离散（恒等关系）。在 Alexandroff 这一族里，分离公理完全翻译成了序论条件。

典型例子

Sierpiński 空间：X = {a, b}、τ = {∅, {b}, {a,b}}。它有 T0 但没有 T1：{b} 是含 b 不含 a 的开集，所以两点可区分（一个方向够）；但含 a 的开集只有 {a,b}，一定也含 b，所以反方向做不到。「只能沿一个方向区分」是 T0 而并非 T1 的标准形状。

本质例子

含多于一点的不可分空间（平凡拓扑）：τ = {∅, X}。任取两个不同点 x, y，仅有的开集是 ∅ 和 X，一个都不含一个不含另一个——连 T0 都没有。认识论读法：这种论域里没有任何可验证命题能区分模型，所有模型在知识上完全等价。这是 T0 的反面，也是「分离公理」这个词的来由：这里根本分不开。

边界与误解

① 别把 T0 读成「两个点不相等」。任何空间里 x ≠ y 都是集合事实；T0 说的是「能否被可验证命题分开」，是拓扑性质。同一批点上换拓扑，T0 会变。② 别以为 T0 的「方向」可以整理成统一方向。Sierpiński 空间里能装 b 不能装 a，但反过来不行——这个不对称不是缺陷，它正是「信息多少有偏序」的表现（定理 3.2 第 2 条）。③ T0 不等于可分。「可分」在拓扑里指有可数稠密子集，是完全另一回事，中文都叫「分」容易混。

来源：拓扑讲义 §4.1（认识论理论）、定义 4.4.2、定义 4.4.4、例 4.4.5、例 4.4.6 及关于 spectral space 与无点拓扑的评论。

4滤子基与滤子 O2O2

它解决什么问题

「两个点能不能分开」这个问题用开集直接问，只能得到粗糙的答案（是/否）。要更细，得换个对象问：不问单点，问「逼近这个点的所有知识」。把「越来越多、彼此相容的知识」打包成一个集合族，就是滤子。

讲义的说法是：我们需要刻画「确定性理论」。一个理论越确定，它承诺的事实越多（集合越小），但必须彼此相容（交不空）。滤子正是这两条的形式化。这个对象在 L02 已经以「闭包系统的对偶」出现过，这里是它在拓扑里的第二次登场。

定义 4.1（定义 4.2.1）

设 X 为集合。若 𝔉 ⊆ 𝓟(X) − {∅} 满足

  • X ∈ 𝔉；
  • A, B ∈ 𝔉 ⟹ A ∩ B ∈ 𝔉，

称 𝔉 为滤子基。若它还向上封闭——A ∈ 𝔉、A ⊆ B ⊆ X 蕴含 B ∈ 𝔉——则称为滤子。

两条公理各管一件事：「X ∈ 𝔉」说不排除任何可能（最弱的知识总是相容的）；「交封闭」说知识可以叠加（同时接受两条，得到更强的一条）。向上封闭则是「知识只会变多不会变少」——正因为这一条太自然，很多教材直接把它写进定义。

定义 4.2（定义 4.2.3，向上闭包）

对滤子基 𝔉，其向上闭包为

𝔉↑ = { C ⊆ X : ∃G ∈ 𝔉, G ⊆ C }

这是一个滤子。所以「滤子基」和「滤子」不是两类对象，而是同一件事的两个详略版本：基是生成元（少而具体），滤子是闭包（多而抽象）。用基是为了省事，用滤子是为了好算。

命题 4.3（UAL 命题 2.2.63，基的显式形式）

设 E ⊆ 𝓟(I)，𝔉 为 E 生成的滤子（即含 E 的所有滤子之交）。则

𝔉 = { X : X = I 或 ∃Y1,…,Yn ∈ E,  Y1 ∩ ⋯ ∩ Yn ⊆ X }

并且 𝔉 是真滤子（不含 ∅）当且仅当 E 具有有限交性质（任取有限个成员，交非空）。

这条命题是后面所有紧致性论证的地基。它说：「生成一个相容的理论」= 「每一小批承诺都不矛盾」。有限交性质是局部的、可逐个检查的条件；真滤子是全局的、一次性的要求。命题 4.3 把全局问题化归成局部检查——这正是 L18 紧致性定理的雏形。

典型例子

在 {a,b,c,d} 上，𝔉 = {{a}, {a,b}, {a,c}, {a,b,c,d}} 是滤子基（交封闭，含全集）。它的向上闭包是所有含 a 的子集之族。这类由单个集合「撑起来」的滤子叫主滤子，是最好算的一类：由 {a} 生成，等于「a 的一切性质」。

本质例子

非主滤子是真正有趣的东西。取无限集 ℕ，令

𝔉 = { A ⊆ ℕ : ℕ − A 有限 }

（余有限集族）。它交封闭（两个余有限集的交仍余有限）、含 ℕ、向上封闭——是滤子。但它不是主的：没有任何单个集合生成它，因为对任意 A ∈ 𝔉，你总能把 A 再删掉一个元素，得到的仍余有限。主滤子对应「确定的知识」（知道就是知道某个具体事实），非主滤子对应「趋近但永不抵达」——这是「极限」这个直觉真正的代数化。

边界与误解

① 本讲的「滤子基」比多数教材强。许多书只要求「非空且任意两成员有更小的成员在族内」，不要求交本身属于该族、也不要求含 X。讲义沿用了较强的约定（译注 2 明确说明了这一点）。做题时先确认用的是哪套定义，否则「滤子基的交封闭」这条会莫名不成立。② 别把滤子与理想搞混。滤子向上封闭、交封闭（朝「大」走）；理想向下封闭、并封闭（朝「小」走）。在布尔代数里两者由补运算互换（L06 讲过），但在一般格上不是。③ ∅ 永远不在真滤子里。一旦 ∅ ∈ 𝔉，由向上封闭得 𝔉 = 𝓟(X)，叫非真滤子——它对应「矛盾的理论」，什么都承诺，因而毫无信息。这类退化情形在定理陈述里必须排除。

来源：拓扑讲义定义 4.2.1、例 4.2.2、定义 4.2.3 及译注 2；UAL 定义 2.2.62、命题 2.2.63。

5邻域滤子与收敛 O3

它解决什么问题

有了滤子，就可以定义「逼近」。但逼近谁？逼近一个点。所以先把「一个点的全部局部信息」打包成滤子——这就是邻域滤子。然后说：一个滤子收敛到 x，意思是它的每个成员都最终落进 x 的每个邻域里。这就是「越来越确定，最后确定到了 x」。

定义 5.1（𝒩(x)，命题 4.2.4）

对拓扑空间 (X, τ) 与 x ∈ X，记 𝒩(x) 为 x 的全部邻域之族。则 𝒩(x) 是滤子。

证明（三行）

X 是 x 的邻域，故 X ∈ 𝒩(x)。若 U, V ∈ 𝒩(x)，取含 x 的开集 U′ ⊆ U、V′ ⊆ V，则 x ∈ U′ ∩ V′ ⊆ U ∩ V，故 U ∩ V 仍是邻域。若 V ∈ 𝒩(x)、V ⊆ K，则 K 显然仍是邻域，故向上封闭。∎

定义 5.2（定义 4.2.6，收敛）

设 𝔉 为 X 上的滤子或滤子基。若对每个 U ∈ 𝒩(x)，存在 V ∈ 𝔉 使 V ⊆ U，称 𝔉 收敛到 x，x 称为其极限。

这句话的形式值得盯住：∃V ∈ 𝔉, V ⊆ U。不是「V 落在 U 里」这么简单，而是「𝔉 里有一个成员整个缩在 U 里面」——即滤子比邻域滤子更细。𝔉 承诺得越多，越容易收敛。极端情形：𝔉 含单点集 {x} 时，它对任何 𝒩(x) 的成员都能取 V = {x}，故必收敛到 x。越确定的理论越容易有极限。

定理 5.3（例 4.2.5 / 4.2.7，两个标准收敛）

(a) 实直线上的区间族。对所有含 a 的开区间组成的族 𝒬a，它收敛到 a。并且不会收敛到别的点：设 a ≠ b，不妨 a < b，由有理数稠密性取 a ∈ (c,d)、b ∈ (e,f)、(c,d) ∩ (e,f) = ∅；若 𝒬a 收敛到 b，则某个含 a 的区间 (c′,d′) ⊆ (e,f)，矛盾。

(b) Cantor 空间的柱集族。固定 x ∈ 2ω，族 {C(x ↾ n) : n ∈ ω} 是滤子基且收敛到 x。证：若 U 是 x 的邻域，取开邻域 V ⊆ U，写 V = ⋃i∈IC(si)，则某个 C(si) 含 x，故 si ⊴ x；于是对某个 n 有 si = x ↾ n，从而 C(x ↾ n) ⊆ V。

两个例子在说什么

都是「取交＝不断细化集合，最终逼近一个点」。(a) 里是区间越缩越窄；(b) 里是柱集越来越长（约束越来越多）。这两个例子正好是 L09 讲过的两种基：度量式的（开区间）和逻辑式的（有限前缀）。

但讲义紧接着泼了一盆冷水：收敛的定义本身不保证唯一性。习题里会出现滤子同时收敛到多个点的空间，而且「看起来相当合理」。这正是下一节要处理的问题——分离公理就是为了控制这件事。

典型例子

在 ℝ 里，𝔉 = {(0, 1/n) : n ≥ 1}↑ 收敛到 0，不收敛到任何别的点。这是「xn → 0」的滤子版：不用序列，只用一个集合族。好处是：序列在一般拓扑空间里不够用（L11 §3 边界与误解里提过），滤子够用。

本质例子

在平凡拓扑 τ = {∅, X} 上（|X| ≥ 2），每个滤子都收敛到每个点。因为对任意 x，𝒩(x) = {X}，而任何滤子都含 X，取 V = X ⊆ X 即可。这不是病态构造，这是「分离失败」的极端形态：空间粗到没有任何局部信息，于是「极限」这个词失去了区分能力。所有收敛都发生，等于没有收敛。这个例子预告了定理 6.1：唯一收敛 ⟺ Hausdorff。

边界与误解

① 「收敛到 x」不等于「x ∈ ⋂𝔉」。非主滤子的交可以是空的，但它照样收敛（比如上面的 (0,1/n) 族，交是空集，却收敛到 0）。收敛是「越来越贴近」，不是「包含」——这个区别是本讲最容易踩的坑。② 滤子基与它的向上闭包收敛性相同，因为定义里只要求「存在成员落在 U 里」，加不加向上封闭不影响。③ 「滤子收敛」与「序列收敛」在度量空间里一致，但不能互相替换。一般空间里序列太少（可能没有可数邻域基），必须用滤子——这一点 L13 会正式用上。

6Hausdorff 与唯一收敛 O4O4

它解决什么问题

上一节说了：收敛可能不唯一。那么「让收敛唯一」这个要求，翻译成开集语言是什么？答案是不交邻域条件——Hausdorff。这个等价是本讲的核心定理，它把「分析里的极限唯一」和「拓扑里的分离」认成同一件事。

定义 6.1（定义 4.3.1）

若任意不同点 x, y ∈ X 都有不交开邻域 Ux, Vy，即

x ∈ Ux,   y ∈ Vy,   Ux ∩ Vy = ∅

称 X 为 Hausdorff 空间或 T2 空间。

讲义在这里记了一个双关语：Hausdorff 空间里每两点都被开集「隔开」（housed off）。认识论上的读法才是重点：这意味着能证明两个不同模型确实不同——存在分别在二者成立的可验证性质 U, V，并且能验证二者不可能同时成立（U ∩ V = ∅ 是一条可验证的否定）。

对比 T0：T0 只要求「有一个开集装一个不装另一个」；T2 要求「两个方向都装，而且两个开集不交」。「不交」这一步才是关键——它让你能验证「二者不会同时成立」，而不只是「二者被区分」。

定理 6.2（定理 4.3.4，核心等价）

对拓扑空间 (X, τ)，下列等价：

  1. X Hausdorff；
  2. X 上每个滤子至多收敛到一个点。
证明（两向，都值得细看）

(1 ⟹ 2) 设 𝔉 同时收敛到不同的 x, y。取不交开邻域 U ∋ x、V ∋ y；由收敛性，存在 U′ ∈ 𝔉 使 U′ ⊆ U，存在 V′ ∈ 𝔉 使 V′ ⊆ V。但 U′ ∩ V′ = ∅，由交封闭得 ∅ ∈ 𝔉，与 𝔉 是真滤子矛盾。

(2 ⟹ 1) 证逆否。设 X 非 Hausdorff，则存在 x ≠ y 使它们任意一对开邻域都相交。令

𝔉 = { U ∩ V : x ∈ U, y ∈ V, U, V 开 }

这是滤子基：X = X ∩ X ∈ 𝔉；两个成员之交可写成 (U ∩ U′) ∩ (V ∩ V′) ∈ 𝔉；由假设不含空集。取向上闭包 𝔉↑。对 x 的任意邻域 W，取开邻域 U ⊆ W，则 U = U ∩ X ∈ 𝔉，故 𝔉↑ 收敛到 x；同理收敛到 y。∎

这个证明的构造值得记住：它从「分离失败」直接造出一个双极限滤子——取「x 的邻域」与「y 的邻域」的所有交。不是随便造的，而是「同时逼近两点」这个描述的最字面翻译。

命题 6.3（命题 4.3.5，保持性）

若 X 及各 Xi 为 Hausdorff，则：X 的任意子空间 Hausdorff；积 ∏iXi Hausdorff；拓扑和 ⨆iXi Hausdorff。

但商一般不保持——见下面那个反例。

反例 4.3.6：双重点实直线

取两份实直线的拓扑和 ℝ ⊔ ℝ，点记为 ⟨x,0⟩、⟨x,1⟩。对每个 x ≠ 0 把这两点等同，但保留两个不同的零点。所得商空间叫「双重点实直线」。

这两个零点不能被任何不交开邻域分开。证：设 U0, U1 分别是 [⟨0,0⟩]、[⟨0,1⟩] 的开邻域。由商拓扑，原像开，故分别含两个副本中的区间 (a,b)×{0}、(c,d)×{1}，其中 a, c < 0 < b, d。令

ε = ½ min{|a|, |b|, |c|, |d|} > 0

则 ⟨ε,0⟩、⟨ε,1⟩ 分别落在两个原像内，而它们被等同，故 [⟨ε,0⟩] = [⟨ε,1⟩] ∈ U0 ∩ U1。交不空。

这个反例的机制很值得琢磨：原空间 ℝ ⊔ ℝ 是 Hausdorff 的（命题 6.3 第 3 条），但把 x ≠ 0 的点两两认同之后，两个零点周围的邻域被迫通过被认同的点「短路」了。直观上：0 附近的 ε 点已经被粘成同一个点，于是任何想分开两个零点的邻域都必须同时包含这个粘合点。取商会破坏分离性，这是商构造的固有代价，L13 还会遇到同样的问题。

典型例子

离散空间 Hausdorff（单点集就开，直接取 {x}, {y}）；含多于一点的不可分空间不 Hausdorff。更实质的：ℝ Hausdorff（用不相交的开区间），Cantor 空间 2ω Hausdorff。Cantor 空间的证法特别干净：若 x ≠ y，取有限序列 t ⊴ x 而 t ⋬ y，则 C(t) 与其补集分别是含 x, y 的不交开集——因为 2ω − C(t) = ⋃s∈Len(n)−{t}C(s) 也开（有限多柱集之并）。这一族基本开集「彼此补得开」，即每个柱集都是 clopen——L10 埋的伏笔在这里兑现：clopen 多，就等于分辨力强。

本质例子

定理 6.2 的证明顺手送了一个「分离失败」的免费诊断工具：想知道一个空间是否 Hausdorff，就去问「有没有滤子同时收敛到两个点」。在双重点实直线上，取「两个零点的邻域之交」生成的滤子，它同时收敛到两个零点——这就是它不 Hausdorff 的证明。这个诊断的价值在于：它把「找一对分不开的点」这种几何/构造性的活，变成「找一个双极限对象」这种代数的活。

边界与误解

① T2 ⟹ T1 ⟹ T0，反向全不成立。反例分别是：Sierpiński（T0 非 T1）、余有限拓扑（T1 非 T2，见 §7）。② 「Hausdorff」与「每个序列至多一个极限」不等价（一般空间里）。序列版本弱于滤子版本——因为序列只能处理第一可数空间。这是为什么本讲用滤子而不讲序列。③ 子空间保持、积保持、和不保持，商不保持——四条要分开记，别一律说「构造都保持 Hausdorff」。④ 双重点例子里，两个零点是同一个商空间里的不同点，不是同一个点；「分不开」不等于「相等」，这正是 T0 之后各公理要处理的核心区分。

7分离公理阶梯与反例库 O5

它解决什么问题

现在有了 T0、T1、T2 三个条件，还有 T4。它们构成一条阶梯。但只知道阶梯不够——还得知道每一级是否严格更弱，靠什么空间来证。这一节的任务就是建一个反例库，让每一格的「严格性」都有一个具体见证。

T4 (正规 + T1) ── 更强 ── 能分离不交闭集 │ 例：ℝ、紧 Hausdorff ▼ T3 (正则 + T1) ── 用连续函数分离点与闭集（Tychonoff） │ ▼ T2 (Hausdorff) ── 不交开邻域 ── 等价于「滤子极限唯一」 │ ✗ 余有限拓扑、Zariski 拓扑 ▼ T1 (Fréchet) ── 每点都是闭集（含 x 不含 y 的开集，两个方向都行） │ ✗ Sierpiński 空间 ▼ T0 ── 存在开集只装住其中一个（一个方向够） │ ✗ 平凡拓扑（含多于一点） ▼ （无） ── 连可区分都做不到

分离公理阶梯，右侧标出「在这一级失败」的见证空间

反例库：三个必记的空间

① Sierpiński 空间　X = {a,b}、τ = {∅, {b}, {a,b}}。T0 而非 T1。它能区分（{b} 只装 b），但只能沿一个方向——含 a 的开集必含 b。作用：证明 T0 ≠ T1。

② 余有限拓扑　X 无限，U 开当且仅当 U = ∅ 或 X − U 有限。T1 而非 T2。它 T1：X − {y} 是含 x 不含 y 的开集。它不 T2：两个非空开集都余有限，交必非空（因为两个有限集的并不可能是整个无限集）。作用：证明 T1 ≠ T2。

③ Zariski 拓扑　ℝ 上取闭集为「某族多项式的公共零点集」：U = {x : ∀f ∈ S, f(x) = 0}。不 Hausdorff（事实上不 T2，且比余有限更粗的意味）。理由：非零多项式只有有限多个零点，两个非空开集的补集都有限，交必非空。作用：说明分离失败在代数几何里是常态，不是病态构造。

注意后两个的失败机制相同：开集都「太大」（补集太小），交不空。T2 要求能造出两个不交的开集，而这需要「开集能小」——这正是 L09 里「基够细」这件事的分离版本。

典型例子

把三个空间排在阶梯上：Sierpiński 卡在 T0、余有限卡在 T1、双重点实直线卡在 T2（它 T1 但非 T2）。四个反例，四个不同的失败层级——这就是「阶梯是严格的」这件事的全部证据。

本质例子

为什么 T2 是「有用」的那一级，而 T0/T1 只是「够用」？因为 T2 给了极限唯一性（定理 6.2），而极限唯一性是把分析搬进拓扑的前提。T1 只保证「点是闭集」，T0 只保证「点可区分」——两者都不足以让「收敛」这个词有意义。这是历史上 Hausdorff 公理一度被当作拓扑空间的必备条件的原因（译注 4 提到的历史）：当时的数学家要的是「能做分析的空间」，而 T2 恰好是那条线。后来才发现，代数几何、域论里的自然空间（Zariski 拓扑、谱空间）都只到 T0，于是标准放宽了。阶梯的意义不是「越高越好」，而是「标出你在哪一级，就知道哪些定理能用」。

边界与误解

① 「正则」「正规」的定义有版本差异。有的书把正则/正规定义成「不交闭集可分离」（不预设 T1），有的要求额外的 T1（即 T3/T4）。讲义的定义 4.5.1 是「设 X 为 Hausdorff 空间」再加不交闭集条件，也就是已经包含了 T2。做题时务必对准定义。② T0 不等于 T1 的「弱化版」，而是另一个方向的条件。T1 要求两个方向都能找到开集；T0 只要一个方向。但它们不是简单的「数量差别」——T0 允许不对称，T1 强制对称，这个差别在 Alexandroff/Kripke 情境里是关键（定理 3.2）。③ 「T1 ⟺ 每点是闭集」这条等价很好用（习题会要），但注意它等价于「对每对 x ≠ y 存在含 x 不含 y 的开集」——即定义 4.4.2 的逐点版本。

8正规、Tychonoff 与 Urysohn O6

它解决什么问题

T2 用「开集」分离点。如果对象不是点，而是闭集呢？这就需要更强的条件。而一旦能分离闭集，就可以做一件 T2 做不到的事：造出连续函数。这就是 Urysohn 引理——它把「拓扑上分得开」翻译成「数值上分得开」，从而把抽象空间接到实直线上。

定义 8.1（定义 4.5.1，正规）

设 X 为 Hausdorff 空间。若任意两个不交闭集 E, F 都有不交开邻域，即存在开集 U, V 满足

E ⊆ U,   F ⊆ V,   U ∩ V = ∅

称 X 正规，或为 T4 空间。

讲义的评价是：正规 T1 空间比 Hausdorff 更强——不仅能区分模型，还能验证模型不满足某些性质。后半句的意思：E 是闭集，可以想成「满足某个可证伪命题的模型集」（L10：闭集＝可证伪）；把 E 和 F 用不交开集分开，等于同时验证了「在 E 上某性质成立」和「在 F 上它不成立」。

定义 8.2（定义 4.5.2 / 4.5.4）

若不交闭集 E, F ⊆ X 存在连续映射 f : X → [0,1] 满足 E ⊆ f−1[{0}]、F ⊆ f−1[{1}]，称二者可由连续函数分离。

称 X 为 Tychonoff 空间，若它满足 T1，且对每个闭集 A 与 x ∉ A，A 与 {x} 可由连续函数分离。

引理 8.3（Urysohn 引理，引理 4.5.3）

设 X 为 T1 空间。X 正规 ⟺ 每对不交闭集均可由连续函数分离。

（讲义未给证明——这个证明要用到「往 [0,1] 里插二进有理数」的经典构造，是点集拓扑里最长的一段技术活之一。这里接受它，重点看它的用法。）

命题 8.4（命题 4.5.5）

正规空间必为 Tychonoff 空间。直接由 Urysohn 引理得到：取 E = A、F = {x}（两个不交闭集），引理给出分离函数。

例 4.5.6：ℝ 为什么正规

这是本讲唯一一个完整的「正规性验证」，值得看清它的两步。

第一步：造距离函数。对非空 A ⊆ ℝ，令 fA(x) = d(x,A) = inf{|x−a| : a ∈ A}。它连续：由三角不等式，对每个 a ∈ A 有 |z−a| ≤ |z−x| + |x−a|，取下确界再交换 x, z，得

|d(z,A) − d(x,A)| ≤ |z−x|

即 fA 是 1-Lipschitz，当然连续。这个不等式是关键：它说「到集合的距离」不会比「点之间的距离」变化得更快。

第二步：归一化。设 E, F 是不交非空闭集，令

h(x) = fE(x) / ( fE(x) + fF(x) )

闭性与不交性保证每个点到其中至少一个集合的距离为正，故分母非零，h 良定义且连续。x ∈ E 时 h(x) = 0；x ∈ F 时 h(x) = 1。若某个集合为空，用常值函数即可。由 Urysohn 引理，ℝ 正规。

记住这个「两个距离相除」的配方——它在好多地方重现：证明完全正则性、构造单位分解、定义度量空间上的 bump 函数。它的本质是：用「离谁更近」来造一个 0 到 1 之间的连续插值。

例 4.5.7：Hausdorff 而不正规（Sorgenfrey 平面）

这是本讲最难但最有价值的一个例子。它证明阶梯的顶端也严格。

构造。在 ℝ 上以半开区间 [a,b) 为基生成拓扑 τsor，称 Sorgenfrey 直线。两份的积 S = ℝ × ℝ 叫 Sorgenfrey 平面，基本开集是「左闭右开」的矩形。

它 Hausdorff。若 ⟨x,y⟩ ≠ ⟨a,b⟩：当 x = a（不妨 y < b），取 y < c < b、d > x，则 [x,d) × [y,c) 与 [a,d) × [c, b+ε) 分含两点且不交；当 x ≠ a，在第一坐标上作类似分离。

它不正规，用反对角线 Δ = {⟨x,−x⟩ : x ∈ ℝ}：

  • Δ 是闭集（⟨a,b⟩ ∉ Δ 时可取小矩形避开直线 a+b=0）；
  • Δ 的子空间拓扑离散，因为 ([x,x+ε) × [−x,−x+ε)) ∩ Δ = {⟨x,−x⟩}。

Jones 引理（引理 4.5.8）：设 X 为可分正规空间、D 为闭离散子空间，则 2|D| ≤ 2ℵ0。由于 |Δ| = 2ℵ0，由 Cantor 定理 2|Δ| > 2ℵ0，与引理矛盾。故 Sorgenfrey 平面不正规。

这个例子的教益有三层。① 正规性不被积保持——两份正规的直线，积却不正规（对比命题 6.3：Hausdorff 是被积保持的）。② 证明用的是基数论证，不是构造——这是集合论拓扑的典型手法，也解释了为什么这类问题会反过来影响集合论公理。③ 「可分 + 闭离散子集太大」这个组合是正规性的硬约束：正规空间里闭离散子集不能比实数多。这是一条非常强的限制，也说明正规比 Hausdorff 强得多。

典型例子

ℝ 正规（例 4.5.6 的完整证明）；紧 Hausdorff 空间正规。这两个是最常用的。注意：ℝ 的正规性证明用到了度量（距离函数），所以它对度量空间普遍成立——所有度量空间都正规，因为 d(x,A) 的构造在整个度量空间里都成立。

本质例子

Urysohn 引理为什么重要？它说「拓扑分离 ⟺ 函数分离」。往一个方向看：函数分离显然推出开集分离（取 f−1[[0,1/2)] 和 f−1[(1/2,1]]，两个不交开集）。难的是反方向——从开集分离造出连续函数。这一步的技术核心是「二进有理数插值」：在 E 与 F 之间不断插入中间闭集，用正规性逐层分离，最终得到一个在 [0,1] 的二进制小数上都有定义的函数，再延拓到全体。

这条引理是整个「把拓扑空间嵌入方块」传统的起点：Tychonoff 定理说每个 Tychonoff 空间都能嵌入某个 [0,1]κ，用的就是 Urysohn 函数族作为坐标。L13 讲紧致化时会再见到它。

边界与误解

① 「正规 ⟹ 可度量」错。正规性只保证能分离闭集，不保证存在度量。反例是 Sorgenfrey 直线：它正规（可用 Urysohn 引理验证），但不可度量——它不第二可数，而度量空间必第二可数。正规与可度量是两个独立方向的性质。

② 「正规被积保持」错，Sorgenfrey 平面是反例。这条最容易记错，因为 Hausdorff 是被积保持的。凡是「保持性」的问题，一定要逐个构造记，不能类推。

③ Urysohn 引理要求 T1（讲义明写「设 X 为 T1 空间」）。少了 T1，单点集未必闭，{x} 与 A 就不一定是「一对不交闭集」，引理的前提不成立。

④ 定义 4.5.1 已经把 Hausdorff 写进前提，所以「正规」在本讲里自动是 T2 的；不要以为可以拿一个非 Hausdorff 空间去验正规性。

要留意一个同名的坑

UAL 里也有「滤子性质」（filter property，定义 3.3.18），但它不是本讲的拓扑滤子。UAL 的滤子性质说的是：一个逻辑 L 存在派生联结词，使得「两个公式的语义值相等」可以用一族二元联结词来表达，「公式有效」可以用一族等式来表达。它是「语义值能由公式内部表达」这件事的技术条件，和集合上的滤子只有名字上的联想。

真正与拓扑滤子对应的是 UAL 的生成滤子（定义 2.2.62）：由集合族 E 生成滤子、有限交性质、命题 2.2.63 的显式刻画。那一条和本讲命题 4.3 是同一个东西——只是 UAL 在布尔代数/幂集上用它做模型论，拓扑讲义在一般拓扑空间上用它做收敛。两处都在为 L18 的紧致性定理铺路：有限交性质 = 局部相容，真滤子 = 全局相容。

收束

整讲只有一个问题：两个东西分不分得开？滤子是工具（把「逼近」打包），收敛是现象（理论在逼近模型），分离公理是等级（用什么工具分、分到什么程度）。

最有用的那一级是 T2，因为它等价于「极限唯一」——这是把分析搬进拓扑的入场券。而 L13 会拿走这根接力棒：紧致性 = 每个素滤子都收敛，配上 T2 就得到「极限存在且唯一」。存在性由紧致给，唯一性由 Hausdorff 给——两条拼起来，才是分析里那个熟悉的「极限存在唯一」。这就是为什么 L12 必须在 L13 之前。

10习题（按目标编号）

O1 · T0 与可区分
  1. O1 证明：X 是 T0 空间 ⟺ 对任意 x ≠ y，存在开集 U 使 x, y 中恰有一个属于 U。
    提示：把「或」的两个情形合并成一个「恰有一个」。
  2. O1 用定理 3.2 验证：取 W = {0,1}、R 为全关系（0R1 且 1R0，自反传递），说明诱导拓扑不是 T0，并指出哪个序公理失效。
O2 · 滤子
  1. O2 判断下列各族是否为滤子基 / 滤子：(a) ℕ 上的余有限集族；(b) {A ⊆ ℕ : 1 ∈ A}；(c) 实直线上所有含 0 的开区间之族。对每族写出向上闭包。
  2. O2 用命题 4.3 证明：若 E 有有限交性质，则它生成的滤子是真滤子；反之若生成的滤子是真滤子，则 E 有有限交性质。再举一个 E 无有限交性质的例子，说明此时生成的「滤子」是什么。
O3 · 收敛
  1. O3 在 ℝ 上验证：𝔉 = {(0, 1/n) : n ≥ 1}↑ 收敛到 0。再说明它为什么不收敛到 1。
    提示：找一个 1 的邻域，使 𝔉 中没有任何成员落在里面。
  2. O3 在 Cantor 空间 2ω 中，验证柱集族 {C(x↾n)} 是滤子基且收敛到 x。再举一个该空间中的滤子，它收敛到 x 但不含任何柱集。
O4 · Hausdorff
  1. O4 完整证明定理 6.2 的两个方向，并说明 (1⟹2) 中哪一步用到了「滤子含空集就非真」。
  2. O4 在双重点实直线上，具体写出一个同时收敛到两个零点的滤子（用 §6 的构造），并验证它确实收敛到两点。
O5 · 阶梯与反例
  1. O5 证明「X 是 T1 ⟺ 每个单点集是闭集」。再说明为什么 T0 没有这个刻画。
  2. O5 在余有限拓扑上：证明它 T1、不 T2；再找出一个同时收敛到两个点的滤子，与定理 6.2 对照。
  3. O5 证明命题 6.3 的三条（子空间、积、拓扑和保持 Hausdorff），并各指出证明中用到哪个开集族的具体形状。
O6 · 正规与 Urysohn
  1. O6 仿照例 4.5.6，证明任意度量空间都正规。指出哪一步必须用「d(x,A) = 0 ⟺ x ∈ cl(A)」。
  2. O6 陈述 Urysohn 引理，并用它证明命题 4.5.5（正规 ⟹ Tychonoff）。再说明为什么引理需要 T1 前提。
    提示：考虑单点集在非 T1 空间里是否闭。
