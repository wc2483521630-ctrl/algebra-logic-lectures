2动机：从「有没有」到「能不能算」

它解决什么问题

L18 的紧致性定理给了你一张存在性证明：有限片段都有模型，整体就有模型。但那张证明靠的是非主超滤子和超积——L13 早就说过，非主超滤子写不出具体例子。所以你知道解存在，却拿不到它。

这一讲换一个问法。不问「解在不在」，问「哪些式子是有效的，我能不能一台机器把它一个个列出来？」如果答案是能，那台机器就是 Hilbert 系统：有限条公理模式、有限条推理规则，剩下全靠机械代入。这是从存在问题走向生成问题。

两件事看着不相干，其实被一个词焊死了：有限。Hilbert 证明是一条有限公式序列；有限，就意味着每一步只用有限多个前提。于是 ⊢ 天生满足「可证的总有有限理由」。如果完全性说 ⊨ 和 ⊢ 是同一件事，那么 ⊨ 也继承这个性质——那正是 L18 的紧致性。

一句话：完全性 = 紧致性 + 一台有限证明的发动机。L18 造好了紧致性这一半，这一讲把发动机装上。

先把话说清楚：两个「完全」别混

① 这里的「完全」是「有效式都可证」，不是「公理写得满满当当」。它是语义与语法的吻合度，不是公理的多少。一个公理很少的系统完全可能完全（命题逻辑就是这样）。

② ⊢ 和 ⊨ 必须分开写，哪怕它们最后相等。写成同一个符号，你就看不出「完全性」在证明什么了。整讲的价值就在让这两套记号先分家、再握手。

3Hilbert 系统三件套 O1

定义 3.1（Hilbert 型推理系统）

一个 Hilbert 系统是三元组 D = ⟨Fm(L), Ax, R⟩：

  • Ax：公理，通常是一族公理模式（把某几个变元任意代入公式都算公理）。
  • R：推理规则，如分离规则 MP「从 φ 与 φ → ψ 得 ψ」、概括规则「从 φ 得 ∀x φ」（x 不在前提中自由出现）。
  • 证明：从 Γ ∪ Ax 出发的一条有限公式序列，每一项或是公理实例、或是 Γ 的成员、或由前面项用某条规则得到。记 Γ ⊢D φ；Thm(D) = {φ : ∅ ⊢D φ}。
命题 3.2（有限支持性）

若 Γ ⊢ φ，则存在有限 Γ₀ ⊆ Γ 使 Γ₀ ⊢ φ。

证明。一条证明只有有限步，每步用到的 Γ 中前提至多有限多个，把这些前提收集起来就是 Γ₀；同一条证明同时也是从 Γ₀ 出发的证明。∎

别小看这一行。它是 L02 闭包算子「有限特征」在语法侧的实例：C⊢(Γ) = ⋃Γ₀ ⊆ Γ 有限 C⊢(Γ₀)。下一节会看到，整个 L19 都是从这一行长出来的。

⊢ 与 ⊨：先分家，再握手

Γ ⊨ φ 说的是：每个满足 Γ 的模型都满足 φ——这是真值问题，语言里谈的是模型和赋值。Γ ⊢ φ 说的是：存在一条从 Γ 到 φ 的有限证明——这是符号操作问题，语言里根本没有模型。

它们凭什么该相等？一点都不显然。一个是关于「所有模型」的全称命题，一个是关于「存在一条序列」的存在命题。完全性定理的全部内容，就是说这两件毫不相似的事情恰好重合。

典型例子

命题逻辑的 Hilbert 系统。几条公理模式（如 φ → (ψ → φ)）加分离规则，就足以生成全部重言式。系统有限、规则单一、证明可检查。这是「有效 = 可证」最干净的样板：你写出的每个重言式，原则上都能被这台机器有限步吐出来。

本质例子

分离规则为什么必须是保真的。若 φ 与 φ → ψ 都有效，则 ψ 有效——所以 MP 这条规则把有效式送到有效式。本质在于：一条推理规则要能进 Hilbert 系统，它得是语义上站得住的推理。否则系统会证出假式子，可靠性失败，桥从这一头就断了。所谓「Hilbert 系统的规则」，其实就是 ⊨ 自身满足的闭包规则被抄到了语法侧。

边界与误解

① 可导出规则 ≠ 可允许规则。规则「前提集 Δ 得结论 ψ」可导出，指 Δ ⊢ ψ；可允许，指对任意代入 σ，只要 σ 把 Δ 全送进定理集，就把 ψ 也送进去。可导出必可允许，反之不必（中间逻辑里有大量反例）。这说明「定理集」比「规则清单」更基本：完全性只保证定理集对上，不保证你选的规则清单唯一。

② 公理模式的「有限」不是「公式有限」。一条模式 φ → (ψ → φ) 代表无穷多条实例。有限公理化说的是模式有限，见 §7。

来源：UAL §4.2.1（Hilbert 系统、可允许规则）；L02 闭包算子的有限特征；L01 语法与语义。

4可靠、完全，与「完全 ⟹ 紧致」 O2

定义 4.1（四个词，两种强度）
名称陈述包含关系
弱可靠⊢ φ ⟹ ⊨ φ定理都是有效式
强可靠Γ ⊢ φ ⟹ Γ ⊨ φ带前提也保真
弱完全⊨ φ ⟹ ⊢ φ有效式都是定理
强完全Γ ⊨ φ ⟹ Γ ⊢ φ带前提也能证

强可靠是「⊢ ⊆ ⊨」（作为二元关系），强完全是「⊨ ⊆ ⊢」。两者同时成立，就是 ⊢ = ⊨。

定理 4.2（完全 + 可靠 ⟹ 紧致；L19 与 L18 的接缝）

设逻辑 L 有强可靠且强完全的 Hilbert 系统，则 L 后果紧致（L18 定义 3.2）：Γ ⊨ φ ⟹ 存在有限 Γ₀ ⊆ Γ 使 Γ₀ ⊨ φ。

证明（三步，每步都是前面见过的）。

① 由强完全，Γ ⊨ φ ⟹ Γ ⊢ φ。

② 由命题 3.2（证明有限），存在有限 Γ₀ ⊆ Γ 使 Γ₀ ⊢ φ。

③ 由强可靠，Γ₀ ⊢ φ ⟹ Γ₀ ⊨ φ。

串起来即得。∎

在有 ¬ 与 ⊥ 的熟悉情形，由 L18 §3 的等价，后果紧致再给出可满足紧致：「每个有限片段有模型 ⟹ 整体有模型」。

这个定理为什么是整讲的枢纽

它说明完全性比紧致性强：完全性不仅保证「有限都行就整体行」，还额外给了你一台能有限步验证的机器。L18 的紧致桥是它的影子，不是它的全部。

更要紧的是方向：「可靠 + 完全 ⟹ 紧致」是容易的，「紧致 ⟹ 完全」却不能照搬。前者只需把有限证明走三遍；后者要凭空造出一个模型来，得动用 Henkin 构造（§6）。这个不对称，是本讲后半段全部技术的来源。

紧致性不够

① 紧致是完全的必要条件，但单靠它造不出 Hilbert 系统。还需要代数侧的条件（定理 4.2.18），核心是 ⊨ 的等价关系要能被代数同余捕捉（L16 的代数对应）。

② 二阶逻辑是反面的镜子。满语义的二阶逻辑紧致性失败（L18 §8 的「有限群」论证同型），因此根本不存在强可靠且完全的有限 Hilbert 系统。紧致性一断，桥就塌。

来源：UAL §4.2.1–4.2.2；L18 定义 3.1/3.2 与 §3 两紧致性等价；L02 闭包算子有限特征。

5定理 4.2.9/4.2.18：双向代数刻画 O3逻辑

定理 5.1（UAL 定理 4.2.9，语法 ⟹ 代数）

设 L 有强可靠、有限完全的 Hilbert 系统。则 ⊢ 与 ⊨ 在有限前提上一致，配合紧致性在全集上一致；于是 L 的有效式恰好是从 Ax 用规则可导出的式子，代数侧的表达就是：Alg⊨(L) 中成立的等式，恰由这族公理的等式翻译生成。

证明骨架。用 L16 的翻译把公式 φ 送到等式 ε(φ)，把 ⊢ 送到代数的等式可导性；再用 L04 的 Birkhoff 定理「等式可证 ⟺ 所有模型成立」闭合。∎
定理 5.2（UAL 定理 4.2.18，代数 ⟹ 语法）

反过来，若 Alg⊨(L) 的等式理论可由一族等式以有限步规则生成（相应的代数性质），且 L 紧致，则可造出强可靠且完全的 Hilbert 系统。

证明骨架。把这族生成元抄成公理模式、把有限步生成规则抄成推理规则，得到 D；先由构造得 ⊢ ⊆ ⊨；反向用 ⊨ 的紧致性把无穷的语义后承压成有限，再用生成元的完备性得到有限证明。∎
两方向各用哪座桥
方向用的工具关键一步
语法 ⟹ 代数（4.2.9）L16 翻译 + L04 Birkhoff把「可证」读成代数里的等式可导
代数 ⟹ 语法（4.2.18）L18 紧致性 + §4 的有限支持性用紧致把「所有模型成立」压成有限证明

和 L18 定理 4.1.5/4.1.6 的模板一模一样：一边是逻辑性质，一边是代数性质，靠 L16 的翻译 + L04 的构造兑现。你已经见过第二遍了。

上面在「有 ¬、Alg⊨(L) 一阶刻画」的熟悉情形写得干净。UAL 一般设定下要补两处：一是没有 ¬ 时用 mng 形式化「反例模型」；二是 Algm(L) 与 Alg⊨(L) 的差距要靠 L16 的可代数化条件弥合。本讲义的目标仍是看清桥的形状与发动机，纯技术验证留给原书。

6Henkin 构造与典范模型 O4拓扑

它解决什么问题

§4 只证了「完全 ⟹ 紧致」，方向是向下的：从完全性推出紧致性，容易。现在要证向上的那个方向——从语义的 Γ ⊨ φ 造出语法的 Γ ⊢ φ，也就是：给定 Γ 一致，造一个模型满足它。没有现成模型可用，只能自己造一个。

怎么造？用语法的材料造——这就是 Henkin 构造。它的思路和 L13 补 Stone–Čech、L18 用超滤子取极限，是同一个动作的第三种写法：把相容的理论扩张到极大，再把极大理论当成一个点。

四步构造（Gödel 完全性定理的 Henkin 证明）

第 1 步：加见证。给每个公式 ∃x φ(x) 配一个新常元 cφ，加入公理 ∃x φ(x) → φ(cφ)。作用：让每个存在断言有一个「看得见的证人」。不加这一步，后面造出的模型里量词没有着落。

第 2 步：扩张成极大一致集。设 Γ 一致，用枚举加逐步扩张（或 Zorn 引理）把它扩成 Γ* ⊇ Γ，满足对每句 ψ，恰有 ψ ∈ Γ* 或 ¬ψ ∈ Γ*，且 Γ* 一致。作用：把理论逼到「对每件事都表态」的饱和状态。

第 3 步：造典范模型（项模型）。论域取闭项的等价类：t ∼ s ⟺ (t = s) ∈ Γ*。函数符号按项解释，关系符号按 Γ* 成员解释。作用：用语法自身的材料（项）当模型的点。

第 4 步：真值引理。归纳证明：对每句 ψ，M* ⊨ ψ ⟺ ψ ∈ Γ*。原子式由解释定义，布尔连接词由极大一致性（第 2 步），量词由见证（第 1 步）。于是 M* ⊨ Γ，Γ 有模型。∎

这三处原来是同一个东西

极大一致集 Γ* = L16 公式代数 F/∼L 上的超滤子（把 Γ* 里公式的等价类收成一族，它对交封闭、向上封闭、极大）。而超滤子空间正是 L18 §6 的 Stone 空间 Spec(L) 的点。

再看 L13：Stone–Čech 紧致化补上的点，也是非主超滤子。三处对照：

场合被补的对象它的真身
L13 紧致化空间缺点，补上的点非主超滤子
L18 紧致性有限相容理论的整体模型超积 ∏AΔ/U
L19 完全性一致理论的模型极大一致集 = 超滤子 = 典范模型

Henkin 构造就是 Stone 表示定理的正确性证明穿上了语法的衣服。L06 把布尔代数的点取作超滤子，这里把逻辑的点取作极大一致集——同一批点。

典型例子

命题逻辑的 Henkin 构造最简单：没有量词，第 1 步省掉；极大一致集直接给每个变元指派真值（p ∈ Γ* 就令 p 真）。于是「每个一致公式集可满足」就是命题逻辑紧致性，典范模型退化成一个真值指派。

本质例子

一阶逻辑里见证常元那一步是命门。Γ = {∃x φ(x)} 一致，若不给证人，你手上没有一个项能充当 φ 的对象；加了 cφ，模型里立刻有 [cφ] 满足 φ。本质在于：模型的点不必是「原本就有的东西」，可以是为理论专门造出来的证人。这正是它区别于超积构造的地方——超积从已有模型取极限，Henkin 从语法造新点。

边界与误解

① 完全性定理不等于「每个理论有模型」。只有一致理论才有。不一致理论（含 φ ∧ ¬φ）没有模型，也不用证。把「一致」忘掉是初学时最常见的错。

② 典范模型满足 Γ，但不唯一。极大扩张有很多种选法，每种给一个不同的 Γ*，模型各不相同。完全性只承诺「存在一个」，不承诺「哪个」。这和 L18 超滤子不唯一是同一件事。

来源：Gödel 完全性定理的 Henkin 证明；L16 公式代数 F/∼L；L18 §6 Stone 空间；L06 Stone 表示；L13 §8 紧致化。

7有限公理化与有限基 O5

定义 7.1（两个「有限」）

逻辑侧：称 L 有限公理化，若存在有限条公理模式与有限条推理规则，其生成的定理集恰为 Thm(L)。

代数侧：称 Alg⊨(L) 有限基，若存在有限个等式生成它的全部等式理论。

两个「有限」靠 Birkhoff 对上：L04 定理 4.12 说「等式可证 ⟺ 所有模型成立」，于是「有限公理生成定理」正好翻译成「有限等式生成等式理论」。这就是标题里「有限公理化」那一格的位置——它是完全性桥在有限性层面的精细版本。

典型例子

布尔代数有限基（几条等式即可，L06），对应命题逻辑有限公理化；群、格、环都是有限基的经典簇。这些「有限」是看得见摸得着的：写下几行等式，整簇的性质就定了。

本质例子

为什么有限基这么值钱？因为它把一个可能无穷的等式理论压缩成有限数据。有了有限数据，才能谈算法、谈判定、谈自动定理证明。本质在于：有限基 = 可存储、可检查的一小段代数编码。§5 定理 4.2.18 里「等式理论由有限步规则生成」说的正是这件事。

边界与误解

① 有限基 ≠ 可判定。有限公理化的理论仍可能不可判定——一阶逻辑本身有限公理化（少量模式 + MP + 概括），但有效性问题是不可判定的（Church）。别把「公理写得下」当成「机器能判定」。

② 有的簇不是有限基。泛代数里已构造出需要无穷多等式、任何有限子集都不够的簇。对应逻辑就没有有限公理化——这是「有限性」这条线索真正断裂的地方。

③ 真算术不可递归公理化（Gödel 第一不完全定理）：不是「完全性定理错了」，而是 Th(ℕ) 这套语义后承无法由任何递归的 Hilbert 系统生成。完全性定理对一阶逻辑仍然成立；不完全性说的是特定理论的公理集找不到。把两者混为一谈，是这一讲最容易踩的坑。

来源：UAL §4.2.2、有限公理化与有限基；L04 定理 4.12（Birkhoff）；L06 布尔代数；Church 不可判定性、Gödel 不完全性定理（边界说明）。

8拓扑侧：理论–模型对应与紧致化 O6

Galois 连接：把理论摆成闭集

回忆 L02 的 Galois 连接。这里取两个映射：

Γ ↦ Mod(Γ) = {A : A ⊨ Γ},    K ↦ Th(K) = {φ : 每个 A ∈ K 满足 φ}。

这是一对反变 Galois 连接，闭包算子 Γ ↦ Th(Mod(Γ)) 正是 ⊨ 的理论闭包。闭集就是「理论」——被自己模型集完全刻画的理论。L18 §6 已经把 Mod(Γ) 认成 Stone 空间的闭子集；这里只是把同一件事写成 Galois 连接的形状。

命题 8.1（三栏翻译）
逻辑拓扑
理论 Γ（一致）Spec(L) 中非空的闭集 / 相容的闭集族
极大一致集 Γ*Spec(L) 的一个点（超滤子）
Henkin 扩张 Γ ⊆ Γ*在闭集里选一点 = 补上缺失的点
Γ 有模型该闭集非空（交非空）
完全性 Γ ⊨ φ ⟹ Γ ⊢ φ闭集包含关系可由点（超滤子）见证
紧致化视角：Henkin 扩张就是补点

L13 §8 说 Stone–Čech 紧致化把「相容但没有具体模型的理论」补成空间里的点。现在看清了：Henkin 第 2 步把 Γ 扩成 Γ*，就是在 Spec(L) 里选一个点；第 3 步的典范模型，就是把那个点读出成一个模型。

于是三件事彻底合一：完全性证明 = Stone 表示 + 真值引理；紧致性定理 = 超滤子收敛；紧致化 = 补上超滤子点。三本教材用的是同一批超滤子，只是穿了不同衣服。

来源：拓扑讲义 Ch5.3（紧致化）；L02 Galois 连接；L13 §8 Stone–Čech；L18 §6 Stone 空间翻译表。

9融合接口：第二座三面一体图

L18 画了紧致性的三面一体图。这里画完全性的——同一副骨架，把「紧致」换成「可证」。

                 「有效 = 可证」· 三副面孔
                        │
     ┌──────────────────┼──────────────────┐
     │                  │                  │
   逻辑 L            语法 D              代数 Alg⊨(L)
     │                  │                  │
  Γ ⊨ φ            Γ ⊢ φ            等式 E 可导
     │                  │                  │
  语义真值          有限证明           有限生成
     │                  │                  │
     ▼                  ▼                  ▼
  完全性 ◀──── 可靠 + 有限支持性 ────▶ Birkhoff
     │                  │                  │
     └── 紧致性（L18） ◀─┴─ 有限公理化/有限基 ─┘
              Henkin 极大一致集 = 超滤子 = Stone 点

图：三列从上到下逐行对齐；第二座桥与第一座共用「有限性」这块积木。

第一座（L18）第二座（L19）

把这座桥记成一句话

「有效 = 可证」在代数里叫「等式可证 ⟺ 所有模型成立」，在语法里叫「有台有限步的机器」，而把它们焊在一起的是「证明有限」这一个词。

到这里，紧致性与完全性两条线汇合：完全性比紧致性强，多出来的正是一台有限证明机。下一讲 L20 走第三座桥——可定义性 ↔ 同态满射 ↔ 可区分性，会把「能不能定义」翻成「同态会不会丢信息」，拓扑侧读出 T0 分离。骨架照旧：逻辑性质翻译成代数性质，靠 L16 的翻译和 L04 的构造兑现。
