0概念清单与依赖关系（简）

L13 问「该有的点在不在」，L14 问「点之间能不能被切开」。两问用的是同一批开集，答案却几乎相反：几何学家要连通，逻辑学家要全分离。分岔点只有一个——你手上那把刀是「开集」还是「开闭集」。

2动机：换一把刀切空间

它解决什么问题

L12 的分离公理阶梯用的是开集：T0 是「有一个开集只含这两点中的一个」，T2 是「有两个不交开集分别包住它们」。开集只保证可验证——你等到某件事发生，就能确认自己在其中一边。

现在把刀换掉：只允许用开且闭的集合。根据 L08 的词典，开闭集是可正反判定的命题：既能在有限时间内确认，也能在有限时间内推翻。这是认识论上强得多的能力。

换刀之后，问题变了：两个不同的世界，能不能被某个命题彻底分开？这个问题的答案谱系，就是本讲的全部内容。

两端的极端

① 连通（connected）：没有任何非平凡的可判定命题。开闭集只有 ∅ 和 X。你没法用一句话把世界分成两半。

② 全分离（totally separated）：任意两个不同世界，都有某个可判定命题把它们分开。每个世界都能被一句话精确指认。

讲义开头那句话很准：几何学家多半希望空间连通，哲学家（做认识论的）多半希望空间高度不连通。同一个东西，两拨人要相反的性质。「天空是紫色的」若可验证，在连通空间里就不能同时可证伪——因为那样它就是一个非平凡开闭集了。

接住 L13：同一批世界，两种拓扑

L13 的闹钟例子最后补上了一点 x∞，得到 α(ω) = ω ∪ {∞}。这个空间里每个 {n}（n ∈ ω）都是开且闭的——它是全分离的 Stone 空间。

而 ℝ 是连通的，一点都不全分离。可 ℝ 和 ω 作为集合的基数相同吗？不同，但 ℝ 和 ω 的 Stone–Čech 紧致化都落在同一套理论里。关键不在有多少点，而在开集怎么给。把 ℝ 换成离散拓扑，它立刻全分离；把 ω 换成余有限拓扑，它立刻连通。本讲要学的，就是这种「换拓扑就像换认识能力」的精确刻度。

先拆一个必踩的坑

连通 ≠ T0 失败。Sierpiński 空间 S = ({0,1}, {∅, {1}, {0,1}}) 是 T0：开集 {1} 把两点分开了。但它连通，因为 {1} 不是闭的——它只能验证，不能证伪。

所以「能被开集分开」和「能被开闭集分开」是两件事。T0 说的是信息不对称，全分离说的是信息完备。看到「连通」就说「两点分不开」，是把 L12 的分离公理和本讲的概念搞混了。

3连通与道路连通 O1

定义 6.1.1 连通

空间 (X, τ) 若开闭子集只有 X 和 ∅，称为连通的。

这个定义看起来消极——只是说「没有什么」。但它积极的一面由下面这个判据给出，而这一步是整个拓扑与逻辑对话的入口。

命题 6.1.2 连续到两点空间

X 连通 ⟺ 每个连续映射 f : X → {0,1}（值域取离散拓扑）都是常值。

证明

(⟹) {0} 在离散空间里既开又闭，所以 f−1({0}) 在 X 里既开又闭。由连通性它只能是 ∅ 或 X，于是 f 恒为 1 或恒为 0。

(⟸) 若 U 是非平凡开闭集，取特征函数 χU : X → {0,1}。对值域中任意开集 V，χU−1(V) 是 ∅、U、X − U 或 X 之一，都开，故 χU 连续而非常值。∎

注意：这个命题把「空间的连通性」翻译成了「映射的刚性」。L11 讲的连续映射在这里第一次充当探测器：到离散二点空间的连续映射就是「可正反判定的命题」，连通就是说这种命题只有常值的。

例 6.1.3 与命题 6.1.4

ℝ 和 [0,1] 连通。理由就是中间值定理：若连续实函数 f 满足 f(a) < c < f(b)，则中间有点取到 c。于是到 {0,1} 的连续映射不可能既取 0 又取 1。

含多于一点的离散空间不连通（每个单点都是开闭集）；任意不可分空间（开集只有 ∅, X）连通，而且是最容易的连通。

命题 6.1.4 给了一条反向约束：含至少两点的正规连通空间，基数至少 2ℵ0。这句话值得记住：在分离性良好的空间里，连通是很「贵」的，最小例子就已经和实数一样大。有限连通空间只能靠不可分拓扑撑着。

命题 6.1.5 与推论 6.1.6 稠密子集判定

若 A ⊆ X 稠密且在子空间拓扑下连通，则 X 连通。

证明

设 U ⊆ X 开闭。则 A ∩ U 和 A ∩ (X − U) 在 A 中开闭。由 A 连通，A ⊆ U 或 A ⊆ X − U。这两个集合在 X 中都是闭的，而 A 稠密，故对应的那个等于 X。∎

推论 6.1.6：连通空间的任意紧致化仍连通。因为 X 在紧致化 cX 中稠密（L13 定义 5.3.2），且连通性被连续满射保持。这里用的是「稠密」，不是「闭」——补点不会把一块布撕开，只会给它封边。

定义 6.1.7 / 命题 6.1.8 道路连通

从 x 到 y 的道路是连续映射 p : [0,1] → X，p(0)=x, p(1)=y。任意两点间有道路则称 X 道路连通。

道路连通 ⟹ 连通。若 X = A ∪ B，A,B 非空不交开闭，取 x ∈ A, y ∈ B 和道路 p。则 p−1[A] 是 [0,1] 中既开又闭的子集，含 0 不含 1，与 [0,1] 连通矛盾。∎

译注：讲义指出，对实直线的子集和有限拓扑空间，这两个概念一致。一般空间不一致，见下面边界例。

例 6.1.9 穿孔平面

ℝ2 − {(0,0)} 道路连通。两点之间的线段若不经过原点，直接走；若经过，取第三点，使两段折线都避开原点，再拼起来。

这个例子的意义在于反差。实直线去掉一点断成两截，平面去掉一点只留下一个洞，还是一整块织物。但两者显然该有不同的几何性质——精确说出这个差别，就是代数拓扑的起点（同伦、同调）。连通性看不见这个洞，它需要更精细的工具。

典型例子

ℝ 与 [0,1]：中间值定理直接给出连通，且它们也是道路连通。这是你要拿来对照所有反例的基准：在 ℝ 里，「不能切开」和「能走过去」恰好重合，所以直觉不会报警。

本质例子

拓扑学家的正弦曲线：S = {(0,0)} ∪ {(x, sin(1/x)) : 0 < x ≤ 1}，取 ℝ2 子空间拓扑。它连通（曲线部分的闭包把它和原点粘住，无法用开闭集切开），但不道路连通：从原点出发的任何连续道路，其横坐标必须从 0 连续走到正数，而正弦在 x → 0 时无限振荡，迫使纵坐标没有极限。

为什么这是本质的：它证明「不能切开」比「能走过去」弱。用命题 6.1.2 的探测器语言说：S 上没有任何非平凡的可判定命题，但存在两个点之间没有连续路径。认识论的「分不开」不等于几何的「走不到」。

边界与误解

① Sierpiński 空间连通，但 T0。前面说过：{1} 开却不闭。所以它只能验证、不能证伪，构不成开闭集。连通不阻止「信息不对称」，只阻止「双向判定」。

② 无限集上的余有限拓扑连通，且是 T1。它的开集是 ∅ 与余有限集，闭集是有限集与 X。取一个非全体的余有限开集 U：X 无限，故 U 也无限，不可能有限，所以 U 不闭。开闭集只有 ∅, X，空间连通。这也说明「T1 + 连通」并不矛盾。

③ 连通空间的紧致化仍连通，但紧致空间的子空间不必连通。[0,1] 紧致连通，挖掉中点 {1/2} 后分成两截。连通不是遗传性质。

4全不连通与全分离 O2

定义 6.2.1 / 6.2.2 两种「碎」

非空子集 A ⊆ X 若连通，且没有严格包含它的连通子集，称为连通分支。全体记作 Con(X)。

若每个非空连通子集都是单点集，称 X 全不连通（totally disconnected）。

译注：原稿两处都漏了限定。第一处写成「只要 A ⊆ B 则 B 不连通」，没有排除 B = A，那样任何连通集都不可能成为分支；第二处没排除空集，按其字面没有任何空间能满足定义。这两处不是文字问题，是把定义改成了不可能满足的东西。

例 6.2.3

离散空间全不连通（每个单点既是开集也是其余点的补，连通子集只能是单点）。含多于一点的不可分空间不全不连通：它整体连通，所以有含两个点的连通子集。

定义 6.2.4 拟连通与全分离

规定

x ≡QC y  ⟺  对每个开闭集 U ⊆ X，x ∈ U ⟺ y ∈ U

若 A 内任意两点都满足这个关系，称 A 拟连通；极大的非空拟连通子集称为拟分支，全体记作 QCon(X)。若每个拟分支都是单点集，称 X 全分离（totally separated）。

记含 x 的连通分支、拟分支为 [x]con、[x]qcon，则

[x]con ⊆ [x]qcon

理由很直接：能被开闭集分开的两点，不可能落在同一个连通分支里——否则那个分支就会被开闭集切成两半。

译注：原稿在拟分支的极大性表述里同样漏了「严格包含」和「拟连通本身」，已补明。这个包含关系是本节的发动机：它让「全分离 ⟹ 全不连通」几乎白送，而反方向需要额外条件。

命题 6.2.5 紧 Hausdorff 下的合流

(1) 全分离蕴含全不连通。
(2) 若 X 紧致 Hausdorff，则 [x]con = [x]qcon。
(3) 因此在紧致 Hausdorff 空间中，全不连通与全分离等价。

证明

(1) 由 [x]con ⊆ [x]qcon，若 X 全分离，则 [x]qcon = {x}，于是 [x]con 也是单点。∎

(2) 设 A = [x]qcon。它可写成

A = ⋂{S ⊆ X : S 开闭且 x ∈ S}

故 A 闭。设 A = B ∪ C，B, C 是 A 中不交开闭集且 x ∈ B。要证 C = ∅。

因 A 在 X 中闭，B, C 在 X 中也闭。紧致 Hausdorff 空间正规（L13 定理 5.3.1 / L12 §8），取不交开集 U ⊇ B、V ⊇ C，有 A ⊆ U ∪ V。

现在第一次用紧致性：由定义 6.2.4 的构造，A 是那族含 x 的开闭集之交，且 A ⊆ U ∪ V。把 X − (U ∪ V) 看成被交掉的闭集，它紧致且与那族开闭集的交为空，故有有限多个 S0, …, Sn 使

S′ = S0 ∩ ⋯ ∩ Sn ⊆ U ∪ V

令 D = S′ ∩ U。它开；又因为 U, V 不交且 S′ ⊆ U ∪ V，有 D = S′ − V，所以它也闭。x ∈ D，而 D ⊆ S′ 且 D 开闭，由拟分支定义得 A ⊆ D。但 D ∩ C = ∅，于是 C = A ∩ C = ∅。所以 A 连通，由连通分支的极大性 A ⊆ [x]con，合上之前的包含即得相等。

(3) 直接由 (2)：两种分支处处相同，单点性互为充要。∎

这一步在做什么：「全不连通」是按连通性定义的，「全分离」是按可判定性定义的。命题 6.2.5 说：在紧 Hausdorff 这个常见环境里，「走不出一块」和「分不开两点」是同一件事。缺了紧致性，证明里那次「有限化」就做不了；缺了 Hausdorff，连不交开邻域都拿不到。

例 6.2.6 Cantor 空间全分离

若 x ≠ y，可取一个有限初段 s，使 x ∈ C(s) 而 y ∉ C(s)。柱集 C(s) 的补是有限个同长度柱集之并，故 C(s) 开闭。于是任意两点被一个 clopen 分开，空间全分离，从而全不连通。

注意「有限」两个字。如果初段长度跑向无穷，补集是无穷并，开闭性就没了。这和 L10 的 Kuratowski 公理是同一个坑：拓扑只对有限运算封闭。

典型例子

离散空间：每个单点开闭，两种「碎」都达到最强。这是逻辑最舒服的地形——每个世界都能被一句话单独指认，代价是没有任何有趣的连续性。

本质例子

Cantor 空间 2ω：全分离、无孤立点、紧致、可度量。它证明「碎成单点」和「一堆孤立点」是两回事——这里每个单点不是开集，但任意两点仍能被某个柱集分开。这是 Stone 空间的原型，也是 L06 布尔代数表示定理里那个「无穷但紧」的点空间。

边界与误解

① 全不连通不一定全分离。两者对一般空间不等价，命题 6.2.5 的紧致 Hausdorff 假设不能删。讲义举的候选是 Knaster–Kuratowski 扇去掉顶点 p。但译注如实指出：原稿那段论证没有写完，这里不冒充已有完整证明。可靠的一般事实只有包含关系 [x]con ⊆ [x]qcon。

② 全不连通不是「没有连通子集」。单点集总是连通的（定义 6.2.2 特意说「非空连通子集」）。若按字面排除空集之外的一切，就没有空间能满足定义了。

③ 别把 Cantor 集当成「离散的」。它是全分离的，但作为 [0,1] 的子空间没有任何孤立点。「能用柱集分开」≠「单点本身是开集」。

5Stone 空间与零维 O3代数

定义 6.2.7 Stone 空间

紧致、Hausdorff 且全不连通的空间称为 Stone 空间。

讲义特别说明： Stone 空间在逻辑里几乎无处不在，涉及模型论的数理逻辑领域都会遇到。原因现在可以说了：L06 的 Stone 表示定理把任意布尔代数 B 变成它的超滤子空间 Ult(B)，而这个空间恰好是 Stone 空间。本讲给它补上了拓扑这一侧的定义。

引理 6.2.8 零维刻画

X 是 Stone 空间 ⟺ X 紧致 Hausdorff，且有一个由开闭集组成的基（这一条常叫零维性）。

证明

(⟹) 设有开闭基。取 x ≠ y，由 Hausdorff 性有不交开邻域 U ∋ x、V ∋ y。在 U 中取含 x 的基本开闭集 W。它不含 y，于是 W 把两点分开，空间全分离，从而是 Stone 空间。

(⟸) 设 X 是 Stone 空间。取开集 U 和 x ∈ U。对每个 y ∉ U，由全分离性（命题 6.2.5(3)）取开闭集 Vx,y 含 x 不含 y。于是

X − U ⊆ ⋃y ∉ U (X − Vx,y)

X − U 是紧致空间的闭子集，故紧致（L13 引理 5.2.11）。由开覆盖定义取有限多个覆盖，设对应的开闭集是 Vx,y1, …, Vx,yk。令它们的交为 Vx。有限交仍是开闭，且 x ∈ Vx ⊆ U。于是

U = ⋃x ∈ U Vx

开闭集构成基。∎

译注（必须看）：原稿写「开闭集的并开闭」，一般只有有限并才保持开闭。上面的证明通过紧致性先取有限子覆盖，把无穷并换成有限交，才把漏洞补上。这就是 L13 的紧致性在本讲第二次出手：第一次是命题 6.2.5 的有限化，这里是第二次。

例 6.2.9 βX 是 Stone 空间

对离散空间 X，L13 构造的 βX 是 Stone 空间。只需检查基本开集 φ(U) = {𝔘 ∈ βX : U ∈ 𝔘} 开闭。由素性，

βX − φ(U) = φ(X − U)

所以 φ(U) 的补仍是基本开集，开闭。

把 L06 接上：βX 的点就是 X 上的素滤子，也就是幂集布尔代数 𝓟(X) 的超滤子。于是 βX = Ult(𝓟(X))——L13 用「补点」造出来的对象，和 L06 用「取超滤子」造出来的对象，是同一个东西。这不是巧合，是本课程第三条融合线的样板。

例 6.2.10 Cantor 集与 Kuratowski 扇

Cantor 空间 2ω 嵌入 [0,1] 的像叫 Cantor 集 C，也可由「反复删去中间三分之一」得到。

在 I2 = [0,1] × [0,1] 中取 p = ⟨1/2, 1/2⟩，对每个 c ∈ C 令 L(c) 为从 (c,0) 到 p 的线段；若 c 是被删区间的端点，令 Xc = {(x,y) ∈ L(c) : y ∈ ℚ}，否则取 y ∉ ℚ 的部分。所有 Xc 之并配子空间拓扑，就是 Knaster–Kuratowski 扇 K。

可以证明（并不容易）K 连通；但 K − {p} 全不连通：任一连通子集必落在单条射线 L(c) 内，而每条射线留下的点其高度坐标全在 ℚ 或全在 ℝ − ℚ，这两者都全不连通。

译注：原稿用「没有连续道路」论证不连通，这在一般空间里不成立。可改用从 K − {p} 到 Cantor 集的连续射影 (x,y) ↦ (x−y)/(1−2y)：连通像只能是单点，从而把连通子集限制在单条射线上。原稿接着说「这个空间也不全分离」但那段没有写完，这里如实保留未完成状态。

典型例子

有限离散空间：它是有限布尔代数的 Stone 空间。n 个点的离散空间对 𝓟(n)。有限情形一切显然，用来校准直觉：每个点既是开闭基成员，也是超滤子。

本质例子

2ω：紧、无孤立点、零维。它的开闭柱集恰好对应「只提到有限多个坐标的命题」——这正是一阶逻辑语言有限性的拓扑影子。你只能检测有限初段，但紧致性保证有限检测足以决定整体。

βω 是另一个本质例子：它的点是非主超滤子，开闭基是 φ(U)。非主超滤子写不出具体例子，但它们在 βω − ω 里密密麻麻。

边界与误解

① ℚ 零维但不是 Stone 空间。它有开闭基（有理区间端点取无理数即可），但不紧致。零维只管基，不管紧致。

② Sierpiński 空间有开闭基吗？开集是 ∅, {1}, X，闭集是 ∅, {0}, X，开闭的只有 ∅, X。所以它不零维：点 1 的开邻域 {1} 里找不到含它的开闭集。这也从另一面说明它不是 Stone 空间。

③ 「全不连通」不等于「零维」。前者是关于连通子集的，后者是关于基的。紧 Hausdorff 下由引理 6.2.8 两者都等价于 Stone 空间；一般空间里两者不等价，别把定义换来换去。

来源：拓扑讲义 §6.2：定义 6.2.7、引理 6.2.8 及译注、例 6.2.9/6.2.10；L06 Stone 表示定理；L13 定义 5.3.8、引理 5.2.11、定理 5.3.1。

6孤立点、导集与散布 O4

定义 6.3.1 聚点与孤立点

设 A ⊆ X。若 x ∈ cl(A − {x})，称 x 为 A 的聚点。全体聚点组成导集 d(A)。若 x ∈ A − d(A)，称 x 为 A 的孤立点，全体记作 iso(A)。

这个定义在问什么：把 x 自己拿掉之后，x 还被 A 的其余部分逼近吗？如果还被逼近，它就是「簇里的一个点」；如果不被逼近，它就能被单独挑出来。

命题 6.3.2 两个判据

设 𝔅 是 X 的基。则：

(1) x 是 X 的孤立点 ⟺ {x} 开。
(2) x ∈ d(A) ⟺ 对每个基本开邻域 U ∋ x，(U − {x}) ∩ A ≠ ∅。

证明

(1) 若 x 孤立，则 x ∉ cl(X − {x})，故 cl(X − {x}) = X − {x}，这说明 X − {x} 闭，即 {x} 开。反向类似。

(2) 由 x ∈ cl(A − {x}) 及 L10 命题 2.4.6（闭包判据），任意基本邻域都与 A − {x} 相交；反向同样由该判据得到。∎

注意 (2) 里那个 − {x}。它把「自己撑自己」的情况排除了。这正是定义 6.3.1 的全部难点，其他都是常规的闭包翻译。

定义 6.3.3 散布与无孤立点

若每个非空子集 A ⊆ X 都含有在 A 中孤立的点，称 X 散布（scattered）。若 X 没有孤立点，称为 crowded（无孤立点）。

讲义列了三个用途：为 GL、GLP 等可证明性逻辑提供模型；与序数结构的序论性质紧密相连；为复杂序结构与拓扑结构提供骨架。「散布」和「无孤立点」是一对反义，不是一回事：ℝ 无孤立点但不散布（取 A = (0,1)，其中没有孤立点）。

命题 6.3.4（Brouwer 刻画）与译注 原稿有错，已修

原稿表述：Cantor 空间 2ω 是满足以下三条的唯一空间（相差同胚）：(1) Stone 空间；(2) 无孤立点；(3) 开闭基具有「任意两个非空开闭集同胚」的性质。

译注：这个刻画一般不成立

原稿缺了可数性限制。例如不可数的 Cantor 立方体 2κ（κ > ω）也满足那三条，却不同胚于 2ω；原稿连空开闭集也没有排除。

标准表述：非空、紧致、可度量、零维且无孤立点的空间，恰为 Cantor 空间（在同胚意义下）。这里的「可度量」把基数卡住了——度量 + 紧致 + 零维 + 无孤立点，强迫它的开闭基可数。

为什么要专门写这条：它是本讲少数几处「教材原文不能直接照抄」的地方。看到漂亮的唯一性刻画，先问基数限制在哪。这件事在 L18 讲「有限公理化」时还会重演：一个性质刻画得好不好，取决于你允许多大的语言。

余导集算子 信念的候补语义

与导集对偶，定义

τ(A) = X − d(X − A)

这里 τ 是算子记号，要和拓扑本身的记号按上下文区分。

命题 6.3.5：x ∈ τ(A) ⟺ 存在开集 U ∋ x，使 U − {x} ⊆ A。

证明

若有这样的 U，则 (U − {x}) ∩ (X − A) = ∅，由命题 6.3.2(2)，x ∉ d(X − A)，即 x ∈ τ(A)。反过来若 x ∉ d(X − A)，存在开邻域 U ∋ x 使这个交为空，即 U − {x} ⊆ A。∎

定义 6.3.6 DSO 空间

若 X 自密（dense-in-itself，即无孤立点），且对每个 A ⊆ X，d(A) 都开，称为 DSO 空间。

无限集上的余有限拓扑是一个例子：若 A 有限，d(A) = ∅（可选避开 A 中除所考察点外所有点的邻域）；若 A 无限，任意开邻域余有限，去掉一点后仍与 A 相交，所以 d(A) = X。导集都开，且无孤立点，故是 DSO 空间。

译注：这个动机不能理解成「DSO 条件消除了 T1 空间里的那公式」。上面的无限余有限空间本身就是 T1 的 DSO 空间，下一节要说的那条公式在其中照样成立。条件加强了，结论并不会自动消失。

典型例子

α(ω) = ω ∪ {∞}（L13 的闹钟空间）：每个 n ∈ ω 都是孤立点（{n} 开），∞ 不是。它是散布但不离散的：d(α(ω)) = {∞}，再导一次为空。

本质例子

ℚ：没有孤立点，导集 d(ℚ) = ℝ。导集可以比原集合大——这是初学者最容易懵的地方。因为闭包是在环境空间 ℝ 里取的。做导集运算时永远先问：在哪个空间里取闭包？

边界与误解

① 孤立点是相对概念。{1/2} 在 [0,1] 中不是孤立点，在 {0, 1/2, 1} 的子空间拓扑里是。说「孤立」必须带上所在空间。

② 散布 ⟹ 存在孤立点，但反向不成立。ℝ ∪ {额外一个孤立点} 有孤立点，却仍不散布（取 A = (0,1) 就没有孤立点）。

③ 超限导集不会一步到顶。习题 6.5 要求给出 d2(A) ≠ d(A) 和 dω+1(A) ≠ dω(A) 的例子。「导一次就没有新点」是很强的条件，序数结构正是用来铺陈出这个过程的关键工具。

来源：拓扑讲义 §6.3：定义 6.3.1/6.3.3/6.3.6、命题 6.3.2/6.3.4（含译注修正）/6.3.5、习题 6.5/6.6/6.7（TD 公理）；L10 命题 2.4.6（闭包判据）。

7极端不连通 O5

它解决什么问题

讲义在这里把内部算子读成模态算子：

x ⊩ □U  ⟺  x ∈ int(U)

「不仅 U 为真，而且能被验证」。再把 ◇U 读成 cl(U)：「所有知识都与 U 相容」。于是复合算子 cl(int(U)) 有了一个很具体的读法——强烈相信 U（Stalnaker 引入）：你相信 U，而且你的全部知识与「知道 U」相容。

现在问：「强烈相信」这件事本身能不能被知道？也就是要公式 ◇□p → □◇□p 成立。它在拓扑侧恰好是一个纯空间条件。

定义 6.3.7 极端不连通

若每个开集 U 的闭包 cl(U) 都开，称 X 极端不连通（extremally disconnected）。

译注：英文词根是 extremal 而不是 extreme，虽然这种不连通性确实相当「极端」。不要写成 Extremely disconnected。

等价写法：因为 U 开当且仅当 U = int(V) 对某个 V（取 V = U 即可），所以条件等价于

cl(int(V)) = int(cl(int(V)))   对所有 V ⊆ X

而这正是 ◇□p → □◇□p 的拓扑翻译。定义和信念公理是同一句话，只是换了语言。

命题 6.3.8 Hausdorff ⟹ 全不连通

Hausdorff 的极端不连通空间全不连通。

证明

若 x ≠ y，取不交开邻域 U ∋ x、V ∋ y。有 x ∈ cl(U)，但 y ∉ cl(U)——否则 V 作为 y 的邻域必与 U 相交，与不交矛盾。

由极端不连通性，cl(U) 开；它按定义又是闭的。于是 cl(U) 是开闭集，含 x 不含 y，空间全分离，进而全不连通。∎

Hausdorff 假设用在哪里：用来造不交开邻域，从而保证 y ∉ cl(U)。去掉它，结论会实质失败——见下面的余有限拓扑。

命题 6.3.9 βX 极端不连通

若 X 离散，则 βX 极端不连通。

证明

回顾其拓扑基 φ(U) = {𝔘 ∈ βX : U ∈ 𝔘}（U ⊆ X）。任意开集可写作 V = ⋃i ∈ I φ(Ui)。我们证明更强的等式：

⋃i ∈ I φ(Ui) = φ(⋃i ∈ I Ui)

左边 ⊆ 右边：由例 6.2.9，φ(Ui) ⊆ φ(⋃Ui)，且右边是闭集，故并仍在其中。

右边 ⊆ 左边：若 𝔘 不在左边，则存在基本邻域 φ(W) ∋ 𝔘 与每个 φ(Ui) 不交。这蕴含 W ∩ Ui = ∅：否则含 W ∩ Ui 的主滤子（或由素滤子定理得到的素滤子）会同时属于 φ(W) 与 φ(Ui)，矛盾。

若 𝔘 ∈ φ(⋃Ui)，则 W ∈ 𝔘 且 ⋃Ui ∈ 𝔘，由滤子对交封闭

W ∩ ⋃i Ui = ⋃i (W ∩ Ui) ∈ 𝔘

但这个集合为空，与滤子真性矛盾。所以 𝔘 也不在右边，等式成立。右边是基本开集，故任意开集的闭包（即右边）是开集。∎

这一手很漂亮：无穷并一般不保持闭性，但素滤子的「表态」性质让 βX 里的无穷并恰好等于一个基本开集。又一次：困难的部分不是计算，是找到正确的表示。

例 6.3.10 余有限拓扑：连通 + 极端不连通

无限集合 X 上的余有限拓扑连通：开闭集只能是 X, ∅（前面算过：余有限集无限，而闭集只能是有限集或全体）。它也极端不连通：每个非空开集的闭包都是 X，空集的闭包为空，都开。

这不与命题 6.3.8 矛盾，因为它不是 Hausdorff（任意两个非空开集必相交）。一个空间可以同时「连通」和「极端不连通」——只要分离性不够，这些词就会退化到失去直觉。这正是 §2 那条警告的极端版本。

讲义最后提到 Gleason 的定理：在紧致 Hausdorff 空间范畴中，投射对象恰为极端不连通的紧致 Hausdorff 空间。翻译成代数侧：它们对应完备布尔代数。L06 的 Stone 对偶在这里第二次出手。

典型例子

离散空间：每个开集 U 的闭包就是 U 自己，当然开。一切性质在离散空间里都平凡成立，所以离散空间只能校准定义，不能用来区分概念。

本质例子

βX：命题 6.3.9 说明它极端不连通，例 6.2.9 说明它是 Stone 空间。两个性质叠加，给出「完备布尔代数的 Stone 空间」——这是泛代数与拓扑交叉处最重要的对象之一（Gleason 定理的代数侧面）。

边界与误解

① 极端不连通 ⟹ 零维，但反之不成立。在 Hausdorff 情形下，命题 6.3.8 给全不连通，引理 6.2.8 给开闭基。清楚的反例是 ℚ：取有理数 q，令 U = ℚ ∩ ((q−1, q+1) − {q})。它在 ℚ 中开，而 clℚ(U) = ℚ ∩ [q−1, q+1]——端点 q+1 处任何邻域都跑出这个集合，所以它不开。ℚ 有开闭基却不极端不连通。顺带：2ω 也不是极端不连通（无穷可度量的紧极端不连通空间不存在），但反例没这么好写，别硬凑。

② 「极端」这个词不表示「比全不连通更强」在任意空间都成立。余有限拓扑就是反例：它极端不连通且连通。所有这类蕴含定理都要检查 Hausdorff 假设。

③ 闭包的闭包没有新东西，但开集的闭包可以很不一样。cl(cl(U)) = cl(U) 是 Kuratowski 公理（L10），而 cl(U) 开不开是额外性质，两者不要混。

来源：拓扑讲义 §6.3：定义 6.3.7 及译注、命题 6.3.8/6.3.9/6.3.10、Gleason 定理的预告；L10 Kuratowski 公理、L13 定义 5.3.8、L06 Stone 对偶。

8逻辑接口：□、τ 与强信念 O6

翻译词典（本讲新增三行）
拓扑模态/认识论读法一句话
int(U)□U被蕴含的最一般的可验证命题
cl(U)◇U所有知识与 U 相容
d(A)「所有可验证事实都与 A 相容」导集=无法排除 A

T1 空间的麻烦

讲义在这里给了一个很不客气的观察。在 T1 空间中，对任意点 x，X − {x} 是开集，而且

d({x}) = ∅,   τ(X − {x}) = X

按上面的读法：在每个世界都必须相信「实际世界并非如此」。这很不理想——认知主体不该被迫否认现实。

由此引出 DSO 空间（定义 6.3.6）等更精细的条件。但译注提醒：不要以为 DSO 消掉了这条公式：无限集上的余有限拓扑本身就是 T1 的 DSO 空间，公式照样成立。修条件不等于修结论。

信念公理与 S4.2 两个公式，一个空间条件

讲义用 ◇□p → □◇□p 来引出极端不连通。它和 S4.2 的那条新公理关系很近——近到在此语义下其实是同一条。这里把账算清。

Geach 公理 .2

◇□p → □◇p，拓扑翻译为

cl(int(A)) ⊆ int(cl(A))

这是 S4.2 = S4 + .2 的那条新公理。Kripke 语义里它对应框架的有向性（两条从同一点出发的路最终能汇合）。

讲义的强信念自反思

◇□p → □◇□p，拓扑翻译为

cl(int(A)) ⊆ int(cl(int(A)))

也就是 cl(int(A)) 是开集——定义 6.3.7。

关键事实：在拓扑语义下两者等价。

(.2 ⟹ 极端不连通) 取任意开集 U，令 p 的解释就是 U。此时 int(U) = U，.2 读作 cl(U) ⊆ int(cl(U))，即 cl(U) 开。U 任意，所以空间极端不连通。

(极端不连通 ⟹ .2) 对任意 A，int(A) 开，故 cl(int(A)) 开；又 cl(int(A)) ⊆ cl(A)，而一个开集包含于 cl(A) 就必然包含于 int(cl(A))。于是 cl(int(A)) ⊆ int(cl(A))。

讲义那条公式在模态证明层面也是 .2 的推论：由 4 公理 □p → □□p 与 ◇ 的单调性得 ◇□p → ◇□□p；再把 .2 用于 q = □p 得 ◇□□p → □◇□p。串起来就是它。所以在 S4.2 里两条可互证。

因此讲义 Ch7「极端不连通空间与 S4.2 密切相关」说得准：在这个语义下，极端不连通正是 S4.2 的空间对应物；Kripke 那边的「有向性」是同一件事长在另一种框架上的形状。完整的框架对应与完全性证明留给 L25。

典型例子

在 α(ω) 上取 A = ω：int(A) = ω，cl(ω) = α(ω)，所以 ◇□A = α(ω)，□◇□A = int(α(ω)) = α(ω)。公式成立，而且两边都是全体——主超滤子式的平凡情形。

本质例子

βω：由命题 6.3.9 极端不连通，所以对所有 A 都有 ◇□A → □◇□A。而且这里有无穷多个非主超滤子，「强烈相信」不是空话：不同超滤子对同一个 A 可以给出不同的信念状态。

边界与误解

① 两条公式写法不同，但在拓扑语义下等价——上面刚证过。真正的坑是换个语义就拆开：Kripke 框架里 .2 对应有向性，强信念公式要靠 4 公理搭桥；「等价」是在特定语义下的结论，不是符号层面的同一。

② 「信念」在这里不是主观心理。它是空间点 x 与开集族之间的一种关系。把拓扑语义和心理状态直接画等号，是这个领域最常见的过度解读。

③ 讲义第 7 章只有短预告，没有定理。本讲借它收束，不冒充已经证明 S4.2 的完全性——那是 L25 的工作。

几何学家想要连通，逻辑学家想要全分离。但两者用的是同一套开集，差别只在「你允不允许正反判定」。这正是全课反复出现的那个母题：数学结构不是被「发现」的，是被你的可观察能力切出来的。

从这里往后，拓扑退出主线，代数化正式开始（L15）。但 L06 的 Stone 表示、L13 的紧致化、本讲的谱系会在 L18、L23、L25 三次回来。你现在看懂了「开闭集」，后面才看得懂「同态」。
