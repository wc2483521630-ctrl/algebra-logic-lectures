L15 把逻辑削成了四元组，但那只是接口。这一讲要问一个更要命的问题：一个逻辑的「代数影子」到底是什么？影子不能随便取——取出来得好用，得让逻辑的性质能在代数这边读到。整讲就是把这个「好用」说清楚。

2动机：影子里该留下什么

它解决什么问题

上一讲结束时我们有一个四元组 L = ⟨F, M, mng, ⊨⟩。它规整，但还不动。现在要做的事是把一个逻辑送进泛代数：给它配一个类 Alg(L)，让逻辑学家问的问题，能翻译成代数家已经在问的问题。

难处立刻来了。一个逻辑有无数个模型，每个模型都吐出一个代数 mngM(F)。要谈「这个逻辑的代数」，必须把它们拢成一个类。怎么拢？

UAL 给了两条路，而且两条都自然：

  • 从模型拢。每个模型 M 能表达哪些概念？把 mngM 的像收下来，得 Algᵐ(L)。这是「一个世界里的概念图」。
  • 从理论拢。一批模型 K 共同承认哪些概念？把公式按在 K 上意义相同归类，取商得 F/∼K。把所有 K 的商收下来，得 Alg⊨(L)。这是「一批世界的共同语言」。

定理 3.3.5 说：这两条路只差一个 SP（取子代数、取积）。于是它们在等式和准等式上完全一致。这件事是整讲的合法性来源——「代数对应物」不是一个随便的约定，而是被定理挑出来的。

有了影子，下一步是挑毛病。一个影子「好用」是什么意思？UAL 挑出三把钥匙：

  • 代入性质：原子公式是真正自由的变量吗？把 p 换成任意公式，模型能不能跟着变形？代数这边说：意义同态类对复合封闭。
  • 条件代入：一阶逻辑里 r(x) 换成 s(x,y) 会炸（一元变二元）。但只要替换不撞类型就能活。代数这边说：取带定义关系的自由代数。
  • 滤子性质：「意义相等」和「公式有效」能互译吗？代数这边说：后承 ⟺ 准等式。这正是 L18–L20 三座桥的词汇准备。

最后，把原子公式集 P 抽成参数，就得到一般逻辑。它不是又一个定义，而是让上面三把钥匙能跨语言使用——否则换一套命题字母，前面的结论就得重证一遍。

              逻辑 L = ⟨F, M, mng, ⊨⟩
                          │
              组合性：mng_M 是同态
                          │
        ┌─────────────────┴─────────────────┐
        │                                   │
  从模型取影                            从理论取影
  Algᵐ(L) = {mng_M(F)}              Alg⊨(L) = I{F/∼K}
        │                                   │
        └──────── 定理 3.3.5 ────────────────┘
           Algᵐ ⊆ Alg⊨ ⊆ SP Algᵐ
           等式、准等式理论相同
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
   代入性质           条件代入           滤子性质
  P 是否自由      带定义关系也自由    意义相等 ⟺ 有效
  Mng = Hom(F,K)  Fr(K,P,∼L)          后承 ⟺ 准等式
        │                 │                 │
        └──────── 一般逻辑（P 作参数） ───────┘

3连接词、公式代数与组合性 O1

它解决什么问题

上一讲把公式集 F 当成一堆字符串。但代数机器不吃字符串，吃的是带运算的集合。要把 F 变成代数，得先指认：哪些符号是运算？哪些是变量？

答案很自然：连接词是运算，原子公式是变量。于是 F 就是项代数 F(P,Cn)，而且是绝对自由的——任意给一个同型代数 A 和一张赋值 P → A，都唯一延成同态。这个「唯一延成同态」就是后面代入性质的全部本钱。

定义 3.3.1 L 有逻辑连接词

说 L 有逻辑连接词 ⟨Cn, P⟩，若：

(i) 固定一个连接词集 Cn(L)，每个 c 有有限元数 rank(c) ∈ ω；k 元连接词全体记作 Cnk(L)。

(ii) 有与 Cn 不交的集合 P（原子公式 / 命题字母 / 参数），使 F 是满足 P ⊆ F 且「c ∈ Cnk, φ1,…,φk ∈ F ⟹ c(φ1,…,φk) ∈ F」的最小集合。

用泛代数的说法：F 是由 P 生成、以连接词为运算的项代数，即绝对自由代数 F(P,Cn) = ⟨F(P,Cn), c⟩c∈Cn。

一个不能省掉的记号

单写 F 恢复不出 P 与 Cn。同一堆公式可以拆出不同的「变量 / 运算」。一阶语句逻辑（例 3.2.30）里 ¬, ∧, ∃v 都不是连接词；但它仍可把 ¬, ∧ 当连接词，只要把 P 取成任意一个包含所有以存在量词开头的公式的集合。所以必须写 F(P,Cn)，不能只写 F。这不是挑剔：L17 谈「两个逻辑是否等价」时，正是这个歧义制造麻烦。

定义 3.3.2 组合性（弗雷格原则）

L 组合，若它有逻辑连接词，且对每个 k 元连接词 c、每个 M ∈ M：

⋀i=1k mng(φi, M) = mng(ψi, M)  ⟹  mng(c(φ1,…,φk), M) = mng(c(ψ1,…,ψk), M)

把 mngM(φ) = mng(φ,M) 记作一个函数 F → 某集合，上式说的正是若分量相等则复合相等，也就是

ker(mngM) 是 F(P,Cn) 上的同余  ⟺  mngM : F(P,Cn) → mngM(F) 是同态

这是本讲第一处关键翻译：「整体意义由部分意义决定」这句认识论的话，在泛代数里就叫「核是同余」。

重言式同余与 Lindenbaum–Tarski 代数

定义 φ ∼L ψ ⟺ 对所有 M ∈ M 有 mngM(φ) = mngM(ψ)：在所有模型里意义相同。组合性保证 ∼L 是同余，于是可以取商

F(L) = F/∼L

称为 L 的重言式公式代数，也就是 Lindenbaum–Tarski 代数。它是「这个逻辑能表达的全部概念」的结构。

典型 · 命题逻辑

令 P 是命题字母，Cn = {¬, ∧}（∨, → 作缩写）。F(P,Cn) 是绝对自由布尔代数状的项代数；∼L 是逻辑等价，F/∼L 是自由布尔代数。这是 L06 已经见过的老朋友。

本质 · 一阶开公式：量词必须成为算子

若只取语句，LT 代数是布尔代数，但未必自由；Rasiowa–Sikorski 做法是再要求某些特殊上确界存在，用来表示存在量词的意义。真正的组合性要求把开公式也收进来：让 ∃v 成为运算，mngM(∃v φ) 由 mngM(φ) 算出。此时 LT 代数是 BAO（L06），确切地说是自由维数限制柱形代数。这就是 L06 那句「量词是模态算子」的正式出处。

边界 · 概念代体会忘掉「哪些是原始的」

① 等式逻辑、准等式逻辑没有这里的连接词：它们是一阶逻辑的片段，公式由项与等号构成，不是从 P 用连接词生成的。

② UAL 脚注 8 给了一个很好的「布尔运算管不着」例子：若 c 是常元、R 是一元关系，则 R(c)/∼L ≤ ∃xR(x)/∼L，但这个序关系不是任何布尔运算造出来的——它是量词带来的。只看布尔结构会丢掉它。

③ mngM(F) 与 F/∼L 都叫「L 可表达概念的结构」，但它们都忘记了哪些概念是原始给的、哪些是复合出来的。要找回这点信息，得在 mngM(F) 上加常元去钉住原子公式的意义。

4两种代数对应物 O2

定义 3.3.3 从模型取影，从理论取影

设 L 组合。

(i) 对 K ⊆ M，定义 φ ∼K ψ ⟺ 对所有 M ∈ K, mngM(φ) = mngM(ψ)。由组合性这是同余。F/∼K 叫 K 的 LT 代数。令

Alg⊨(L) = I{F/∼K : K ⊆ M}

(ii) 令

Algm(L) = {mngM(F) : M ∈ M}

其中 mngM(F) 是同态像——含它且使 mngM 落到其中的最小子代数。

两个影子各是什么意思

mngM(F) 是一个世界里可表达的概念：每个公式在这个世界里切成一片东西，这些片组成的代数。

F/∼K 是一批世界的共同语言：两个公式若在 K 的每个模型里意义都相同，就合并。K 越大，合并越多，商越小。

一个从下往上（模型给概念），一个从上往下（理论做识别）。它们居然只差 SP，这是定理。

定理 3.3.5 Algᵐ 与 Alg⊨ 的距离

若 L 组合，则

(i)  Algm(L) ⊆ Alg⊨(L) ⊆ SP Algm(L)
(ii)  SP Alg⊨(L) = SP Algm(L)
证明

第一个包含。取 A = mngM(F) ∈ Algm(L)。令 K = {M}，则 ∼K = ker(mngM)，故 A = F/∼K ∈ Alg⊨(L)（后者对同构封闭）。

第二个包含。取 A ∈ Alg⊨(L)，即 A ≅ F/∼K。这里必须先把 K 缩进一个集合 K′ ⊆ K：因为 F 是集合，商 F/∼K 只用到 F 中有限多对公式的相等关系，取 K′ 足够大即可使 ∼K′ = ∼K（练习 3.3.6 问的正是为什么不能是真类——真类上取不了积）。

于是设 K 是集合。定义

h : F/∼K → ∏M∈K mngM(F),    h(φ/∼K) = ⟨mngM(φ) : M ∈ K⟩

良定义（若 φ ∼K ψ 则每个分量相等）；按分量逐点运算，h 是同态；若 h(φ/∼K) = h(ψ/∼K)，则每个 M ∈ K 上相等，即 φ ∼K ψ，所以 h 是单射。故 F/∼K ∈ SP Algm(L)。

(ii)。SP 是闭包算子：单调 + 幂等。由 (i) 的包含和单调性得 SP Algm ⊆ SP Alg⊨；由 (i) 的第二个包含和幂等性得反向。

推论 3.3.7 两个影子说同一套等式语言

Alg⊨(L) 与 Algm(L) 有相同的等式理论与准等式理论。因为 SP 不改变这两者（定理 2.4.11/2.4.12）。

这就是「代数对应物」这个说法的底气：不管你从哪条路取影，代数家拿等式和准等式能问的问题，答案一模一样。

Remark 3.3.4：故意不对同构封闭

Algm(L) 不是抽象类，不对同构封闭。这是刻意的：它的成员是「模型的概念代数」，是具体代数；换成同构副本会丢掉语义-模型论信息，尤其在可定义性理论里（L20 的 Beth 性质正需要这一点）。

对比：Alg⊨(L) 按定义带 I，对同构封闭。一个是具体对象，一个是抽象类型，各司其职。

典型 · 经典命题逻辑的影子

Algm(LS) 是布尔集合代数的子类；Alg⊨(LS) 是它的 SP 闭包，即所有布尔代数（练习 3.3.35(4) 要你验证等号成立）。影子认出了熟悉的代数类。

本质 · 定理 3.3.5 的嵌入在做什么

h(φ/∼K) = ⟨mngM(φ)⟩ 是把「公式」变成「它在每个世界里的值」的坐标化。这正是 Stone 表示（L06）和 Jónsson–Tarski 表示（L07）的装置：一个抽象元素被它在一族具体结构上的行为完全确定。单射性就是「共同语言不丢信息」。

边界 · 两个容易踩的坑

① Algm(L) 里没有「同构副本」这一说。若两个不同模型给出同构但不同的概念代数，Algm 把它们当作两个成员。在可定义性里这正是信息。

② 影子里「原始 vs 复合」被抹掉了。mngM(F) 只知道 p∧q 的像是 p 的像与 q 的像之交，不记得 p 曾是字母。要记得，得给概念代数加常元钉住原子公式。

5语义代入与句法代入 O3

它解决什么问题

在命题逻辑里，p 代表任意公式。我们天天用这条：重言式 p ∨ ¬p 里的 p 换成任何公式，结果还是重言式。这件事太自然，自然到没人问它是不是一条需要单独假设的性质。

一问就出问题。一阶逻辑里 r(x) 是一元关系，换成 s(x,y) 变成二元——语言的类型被撞坏了。所以「变元自由」不是天经地义，而是逻辑的一条结构性质。UAL 给出两个版本：

  • 句法版：有效式在替换后仍有效（只管 ⊨）。
  • 语义版：替换公式的同时，模型能跟着变出一个「代入后的模型」（管 mng）。

语义版强得多，而它的代数翻译漂亮得出奇：意义同态类恰好是全体从公式代数出发的同态。

定义 3.3.9 句法代入性质

若对任意 p0,…,pk ∈ P 与 ψ, φ0,…,φk ∈ F：

⊨L ψ(p)  ⟹  ⊨L ψ(p/φ)

其中 ψ(p/φ) 是同时把每个 pi 的所有出现换成 φi。

定义 3.3.10 语义代入性质，式 (3.3)

若对任意 s : P → F、任意 M ∈ M，存在 N ∈ M 使对任意公式 φ：

mngN(φ) = mngM(φ(p0/s(p0), …, pk/s(pk)))

N 叫 M 沿 s 的代入版本。由于 F 是自由的，s 唯一延成 ŝ : F → F，上式就是 mngN = mngM ∘ ŝ。

UAL 还给出两个等价写法，一个比一个干净：

(∀h ∈ Hom(F,F))(∀M ∈ M)(∃N ∈ M)  mngN = mngM ∘ h
(∀M ∈ M)(∀h ∈ Hom(F, mngM(F)))(∃N ∈ M)  mngN = h

记 MngL = {mngM : M ∈ M}，即所有意义同态组成的类。

命题 3.3.11 语义代入的代数刻画

设 L 组合。则以下等价：

(i)  L 有语义代入性质
(ii)  MngL = Hom(F, Algm(L))
(iii)  MngL = Hom(F, K)，对某个代数类 K
证明要点

(i) ⟹ (ii)。⊆ 显然：mngM : F → mngM(F) ∈ Algm(L)。

⊇ 是这证明的心脏。取任意 h : F → mngM(F)。对每个 p ∈ P，因 h(p) ∈ mngM(F)，可取 φp ∈ F 使 h(p) = mngM(φp)（这里用的是「像中的元素必有原像」）。令 s(p) = φp。语义代入给出 N 使 mngN = mngM ∘ ŝ。于是对生成元 p：

mngN(p) = mngM(s(p)) = h(p)

两同态在 P 上相同，而 F 由 P 生成，故 h = mngN。

(iii) ⟹ (i)。取 s : P → F 与 M。由 (iii) 得 mngM : F → A ∈ K；复合 mngM ∘ ŝ : F → A 仍在 K，故由 (iii) 它是某个 mngN。「代入后还是意义同态」——这就是代数说法。(ii) ⟹ (iii) 显然。

推论 3.3.12 自由性的红利

若 L 有语义代入性质，则

F(L) = F/∼L = Fr(Algm(L), P)

即重言式公式代数是 Algm(L) 上由 P 生成的自由代数（定义 2.5.3）。L05 的自由代数机器在这里领到第一笔工资。

典型 · 命题逻辑：换字母天经地义

取 s(p) = p ∧ q，M 是一个赋值。想让 N 满足「p 在 N 里的意义 = p∧q 在 M 里的意义」，只需令 N 是把 p 改判成 M ⊨ p∧q 的赋值。模型总能跟着变。

本质 · MngL = Hom(F, Algᵐ(L)) 在说什么

它说的是：「换掉原子公式」这件事，在代数这边就是「把自由代数的生成元送到任意元素」。生成元的自由性保证有唯一同态；语义代入性质保证这个同态还能落回本逻辑的模型里。少了后半句，只有代数同态，没有对应模型。

边界 · 一阶逻辑两条都不满足

句法失败：取一元 r、二元 s，⊨ ∃y r(x) 成立（只要有个对象满足 r），但把 r(x) 换成 s(x,y) 后 ⊨ ∃y s(x,y) 不成立（并非每个对象都关系到一个对象）。

语义失败：取 s(r(x)) = s(x,y)，M 里 s 的解释是真正的二元关系。若 N 存在，r(x) 在 N 里的意义必须等于 s(x,y) 在 M 里的意义——前者是一元关系的集合，后者是二元关系的集合，根本不是同一类东西。

UAL 练习 3.3.22 还问反方向：找一个有句法代入但没有语义代入的逻辑。存在，这说明两条确实不等价。

6条件代入：一阶逻辑怎么活下来 O4

它解决什么问题

一阶逻辑连条件代入都没有？那也太苛刻了——我们明明天天在做替换，只是不撞类型的替换。∃y r(x) 与 r(x) 之间有 ∼L 关系，替换必须尊重它。

UAL 的办法：把「任意替换」 weakened 成「尊重逻辑自身恒等关系的替换」。只加一个前提 ∼L ⊆ ker(mngM ∘ ŝ)，一阶逻辑就进来了。代数上的回报是：自由代数变成「带定义关系的自由代数」——L05 的第二件工具。

定义 3.3.14 条件（弱）语义代入，式 (3.4)

若对任意 s : P → F：

(∀M ∈ M)  [ ∼L ⊆ ker(mngM ∘ ŝ)  ⟹  (∃N ∈ M) mngN = mngM ∘ ŝ ]

读作：只要这个替换没有把逻辑认为「永远同义」的两条公式拆成不同意义，就存在代入后的模型。∼L 在这里扮演约束条件。

命题 3.3.15 条件代入的代数刻画

设 L 组合。则以下等价：

(i)  L 有条件语义代入性质
(ii)  MngL = {h ∈ Hom(F, Algm(L)) : ∼L ⊆ ker(h)}
(iii)  MngL = {h ∈ Hom(F, K) : S ⊆ ker(h)}，对某代数类 K 与某关系 S ⊆ F×F
与命题 3.3.11 的差别

证明几乎照抄，只多一件事：要检查 ∼L ⊆ ker(h) 这个前提能被带上带下。

(i) ⟹ (ii) 的 ⊇。取 h : F → mngM(F) 且 ∼L ⊆ ker(h)。照旧逐生成元取 φp 使 h(p) = mngM(φp)，令 s(p) = φp。此时 mngM ∘ s = h，所以前提 ∼L ⊆ ker(mngM ∘ ŝ) 自动满足；条件代入给出 N，再用在 P 上相等推出 h = mngN。

(iii) ⟹ (i)。设 ∼L ⊆ ker(mngM ∘ ŝ)。关键一步：由 S ⊆ ⋂{ker(mngM) : M ∈ M} = ∼L 得 S ⊆ ker(mngM ∘ ŝ)，于是 h := mngM ∘ ŝ 满足 (iii) 的条件，故是某个 mngN。

推论 3.3.16 带定义关系的自由代数

若 L 有条件语义代入性质，则

F/∼L = Fr(Algm(L), P, ∼L)

即在 Algm(L) 上由 P 生成、以 ∼L 为定义关系的自由代数（定义 2.5.10）。L05 的「自由代数 + 定义关系」在这里领到第二笔工资。

典型 · 一阶逻辑的条件代入

令 S = {⟨∃y r(x), r(x)⟩ : x ≠ y} ∪ {⟨r(x), ∃y (x=y ∧ r(y))⟩}。这些是逻辑自身承认的恒等关系。只要替换不破坏它们，MngL 里就还有对应的同态（UAL 练习 3.3.17）。

本质 · ∼L 从障碍变成数据

在完全代入里，∼L 只是商掉的东西；在条件代入里它升格为定义关系，被写进自由代数的构造。「哪些替换被禁止」这件事本身成了代数结构的一部分。这也是 L05 为什么提前讲了 Fr(K, P, R)。

边界 · 等号该放哪儿，决定生死

UAL 练习 3.3.17(4) 给了一个极好的反例。设语言只有二元关系 R，令替换 s 送 x=y ↦ R(x,y)、R(x,y) ↦ R(x,y)，取 M 使 RM 是等价关系。则 ∼L ⊆ ker(mngM ∘ ŝ) 成立，但代入版本不是该逻辑的模型——于是条件代入失败。

修法很轻：把 x=y 当零元逻辑连接词，而不是原子公式。一个符号放在 P 里还是 Cn 里，会决定一条结构性质成立与否。这也回扣了定义 3.3.1 那个「必须写 F(P,Cn)」的告诫。

7滤子性质：两套语言之间的翻译协议 O5

它解决什么问题

代数家说「这两个元素相等」，逻辑学家说「这个公式有效」。两句话能不能互译？在经典命题逻辑里能：

(a)  mngM(φ) = mngM(ψ)  ⟺  M ⊨ φ ↔ ψ
(b)  M ⊨ φ  ⟺  mngM(φ) = mngM(⊤)

有了这两条，逻辑的问题就能写成代数的问题。但有些逻辑没有 ↔ 或 ⊤，怎么办？UAL 问：能不能用一组导出连接词代替这一对？答案是滤子性质。

注意：这是 UAL 定义的「滤子性质」（filter property），和 L12 辨析过的拓扑滤子不是同一个东西——它说的是「意义相等」与「公式有效」之间的可翻译性，名字来自「用等式集合定义理论滤子」这个用法。

定义 3.3.18 滤子性质

存在一元导出连接词 ε0,…,εm−1、δ0,…,δm−1 与二元导出连接词 ∆0,…,∆n−1，使：

(i) 对任意 M ∈ M、φ, ψ ∈ F：

mngM(φ) = mngM(ψ)  ⟺  (∀i < n)  M ⊨L φ ∆i ψ

(ii) 对任意 M ∈ M、φ ∈ F：

M ⊨L φ  ⟺  (∀j < m)  mngM(εj(φ)) = mngM(δj(φ))

取 m = n = 1、∆0 = ↔、ε0(φ) = ⊤、δ0(φ) = φ，就得到 (a)(b)。注意 (a)+(b) 合起来比滤子性质更强：滤子性质只要求「有效 ⟹ 某组等式」和「相等 ⟹ 某组公式有效」，不要求 ⊤ 与 ↔ 真存在。

Fact 3.3.20 滤子性质的两个直接后果

设 L 组合。

(i) 若满足条件 (i)，则

Alg⊨(L) = I{F/∼ModL(Γ) : Γ ⊆ F}

即影子只需由理论（而非任意模型类）给出。证明要点：对任意 K ⊆ M，由 (i) 得 ∼K = ∼Mod(T h(K))。

(ii) 若满足条件 (ii)，则对所有 M ∈ M、Σ ⊆ F：

M ⊨L Σ  ⟺  ker(mngM) ⊇ ∼Mod(Σ)

证明：对 φ ∈ Σ 记 S(φ) = {⟨εj(φ), δj(φ)⟩ : j < m}，则 S(φ) ⊆ ∼Mod(Σ)，而条件 (ii) 把 M ⊨ φ 翻译成 S(φ) ⊆ ker(mngM)。

(ii) 是本讲最有用的单独一行：「模型满足理论」被写成「模型的同余比理论的同余更粗」。这是 L20 可定义性定理的雏形。

命题 3.3.21 语义代入 + 滤子性质 ⟹ 句法代入

设 L 组合、有滤子性质、有语义代入性质，则它有句法代入性质。

证明：一个四行链条

取 ⊨L φ 与替换 s，任取 M ∈ M。语义代入给出 N 使 mngN = mngM ∘ ŝ。于是

N ⊨ φ  ⇒  (∀j<m) mngN(εj(φ)) = mngN(δj(φ))
 ⇒  (∀j<m) mngM(ŝ(εj(φ))) = mngM(ŝ(δj(φ)))
 ⇒  (∀j<m) mngM(εj(ŝ(φ))) = mngM(δj(ŝ(φ)))  ⇒  M ⊨ ŝ(φ)

第三行用 ŝ 是同态（式 (3.2) 的组合性在此出手），首尾两行用滤子性质 (ii)。三个抽象性质各出一手，拼成一条熟悉结论。

定理 3.3.23 桥：后承 ⟺ 准等式

设 L 组合、有滤子性质、语义代入。则：

(i) 对任意公式 φ0,…,φk：

{φ1,…,φk} ⊨L φ0  ⟺  对每个 j<m， Algm(L) ⊨ ⋀1⩽s⩽k, i<m(εi(φs)=δi(φs)) → (εj(φ0)=δj(φ0))

(ii) 对任意准等式 q = (τ1=τ′1 ∧ … ∧ τk=τ′k) → τ0=τ′0，对每个 i < n：

Algm(L) ⊨ q  ⟺  {τs ∆j τ′s : 1⩽s⩽k, j<n} ⊨L τ0 ∆i τ′0
证明 (i) 的 ⟹ 方向（本讲最长的一条链）

设前提成立，取任意 A ∈ Algm(L)，即 A = mngM(F)。任取赋值 a : P → A。设 p0,…,pℓ 是出现的所有原子公式，记 ai = a(pi) ∈ mngM(F)。由于 ai 是同态像中的元素，可取 γi ∈ F 使 ai = mngM(γi)。

组合性在此把「代数里的计算」还原成「公式里的替换」：

φ[a0,…,aℓ]A = mngM(φ(γ0,…,γℓ))

若 A ⊨ εj(φs) = δj(φs)[a] 对所有 s,j 成立，即是说 mngM(εj(φs(γ))) = mngM(δj(φs(γ)))。此刻语义代入出手：对 s 送 pi ↦ γi，存在 N 使 mngN(ψ) = mngM(ψ(γ))。于是

N ⊨ φs (All s)  ⇒  N ⊨ φ0  ⇒  mngM(εj(φ0(γ))) = mngM(δj(φ0(γ)))

第一步用后承假设，后两步用滤子性质。a 任意，得证。

⟸ 方向短得多：若 M ⊨ φs 对所有 s，滤子性质 (ii) 给 mngM(εi(φs)) = mngM(δi(φs))；把 A = mngM(F) 与由 p ↦ mngM(p) 给的赋值 a 代进准等式，得 M ⊨ φ0。这一段不需要语义代入。

(ii) 的证明同构：⟹ 方向把 M ⊨ τs ∆j τ′s 经滤子性质 (i) 变成等式，再用 A ⊨ q；⟸ 方向反走，中间同样靠语义代入把 A 中的赋值还原成 M 中的公式替换。

Remark 3.3.24：三个方向的前提并不对称

别把定理 3.3.23 当铁板一块。UAL 特意指出：

  • 证 (i) 的 ⟸ 只需组合性 + 滤子性质；
  • 证 (ii) 的 ⟹ 只需组合性 + 滤子性质的条件 (i)；
  • 存在满足条件 (i) 的组合逻辑，使 (ii) 的 ⟸ 失败。所以条件 (ii) 不是多余的。
推论 3.3.25 有效式 ⟺ 等式

若 L 组合、有滤子性质、有句法代入性质，则

⊨L φ  ⟺  Algm(L) ⊨ εj(φ) = δj(φ)  (∀j<m)
Algm(L) ⊨ τ = τ′  ⟺  ⊨L τ ∆i τ′  (∀i<n)

证法与定理 3.3.23 对应，只是把语义代入换成句法代入：⊨ φ(p) 经句法代入得 ⊨ φ(γ)，再交给滤子性质。

典型 · 经典命题逻辑的 (a)(b)

∆0 = ↔，ε0 = ⊤，δ0 = id。于是「两个公式在所有模型同义」⟺「它们是重言等价的」，「公式有效」⟺「它的意义等于 ⊤」。这是 L06 布尔代数的老结论。

本质 · 定理 3.3.23 是三座桥的词汇表

它把 Σ ⊨ φ（逻辑）与 Algm(L) ⊨ q（代数准等式）等同。L19 的有限公理化、L20 的可定义性、L18 的紧致性，用的都是这本词典。没有滤子性质，「代数化」就只能停在「取个影子」，做不到「翻译问题」。

边界 · 两个必须记住的限制

① UAL 练习 3.3.19(2) 给的条件 (3.5)：(⊨ φ 且 ⊨ ψ) ⟹ (∀M) mngM(φ) = mngM(ψ)，由 (a)+(b) 可得，但一般滤子性质推不出。⊤ 不存在时，「都有效」不意味着「意义相等」。

② 此滤子非彼滤子。L12 辨析过 UAL 定义 3.3.18 的 filter property 与拓扑滤子同名非同物；真正与拓扑滤子对应的是 UAL 的生成滤子（定义 2.2.62）。本讲的「滤子性质」既不是集合族的上闭交封闭，也不是素滤子。

8一般逻辑：把原子公式集变成参数 O6

它解决什么问题

§3.2 里每个逻辑都带一个参数 P：换一批命题字母，得到的是一个新逻辑。命题逻辑的 LS 其实是一族逻辑。那前面那些性质（代入、滤子、影子）是对某个 P 成立，还是对整族成立？

一般逻辑把这一族打包成一个对象 L = ⟨LP : P ∈ Sig⟩，并规定各成员之间必须足够「像」。目的很实际：让替换性刻画对整族一次成立，而不是每个 P 重证一遍。

定义 3.3.26 / 3.3.27 子逻辑、同构副本、一般逻辑

子逻辑：LP 是 LQ 的子逻辑，若 P ⊆ Q 且 {mngMP} = {(mngMQ)↾FP : M ∈ MQ}。换更大的字母表，旧的模型在旧公式上的表现必须原样保留。

同构副本：由双射 f : P → Q 诱导出公式与模型两个双射，且 mng 与 ⊨ 全部保持。

一般逻辑是类 L = ⟨LP : P ∈ Sig⟩，每个 LP 是组合逻辑，并满足七条件：

条件内容直观
(1)P 是 LP 的原子公式集参数名副其实
(2)Cn(LP) = Cn(LQ) = Cn(L)连接词跨字母表不变
(3)能延成重言式代数双射的 f : P → Q 诱导出逻辑同构字母表改名不改变逻辑
(4)P ⊆ Q ⟹ LP 是 LQ 的子逻辑加字母不破坏旧语言
(5)任意 P 与集合 H，存在与 H 不交的 P′ ∈ Sig，LP′ 是同构副本总能找到「全新」的字母表
(6)两两不交的 Pi 的并仍在 Sig，且在 Fr(Algm(LP), P) 中重言同余由各 ∼i 生成可拼接、可放大
(7)Sig 含至少一个非空集不是空族

一般逻辑有滤子性质，指每个 LP 都有，且那组特殊连接词 εj, δj, ∆i 对所有 P 是同一组。

Remark 3.3.28–3.3.30：三条容易被略过的推论

(1) Sig 里有任意大的集合。由 (5) 递归造出两两不交的 Pi，再由 (6) 取并。「总能换到足够多新字母」是定理，不是默契。

(2) 一般逻辑若有滤子性质，连接词里必须有常值连接词（Remark 3.3.29）。因为 P 与 P′ 不交，而那组 ε, δ, ∆ 对所有 P 相同——它们只能是空字母表上的公式，即由常值连接词造成。

(3) 有约化函数（Remark 3.3.30）：对 P ⊆ Q，存在满射 r : MQ → MP，使 N ⊨Q φ ⟺ r(N) ⊨P φ 且 mngNQ(φ) = mngr(N)P(φ)。大字母表的模型可以「忘掉」多余字母，回到小字母表。

定义 3.3.31 / 3.3.34 一般逻辑的影子与具体例子
Alg⊨(L) = ⋃P∈Sig Alg⊨(LP),    Algm(L) = ⋃P∈Sig Algm(LP)

具体逻辑的一般逻辑版本（定义 3.3.34）：经典命题逻辑 LS 取 SigS 为所有与 {¬,∧} 不交的集合；一阶逻辑 LFOL 取 SigFOL = {Pt(V) : t 是关系型}；再限制 |V| = n 得 Ln，限制为有限型得 L(rFOL)，等等。L15 的「旋钮二」在这里被正式纳入定义。

命题 3.3.32 / 3.3.33 / 定理 3.3.36 整族的替换性与等式

命题 3.3.32：一般逻辑 L 有语义代入性质 ⟺ 对每个 P ∈ Sig，MngP = Hom(FP, Algm(L)) ⟺ 存在单一代数类 K 使对每个 P 都有 MngP = Hom(FP, K)。注意：K 对整族是同一个。

命题 3.3.33：条件代入的对应版本——MngP = {h ∈ Hom(FP, K) : SP ⊆ ker(h)}，其中 SP 可随 P 变。

定理 3.3.36：对可代入的一般逻辑，

Alg⊨(L) = SP Algm(L)

证明要点（Claim 3.3.37）：取 A ∈ SP Algm(L)，设 A ⊆ ∏i∈I Ai，其中每个 Ai ∈ Algm(L)，故 πi ∘ h : FP → Ai 是到 Algm(L) 成员的同态。由命题 3.3.32(ii)，每个 πi ∘ h = mngNiP。令 K = {Ni : i ∈ I}，则 ker(h) = ∼K，即 A ≅ FP/∼K ∈ Alg⊨(L)。和定理 3.3.5 的嵌入是同一个装置，只是这次靠整族替换性把「投影同态」认成「意义同态」。

典型 · LS 作为一般逻辑

任意两批命题字母之间，只要等势就能改名，公式、模型、意义全跟着搬。Algm(LS) = setBA（全布尔集合代数类），这是练习 3.3.35(4) 的结论。

本质 · 为什么非要参数化

命题 3.3.32 里 K 对所有 P 同一个。这不是顺便写的：它把「换字母表不改变代数行为」变成了一句可验证的等式。没有一般逻辑这层，你只能对每个 P 说一遍，还得解释为什么它们彼此一致。

边界 · 谁有完全代入，谁只有条件代入

UAL 练习 3.3.35(3)：LS, LS5, L(fuFOL), Ln 有语义代入性质；一阶逻辑的其余版本只有条件语义代入。所以定理 3.3.36 只对前一类直接可用，后者要用命题 3.3.33 的带关系版本。

这一讲的口号是大纲里那句话：逻辑的「结构性质」开始对应代数的「算子封闭性」。下面把已经搭好的桥列清，并把尚未通车的标出来。

表二 · 两种影子的拓扑读法

mngM(F) 像「一个世界里的概念图」——对应 L08 的一个模型上哪些命题可验证。

F/∼K 像「一批世界的共同语言」——对应 L02 的 Th(K)，也对应 L13 中 βX 上由一族函数分离出来的结构。定理 3.3.5 的嵌入 φ/∼K ↦ ⟨mngM(φ)⟩，与 L06 Stone 表示、L07 JT 表示是同一类「坐标化」装置。

往前看：本讲是 L18–L20 的 vocabulary

L18 紧致性要用 Csq(Σ) = Th(Mod(Σ)) 与超积；本讲的 Alg⊨, Algm 是它的对象。L19 完全性要用定理 3.3.23 把「有 Hilbert 证明」翻成「所有代数满足某准等式」。L20 可定义性要用 Fact 3.3.20(ii) 和 Remark 3.3.4——后者为什么坚持 Algm 不对同构封闭，到那里才见分晓。

本讲没有证一条「大定理」，但它把后面三座桥的地基浇好了。
