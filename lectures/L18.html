2动机：欠债必还，与讨债的机器

它解决什么问题

L16 结束时，我们手上有一张翻译表：逻辑性质 ↔ 代数性质。L04 造好了一台机器——超积，能把一族代数「取极限」粘成一个。L13 讲了一个承诺——紧致性，说「每一小批都有解，整体就有解」。三条线各走各的，谁也没碰谁。

这一讲让它们相撞。相撞之后你会发现：紧致性是一张欠条，超积是讨债的机器，而定理 4.1.5/4.1.6 说的就是「这张欠条刚好由这台机器兑现」。

先把问题摆具体。Γ 是一堆公式，可能有无穷多条。每一小批 Δ ⊆ Γ 都有模型——但模型各不相同，Δ₁ 的模型是 A₁，Δ₂ 的模型是 A₂，越往后越多。怎么把这无穷多个各管一段的模型，拼成一个管全程的模型？这就是本讲要回答的唯一问题。

答案你已经见过，只是没认出来：取极限。拓扑里，紧致性保证「每个滤子都有极限点」；代数里，超积就是极限点的构造。把 A₁, A₂, … 的超积造出来，用 Łoś 定理把每段成立的事实传上去——那个管全程的模型，就在超积里。

       有限片段 Δ₁, Δ₂, Δ₃, …        每个 Δ 有自己的模型 A_Δ
              │                              │
              │  f.i.p.                      │  取超滤子 U
              ▼                              ▼
       「每一小批都相容」           超积 A = ∏ A_Δ / U
              │                              │
              │  紧致性（承诺）               │  Łoś（兑现）
              ▼                              ▼
       「整体有解」  ◀──── 同一个解 ────▶  A ⊨ Γ 全部公式

       逻辑：Γ 可满足      代数：Alg 对超积封闭      拓扑：滤子收敛
先把话说清楚：三种「紧致」不是三个巧合

① 别以为「超积」是逻辑学家发明的。它是代数里的构造（L04），Łoś 定理是模型论的（L04），紧致 ⇔ 超滤子收敛是拓扑的（L13）。三样东西出自三本教材，但拼起来只证明一件事。这一讲的全部工作就是把这个「一件事」说清楚。

② 也别把桥想成单向的。「代数对超积封闭 ⟹ 逻辑紧致」用来证紧致；反过来「逻辑紧致 ⟹ 某代数类不对超积封闭」用来证不可公理化（§8）。两个方向都有用，这就是桥的价值。

3两种紧致性 O1

定义 3.1（可满足紧致；UAL 定义 4.1.1 的语义版）

逻辑 L = ⟨F, M, mng, ⊨⟩ 称为可满足紧致，若对任意公式集 Γ ⊆ Fm(L)：

Γ 的每个有限子集都有模型 ⟹ Γ 有模型。

换成集合语言更清楚。记 Mod(Γ) = {⟨A, h⟩ : A ∈ M, h 是赋值, ⟨A, h⟩ ⊨ 每个 φ ∈ Γ}，则条件就是：若 {Mod(φ) : φ ∈ Γ} 有有限交性质，则 Mod(Γ) = ⋂φ∈Γ Mod(φ) ≠ ∅。写成这样你就认出来了——这正是 L13 里的闭集 f.i.p. 判据。

定义 3.2（后果紧致；UAL 定义 4.1.4）

称 L 后果紧致，若语义后承满足：对任意 Γ ⊆ Fm(L) 与 φ ∈ Fm(L)，

Γ ⊨ φ ⟹ 存在有限 Γ0 ⊆ Γ 使 Γ0 ⊨ φ。

这就是 L02 闭包算子 C(Γ) = {φ : Γ ⊨ φ} 的「有限特征」：C(Γ) = ⋃Γ₀ ⊆ Γ 有限 C(Γ₀)。后果紧致说的是：可证的东西总有个有限的理由。

两种紧致什么时候是同一句

在经典语义下（语言有常假式 ⊥ 和否定 ¬），两者等价，而且证明只有两行：

  • 后果 ⟹ 可满足：若 Γ 每个有限子集可满足而 Γ 不可满足，则 Γ ⊨ ⊥，由后果紧致有有限 Γ₀ ⊨ ⊥——可 Γ₀ 可满足，矛盾。
  • 可满足 ⟹ 后果：若 Γ ⊨ φ 但每个有限 Γ₀ ⊭ φ，则 Γ ∪ {¬φ} 每个有限子集可满足（有限 Δ ∪ {¬φ} 不可满足会给出 Δ ⊨ φ），由可满足紧致后者整体可满足——与 Γ ⊨ φ 矛盾。

UAL 为什么要把它们分开写？因为 UAL 面向的是「一般逻辑」——不一定有 ¬，不一定有 ⊥，甚至公式不一定能取否定（回想 L17 说的多排序缺口）。在这种一般性下，上面两行证明会卡住。于是紧致性分裂成两个性质：超积封闭直接对应的是后果紧致（定理 4.1.6），可满足紧致需要在有否定的常见情形里才与它合流（定理 4.1.5）。记住这个分裂，L25 处理直觉主义逻辑时它还会冒出来。

典型例子

命题逻辑。Γ 是一堆命题公式，每个有限子集可满足 ⟹ 整体可满足。这条你大概早就用过（比如「每个有限子集相容的理论相容」），但它现在有了两个靠山：布尔代数类 BA 对超积封闭（代数侧，§4），以及 Stone 空间 2ω 紧致（拓扑侧，§6）。同一个事实，三处落地。

本质例子

非标准自然数。取 Γ = Th(ℕ) ∪ {c > n : n ∈ ω}——皮亚尼算术的全部真句子，外加一个常元 c 比每个具体自然数都大。任取有限子集，只用到有限多条 c > n，在 ℕ 里取个足够大的数解释 c 就满足了。每个有限片段可满足。但 ℕ 里没有无穷大，整体在标准模型里无解。紧致性说解存在，超积把它造出来：ℕω/U（U 非主）就是含无穷大 c = [(0,1,2,…)] 的非标准模型。这就是紧致性的本质：它凭空变出「原本不存在的点」，而超积是造点的模具。

边界与误解

① 紧致性说「有模型」，不说「有你想要的那种模型」。上面 Γ 的模型是非标准的，不是 ℕ。想既要紧致性又要「标准性」（比如只要良序模型），一般做不到——这正是 §8 不可公理化论证的入口。

② 「有限可满足」里的「有限」不能换成「可数」。ω1-紧致、可数紧致是另一个概念（L13 §7 的 ω1 反例已经埋了伏笔）。本讲所有「有限」都是货真价实的有限。

③ 别把可满足紧致读成「Γ 有个有限子集等价于 Γ」。那是后果紧致加否定后的推论，不是定义本身。定义只承诺「有模型」，不承诺「找得到有限证据」——虽然在有否定时会蕴涵它。

来源：UAL 定义 4.1.1、4.1.4；L02 闭包算子的有限特征；L13 §3（f.i.p.）、§4（紧致判据）。

4定理 4.1.5：超积造模型 O2逻辑

定理 4.1（UAL 定理 4.1.5，紧致性的代数充分条件）

设逻辑 L 的代数类 Alg⊨(L) 对超积封闭，并且 L 的满足关系由代数约化承载（即「Γ 有模型」等价于「Γ 在 Alg⊨(L) 中有代数模型」，这是 L16 建立的翻译）。则 L 可满足紧致。

换句话说：只要「取超积」这个动作不出界，紧致性就是免费的。

证明（四步，全程只用 L04 和 L13 的工具）。

第 1 步：备料。设 Γ 的每个有限子集有模型。令指标集

I = {Δ ⊆ Γ : Δ 有限}。

对每个 Δ ∈ I，由假设取一个代数模型 AΔ ∈ Alg⊨(L) 满足 Δ 中每一句。I 非空（空集是它的元素）。

第 2 步：造 f.i.p. 族。对每句 φ ∈ Γ，令

Iφ = {Δ ∈ I : φ ∈ Δ} ⊆ I。

族 {Iφ : φ ∈ Γ} 有有限交性质：给定有限多句 φ₁, …, φn，集合 Δ₀ = {φ₁, …, φn} 本身是 I 的元素，且属于每一个 Iφᵢ，所以 Iφ₁ ∩ ⋯ ∩ Iφn ∋ Δ₀ ≠ ∅。这一步是整场的核心：Γ 的「有限片段」被编码成了指标集里的一点。

第 3 步：上超滤子。由素滤子定理（L13 §3，等价 BPI），把 {Iφ} 生成的滤子扩成 I 上的超滤子 U。于是每个 Iφ ∈ U。这个 U 必须是非主的：若 U = UΔ₁ 主于某一点，则对 φ ∉ Δ₁（Γ 无限时总找得到）有 Δ₁ ∉ Iφ，即 Iφ ∉ U，矛盾。

第 4 步：取超积，用 Łoś 兑现。造 A = ∏Δ∈I AΔ / U。由前提，A ∈ Alg⊨(L)。对任意 φ ∈ Γ：

{Δ ∈ I : AΔ ⊨ φ} ⊇ Iφ ∈ U ⟹ {Δ : AΔ ⊨ φ} ∈ U ⟹ A ⊨ φ,

最后一步正是 Łoś 定理（L04 定理 4.6）：一阶/等式性质在超积里「按超滤子的多数票」决定。于是 A ⊨ Γ 全部公式，Γ 可满足。∎

这四步到底在干什么

第 1、2 步是记账：把「Γ 的有限片段」和「指标集的点」一一对应起来，让「φ 出现在片段里」变成「指标集的一个集合 Iφ」。第 3 步是选极限：超滤子 U 替我们决定「哪些片段算数」——它把 f.i.p. 的有限相容性，一次性升级成「整体相容」的表态。第 4 步是兑现：超积把选中的片段粘成一个代数，Łoś 定理保证每个片段里成立的事，在粘出来的代数里还成立。

一句话：超滤子把「有限相容」变成「一点的表态」，超积把「一点的表态」变成「一个对象」。这就是从有限到整体的全部秘密。

和 L13 是同一场证明

把 Iφ 读成拓扑空间里的开集，把「AΔ ⊨ φ」读成「点 Δ 落在集合里」，上面四步一字不改就是 L13 命题 5.2.9「紧致 ⟺ 每个超滤子收敛」的证明。定理 4.1.5 不是新证明，是同一个证明穿了代数的衣服。L13 §9 预告的那座桥，在这里正式落地。

两个容易踩的坑

① 「对超积封闭」是前提，不是结论。在等式逻辑（代数簇）里它是免费的——簇对 H, S, P 封闭，超积是 P 的精细化（L04 §8）。但在一般逻辑里，Alg⊨(L) 未必是簇，这时必须先验证这一步，紧致性才拿得到。

② 超滤子取不出来，整个证明就空转。第 3 步依赖 BPI。L13 §3 已经说过：紧致性定理、Tychonoff、素理想定理三者与 BPI 等价。这里又添一个：定理 4.1.5 也站在同一份公理上。

来源：UAL 定理 4.1.5、定理 2.2.74（Łoś）；L04 定义 4.5/定理 4.6；L13 命题 5.2.9、§3 素滤子定理。

5定理 4.1.6：双向等价 O3逻辑

定理 4.2（UAL 定理 4.1.6，桥的两端）
L 后果紧致 ⟺ Alg⊨(L) 对超积封闭。

这是全课第一座完整的双向桥：左边是纯逻辑性质（「可证的总有有限理由」），右边是纯代数性质（「取超积不出界」）。定理 4.1.5 是它半个方向的语义版本，这一条把它钉死成充要条件。

方向一：超积封闭 ⟹ 后果紧致

这是 §4 那台机器的另一面。设 Γ ⊨ φ，但要假设没有有限 Γ₀ ⊆ Γ 使 Γ₀ ⊨ φ，看会发生什么。

把「Γ₀ ⊭ φ」翻译成语义：Γ₀ ∪ {¬φ} 可满足（这里有 ¬；一般逻辑里要换成 UAL 的「反例模型」条件，技术细节见下方注解）。于是 Γ ∪ {¬φ} 的每个有限子集可满足。由 §4 的超积构造，它整体可满足，取到一个模型 A ⊨ Γ ∪ {¬φ}。但 A ⊨ Γ 且 Γ ⊨ φ 应给出 A ⊨ φ——与 A ⊨ ¬φ 矛盾。所以有限理由必然存在。

用的桥：L16 的「后承 ⟺ 代数模型」翻译 + §4 的超积构造。没有新工具。

方向二：后果紧致 ⟹ 超积封闭

设 Ai ∈ Alg⊨(L) (i ∈ I)，U 是 I 上超滤子，B = ∏i∈I Ai / U。要证 B ∈ Alg⊨(L)，即 B 满足 L 的所有有效公式。取一个有效公式 φ：若 B ⊭ φ，用 Łoś 反向得 {i : Ai ⊭ φ} ∈ U，该集合非空，某个 Ai ⊭ φ——与 Ai ∈ Alg⊨(L) 矛盾。

等等，这里好像没用到紧致性？问得好。如果 Alg⊨(L) 是由一阶句子集刻画的（初等类），Łoś 定理单独就够，紧致性确实是多余的。紧致性真正登场，是在 Alg⊨(L) 的刻画条件不是一阶的时候——比如它由无穷的公式集定义，或条件本身涉及「所有模型」。这时要把「B 满足所有条件」有限化，就得用后果紧致把无穷的要求压成有限的一条，再交给 Łoś。

用的桥：Łoś 定理（L04）+ 后果紧致把无穷公理集压缩成有限子集。这一压，就是方向二的全部内容。

技术注解（可跳过，但值得知道）

上面两个方向在「有 ¬、Alg⊨(L) 一阶刻画」的熟悉情形里写得干净。在 UAL 的一般设定下，需要补两处：一是用 mng 把「反例模型」形式化（没有 ¬ 时靠语义本身给出「某模型使 φ 不成立」）；二是 Alg⊨(L) 与 Algm(L) 的差距要靠「逻辑可代数化」来弥合（L16）。UAL 定理 4.1.6 的完整陈述正是把这些条件打包进去的。本讲义的目标是让你看清桥的形状和两台发动机，纯技术验证留给原书。

双向桥的意义

定理 4.1.5/4.1.6 是 L19–L22 全部桥定理的模板。往后每一座桥都是这个形状：逻辑这边一个性质 ⟺ 代数这边一个性质，证明靠 L16 的翻译 + L04 的构造。你把这一座吃透，后面四座只是换词。

来源：UAL 定理 4.1.6、定义 4.1.1/4.1.4、§4.1 关于 Algm 与 Alg⊨ 的讨论；L16 代数对应与滤子性质。

6拓扑侧：紧致 ⇔ 超滤子收敛 O4

命题 6.1（L13 命题 5.2.9，回顾）

拓扑空间 X 紧致，当且仅当 X 上每个超滤子（幂集布尔代数上的极大真滤子）都收敛到某点。

L13 已经完整证过，这里不重复。本讲要做的是把这个命题翻译成逻辑语言，让它在桥里占一个位置。

翻译：公式变成开集，模型变成点

取公式集 Fm(L)，考虑它的「理论空间」——所有完备一致的（超滤子式）理论 T 组成的集合 Spec(L)。对每句 φ，令

[φ] = {T ∈ Spec(L) : φ ∈ T}。

这些 [φ] 既开又闭，做成一组基，得到的正是 L14 讲过的 Stone 空间：紧致、全不连通、Hausdorff。现在翻译对照如下：

逻辑拓扑
公式 φ基本开闭集 [φ]
理论 Γ子集 ⋂φ∈Γ [φ]（闭集）
Γ 有限可满足{[φ] : φ ∈ Γ} 有 f.i.p.
Γ 有模型⋂φ∈Γ [φ] ≠ ∅（有落点）
紧致性Spec(L) 紧致 ⇔ 每个超滤子收敛

整张表只有一句实质：把「公式」读成「开集」，把「满足」读成「属于」，紧致性定理就变成紧致性。而这个翻译之所以合法，是因为 Mod 把 ∧ 送到 ∩、把 ∨ 送到 ∪、把 ¬ 送到补——它是布尔代数同态（L06）。

典型例子

命题逻辑的理论空间就是 2ω（Cantor 空间）：变元集可数时，每个指派是一个 0/1 序列，公式 φ 对应「使 φ 为真的指派」这个开闭集。它紧致（L13 例 4.5 的二分树证明），于是命题逻辑紧致。「每个有限相容的公式集整体相容」在 Cantor 空间里只是「闭集族 f.i.p. 交非空」。

本质例子

非标准分析里那个「无穷大 c」的落点，在拓扑侧就是 βℕ（ℕ 的 Stone–Čech 紧致化，L13 §8）里 ℕ 之外的点。有限片段 c > n 把 c 往「越来越远」逼，超滤子收敛到那个「无穷远点」。代数侧的 ℕω/U 与拓扑侧的 βℕ − ℕ 是同一个对象的两种说法。

边界与误解

① 这个翻译要有布尔结构才顺。「¬ 送补」依赖经典否定。直觉主义逻辑的理论空间不是 Stone 空间而是 Esakia 空间（有偏序的拓扑空间），紧致性还在，但「开闭集」要换成「上集」。这正是 L17 说的「保留 mng 才能在非经典情形里继续做」的回报。

② 紧致 ≠ 序列紧致。又见 L13 §4 的警告：βℕ 里的无穷远点不是任何序列的极限（序列只能逼近可数多个点），只能用滤子/超滤子抓。这正是为什么桥要用超积而不是「取一列模型的极限」。

来源：拓扑讲义命题 5.2.9、定理 5.2.13；L13 §4/§6/§8；L14 Stone 空间；L06 布尔代数同态。

7用代数方法证逻辑紧致 O5

使用说明书

定理 4.1.5 给了一条生产线，往后证任何逻辑紧致，只要走两步：

  1. 找出该逻辑的代数类 Alg⊨(L)；
  2. 证明这个代数类对超积封闭。

第 2 步通常最省力——最常见的情况是它是一个簇，而簇对超积封闭是免费的（L04 §8）。下面走两个例子，一个命题级、一个模态级。

例 7.1：命题逻辑

代数类是布尔代数 BA。BA 由等式公理化，是一个簇（等式类），对 H, S, P 封闭；超积是约化积的特例，仍在该簇里。于是对超积封闭成立，定理 4.1.5 给出命题逻辑紧致。整条证明只有一句「BA 是簇」。

例 7.2：模态逻辑 S4 与 S5

S4 的代数类是内部代数（布尔代数加一个满足 □x ≤ x、□x ≤ □□x、□(x ∧ y) = □x ∧ □y、□1 = 1 的算子）——L06 已经见过。这些公理全是等式，形成一个簇；超积逐点保持等式（Łoś），所以对超积封闭。于是 S4 紧致。S5 加上 ◇x ≤ □◇x 一类的等式，同样处理。

对比拓扑侧：S4 对应拓扑语义里的内部算子，紧致性的拓扑证明要用 L13 的「开覆盖有限化」。代数侧这里只需「等式簇 ⇒ 超积封闭」——同一结论，代数证明三行，拓扑证明一页。这就是桥带来的实际省力。

这说明了一个更大的道理

「对超积封闭」在代数侧往往是个结构性的事实（是簇、是拟簇、由一阶句子刻画），一眼就能验；而它对应的逻辑紧致性在语法侧是个整体性的事实（对无穷公式集的全称命题），证明起来要绕远路。桥的价值就是把难证的那侧翻译成好证的这侧。

来源：UAL 定理 4.1.5、§4.1；Bergman §5.1（簇与超积）；L04 §8 Birkhoff 定理；L06 内部代数。

8用逻辑方法证代数不可有限公理化 O6逻辑

反向使用：从「超积封闭失效」读出「不可公理化」

把定理 4.1.5 倒过来看。如果一个代数类 C 不对超积封闭，而它又可以由一阶句子集 T 公理化，那么由 Łoś，C 自动对超积封闭（初等类对超积封闭）——矛盾。所以：不对超积封闭 ⟹ 不可一阶公理化。而紧致性是这个论证背后的发动机。

更常用的写法直接用紧致性，不经过超积。套路固定，三步：

  1. 假设「属于 C」可由一阶句子集 T 刻画；
  2. 造一个句子集 Γ，每个有限子集都能在 C 里找到模型；
  3. 由紧致性，Γ 整体有模型 A；但 A ⊨ T 迫使 A ∈ C，而 A 的结构又违背 C 的定义——矛盾。
例 8.1：有限群类不可一阶公理化

设 C = 所有有限群。假设它由一阶句子集 T 刻画。给语言添一族常元 c1, c2, …，令

Γ = T ∪ {ci ≠ cj : i ≠ j}。

任取有限 Γ₀ ⊆ Γ，它只用到有限多个常元，取一个足够大的有限群（阶数 ≥ 用到的常元个数）把这些常元解释成不同元素，Γ₀ 满足。由紧致性，Γ 整体有模型 A。A ⊨ T 迫使 A 是有限群；但 A 里有无穷多个两两不同的元素 ci——矛盾。所以「有限」不可一阶公理化。

超积侧的说法：取 ℤ/2ℤ 的可数份拷贝对非主超滤子做超积，得到的布尔群（每个元素都是自己的逆元）是无限的。有限群类对超积不封闭，正是「有限」不可一阶定义的代数影子。

例 8.2：有限维向量空间

同理，固定域 F，「有限维 F-向量空间」不可一阶公理化：把「存在 n 个线性无关向量」对无穷多个 n 全部加入，每个有限子集有有限维模型，紧致性给出一个无限维模型。代数侧：F 上有限维空间的类不对超积封闭——维数会被超积撑成无限。

例 8.3：良序与连通性

「良序」不可一阶公理化：加常元要求 c0 > c1 > c2 > ⋯，每个有限片段有良序模型（把常元排成有限下降链后接到更大的序数上），紧致性给出含无穷下降链的模型，不是良序。「连通图」不可一阶公理化：加常元要求每对 ci, cj 之间距离 > n，紧致性给出不连通的「无限远」模型。这两个例子说明紧致性的反面有多强：它不只管代数，还管任何想用一阶语言圈住「有限/良序/连通」这类全局性质的企图。

和 L04 拟簇的呼应

L04 §8 说过：拟簇 = 对 S, P, Up（子代数、直积、超积）封闭 = 可由拟等式刻画。现在有了紧致性这座桥，这句话有了新解读：拟等式是一阶句子，所以拟簇对超积封闭（Łoś）；而「簇」（等式类）还多要 H（同态像）。「能不能用有限等式公理化」这个代数问题，从此可以翻译成「对应的逻辑性质在超积下保不保」——这是 L19 的直接入口。

来源：UAL §4.1、定理 2.2.74；Chang–Keisler 模型论紧致性标准例；L04 §8 拟簇 SPUp。
