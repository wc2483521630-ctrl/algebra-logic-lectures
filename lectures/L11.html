2动机：连续性的四种说法与一条裂缝

它解决什么问题

「连续」这个词，从初中到大学被重新定义了三回，每回都更抽象一点：

  1. 铅笔说：图像没有断裂，一笔画完不抬笔。
  2. 接近说：定义域里靠近的点，映过去也靠近。
  3. ε–δ 说：对每个误差 ε 都能找到 δ。
  4. 开集说：开集的原像还是开集。

第四种乍看最不像。它把「靠近」这个含糊的词整个删掉了——没有距离、没有 ε，只剩「开集」。为什么要这么狠？因为前三种说法都暗中依赖度量，一旦你手里的空间没有距离（比如 Kripke 框架、比如代数簇上的 Zariski 拓扑），前三种根本说不出口。第四种是唯一能搬到任何拓扑空间上的说法。

一个必须先拆掉的误解

学生最常见的反应是：「连续应该是把开集映成开集吧？」——恰恰相反。连续说的是原像，不是像。为什么？看常值映射 f : ℝ → ℝ，f(x) ≡ 0。它显然连续（一笔画，就是条横线）。但它的像只有 {0}，在 ℝ 里不开放。把整条实直线压成一个点，信息全丢了，可它还叫连续。

这条裂缝说明：连续性允许「坍缩」。它只管一件事——不许凭空造出原来没有的知识。至于你丢掉多少，它不管。管「不丢」的是另一个概念，叫开映射。这两个概念各自一半，合起来才是「结构不变」，也就是同胚。

3连续性的定义与四种面孔 O1

它解决什么问题

把「靠近」翻译成开集的语言，需要一步跳跃：不用「距离近」，用「同处一个可验证命题之中」。两个点在拓扑上分不开，意思就是没有任何可验证命题能把它们分开。这个替换是整章的关键，也是它能把度量空间里的一切搬到任意空间的原因。

定义 3.1（拓扑讲义定义 3.0.1）

设 (X, τX)、(Y, τY) 为拓扑空间，f : X → Y。称 f 连续，当且仅当 Y 中每个开集的原像在 X 中开：

∀U ⊆ Y  ( U ∈ τY  ⟹  f−1[U] ∈ τX )

严格说应称「f 相对于 τX, τY 连续」——同一个函数，换个拓扑就可能从连续变不连续。这是本讲后面所有「反例」的来源。

定理 3.2（命题 3.1.1，闭包形式）

f : X → Y 连续，当且仅当对每个 S ⊆ X：

f[clX(S)] ⊆ clY(f[S])

即 x ∈ clX(S) ⟹ f(x) ∈ clY(f[S])。

证明

(⟹) 设 f 连续，取 S ⊆ X、x ∈ clX(S)。要证 f(x) ∈ clY(f[S])，由 L10 命题 2.4.6（闭包 ⟺ 邻域相交），只需证 f(x) 的每个开邻域 V 都与 f[S] 相交。因 V 开且 f 连续，f−1[V] 是 x 的开邻域；由 x ∈ cl(S) 知它有元素 y ∈ S，于是 f(y) ∈ V ∩ f[S]。

(⟸) 设 V ⊆ Y 开。把条件用于 S = f−1[Y − V]，得 f[cl(S)] ⊆ cl(f[S]) ⊆ cl(Y − V) = Y − V（最后一步用了 Y−V 闭）。于是 cl(S) ⊆ f−1[Y − V] = S，故 S 等于自身闭包因而闭。取补得 f−1[V] = X − S 开。∎

这条定理在说什么

「接近」被定义为「落在闭包里」。定理说的是：如果 x 接近 S，那么 f(x) 接近 f[S]。这就是「接近说」的严格版本，而且它用的是 L10 已经建好的 cl，不再需要距离。

注意方向：只有 ⊆，没有 ⊇。反过来（cl(f[S]) ⊆ f[cl(S)]）不成立，因为 f 可以坍缩——常值映射里 f[S] 是个点，闭包还是那个点，而 f[cl(S)] 也就那个点，这条恰好成立；但若 f 不满，cl(f[S]) 可能含 f 值域外的极限点。「不增」这件事，写成包含式就是单向的。

定理 3.3（命题 3.1.2，四种等价）

设 f : X → Y，ℬY 是 Y 的一个基或子基。f 连续 ⟺ 下列任一成立：

  1. 每个（子）基本开集 U ∈ ℬY 的原像 f−1[U] 在 X 中开；
  2. 每个闭集的原像闭；
  3. 对每个 x ∈ X，只要 V 是 f(x) 的（基本）开邻域，就存在 x 的开邻域 U 使 f[U] ⊆ V。

证 1 ⟹ 2 的反向（基的情形）：任一开集 V = ⋃iVi（Vi ∈ ℬY），而原像与并交换：f−1[V] = ⋃if−1[Vi]，仍是开集之并。子基的情形：先取有限交成基，用 f−1[V1∩⋯∩Vn] = f−1[V1]∩⋯∩f−1[Vn]，再回到基的情形。

为什么这四条要一起记

它们不是四个定理，是同一件事的四种查法。实际做题时挑最省事的那条：

  • 要证明连续 → 查基（第 1 条），只需验开区间/柱集这类小块。
  • 要用连续 → 用闭包式（定理 3.2），形如「x 是极限点所以 f(x) 也是」。
  • 要局部讨论 → 用第 3 条（邻域式），它不要求整体结构。
  • 要反驳连续 → 找一个闭集或基本开集，原像不闭/不开，做一次就够。
典型例子

f : ℝ → ℝ，f(x) = x²。用第 1 条：只需看开区间 (a,b) 的原像。解 a < x² < b：当 0 ≤ a < b 时是 (√a,√b) ∪ (−√b,−√a)；当 a < 0 < b 时是 (−√b,√b)；其余情形为空。三种都是开区间之并，故连续。这一题把「查基」的省力之处演示得很清楚——不用碰任意开集，只解开一个不等式。

本质例子

连续性是相对于拓扑的，不是函数的固有属性。取恒等映射 id : ℝ → ℝ。若两边都用欧氏拓扑，它连续。若定义域取离散拓扑、值域取欧氏拓扑，它仍然连续（离散空间里每个集合都开，原像自动开）。若反过来，定义域欧氏、值域离散，则 id−1[{0}] = {0} 在欧氏拓扑里不开，立刻不连续。同一个函数，只因换了拓扑，结论翻转。「连续」从来不是 f 一个人的事，是三元组 (f, τX, τY) 的事——这是 L08「拓扑＝知识标准」的直接后果。

边界与误解

三个常见的错。① 「连续 ⟹ 保开集」错，常值映射就是反例（§2 已拆）。② 「连续 ⟹ 保收敛序列，且逆也真」错：连续确实保证 xn → x 时 f(xn) → f(x)（在序列能刻画拓扑的空间里，如度量空间）；但反之「序列连续 ⟹ 连续」在一般拓扑空间失效——需要第一可数性。这是 L12 之后才说得清的事，先记住别乱用。③ 「连续 ⟹ 保闭集」错：等价的说法是「闭集的原像闭」，不是「闭集的像闭」——后者是闭映射，见 §6。

来源：拓扑讲义定义 3.0.1、命题 3.1.1 及其证明、注 3.1.1、命题 3.1.2、例 3.1.3。

4认识论读法：不增加知识的翻译 O2O2

它解决什么问题

L08 把拓扑空间解释成「论域 + 认识论框架 + 命题」，开集 = 可验证命题。那么两个论域之间的映射是什么？讲义给的答案是：翻译。于是「什么样的翻译算好翻译」这个问题，就变成了「什么样的映射算连续」。这个转换一旦做出，连续性的定义就不再是技术条件，而是一条可以争论的认识论要求。

读法 4.1（注 3.1.2）

设 X, Y 是两个认识论论域，f : X → Y 是命题翻译。若 Y 中命题 U 可验证，则它在原论域的对应命题 f−1[U] 也应可验证——

翻译不能凭空增加知识

而这恰好就是连续性的条件。

三个词，一条谱

把 §2 的裂缝接到认识论上，三个概念立刻排成一条谱：

映射开集条件认识论读法信息流向
连续U 开 ⟹ f−1[U] 开不增加知识只能丢，不能造
开映射U 开 ⟹ f[U] 开不丢失知识只能造，不能丢
同胚双射 + 连续 + 开知识不增不减完全保真

讲义还补了一句公道话：允许信息损失的翻译本身仍然值得研究。这不是将就——现实里的翻译总在丢东西，而「丢得多但还是可靠」正是连续性单独刻画的那一类。要求翻译完全保真（同胚）太苛刻，绝大多数有用的映射都不满足。

典型例子

常值映射 f : ℝ → ℝ、f(x) ≡ 0。它连续：任意开集 U 的原像是 ℝ（若 0 ∈ U）或 ∅（若 0 ∉ U），两者都开。它不开：f[(0,1)] = {0}，而 {0} 在 ℝ 中不开。认识论上这就是「一种语言把整段事实压成一个词」——可靠（不会说错），但毫无分辨率。

本质例子

例 3.1.5 那个折线函数才是最有说服力的：

f(x) = x (x ≤ 0)，   f(x) = 0 (x > 0)

它连续（左半段恒等、右半段常值，在 0 处接上），但不开：f[(−1,1)] = (−1,0]，半开区间不是开集。读法：正半轴那一整段知识被压成了一个点，压完之后再也分不出来。0 这个端点恰好是「压扁」的痕迹——它把右半轴的全部分辨率收进了自己。这类映射在认识论上很常见：一种语言能说「不是正的」，却说不出「正多少」。

边界与误解

别把「不增加知识」读成「知识变少」。连续只禁止凭空多出，不承诺一定减少——恒等映射连续且一点不丢，它的开性也成立（同胚）。真正的关系是：连续与开是两个独立条件，四种组合都存在（连续不开、开不连续、两者皆是＝同胚到像、两者皆非）。§6 会把四种组合都摆出来。另一个误解：不要把 f−1[U] 当成逆映射——这里 f 根本不必可逆，f−1 只是「取原像」这个集合运算。

来源：拓扑讲义注 3.1.2（认识论直观）、注 3.1.4（开映射的认识论直观）、例 3.1.5。

5点连续、ε–δ 与「局部」 O3

它解决什么问题

整体连续（每个开集原像开）是个全局条件，但很多时候我们只关心「在这一点附近」的行为。更实际的是：验连续时不必一次看全空间，可以逐点查。点连续就是把连续拆成「每个点各管一段」的版本，而它的邻域形式正是 ε–δ 定义的拓扑化。

定义 5.1（命题 3.1.2 第 3 条、注 3.1.3）

f 在点 x 连续，若对 f(x) 的每个（基本）开邻域 V，存在 x 的开邻域 U 使 f[U] ⊆ V。等价地，用「接近」写：

∀S ⊆ X,   x ∈ cl(S) ⟹ f(x) ∈ cl(f[S])

注意这是逐点版的定理 3.2——把「对所有 S」的 x 固定住。整体连续 ⟺ 处处点连续。

定理 5.2（习题 3.8，ε–δ 的等价）

在标准实直线上，f : ℝ → ℝ 在 a 连续，当且仅当

∀ε > 0 ∃δ > 0 ∀x ∈ ℝ,   |x − a| < δ ⟹ |f(x) − f(a)| < ε

提示：用三角不等式 |x − z| ≤ |x − y| + |y − z|。

怎么把两套语言对上

对应关系是一词换一词，非常机械：

ε–δ 语言拓扑语言
|x − a| < δx ∈ U，U 是 a 的开邻域
|f(x) − f(a)| < εf(x) ∈ V，V 是 f(a) 的开邻域
开区间 (a−δ, a+δ) 是 a 的邻域开集族构成邻域基（L09 的基思想）
「对每个 ε 找 δ」「对每个 V 找 U」

ε–δ 里所有的「小」都被抽象成了「开邻域」。一旦你接受这一点，拓扑定义就不是新东西，只是把 ε–δ 里的度量外套脱掉了——脱掉之后，结论对任何空间都成立。

典型例子

f(x) = x² 在 a = 3：给定 ε，取 δ = min(1, ε/7)。当 |x−3| < 1 时 |x+3| < 7，于是 |x²−9| = |x−3||x+3| < 7δ ≤ ε。这类计算的标准套路是「先框住变量范围，把因子估成常数」——拓扑语言里对应「先用一个基本开邻域把点圈住」。

本质例子

取 f : ℝ → ℝ，f(x) = 0（x ≠ 0），f(0) = 1。处处连续，恰在 0 处不连续。0 处失败的原因很具体：f(0)=1 的邻域 V = (1/2, 3/2) 的原像是 {0}，而 {0} 在 ℝ 里不是 0 的邻域——你没法在 0 附近找到一小块，保证它整个映进 V。这说明点连续是真正局部的性质：它可以只在一点崩坏，其余全好。而整体连续性恰恰不允许这种「单点违约」。

边界与误解

① 「点连续 + 处处点连续 ≠ 整体连续」？——其实等于，这是定理，不是反例。但注意：「在每点分别连续」这句话里的邻域 U 可以随点剧烈变化，不能以为是同一个 U 管所有点。② 「连续点集是开的」错：上例中 f 的连续点集是 ℝ − {0}，它确实开；但这不是定理，连续点集只是 Gδ 集，可以更怪。③ 最容易混的：点连续用的是「f(x) 的每个邻域 V」而不是「x 的每个邻域」——方向和 L10 的闭包刻画是一致的（先固定 f(x) 的周边，再回头找 x 的周边）。

来源：拓扑讲义命题 3.1.2 第 4 条、注 3.1.3、习题 3.8。

6开映射、闭映射与 forth / back O4O4

它解决什么问题

连续只管「不增」，于是允许坍缩。如果我们要的是「保结构」，就必须补上另一半：不丢。开映射就是这另一半。单独看它意义有限（开而不连续的例子一堆），但一旦和连续合起来，就得到了拓扑空间的「同构」，见 §7。而讲义顺手用它解释了一件模态逻辑里的事：Kripke 框架之间的 forth / back 条件，正是连续 / 开。

定义 6.1（定义 3.1.4、3.2.2）

f : X → Y 称开映射，若 X 中每个开集 U 的像 f[U] 在 Y 中开：

∀U ⊆ X  ( U ∈ τX ⟹ f[U] ∈ τY )

称闭映射，若每个闭集的像闭。

注意：开映射与闭映射是两回事，都不与连续互推。开只对开集说话，闭只对闭集说话，而一个集合可以既开又闭、只开、只闭、都不是——L10 已经讲过这个四分。

定理 6.2（命题 3.1.7，forth / back）

设 𝔉 = (W,R)、𝔉′ = (W′,R′) 为 Kripke 框架，映射 f : W → W′。称 f 满足

  • forth：xRy ⟹ f(x)R′f(y)；
  • back：f(x)R′y′ ⟹ ∃y ( xRy 且 f(y)=y′ )。

若两框架自反且传递、并赋以 Alexandroff 拓扑（上集为开集），则：

forth ⟺ f 连续      back ⟺ f 为开映射

证明要点。 (forth ⟹ 连续) 设 U′ 是 R′-上集，x ∈ f−1[U′] 且 xRy，则 f(x)R′f(y)；由 f(x) ∈ U′ 与上集性得 f(y) ∈ U′，故 y ∈ f−1[U′]——原像是上集。反向用上集 ↑f(x) = {z′ : f(x)R′z′}，其原像是上集且含 x，故含所有 y（xRy），于是 f(y) ∈ ↑f(x) 即 f(x)R′f(y)。back 一侧完全对偶：把「原像是上集」换成「像是上集」，自反性负责让 x ∈ ↑x 这一点落回像里。∎

这条定理为什么重要

forth + back 合起来，在模态逻辑里叫有界态射（bounded morphism，也叫 p-态射）。它是模态逻辑的「同态」：满足它的映射双向保持模态公式的真值——w ⊨ φ 当且仅当 f(w) ⊨ φ。定理 6.2 说的是：这个逻辑概念在拓扑里就是「连续 + 开」。

于是三线在这里合上了：forth（逻辑的「前向保真」）＝ 连续（拓扑的「不增知识」），back（逻辑的「后向满」）＝ 开（拓扑的「不丢知识」）。两侧都成立时，就是「表达力等价」——和 §7 的同胚是同一件事。L06 讲 Alexandroff 拓扑与预序的对应，现在看到了它的用处：预序上的「保序 + 满射到上集」和拓扑上的「连续 + 开」是同一句话。

典型例子

连续不开：例 3.1.5 的折线 f(x) = x (x≤0)、f(x)=0 (x>0)，f[(−1,1)] = (−1,0] 不开。开不连续：取 X 为平凡拓扑（只有 ∅,X）、Y 为离散拓扑，f 为双射。X 里只有两个开集，像分别是 ∅, Y，都开——所以 f 开。但 Y 里单点集开，原像是单点集，在 X 里不开——不连续。

本质例子

Alexandroff 拓扑下的 forth / back，用最简单的预序看：W = {0,1}，R 为 0R1（自反传递），上集是 ∅, {1}, {0,1}。取 f : W → W、f(0)=0, f(1)=0。它 forth 吗？0R1 需 f(0)Rf(1) 即 0R0，成立（自反）——forth 成立，故连续。它 back 吗？f(1)=0，取 y′=1，需找 y 使 1Ry 且 f(y)=1，即 y=1 且 f(1)=1，但 f(1)=0——back 失败，故不开。这个映射把世界 1 的信息彻底抹掉了，正是「坍缩」的极小模型。

边界与误解

① 「开映射 ⟺ 连续的双射的逆」错：开映射不必双射也不必连续。② 「开 ⟹ 闭」错：折线 f(x)=x (x≤0), 0 (x>0) 既不开也不闭（f[[0,∞)) = {0} 闭，f[(−∞,0]] = (−∞,0] 不闭）。③ 最容易错的：以为「f 连续且双射 ⟹ f 开」。完全错误，§7 有个标准反例。④ 注意 forth/back 只在下标 — 它们依赖框架关系，换拓扑就换说法，不要当成任意空间上的通用判据。

来源：拓扑讲义定义 3.1.4、注 3.1.4、例 3.1.5、定义 3.1.6、命题 3.1.7、定义 3.2.2、图 3.1。

7同胚与嵌入 O5O5

它解决什么问题

拓扑学要「在同胚意义下研究空间」，那就必须先说清什么时候两个空间算同一个。连续只保证不增，开只保证不丢，两个都要，才叫结构不变。同胚就是拓扑空间的同构——和 L03 的代数同构、L05 的项等价，是同一个想法的第三次出现。而嵌入是它的「相对版」：不一定占满整个陪域，只要在自己的像上同胚就够。

定义 7.1（定义 3.2.1）

设 f : X → Y 为拓扑空间间的映射。

  • 若 f 满射，且对每个 U ⊆ Y：U 在 Y 中开 ⟺ f−1[U] 在 X 中开，称 f 为商映射；
  • 若 f 双射、连续且开，称为同胚；
  • 若把陪域限制到像得到的 f′ : X → f[X] 是同胚（f[X] 取子空间拓扑），称 f 为（拓扑）嵌入。

同胚的等价说法（习题 3.6）：f 同胚 ⟺ 存在连续 g : Y → X 使 g∘f = idX、f∘g = idY。注意 g 必须也连续——只说「有集合论逆」不够。

定理 7.2（引理 3.2.3）

以下各条均成立：

  1. 商映射 ⟺ 满射且「U 闭 ⟺ f−1[U] 闭」；商映射必满射且连续；满射 + 连续 + 开（或闭）⟹ 商映射。
  2. 嵌入必单射且连续；单射 + 连续 + 开（或闭）⟹ 嵌入。

但它只是部分逆命题：商映射可以不开也不闭，嵌入可以不开也不闭（注 3.2.1）。

嵌入两条的证明（引理的 (1.e)、(2.e)）

(1.e) 若 f 是嵌入，则 f′ : X → f[X] 同胚，故单射，于是 f 单射。取 V ⊆ Y 开，则 V ∩ f[X] 在子空间 f[X] 中开；由 f′ 连续，(f′)−1[V ∩ f[X]] = f−1[V] 在 X 中开，故 f 连续。

(2.e) 若 f 单射、连续且开，则 f′ 是双射。对 Y 中开集 V，(f′)−1[V ∩ f[X]] = f−1[V] 开，故 f′ 连续。又对 X 中开集 U，f′[U] = f[U] = f[U] ∩ f[X]，其中 f[U] 在 Y 中开，故此像在 f[X] 中开。所以 f′ 是同胚。∎

这两条证明的关键动作是同一个：把「Y 中的开集」换成「f[X] 中的开集」，即与 f[X] 取交。这就是 L09 子空间拓扑的定义在起作用——嵌入的本质是「先缩到像上，再谈同胚」。

典型例子

(−1,1) ≅ ℝ，同胚可取 f(x) = tan(πx/2)（或 x/√(1−x²)）。由此对任意 a < b 有 (a,b) ≅ ℝ。这就是讲义注 3.3.1 说的「拓扑空间可以伸展」——长度、直径这些度量概念在同胚下全不作数，留下的是「有没有断、有没有洞」。

本质例子

连续双射不必是同胚——这是本讲最该记住的反例：

f : [0,1) → S¹,   t ↦ (cos 2πt, sin 2πt)

它连续、双射（绕一圈，起点不重复），但不是同胚：它的逆在 (1,0) 处不连续。拓扑上看，[0,1) 里 [0, 1/2) 是开集（子空间拓扑），但它的像不是 S¹ 的开集——「剪开的区间」和「闭合的圆」在端点处结构不同。这个例子同时说明：「不增」和「不丢」必须分别验，双射只保证集合层面一一对应，完全不保证拓扑层面。

嵌入的例子则是 Cantor 空间：2ω → [0,1]，(ai) ↦ Σn 2an/3n+1。它把二进制序列映成三进制只含 0、2 的数，像是 Cantor 三分集——在 ℝ 中并不开，但 2ω 与它同胚。这说明嵌入的像可以很「瘦」，只要子空间拓扑对得上就行。

边界与误解

① 「单射 + 连续 = 嵌入」错。取 id : (ℝ, 离散) → (ℝ, 欧氏)：单射、连续（离散定义域），但不是嵌入——它的逆（欧氏 → 离散）不连续。② 「同胚是等价关系」对（习题 3.5：自反、对称、传递），所以「同胚于」可以随便传递使用，这是后文把性质沿同胚搬运的依据。③ 别把嵌入与「包含映射」混为一谈：习题 3.7 说明，U ⊆ X 开时包含映射 U ↪ X 是连续开映射（故是嵌入）；U 不开时只连续不开，一般不是嵌入。④ 同胚不必「形状像」——同胚可以极其奇异，讲义的提醒是认真的。

来源：拓扑讲义定义 3.2.1、引理 3.2.3 及证明、注 3.2.1、例 3.2.4、习题 3.4/3.5/3.6/3.7、注 3.3.1。

8商映射、商拓扑与泛性质 O6O6

它解决什么问题

前面都是「给定两个空间，问映射好不好」。商映射反过来：把映射的条件当作定义，用它造出新空间。这在代数里叫商代数（L03），在拓扑里叫商拓扑，两边的动作一模一样：把某些点认同成一个，然后要求新空间上的结构「恰好是使投影保持结构的那个」。

定义 8.1（定义 3.2.5）

设 X 为拓扑空间，∼ 是 X 上的等价关系，q : X → X/∼ 为自然投影 q(x) = [x]∼。在 X/∼ 上定义商拓扑：

U ⊆ X/∼ 开  ⟺  q−1[U] 在 X 中开

可以验证这确实是拓扑，且配备它之后 q 确实是商映射。注意这个定义只在一个方向上要求：它把 X/∼ 的开集定为「拉回后开」的那些——这是使 q 连续的最细拓扑，不能再细，再细 q 就不连续。

与 L03 商代数逐条对照
商代数 A/θ商拓扑 X/∼
商家等价类 [a]θ等价类 [x]∼
运算良定义ai θ bi ⟹ f(a⃗) θ f(b⃗)开集用原像定义，自动良定义
投影π : A → A/θ 是满同态q : X → X/∼ 是商映射
极值性θ 是使 π 为同态的最大同余商拓扑是使 q 连续的最细拓扑
泛性质在 θ 上常值的同态唯一分解在等价类上常值的连续映射唯一分解

同一个模式，一个在「最大」的方向上取极值，一个在「最细」的方向上取极值——因为代数的条件是等式（越少认同越容易满足），拓扑的条件是包含（越少开集越容易满足）。这是 L03 与本节之间唯一的实质差别。

定理 8.2（习题 3.9.3，商拓扑的泛性质）

设 Y 为拓扑空间。每个在等价类上常值的连续映射 f : X → Y，都唯一诱导映射 f̃ : X/∼ → Y 使下图交换：

f = f̃ ∘ q

并且 f̃ 连续 ⟺ f 连续。

为什么这是「定义商拓扑」的真正理由：泛性质说的是「从商空间出发的连续映射 = 从 X 出发、在等价类上常值的连续映射」。你要在商空间上构造连续映射，只需在 X 上构造，然后检查它尊重认同——这是商空间所有实际用法的技术基础。

典型例子

把区间端点粘起来：I = [0,1]，x ∼ y ⟺ x=y 或 {x,y}={0,1}。商空间 [0,1]/∼ 与 S¹ 同胚。这就是「取商＝粘合」的字面意思：0 与 1 认同成一类，区间卷成圆。更狠的是 Möbius 带：I² = [0,1]×[0,1]，令 (x,y) ∼ (x′,y′) ⟺ (x,y)=(x′,y′) 或 [x = 1−x′ ∈ {0,1}, y = 1−y′]，即一条边翻转后粘到对边。先在 [0,1] 取子空间拓扑、再取积拓扑、最后取商拓扑——三步都是 L09 讲过的构造，组合起来就得到那个几何对象该有的拓扑。

本质例子

连续满射不一定是商映射（习题 3.9.2）。取 X = (ℝ, 欧氏)、Y = (ℝ, 离散)，f = id。它满射且连续（欧氏比离散粗，恒等从粗到细连续）。但 {0} 在 Y 中开，其原像 {0} 在 X 中不开——若 f 是商映射，Y 的开集必须恰好是那些拉回后开的集合，而 {0} 不满足。失败的原因：Y 的拓扑比商拓扑更细。商映射的定义是「Y 的拓扑恰好是商拓扑」，多一点都不行。这是「满射 + 连续」与「商映射」之间的真实间隙，也是引理 3.2.3 只说部分逆命题的原因。

边界与误解

① 「商映射 = 连续满射」错，上例即是；正确条件是「开或闭」再加满射连续。② 「商空间继承原空间的性质」错：分离性、紧致性都可能在取商时崩掉——把 ℝ 的两个点认同，Hausdorff 就可能失去。这是 L12 要专门处理的事。③ 「商拓扑是最粗的使 q 连续的拓扑」错，是最细的——因为条件 q−1[U] 开越容易满足，U 就能越多，故商拓扑比任何让 q 连续的拓扑都细。④ 泛性质里的「唯一」指的是集合层面唯一（f̃ 的值被 f 完全决定），连续性则要另外验——但由「f̃ 连续 ⟺ f 连续」这条，验起来很省事。

来源：拓扑讲义定义 3.2.5、例 3.2.6/3.2.7、习题 3.9、注 3.2.1。

9融合接口

代数 ↔ 逻辑 ↔ 拓扑
拓扑逻辑代数
连续映射（不增知识）翻译的保真性：Y 中可验证 ⟹ X 中可验证同态（保持运算）
开映射（不丢知识）翻译的满性 / back 条件同态的像（子代数）

一句话串起来

整讲只有两层意思。第一层：连续性的定义是在问「这个翻译会不会凭空造知识」——答案是原像条件，它单向，所以允许坍缩；坍缩的另一面由开映射补上。第二层：同胚 = 两个条件都成立，于是拓扑学有了一杆秤，可以判断两个空间是否「同一个」——这正是后面所有「沿同胚搬运性质」论证的许可证。

再往前看一步：L12 会问「点能不能被分开」——那是把「连续」用到「单点集」上；L13 / L18 会问「空间够不够小」——那是把「开覆盖」和连续映射拉回结合。而 L15 之后进入逻辑的代数化时，连续映射与同态的关系会以「桥」的形式再出现一次。
