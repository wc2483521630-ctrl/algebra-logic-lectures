0概念清单与依赖关系（简）

前三座桥各造了一台翻译机。这一讲要把三台机器同时开动：逻辑侧问「两个公式之间能不能插进一句共同语言的话」，代数侧问「两块代数沿公共子代数能不能粘成一个大代数」，两侧的回答居然是同一条定理。这是全书技术含量最高的一讲，慢一点走。

2动机：把两个世界粘起来，会不会漏信息

它解决什么问题

先讲一个动作：粘合。你手里有两块结构 B 和 C，它们共享一小块 A。你想把它们沿 A 拼成一个更大的 D，并且要求拼完之后 A 在两边还是同一个东西。

听起来只是小学手工。但「能拼」和「拼得干净」是两件事。设想 B 里有个元素 b，C 里有个元素 c，它们都不在公共部分 A 里。拼好之后，你可能在 D 里发现 b ≤ c。这个大小关系是从哪来的？如果 A 里能找到一个中间人 a，让 b ≤ a ≤ c，那还算有据可查——关系是被公共部分「传导」过来的。如果找不到，那就是凭空偷渡：拼的这个动作本身泄露了 B 与 C 之间的私密信息。

现在把「元素」换成「公式」，「大小」换成「蕴含」，「公共部分」换成「两种语言共有的符号」。「能拼且拼得干净」翻译成逻辑，正是 Craig 插值：若 φ 蕴含 ψ，那么这份蕴含必须由两者共有的语言承担，不能靠各自私有的符号暗中传递。

这就是第四座桥的全部直觉。逻辑问插值，代数问合并与超合并，而它们说的是同一件事。

               「粘得干净」的三副面孔
                      │
      ┌───────────────┼───────────────┐
      │               │               │
    逻辑 L          代数 Algᵐ(L)      拓扑 Spec
      │               │               │
  φ ⊨ ψ          B ← A → C          沿公共闭集粘合
      │               │               │
  中间有 θ         拼成 D            得到公共扩张
      │               │               │
  θ 只用共同语言   b ≤ f(a) ≤ c      a 落在公共部分
      │               │               │
      └── 插值 ⟺ 超合并 ⟺ 粘合不偷渡 ──┘
            共同语言 ↔ 公共子代数 ↔ 公共子集
先把话说清楚：合并很便宜，超合并很贵

① 「能拼」几乎总是能做到。集合层面把 B 与 C 沿 A 取并，再随便黏一黏就行。难点从来不是拼，而是拼出来的东西还得留在原来的类里、且不能偷渡信息。这就是「合并」与「超合并」的差别（§4、§5）。

② 「共同语言」必须真的是交，不能私自扩大。如果你偷偷把 B 或 C 的私有符号也放进中间，插值当然写得出——但那是作弊。插值的价值恰恰在于中间人只准用两边都认识的词。

③ 这一讲要同时花三笔钱。L18 的紧致性用来把无穷压成有限；L19 的有限证明用来把「有效」换成「可证」；L20 的可定义性用来把「隐含」换成「显式」。少任何一件，定理 4.4.24 的某个方向就证不出来。

3Craig 插值与 Beth 证明的补齐 O1

定义 3.1（Craig 插值性质）

设逻辑 L 有语义后承 ⊨。称 L 有 Craig 插值性质，若对任意公式 φ, ψ，只要 ⊨ φ → ψ，就存在公式 θ 满足：

  1. ⊨ φ → θ 且 ⊨ θ → ψ；
  2. θ 只使用 L(φ) ∩ L(ψ) 里的符号（再加上等号、逻辑常项与自由变量）。

这个 θ 叫 插值式。第 2 条是灵魂：中间人不许认识任何一边的私符号。

先看两个成功例子。它们简单到几乎不像定理，但已经把「中间人只用共同语言」这把刀磨出来了。

例 3.2（命题层）

φ = p ∧ q，语言 {p, q}；ψ = p ∨ r，语言 {p, r}。显然 ⊨ φ → ψ。共同语言只有 {p}，而插值式取 θ = p：

⊨ (p ∧ q) → p　且　⊨ p → (p ∨ r).

注意 q 和 r 都被 θ 甩掉了——它们各是一边的私符号，进不了中间。

例 3.3（量词层）

φ = ∀x(Px → Qx) ∧ Pa，语言 {P, Q, a}；ψ = ∃x Qx ∨ Rb，语言 {Q, R, b}。共同语言是 {Q}（常元 a 与 b 各自私有）。插值式取 θ = ∃x Qx。

这里有个小陷阱：不能写 Qa。虽然 φ 确实推出 Qa，但 a 不在 ψ 的语言里，Qa 不是合法插值。共同语言这一条会硬生生逼你把常元换成量词。

命题 3.4（插值 ⟺ Robinson 联合一致性）

称逻辑 L 有 Robinson 联合一致性，若：只要理论 T₁ ⊆ Sent(L₁) 与 T₂ ⊆ Sent(L₂) 各自可满足，且它们在公共语言 L₀ = L₁ ∩ L₂ 上相容（即不存在 L₀-句子 σ 使 T₁ ⊨ σ 且 T₂ ⊨ ¬σ），则 T₁ ∪ T₂ 可满足。

结论：Craig 插值性质 ⟺ Robinson 联合一致性。

证明（两个方向各用一次我们见过的机器）。

方向一：插值 ⟹ 联合一致。设 T₁, T₂ 在公共语言上相容但 T₁ ∪ T₂ 不可满足。由 L18 紧致性，取有限子集使 φ = ∧Γ₁ ⊆ T₁、ψ = ∧Γ₂ ⊆ T₂ 满足 ⊨ φ → ¬ψ。Craig 插值给 L₀-公式 θ 夹在中间：T₁ ⊨ θ 且 T₂ ⊨ ¬θ。这与公共语言上相容矛盾。∎

方向二：联合一致 ⟹ 插值。设 ⊨ φ → ψ 但不存在插值式。取 T₁ = {φ}、T₂ = {¬ψ}。若它们在 L₀ 上不相容，就有 L₀-句子 σ 使 ⊨ φ → σ 且 ⊨ σ → ¬¬ψ，即 σ 是插值式——与假设矛盾。故 T₁, T₂ 在 L₀ 上相容；联合一致性给出 {φ, ¬ψ} 有模型，与 ⊨ φ → ψ 矛盾。∎

命题 3.5（补齐 L20 的欠账：Beth ⟺ Craig）

L20 §3 用紧致性证明了「隐含可定义 ⟹ 显式可定义」时说「完整证明待插值工具就绪」。现在补上：在一阶逻辑里，Beth 可定义性定理与 Craig 插值定理等价，二者通过命题 3.4 的 Robinson 联合一致性连成一条环。

Craig ⟹ Beth。

设关系符号 R 在理论 T（语言 L）中隐含可定义。引入新符号 R′，令 L′ = L ∪ {R, R′}，T′ 是把 T 中 R 全换成 R′ 得到的副本。隐含可定义意味着 T ∪ T′ ⊨ ∀x̄ (R(x̄) ↔ R′(x̄))。取一个方向，由紧致性压成有限：⊨ (∧T₀) ∧ R(x̄) → R′(x̄)。此时 R 只出现在左侧前提、R′ 只出现在右侧结论，共同语言恰是 L。Craig 插值给 L-公式 θ(x̄)，使 ⊨ ∧T₀ ∧ R(x̄) → θ(x̄) 且 ⊨ θ(x̄) → R′(x̄)。第二式里没有 R，把它读回原语言即得 T ⊨ θ(x̄) → R(x̄)；对称地做另一个方向得反向包含。于是 θ 显式定义了 R。∎

典型例子

命题逻辑的一阶扩张总有插值。例 3.2、3.3 已经演示了「把私符号甩掉」的动作。一阶逻辑的 Craig 定理说这个动作永远做得成——这是逻辑学最漂亮的定理之一，也是本讲所有代数刻画的正确性来源。

本质例子

为什么「中间人不许认识私符号」这么要紧？因为如果允许，插值就退化成一句废话：φ → ψ 时取 θ = φ 即可，⊨ φ → φ、但 ⊨ φ → ψ 是原前提，第二个条件白给。插值的全部内容都在「共同语言」这四个字里——它强迫蕴含关系由公共信息承担，而不是靠两边各自的私货搭桥。

边界与误解

① Beth 与 Craig 的等价是「一阶逻辑里」的等价。在模态逻辑、直觉主义逻辑、次结构逻辑里，二者可能分家：有的有插值而无 Beth，有的反之。别把这里的等价当成普世规律。

② 「存在插值」不等于「能算出插值」。Craig 定理是存在性证明（靠紧致性），本讲后面会看到：要有可计算的插值，得额外要求 Hilbert 系统给出有效证明（L19）。

来源：UAL §4.4.1（Craig 插值与合并）；命题 3.4–3.5 沿用 L18 紧致性、L20 §3 的 Beth 框架；完整教材编号请核对 §4.4.1–4.4.2 原文。

4代数侧：合并性质 O2

现在把上一节的「粘」写成代数。取一个代数类 K（在 AAL 里就是 Algm(L) 或 Alg⊨(L)，见 L16）。

定义 4.1（合并性质）

称 K 有 合并性质，若对任意 A, B, C ∈ K 与嵌入 f : A → B、g : A → C，存在 D ∈ K 与嵌入 h : B → D、k : C → D，使下图交换：

h ∘ f = k ∘ g.

也就是说，A 在 B 里的像与在 C 里的像，到了 D 里是同一个东西。「沿公共部分粘」的全部要求就这一条交换律。

              B
             ╱ ╲
        f   ╱   ╲  h
           ╱     ╲
          A ─────→ D
           ╲     ╱
        g   ╲   ╱  k
             ╲ ╱
              C

        交换条件：h ∘ f = k ∘ g
        （A 在两边是同一块）

图：合并的交换图。注意 D 不要求唯一——「能拼出一个」就够。

例 4.2（哪些类有合并）
  • 群、环、布尔代数、向量空间（固定域）的簇都有合并：用自由积、张量积之类的构造就能拼。大部分「熟」的代数簇都满足。
  • 所有集合的类显然有合并：取并集即可。这一条别小看——它说明「合并」本身是个很弱的要求。
  • 有限群的类没有合并。把 A 拼进 B 与 C 后，得到的 D 通常是无限的，逃出了「有限」这个类。这一条很重要：类的边界一收紧，合并就可能失败。
合并对应逻辑的什么

回看命题 3.4 的 Robinson 联合一致性：T₁ 与 T₂ 在公共语言上相容，问能不能合起来有模型。把「理论」换成「代数」、「公共语言」换成「公共子代数」、「有模型」换成「拼出 D」，就是合并性质。

所以定理 4.4.18 的前半几乎是翻译：合并性质 ⟺ Robinson 联合一致性 ⟺ （由命题 3.4）Craig 插值的弱化版。说「弱化」，是因为合并只保证拼得出来，还没保证拼得干净——那要等超合并。

一处容易踩的坑：用哪个代数类

L16 特意区分了 Algm(L)（具体模型给出的代数，故意不对同构封闭）与 Alg⊨(L)（满足理论的抽象类，对同构封闭）。合并性对这两个类可能给出不同答案。本讲谈到「插值的代数刻画」时默认用 Algm(L)，因为插值关心的是语法与语义的精确对应，不能把具体副本丢掉——这和 L20 用 Algm 讲可定义性是同一个理由。

来源：UAL §4.4.1（合并性质、合并与 Robinson 性质的关系）；L16 关于 Algm 与 Alg⊨ 的区分。

5超合并：合并之上再加一道夹逼 O3

现在给「拼得干净」一个精确定义。为把话说清楚，先取一类带序的代数（布尔代数、格、偏序都在此列），用 ≤ 表示序关系。

定义 5.1（超合并）

称 K 有 超合并性质，若 K 有合并性质，并且对上面那张交换图的任意一个合并 D（即任意满足 h ∘ f = k ∘ g 的 D, h, k）、任意 b ∈ B、c ∈ C，只要在 D 里成立

h(b) ≤ k(c),

就存在 a ∈ A，使在原来的两块里成立

b ≤ f(a)　且　g(a) ≤ c.

这第二条叫 夹逼条件：在任何合并里冒出来的大小关系，都必须能在公共部分 A 里找到一个中间人作证。

量词位置：超合并最容易写错的地方

夹逼条件前面是「对任意合并 D」，不是「存在某个合并 D」。这个差别要命：若只要求存在一个，任何有合并的类几乎都能过关——只要挑一个让跨块关系尽量少的 D，夹逼前提就真空成立，条件自动满足。超合并之所以等价于插值，正因为它是全称的：无论怎么拼，都不许偷渡。习题 E11 专门练这一点。

夹逼条件为什么就是插值

把代数词换成逻辑词，逐项对照：

代数侧逻辑侧
b ∈ B（B 是加了私符号的公式代数）公式 φ
c ∈ C公式 ψ
A（公共子代数）共同语言 L(φ) ∩ L(ψ) 生成的公式集
h(b) ≤ k(c) 在 D 中⊨ φ → ψ
夹逼元 a ∈ A，b ≤ f(a) ≤ c插值式 θ，⊨ φ → θ → ψ

「a 落在 A 里」正是「θ 只用共同语言」。整张表逐行对齐，一个词都不差。这不是巧合，而是定理 4.4.24 的内容。

典型例子

布尔代数类有超合并。若 h(b) ≤ k(c) 在共同的扩张 D 里成立，布尔代数的分配格结构保证能在交 A 里找到夹逼元。这正好对应命题逻辑有 Craig 插值——两个事实是同一件事的两种说法。

本质例子

普通合并为什么不够？合并只要求 A 在两边「是同一块」，但拼的时候完全可以让 b 与 c 之间凭空冒出一条大小关系。超合并多要的那一条，是禁止这种凭空冒出——所有跨块关系都得由公共部分居中作证。这就是「插值」在代数里的原话。

边界与误解

偏序类有合并，却没有超合并。取 A = {0 < a}，B = {0 < a < b}，C = {0 < a < c < d}，公共部分都是 A。把 B 与 C 沿 A 拼，可以得到不同的合并。取其中一个 D = {0 < a < b < c < d}——合并成功，D 仍是偏序。但在这个 D 里 b ≤ c，而 A 里只有 0, a，b ≤ a 不成立：夹逼元不存在。既然夹逼要求对所有合并成立，这一个反例就判了超合并失败。按定理 4.4.24，这意味着「以全体偏序为代数语义的逻辑」缺乏插值。D 里那条 b ≤ c 就是偷渡进来的信息。

反过来若取 b 与 c 不可比的那个合并，夹逼前提根本不触发，真空成立。可见「挑一个好的合并」救不了超合并——这正是量词必须是全称的原因。

来源：UAL §4.4.1–4.4.2（超合并与夹逼条件）；例中的偏序反例为说明性构造，用于展示「合并成功但超合并失败」的机制。

6定理 4.4.18 / 4.4.24：双向刻画 O4逻辑

现在把前三节拼起来。两个定理，一个管「能拼」，一个管「拼得干净」。

定理 4.4.18（合并 ↔ Robinson 联合一致性）

对逻辑 L = ⟨F, M, mng, ⊨⟩，其代数类 Algm(L) 有合并性质，当且仅当 ⊨ 有 Robinson 联合一致性。再由命题 3.4，这等价于 Craig 插值的弱化版。

定理 4.4.24（超合并 ↔ Craig 插值）

对同一逻辑，Algm(L) 有超合并性质，当且仅当 ⊨ 有Craig 插值性质。

技术注解：编号与精确陈述

本讲沿用大纲已核准的编号（UAL §4.4.1–4.4.2，定理 4.4.18、4.4.24）。教材原件最初以附件提供、未留在工作区，若你手头有全书，建议核一遍两条定理的精确假设。一般设定下常需补两条口径：①「代数类」取 Algm(L) 还是其对同构闭包，会影响陈述；②「嵌入」是否要求保全部结构（含 mng 指定的子集），不同口径下定理名字相同而内容强弱不同。但两座桥的形状是稳的：合并对应联合一致，超合并对应插值。

方向一：插值 ⟹ 超合并（证明的形状；严格细节见 UAL §4.4.2）。

给定图 B ← A → C。把 A, B, C 读成公式代数按各自语言作的商：b, c 是公式的等价类，公共部分 A 对应两种语言共有的公式。由命题 3.4，Craig 插值给 Robinson 联合一致性，于是两套理论可合成一个共同扩张——这就是合并，它保证合并至少存在一个。

现在验证夹逼的全称性。任取一个合并 D，设 h(b) ≤ k(c) 在其中成立。把 b, c 读回公式 φb, φc；Craig 插值给出共同语言里的 θ，使 ⊨ φb → θ → φc 在所有模型中成立。把 θ 读回 A 里的元素 a，由 θ 的语义有效性立刻得 b ≤ f(a)（在 B 中）与 g(a) ≤ c（在 C 中）。注意这两条不等式是在 B, C 里成立的，与挑了哪个 D 无关——这正是夹逼能对任意合并成立的原因。「θ 只用共同语言」保证 a 落在 A 里。∎

方向二：超合并 ⟹ 插值（证明的形状）。

给定 ⊨ φ → ψ。构造一张合并图：令 A 为公共语言 L(φ) ∩ L(ψ) 生成的公式代数，B 为加上 φ 一侧私符号后的代数，C 为加上 ψ 一侧私符号后的代数；f, g 是自然的包含嵌入。令 b 为 φ 在 B 中的语义值、c 为 ψ 在 C 中的语义值。

由合并性质，存在 D 与嵌入 h, k 把两块拼起来；由 φ → ψ 的有效性，在 D 里成立 h(b) ≤ k(c)。超合并的夹逼条件给出 a ∈ A 使 b ≤ f(a) ≤ c。把 a 读回公式，就是插值式 θ：它落在 A 里，所以只用共同语言；两条不等式给出 ⊨ φ → θ 与 ⊨ θ → ψ。∎

7应用：插值缺失的逻辑怎么改造 O5

定理 4.4.24 不只是「好看的等价」，它是一台诊断机：逻辑的病，可以在代数上看见；反过来，代数上的病，也能给出改造逻辑的路线。

诊断流程

发现某逻辑 L 没有插值 → 按定理 4.4.24，Algm(L) 的超合并失败 → 去看夹逼条件 b ≤ f(a) ≤ c 到底卡在哪一步 → 对号入座选下面的改造方案。

四条改造路线
  1. 换语言。把导致失败的私符号收进公共部分，或干脆限制到插值成立的语言片段。代价：表达力下降。这是最便宜的一招，也是实践中最该先试的一招。
  2. 换语义。从 Algm(L) 换到 Alg⊨(L)，把具体模型抽象成类。代价：丢掉 L20 强调的「模型身份」，可定义性问题会变味。先想清楚你要的是插值还是可定义性。
  3. 降要求。放弃 Craig 插值，退到 Robinson 联合一致性（对应普通合并）。很多逻辑没有插值但仍有联合一致性——后者对「理论能否合并」往往已经够用。
  4. 加定义。把想要的东西作为新符号显式加进语言，再用公理约束（Beth 路径）。代价：语言膨胀，但保留了插值的骨架。
典型例子

命题逻辑、一阶逻辑、直觉主义逻辑、模态 S4 都有 Craig 插值。它们的代数类都有超合并，所以上述改造一条都不用上。这组「成功名单」是判断新逻辑时的参照系。

本质例子

有限群类为什么不能做「有限逻辑」的语义？它的合并已经失败（拼出的 D 通常无限），更别提超合并。本质教训：一旦把语义类卡在「有限」上，紧致性与插值会同时塌方——这正是 L18 里「有限性不可一阶公理化」的同一个病根。

边界与误解

偏序例子（§5）演示了最阴险的一种失败：合并成功、超合并失败。这种逻辑看起来「理论都能合起来有模型」，却写不出插值式。诊断要点：只看合并会误判为健康，必须查夹逼条件。对应到改造，路线 3（退到 Robinson）在这里无效——因为合并本来就成立——只能走路线 1 或 4。

来源：UAL §4.4.2（插值缺失的例子与改造讨论）；L18 有限性不可公理化；L20 Beth 路径。

8三件工具同时上场；四座桥对照 O6

四座桥走完，把它们的模板并排钉在一起看，会发现每一座都是「一个逻辑性质 ↔ 一个代数性质 ↔ 一个拓扑性质」的三端结构，但发动机不同。

桥逻辑侧代数侧拓扑侧主发动机
L18紧致性对超积封闭超滤子收敛超积 + Łoś
L19完全性簇 / 有限基紧致化Henkin + Birkhoff
L20可定义性同态满射T0 可分不可区分关系
L21插值超合并沿公共部分粘合夹逼条件 + 三工具合用
为什么第四座最难

前三座每座只用一台主发动机：紧致性、Henkin、不可区分。第四座要三台一起开：紧致性把无穷压成有限，有限证明把有效变成可计算，可定义性把隐含变成显式。少了任何一台，定理 4.4.24 的某一端就接不上。

但回报也最大：插值同时是 Beth 定理的引擎（L20）、是完全性证明的副产品（L19）、也是紧致性的近亲（L18）。它把前三座桥焊成了一个整体——这就是为什么把它放在桥定理这一篇的最后一讲。

一处温和的提醒

「超合并」这个名字在不同文献里口径不完全一致，有的要求嵌入保序、有的还要求保补、有的区分强 / 弱版本。读文献时先对齐定义，再谈等价——定理 4.4.24 的证明对口径敏感，但「夹逼元 = 插值式」这个核心图像对所有版本都成立。

来源：UAL §4.4（整合）；前三桥回指 L18 §9、L19 §9、L20 §9。

把这座桥记成一句话

「能插一句共同语言的话」在代数里叫「超合并时夹逼元落在公共子代数里」，在拓扑里叫「沿公共部分粘合不偷渡信息」；把它们焊在一起的是「公共部分恰好是交」这一个条件。

四座桥走完，你已经有一整套词典：紧致、完全、可定义、插值，各自在逻辑 / 代数 / 拓扑三侧的名字都能对上。下一讲 L22 走第五座桥——判定性与 Gödel 不完全性，那是全课的收尾：把「译过去 → 用代数解 → 译回来」这条方法论反过来用，看有限基问题的不可解怎样变成逻辑的不可判定。
