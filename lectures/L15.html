0概念清单与依赖关系（简）

前十四讲我们一直在用各种逻辑：命题逻辑、模态逻辑、一阶逻辑、S4。它们看起来毫无关系。本讲做一件很机械的事：给「逻辑」规定一个统一接口。接口定好，后面的代数机器才有东西可接。

2动机：先做接口，再谈代数

它解决什么问题

UAL 一开始就拿 C++ 打比方。定义一门语言分两步：先说哪些字符串是合法程序，再说这些程序跑起来会干什么。第二步又拆成两小步——先说清楚有哪些可能的机器，再说每个程序在每台机器上跑出什么。

逻辑也一样。但我们要的不是「讲清楚某一个逻辑」，而是「讲清楚逻辑这类东西长什么样」。因为后面要给逻辑做代数化，而一台机器不可能对着无数种各自为政的定义工作。得先把它们削成同一个形状。

UAL 给出的形状是四元组 L = ⟨F, M, mng, ⊨⟩。它有两个旋钮可以单独拧：换公式那一份，或者换模型那一份。拧一拧，命题逻辑、S5、difference logic、arrow logic、一阶逻辑、带「不可数多」量词的逻辑，全从同一个模子里出来。

        公式 F                     模型类 M
        （语法）                    （语义环境）
           │                          │
           │   mng(φ, M)              │
           └──────────┬───────────────┘
                      │
                 意义（集合）
                      │
                  ⊨ 挑选「真」
                      │
               语义后承 ⊨ ⊆ P(F) × F

       UAL 图 3.1 的「扇形结构」：
       一个公式对着许多模型，每个交点给出一个意义。
先说清楚一件事：这个框架不是「逻辑哲学」

它不回答「逻辑究竟是什么」这种问题。它只规定：如果你想要本书后面的定理用在你身上，你至少得交出这四样东西。交不出来也没关系——UAL 专门说明了怎么把纯语法的证明系统改造成这个形状（下面 §8 的伪模型构造）。

所以别把它当成本体论声明。它是一个接口规范。

3逻辑的四元组 O1

定义 3.1.3（逻辑）本讲的核心

一个逻辑 L 是有序四元组

L = ⟨FL, ML, mngL, ⊨L⟩

其中：

(i) FL 是公式集，要求是某个字母表 X 上的有限字序列之集，即 FL ⊆ X*。

(ii) ML 是（可以是真类的）模型类。

(iii) mngL : FL × ML → Sets 是意义函数。

(iv) ⊨L ⊆ ML × FL 是有效性关系，写作 M ⊨L φ。

(v) 对一切 φ, ψ ∈ FL 与 M ∈ ML：

mng(φ, M) = mng(ψ, M)  且  M ⊨ φ  ⟹  M ⊨ ψ

这条叫式 (3.1)。它是整个框架唯一的技术性约束，看起来平淡，实际上把「真」拴在了「意义」上。

每个部件在干什么

F 是「能说什么」；M 是「可能在什么场合说」；mng 是「这句话在这个场合指什么」；⊨ 是「这句话在这个场合算不算真」。

为什么 mng 是核心。UAL 特意拿它跟 Tarski–Givant 的 formalism 比较：那边只有 ⟨F, M, ⊨⟩，可以把 mng(φ,M) 草草设成 TRUE/FALSE。但那会把量词逻辑挡在门外。一阶逻辑里 φ(x) 在一个模型中的意义不是一个真值，而是满足它的赋值之集。没有 mng，你连「一个开出公式指什么」都说不出来，更别说把它代数化。

为什么有式 (3.1)。如果两个公式在同一个模型里意义相同，那么它们在该模型的真假必须一致。没有这条，「真」就可以任意指派，跟意义脱钩，后面的代数化就无从谈起。注意它只要求一个方向：意义相同 ⟹ 真假相同；不要求反方向。两个意义不同的公式完全可能同真。这一点在边界例里会用到。

例 3.1.1：一阶逻辑的规范表示

相似类型 t、变量集 V 的一阶逻辑写成

LFOL = ⟨Fmlt(V), ⊢, Modt, mngFOL, ⊨⟩

其中意义函数是

mngFOL(φ, M) = { k : M ⊨ φ[k] }

即所有使 φ 在 M 中成立的赋值 k 的集合。

这就是 UAL 跟别家最大的不同。把 k 收进 mng，量词就变成了「对赋值集合做的操作」，于是整个一阶逻辑也能进代数机器。L06 讲 BAO、后面 L23 讲关系代数时，靠的都是这一步。

典型例子

命题逻辑：字母表是命题字母 P，公式是 P ∪ {⊥} 经 ∧, ¬ 生成的字；模型是赋值；意义是真值。这是最贴合直觉的情形，先拿它校准定义。

本质例子

一阶逻辑：mngFOL(φ, M) 是赋值集合而不是真值。对开公式 R(x,y)，同一个模型里有些赋值满足、有些不满足——只有把它收成集合，意义函数才装得下这个差异。这才是 mng 存在的理由。

边界与误解

① 定义要求 F ⊆ X*，所以无穷语言被挡在外面。UAL 明说这是技术上的方便，不是原则限制：Lκ,λ 那类无穷语言稍作修改也能处理。

② M 可以是真类。一阶逻辑的所有模型就不是集合。后面在模型类上做超积时，这是在类上取积，不能照搬集合上的构造。L18 把 L13 的紧致性搬到逻辑侧时，这一层必须重新交代。

③ 式 (3.1) 不是「⊨ 由 mng 定义」。UAL 明说不要求 ⊨ 可从 mng 定义出来；只要求这条单向的相容性。把两者搞混，就会误以为真值语义是唯一选择。

来源：UAL 定义 3.1.3、式 (3.1)、定义 3.1.1 前的讨论、例 3.1.1、注释 2–4；Tarski–Givant 的 formalism 比较段（§3.1 第 104–105 页）。

4后承、Mod、Csq 与 Th O2

定义 3.1.5 / 3.1.6 四个标准记号

设 L = ⟨F, M, mng, ⊨⟩，Σ ⊆ F，K ⊆ M。

M ⊨ Σ  ⟺  对每个 φ ∈ Σ 有 M ⊨ φ
Mod(Σ) = { M ∈ M : M ⊨ Σ }
Σ ⊨ φ  ⟺  Mod(Σ) ⊆ Mod({φ})
Csq(Σ) = { φ ∈ F : Σ ⊨ φ }
Th(K) = { φ ∈ F : 对所有 M ∈ K，M ⊨ φ }

Th(M) 叫 L 的有效式集（重言式集）；Th({M}) 简写为 Th(M)。

注意 ⊨ 被用了两次：一次是 M ⊨ φ（模型与公式之间），一次是 Σ ⊨ φ（公式集与公式之间）。UAL 说希望这不会造成歧义——看左边是模型还是公式集就知道。

它解决什么问题

这四个记号把 L02 那套 Galois 连接整个搬了过来。Mod 从公式集到模型类，Th 从模型类到公式集，两者构成一对反变 Galois 连接：

Σ ⊆ Th(K)  ⟺  K ⊆ Mod(Σ)

而且 Th ∘ Mod 与 Mod ∘ Th 都是闭包算子。L02 讲的所有性质这里原封不动成立——那一次的「闭集」是代数子集，这一次的「闭集」是理论。本讲不做重复证明，但你要能自己认出来。

把 K = Mod(Σ) 代进去，得到

Csq(Σ) = Th(Mod(Σ))

这一行是本讲最有用的等式：语义后承 = 「先取 Σ 的所有模型，再取这些模型共同满足的东西」。它把「推出」变成了「取公共部分」。

例：在命题逻辑里算一次

令 Σ = {p, p → q}。则 Mod(Σ) 是所有让 p 真且 q 真的赋值。Th(Mod(Σ)) 包含 q、包含 p ∧ q、也包含 p ∨ r——凡是所有这类赋值都满足的都在里面。

注意 r 不在里面：有赋值让 p,q 真而 r 假。「共同满足」这四个字在干活。

典型例子

Th(∅) = Th(M) 是所有重言式；Mod(∅) = M。空假设给出最大的模型类、最小的理论，和 L02 的 Galois 连接完全同向。

本质例子

Csq(Σ) = Th(Mod(Σ))。在可满足性问题里，Σ ⊨ φ 等价于 Σ ∪ {¬φ} 不可满足，即 Mod(Σ ∪ {¬φ}) = ∅。「推出」被翻译成「模型类空」——这正是 L13 紧致性定理能兑现为「有限可满足 ⟹ 整体可满足」的入口。L18 会把它讲透。

边界与误解

① Th(K) 和 Csq(Σ) 的键不同：前者键是模型类，后者键是公式集。Th(M) = Csq(∅) 只在 K = M 时重合。别混用。

② Galois 连接给出的是闭包，不是内部。Th(Mod(Σ)) ⊇ Σ，永远只会变大。想变小要靠假设，不是靠闭包。

③ UAL 练习 3.2.4 问过一个尖锐的问题：当命题字母集 P = ∅ 时，|F| 与可公理化模型类 |{Mod(Σ) : Σ ⊆ F}| 各是多少？答案是有限个小数字；P 无限时后者也只有连续统那么多。这说明「模型类的丰富度」是被语言卡住的。

来源：UAL 定义 3.1.5（Mod、有效式、⊨、Csq）、定义 3.1.6（Th）、例 3.2.4；L02 Galois 连接与闭包算子。

5经典命题逻辑的两副样子 O3

例 3.2.1 集合语义版 LS0

取命题字母集 P，连接词 {∧, ¬, ⊥}。公式集 FS 是满足下列条件的最小集：

P ∪ {⊥} ⊆ H  且  φ, ψ ∈ H ⟹ (φ ∧ ψ), ¬φ ∈ H

模型类：

MS = { ⟨W, v⟩ : W 是非空集，v : P → 𝓟(W) }

意义函数按结构递归，每一步都是集合运算：

mng(p, M) = v(p),   mng(φ ∧ ψ, M) = mng(φ, M) ∩ mng(ψ, M)
mng(¬φ, M) = W − mng(φ, M),   mng(⊥, M) = ∅

有效性：M ⊨0S φ ⟺ mng(φ, M) = W。

证明系统 ⊢0S 可以给一组公理加分离规则 {φ, φ → ψ} ⊢ ψ，其中 φ → ψ 是 ¬(φ ∧ ¬ψ) 的缩写。UAL 紧接着就说了：这部分可以先不管，后面不依赖它。

例 3.2.3 模态式写法 LS

同样的 FS 和 MS，但改用强制关系 w ↣v φ：

w ↣v p ⟺ w ∈ v(p);   w ↣v ¬ψ ⟺ 非 w ↣v ψ
w ↣v (ψ1 ∧ ψ2) ⟺ 两者都成立

然后 mngS(φ, ⟨W,v⟩) = { w ∈ W : w ↣v φ }，⟨W,v⟩ ⊨S φ ⟺ 对所有 w ∈ W 有 w ↣v φ。

两种写法给出同一个逻辑。集合版把 W 当成一个整体来算；模态版把 W 拆成点，逐点判定再收成集合。后者是前者的「展开」，展开之后才好挂模态连接词——下一节全是这个套路。

练习 3.2.2 真值函数版 LS1

再换一副样子：模型直接是函数 M : P → {0,1}，意义函数取值在 {0,1} 里，mng(¬φ) = 1 − mng(φ)。

UAL 让你验证：LS0 与 LS1 有相同的语义后承关系，也有相同的有效式集。

这说明了什么：mng 的值域可以变（集合 vs 真值），⊨ 的内部机制可以变（等于 W vs 等于 1），只要最后诱导出的 ⊨ ⊆ 𝓟(F) × F 一样，两个逻辑在「后承」这个层面上就是等价的。别把「看起来不同」当成「逻辑不同」。

典型例子

p ∧ ¬p 在任一模型里意义为 v(p) ∩ (W − v(p)) = ∅，不等于 W，所以无效。集合运算自己就把矛盾律算出来了，不用查真值表。

本质例子

mng(φ ∧ ψ, M) = mng(φ, M) ∩ mng(ψ, M) 这一行是整个代数化的第一块砖：连接词变成了集合代数上的运算，意义函数变成了从公式代数到集合代数的同态。L16 的组合性定义就是把这条规律一般化。

边界与误解

① 为什么要求 W 非空？若允许 W = ∅，则 mng(φ, M) = ∅ = W 对一切公式成立，所有公式在这个模型里都有效。一个空模型把逻辑炸成了平凡逻辑。

② 「等价」不等于「相同」。LS0 与 LS1 的模型类根本不是同一个东西，只是后承关系与有效式集相同。UAL 后面到处用这种「在某方面等价」的说法，每次都要问是哪方面。

③ 别小看 P 这个参数。UAL 说 LS 严格讲是 LS(P)；P 空、单点、无限时公式集的基数不同，可公理化模型类个数也不同。大部分时候这个参数不重要，但做题时它会突然重要。

来源：UAL 例 3.2.1（LS0 全部定义）、例 3.2.3（LS 模态式）、练习 3.2.2（LS1 与等价性）、例 3.1.1。

6旋钮一：固定模型，换连接词 O4

它解决什么问题

命题逻辑很弱。一阶逻辑很强，但要从 LS 走到一阶逻辑，得连模型类、原子公式、变量一起大改——那是大手术。有没有办法只加连接词就把表达力提上去？

有。而且 UAL 一口气给了六七个。它们的模型类全都是 MS，原子部分也全一样，差别只在一条新连接词的语义子句。这是本讲最值得你看的一组例子：它把「逻辑的表达力」变成一个可以直接拧的旋钮。

固定不动的部分

所有下列逻辑都取 M = MS，即模型仍是 ⟨W, v⟩，W 非空、v : P → 𝓟(W)；布尔连接词 ∧, ¬, ⊥ 的含义不变。有效性的定义也不变：⟨W,v⟩ ⊨ φ ⟺ 对所有 w ∈ W，w ↣ φ。

变的只有：公式里多出什么符号，以及 w ↣ 多出哪一条。

一张旋钮图谱 UAL §3.2 的示例序列
逻辑新连接词新增语义子句直觉
LS（例 3.2.3）无—此处此刻
S5（例 3.2.5）♦w ↣ ♦φ ⟺ ∃w'∈W : w' ↣ φ某处
Difference LD（例 3.2.7）Dw ↣ Dφ ⟺ ∃w'∈W−{w} : w' ↣ φ别处（some-other-time）
κ-times（例 3.2.8）♦κ∃H⊆W, |H|=κ, ∀w'∈H : w' ↣ φ有 κ 个地方
At-two-other-places（例 3.2.10）♪（二元）∃u,z∉{w}, u≠z : u ↣ φ 且 z ↣ ψ两个别处各占一处
More-often（例 3.2.12）≻（二元）|{u:u↣φ}| ≥ |{u:u↣ψ}|φ 比 ψ 更常成立
三个要算的细节

① κ-times 的两端。κ = 0 时 ♦0φ 永真（取空集），这个逻辑等价于 LS；κ = 1 时等价于 S5；κ = 2 有个名字叫 Twice logic，记作 Tw。

② 可表达性。♦2 可以在 LD 里表达。UAL 反过来问「D 能不能在某个 Ln-times 里表达」，把答案留作思考。这个不对称本身很有意思：能表达对方的逻辑，表达力不一定互相对等。

③ More-often 是个怪东西。w ↣ φ ≻ ψ 的真假完全不依赖 w，只比较两个集合的基数。它不像通常的模态算子那样只看 w 的可达点。但 UAL 照样把它放进四元组——这说明框架对「什么样的连接词」几乎不挑食。

典型例子

S5 的 ♦φ：只要 W 里有一个点满足 φ 就算。这就是模态逻辑最熟悉的「可能」，先拿它理解「换连接词」这一步。

本质例子

Difference logic：它和 S5 的唯一区别是 w' 不能等于 w。一个「≠」就造出一个不同的逻辑，而且这个逻辑在时序推理里有专门名字（some-other-time）。这说明表达力的差别可以小到一个符号，但后果是实质性的。

边界与误解

① 把 ♦2 和 ♦3 都加进去，不等于 L3-times。UAL 练习 3.2.9(3) 特意提示「No」。 多个连接词的合力不一定等于单个更一般的连接词——因为可表达性是「语义力量」，不是「符号清单」。

② 模型不变，不代表逻辑不变。所有这些例子的 M 一模一样，但 Csq 不同。是连接词决定了你能对同一批世界问什么问题。

③ UAL 练习 3.2.20 的三个结论值得记：L1 在某种意义下等价于 S5；LD 和 L2-times 都能跟 L2 比较；且两者严格弱于 L2。注意「在什么意义下」这五个字——UAL 让学生自己定义。

来源：UAL 例 3.2.5、3.2.7、3.2.8、3.2.10、3.2.12 及练习 3.2.9、3.2.11、3.2.13、3.2.20。

7旋钮二：固定公式，换模型 O5

它解决什么问题

第一个旋钮动了公式，模型没动。第二个旋钮反过来：公式一样，把模型类改一改，逻辑就变了。UAL 用 arrow logic 做了整组对照，然后把它接到一阶逻辑的各种变体上。

这件事在逻辑史上很重要：很多看起来是「逻辑系统不同」的争论，其实只是背后允许的模型类不同。把它写清楚，争论就能定位。

Arrow 逻辑家族（例 3.2.14 / 3.2.15 / 3.2.17）公式不变，模型收紧

连接词统一是 {∧, ¬, ⊥, ◦}，后来再加 {⁻¹, Id}。◦ 读作复合，语义是「中间能找到一个转接点」：

⟨a,b⟩ ↣ φ ◦ ψ  ⟺  ∃c : ⟨a,c⟩, ⟨c,b⟩ ∈ W 且 ⟨a,c⟩ ↣ φ, ⟨c,b⟩ ↣ ψ
逻辑模型类差别
LPAIRW ⊆ U × U世界是有序对，但不必填满
LSQRW = U × U唯一区别：要求「方形」
LARW0⟨⟨W,v⟩, C1, C2, C3⟩三个任意可达关系，C1⊆W³, C2⊆W², C3⊆W
LARROWMPAIR加 φ⁻¹（反转对）与 Id（a=b）
LRELMSQR同上，但模型是方形

练习 3.2.18 给了一个很干净的对照：把 LARW0 的 ⁻¹ 和 Id 去掉后，它与 LPAIR 有相同的后承关系；但它与 LARROW 不等价。多加两个连接词，后承就变了。

一阶逻辑及其变体（例 3.1.1、3.2.19、3.2.27、3.2.28、3.2.34）

Ln（n 个变量的一阶逻辑）：变量只有 v0,…,vn−1，原子公式固定写成 ri(v0…vn−1)。模型是 ⟨M, Ri⟩，Ri ⊆ nM。意义函数依然是赋值集：

mngn(φ, M) = { q ∈ nM : M ⊨ φ[q] }

Lvd（变量依赖）：公式集与普通一阶逻辑相同，模型多带一个容许赋值集 W ⊆ ωM，量词只能在 W 里找见证。同一套公式，改变「哪些赋值算数」，逻辑就变了。

LQ（不可数多量词）：公式里加 Qxφ，读作「有不可数多个 x 使 φ」。模型类与普通一阶逻辑完全相同——只加了一个量词。

动态 arrow logic（例 3.2.34）：加 φ*，意义是「关系 φ 的自反传递闭包」。这是程序语义的标准做法，被塞进了同一个四元组。

典型例子

LPAIR 与 LSQR：公式集一模一样，唯一区别是模型要求 W ⊆ U×U 还是 W = U×U。就这一个「等号」，两个逻辑的后承不同。

本质例子

LARW0：把「复合」抽象成任意三元关系 C1(w,w1,w2)，把「反转」抽象成 C2，把「恒等」抽象成 C3。它把具体的「有序对 + 关系复合」升格成抽象的可达关系——这一步和 L05 从具体代数升到抽象簇是同一种动作。

边界与误解

① 「L1 等价于 S5」要说清是什么等价。UAL 练习 3.2.20(2) 特意加括号问「在什么意义上？」。是后承相同、可互相翻译，还是模型类之间有对应？三种说法强度不同。

② 换模型不等于换语义。Lvd 的模型类变了，但 ∧, ¬ 的含义没变。把旋钮分开拧，才看得清是哪一处造成了差别。

③ 别以为「公式相同」就没换语法。Ln 的原子公式固定为 r(v0…vn−1)，不允许写 r(v1…)。这不是限制，UAL 说可以用量词和等号表达出替换效果。

来源：UAL 例 3.2.14/3.2.15/3.2.17 及练习 3.2.18、例 3.2.19 及练习 3.2.20、例 3.2.27、例 3.2.28、例 3.2.34。

8为什么要规范化：通向 Alg(L) O6

它解决什么问题

到目前为止，四元组还只是个「登记格式」。真正的问题是：凭什么从一个逻辑能造出一个代数？UAL 的回答分三步，每一步都只用到已经登记好的那四样东西。

第一步：公式集本来就是代数（定义 3.3.1）

给出原子公式集 P 和连接词集 Cn，公式集 F 是最小满足 P ⊆ F 且对 Cn 封闭的集合。用 L05 的话说，F 就是 P 生成的绝对自由代数：

F(P, Cn) = ⟨F(P,Cn), c𝔉c∈Cn⟩

连接词是运算符号，原子公式是生成元。公式代数不需要额外构造，它已经在那里了。

一个陷阱：UAL 明说，从集合 F 本身不能唯一恢复 P 和 Cn。同一个公式集可以配不同的原子集与连接词集。所以要写 F(P,Cn)，不能只写 F。

第二步：组合性（定义 3.3.2，式 (3.2)）Frege 原则的精确版

L 是组合的，若对每个 k 元连接词 c、所有 φi, ψi ∈ F 与 M ∈ M：

⋀i=1k mng(φi, M) = mng(ψi, M)  ⟹  mng(c(φ⃗), M) = mng(c(ψ⃗), M)

说人话：子公式意义相同，复合公式意义就得相同。不许偷偷看子公式的「长相」。

翻译成代数是什么

固定 M，记 mngM = ⟨mng(φ,M) : φ ∈ F⟩。式 (3.2) 说的是：mngM 的核是公式代数 F 上的一个同余关系；等价地，mngM 是从 F 到某个集合代数的同态。

这一步是整本书的枢纽。「语义由部分决定」这句哲学口号，一旦写严，就变成了「语义映射是同态」。后面所有代数化，都是这句话的展开。

第三步：取商，得到 Lindenbaum–Tarski 代数

定义 F 上的关系：

φ ∼L ψ  ⟺  对所有 M ∈ M，mngM(φ) = mngM(ψ)

在组合逻辑里 ∼L 是同余，于是有商代数

F(L) = F / ∼L

叫重言式公式代数或 Lindenbaum–Tarski 代数（L06 已经用过这个构造）。

注意商掉的是什么：在所有模型里意义都一样的公式，被认成同一个元素。这是「逻辑等价」的代数版本。

一个必须交代的绕路：⊢ 去哪了

定义 3.1.3 是四元组，没有 ⊢。但逻辑当然有证明系统。UAL 的态度很干脆：

凡是关于 ⊨ 证明的定理，只要不涉及 ⊨ 与 ⊢ 的关系，都能原样搬到 ⊢ 上。所以先不带 ⊢ 走，到完全性定理那种必须谈两者关系的地方，再把它请回来。这不是遗失，是刻意减负。

纯语法逻辑 Lsyn = ⟨F, ⊢⟩ 也能装进四元组。若能表达 ↔，取

M⊢ = { T ⊆ F : T 对 ⊢ 封闭 }
mng⊢(φ, T) = { ψ ∈ F : T ⊢ (φ ↔ ψ) },   T ⊨⊢ φ ⟺ φ ∈ T

这样造出的 L⊢ 满足式 (3.1)，且它诱导的后承恰好是原来的 ⊢。若连 ↔ 都表达不了，UAL 的 Remark 3.1.2 给了一个带同态 h : F → F 的备用构造：把模型改成 ⟨T,h⟩，mng(φ,⟨T,h⟩) = h(φ)，⟨T,h⟩ ⊨ φ ⟺ h(φ) ∈ T。

结论：四元组不是只对「已经语义化」的逻辑管用。纯证明系统也能塞进去，塞法就在上面两行里。

典型例子

经典命题逻辑的 F(L) 是自由布尔代数。φ ∼ ψ ⟺ φ ↔ ψ 是重言式；商掉之后剩下的就是布尔代数。L06 的 Stone 表示从此有了来源。

本质例子

一阶逻辑开公式的 F(L) 不是纯布尔代数，而是带量词算子的 BAO（L06）；更精确地说，是自由维数限制柱形代数。为什么必须是开公式？因为只有把赋值收进 mng，∃v 才表现为作用在集合上的一个运算。语句代数做不到这一点——它会丢掉量词的结构。

边界与误解

① 从 F 读不出 P 与 Cn。前面说过。同一个公式集可以有多种原子/连接词分解，组合性是对某个分解而言的。

② 一阶语句的 LT 代数是布尔代数，但未必自由。UAL 特意区分了「开公式的 LT 代数」与「语句的 LT 代数」。 别把它们当成一个。

③ 这里还没有 Alg(L)。本讲只造出 F(L)；「一个逻辑对应哪个代数类」是 L16 的定义 3.3.3。先把料备齐，别抢跑。

来源：UAL §3.3.1（定义 3.3.1）、§3.3.2（定义 3.3.2、式 (3.2)、∼L、F(L)）、§3.1 Remark 3.1.2（伪模型构造）；L05 自由代数、L06 Lindenbaum–Tarski 代数与 BAO。
