逻辑的推广与新种类

前面三十讲一直在问「这个逻辑能不能代数化」。这一讲改问：把可代数化的条件一条条拆掉，框架会不会塌？答案是它比想象中结实——主题变元可以不要（换成部分运算），滤子性质可以不要（换成相继式），连真值都可以不是「最大意义」。最后老实交代这套框架真正的缺口：多排序

本讲新概念（九个，按依赖排序）
  1. 半 nice 逻辑：组合性 + 滤子性质 (i) + 句法代入性，删掉「主题变元 εj, δj」那条（定义 6.1.1(i)）。
  2. 半可代数化：半 nice 再加语义代入性（定义 6.1.1(ii)）；对应的一般逻辑版本见 (iii)。

2动机：拆脚手架，看框架还剩什么 O1

L16 定义「可代数化逻辑」时立了几根柱子：组合性、滤子性质、句法代入、语义代入、还有一组把「有效」翻译成等式的主题变元 εj, δj。前三十讲一直在这套条件下工作。第 6 章换了个实验方法：一次拆掉一根柱子，看哪根是真的承重墙。

直觉 · 三条拆法，三种回报
  1. 拆主题变元。原来靠 εj(φ)=δj(φ) 编码「φ 有效」。拆掉后用什么？答案是给代数加一个部分运算 c：c(φ)=φ 当且仅当 φ 有效，否则不定义。有效性被编进了「有没有定义」这件事里。这一拆得到 半 nice / 半可代数化（§6.1）。
  2. 拆滤子性质。有效性不再对所有公式定义，只放到相继式 (φ ⇒ ψ) 上，读成「φ 的意义含于 ψ 的意义」。代数侧要补一个偏序 ⩽；若再把有效性限到成对的 (φ⇒ψ), (ψ⇒φ)，连偏序都不必加。
  3. 不拆，而是换 paradigm。§6.2 的三个逻辑来自完全不同的研究传统：模糊/多值语义、相关逻辑、量子力学里的「无意义陈述」。它们要检验的是：这套框架是不是只配处理「乖」的经典逻辑？结果是三个都能装进来。
别把「推广」读成「前三十讲白学了」

第 6 章的推广是保守的：nice 逻辑仍是半 nice 逻辑的特例，εj(φ)=δj(φ) 的位置换成了 c(φ)=φ，定理 3.3.23、4.1.5 的形式只需自然修改就搬得过去（教材练习 6.1.4(2)(4)(5) 就是让你逐个验证）。真正搬不过去的地方，教材也明说了——我们到 O5 会看见。

3半 nice 逻辑：主题变元退场 O2

定义 6.1.1（UAL 原编号）

设 L = ⟨F, M, mng, ⊨⟩ 是定义 3.1.3 意义下的逻辑（即 L15 的四元组）。则：

  1. L 半 nice（semi-nice / semi-algebraizable 的弱版）当且仅当：组合性 + 滤子性质 (i) + 句法代入性。
  2. L 半可代数化当且仅当它半 nice 且还有语义代入性（定义 3.3.10）。
  3. 把定义 3.3.27(1) 里的「nice 逻辑」换成「半 nice 逻辑」，得到半 nice 一般逻辑；「可代数化」同样换，得半可代数化一般逻辑。

被拆掉的是定义 3.3.18 里的条件 (ii)：存在导出联结词 εj, δj（j < m）把有效性翻成等式。其余原封不动。

典型 · 差一条是什么感觉

把 L16 的定义表抄成两栏看更清楚：

条件nice / 可代数化半 nice / 半可代数化
组合性要要
滤子性质 (i)要要
句法代入性要要
语义代入性要（可代数化）要（半可代数化）
εj, δj 存在（条件 ii）要不要（改用 c）

差别就这么一行。但这一行牵动全局：整个 Alg⊨ / Algm 的定义都要重写成带 c 的版本，等式对应的公式也从 εj(φ)=δj(φ) 变成 c(φ)=φ。架构没变，接口换了。

来源与背景：教材指出，即便不要求句法代入性，半 nice 逻辑也已有人研究（文献 [35]），但那里把 ⊨ 限制在只有一个 Δi、公式形如 (φ Δ0 ψ) 的窄范围内。第 6 章做的是把它推广到所有公式——这就是 L16 那套理论向半 nice 逻辑的平移。

4部分运算 c 与矩阵语义 O3

这一节是全讲技术核心：怎么在没有主题变元的情况下，把「有效」这件事编码进代数。

定义 6.1.2 · Alg+⊨(L) 与 Alg+m(L)

设 L = ⟨F, M, mng, ⊨⟩ 组合，K ⊆ M。定义部分函数 cK : F → F：

若 K ⊨ φ，则 cK(φ) 有定义且 cK(φ) = φ；　若 K ⊭ φ，则 cK(φ) 无定义.

于是 ⟨F, cK⟩ 是部分代数；定义 3.3.3 的 ∼K 不只是 F 上的同余，也是 ⟨F, cK⟩ 上的同余（cK 就是这么定义的，为的就是这件事）。于是

Alg+⊨(L) = I{ ⟨F, cK⟩/∼K : K ⊆ M }.

模型侧对称地做：在 A(M) = mngM(F) 上定义部分运算 c——若 M ⊨ φ 则 c(mngM(φ)) = mngM(φ)，否则无定义；记 A+(M) = ⟨A(M), c⟩，再令

Alg+m(L) = { A+(M) : M ∈ M }.
直觉 · 为什么用「无定义」而不是「取 0」

「φ 有效」是个元语言判断，不是公式的真值函数。硬要用全运算编码，就得给无效的 φ 指派某个值（练习 6.1.4(6) 试着令 cK(φ) = φ Δ0 φ），但教材明确警告：那样定理 3.3.5 会失效、定理 4.2.9 连改都改不过去。部分性的作用就是把「有效 / 无效」这一区分保留为「有定义 / 无定义」，不让它在代数运算里被抹平。教材举的现成例子：实数域里的逆 x ↦ x−1，0 处无定义。

部分代数：需要重新交代的几件事
  • 部分代数也是模型论意义下的模型（把 c 看成二元关系），所以 P、Up、Pr 都不必另定义；子代数要对 c 封闭：若 c 在 x 有定义，则 c(x) 也在子代数里。
  • 项 τ 在赋值 k 处有定义当且仅当每个子项都有定义；A ⊨ (τ = σ)[k] 当且仅当 τ, σ 都有定义且值相等。「两边都没定义」不算相等。
  • 准等式照常解释，准簇刻画照常成立：K 是准簇当且仅当 K = SPUp K = SPr K；簇则由等式定义。
本质 · 真值谓词 T：不用部分运算的等价写法（注 6.1.3）

若不想碰部分代数，加一个一元谓词 T(x)（T for truth）即可。仿照 cK 令 TK = {φ ∈ F : K ⊨ φ}；模型的代数对应物长成 ⟨A, T⟩，其中 A ∈ Algm(L)、T ⊆ A 满足

(∀φ ∈ F)　M ⊨ φ　⇔　mngM(φ) ∈ T.

教材说这条路与 c 那条「practically equivalent」，而且非常接近 Blok–Pigozzi、Czelakowski 所说的「矩阵语义」。c(φ)=φ 与 mng(φ) ∈ T 是同一个判断的两种写法：前者把「真」编码进运算的定义域，后者把「真」编码进一个指定的子集。这正是 L27 四步流程里 Algm 那一格在推广版里的样子。

推广后的翻译（教材 §6.1 末）

许多已证定理可以平移（把 Alg 换成 Alg+）：

⊨L φ　⇔　Alg+m(L) ⊨ c(φ) = φ　　（对照定理 3.3.23）

以及「Alg+⊨(L) 对 Up 封闭 ⇒ L 满足紧致性」（对照定理 4.1.5，即 L18 的桥之一）。唯一的接口变化：等式从 εj(φ)=δj(φ) 变成 c(φ)=φ。

再拆一步：相继式（§6.1 结尾段）

若连滤子性质都想丢，可以把 ⊨ 限制到相继式 (φ ⇒ ψ)——注意 ⇒ 不是对象语言联结词，而是元层次符号，相继式不是公式：

M ⊨ (φ ⇒ ψ)　⇔　mngM(φ) ⊆ mngM(ψ).

代价：代数侧要引入偏序 ⩽ 来编码 ⇒。好处：适用的逻辑更多、Algi(L) 里出现的代数种类更多。若再退一步，只保留成对的 (φ⇒ψ) 与 (ψ⇒φ)，连 ⩽ 都不必加（文献 [35] 做了不少；亦见 Blok–Pigozzi 的 k-演绎系统、Guzmán–Verdú 与 Font–Verdú 的一般相继式方法）。把这一条记牢：L31 的「拆条件」与 L28–L29 的「换模型类」是两种独立的自由度。

5三种新风味的逻辑 O4

§6.2 原文开门见山：这些例子的主要目的是显示「本框架能处理来自逻辑、语言学、计算机科学等不同范式的各种寻常外观之外的逻辑」。注意它们的来源根本不是代数逻辑内部。

定义 6.2.1 · 无限值逻辑 L∞

原子集 P 任意，联结词 ∧, ¬, ∨, →。模型集

M∞ = { f : P → [0, 1] },　　意义函数取值于意义的格

先算了「真值」 mnff（教材记号 mnf）：

mnf(p) = f(p)；　mnf(φ ∧ ψ) = min{mnf(φ), mnf(ψ)}；　mnf(¬φ) = 1 − mnf(φ)；
mnf(φ ∨ ψ) = max{mnf(φ), mnf(ψ)}；
mnf(φ → ψ) = 1　若 mnf(φ) ⩽ mnf(ψ)，否则　1 − (mnf(φ) − mnf(ψ)) = 1 − mnf(φ) + mnf(ψ).

关键是「意义」不是真值，而是下集：

mng∞(φ, f) = { x ∈ [0,1] : x ⩽ mnf(φ) },　　f ⊨∞ φ　⇔　mng∞(φ, f) = [0,1].

技术注（教材边界）：PDF 里 → 的 else 分支印成 1 − mnf(φ) − mnf(ψ)，中间有一个丢失的控制字符；按 Łukasiewicz 蕴涵的标准语义（且须保证值仍在 [0,1] 内），应读作 1 − (mnf(φ) − mnf(ψ))，即上文所写。此处按正确语义讲解，不沿用字面误植。

本质 · 为什么「意义 = 下集」这一招重要

如果直接把 mnf(φ)=1 当作「有效」，那只是换了个多值真值表，谈不上新东西。教材特意指出：真值不等于最大意义，甚至不等于某个单一意义。它用 |=1 做例子：令 f ⊨1 φ ⇔ mnf(φ) ⩾ 1/2，而这个新有效性可以从 mng 定义出来：

mnf(φ) ⩾ 1/2　当且仅当　mng∞(¬φ → φ) = mng∞(φ → φ).

也就是说 ⊨1 不是「意义等于 [0,1]」这种粗暴识别，而是两个意义相等。这就给了 O3 里 c(φ)=φ 一个预告：有效性总是靠「两个东西相等」来编码的，无论主题变元在不在。这是全讲最值得停下来想的一个设计。

典型 · L∞ 的「反常」与可代数化
  • 连直觉主义逻辑都证 ⊨ ¬(φ ∧ ¬φ)，但 L∞ 里不成立：φ ∧ ¬φ 的真值可以高达 1/2（取 mnf(φ)=1/2）。教材开了个冷玩笑：按这个理由可以叫它「辩证法逻辑」，但它不这么叫。
  • φ ↔ ¬φ 在某些模型里有效——直觉主义里也不可能。
  • 它仍然可代数化：取 ε0(φ) = (φ → φ)、δ0(φ) = φ、(φ Δ0 ψ) = (φ → ψ) ∧ (ψ → φ) 即可（定义 6.2.1 末）。反常的语义并不妨碍标准的代数翻译。

注 6.2.2：若去掉 ∧，就得用 Δ0 = →、Δ1 = ←；若把有效性改成 mnf(φ) > 0.9，就失去 niceness，但仍是 O2 的半 nice——注 6.2.2 明说这正是 §6.1 的用武之地。

定义 6.2.4 · 相关逻辑 Lr（文献中又叫 R-Mingle / RM）

从 L∞ 改三处：把 [0,1] 全换成有理数集 ℚ；mnf(¬φ) = −mnf(φ)；蕴涵改成分段函数

mnf(φ → ψ) = max{ −mnf(φ), mnf(ψ) }　若 mnf(φ) ⩽ mnf(ψ)；
　　　　　　　 = min{ mnf(φ), −mnf(ψ) }　否则.

其余同练习 6.2.3(4)（即 LQ 的版本）。于是 Lr = ⟨Fr, Mr, mngr, ⊨r⟩。

本质 · 相关逻辑在「治」什么病

练习 6.2.3(4c) / 6.2.5(3) 要求证明

⊭r p0 → (p1 ∨ ¬p1).

理由是 p0 与 (p1 ∨ ¬p1) 没有公共原子公式，彼此不相干，因此不该「相关地蕴涵」——这正是相关逻辑的动机。教材还让你证 ⊨r (φ → ψ) → (¬φ ∨ ψ) 但反向不成立（练习 6.2.5(7)），以及 ⊨r φ ∨ ¬φ 成立。与 L27 的 LREL 对照：那边是换语义类来制造可代数化失败，这边是换意义函数来精确控制「相干性」。

定义 6.2.6 · 部分逻辑 LP（Prior 提出，Ruzsa 推进）

联结词 ∧, ∨, ¬, N，其中 N 是强否定：N(φ) 意为「φ 要么无意义、要么为假」，即「并非如此 / 不是这个事实」。

MP = { f : f ∈ P{0, 1, 2} }.

三值 0, 1, 2 分别表示假、真、无定义。只要 2 不在 mngP(φ,f), mngP(ψ,f) 之中，∧, ∨, ¬ 按经典逻辑 LS 算；只要有一个是 2，三者全取 2（无意义会传染）。强否定单独定义：

mngP(N φ, f) = 0　若 mngP(φ,f) = 1；否则 = 1.
f ⊨P φ　⇔　mngP(φ, f) = 1.
动机 · 为什么需要「无意义」这个第三值

教材举了两个例子：「整数 2 是粉红色的」在这样的情境下可能不是「假」，而是根本无意义；哥本哈根诠释下的量子力学——当粒子只有位置概率分布时，问它的精确位置是无意义的。N 的存在让你能断言「φ 不是事实」而不预设 φ 有真值。这个逻辑直接来自物理哲学，却能被 L15 的四元组框架完整容纳。

边界 · LP 居然是 nice 的（练习 6.2.7(1) 的答案骨架）

教材提示取

ε0(φ) = N(φ ∧ ¬φ),　　δ0(φ) = φ,

再令 φ Δ0 ψ = N ¬(φ ↔ ψ) ∧ (u(φ) ↔ u(ψ))，其中 u(φ) ⇔ N(φ) ∧ N(¬φ) 表示「φ 无定义 / 无意义」。一个处理「无意义」的三值逻辑，照样有主题变元、照样 nice——这一事实和 L∞ 改阈值就掉到半 nice 放在一起看，很有意思：决定 nice 与否的不是「语义多怪」，而是「有效性能不能被干净地写成等式」。

6真正的缺口：多排序逻辑 O5

这是全书最诚实的一段话。作者在前言里写完 UAL 与抽象代数逻辑（AAL）、模型论逻辑、机构论的关系之后，说：

Preface 原文要点（逐句对照）
  • UAL 与 AAL 的分工：目标和方法非常接近；UAL 更看重语义方面和易应用性，AAL 更追求概念的优雅。
  • 本书的新意：给出了用原本的、非代入式的形式处理量词逻辑（如 FOL）的方法（这正是 L29 的排序版与非排序版之分）。
  • 与模型论逻辑、机构论的连接：来自语义方面的强调与对 FOL 的处理；§3.4 有详细比较。
  • 关键缺口：Perhaps the most important direction in UAL missing is the treatment of many-sorted logics.——「也许最重要的、UAL 尚未覆盖的方向，就是多排序逻辑的处理。」起点可看文献 [66] 与 [192]。
  • 为何重要：Many-sorted logics are more and more important in applying logic to other sciences，见 Halvorson [93]；同一文献也讲了代数逻辑在维也纳学派中的根源，以及本书副标题「Dedicated to the unity of science」的来历。
直觉 · 这个缺口我们其实早就撞见过
  1. L17 就发现：一阶语言想做「项代人」必须分排序，否则替换会错位；L28 的 L′n 里，替换原子 R(v1,v0) 与形式原子 R(v0,v1) 被同态对调而核不变——直接用单排序框架就炸。
  2. L29 的非排序版 Lrf 之所以要不紧致反例、要用 π(i)R 造弱 Beth 反例，根源也是「 substitution 与变量角色纠缠」。排序版 Lranked 能把 Gödel 完全性救回来，靠的就是把变量按可用序号分层。
  3. L30 里那个三排序语言 S, P, R（集合 / 对 / 关系）——用来给 Sir(BRA) 做伪公理化——本身就是一次临时多排序：作者脚注 5 还得教读者「若不熟悉多排序模型，可把它想成单排序 + 一元谓词 S/P/R」。连本书自己都在用多排序工具，却没把它纳入一般框架。

所以这个缺口不是「没提到」，而是「一直在外面帮忙、始终没被请进来」。

为什么这对「统一科学」要紧

前言把副标题 Dedicated to the unity of science 与多排序逻辑放在同一段，不是随手为之。用逻辑去组织别的科学时，对象天然分型：个体、量、函数、测量值、状态、时间片混在一个单排序论域里，代入规则就会失真。UAL 这套框架要真正成为「跨科学的逻辑基础设施」，多排序是绕不过去的一步。这是 L32 收束时要回答的问题的一半。

7前沿地图与下一讲 O6

把这一讲放到全课末尾看，它给出的不是终点，而是一张「哪些门还开着」的地图。

三条开放的线
方向现状（本讲 / 前讲证据）通向哪里
代数侧 推广半 nice、部分运算 c、矩阵语义 T、相继式偏序；Blok–Pigozzi / Czelakowski 有大量强结果与 AAL 的合流；k-演绎系统

本讲最重要的结论，一句话

代数逻辑框架的承重墙只有两样：组合性（意义由部分决定整体）与「有效性可编码为某种相等」。主题变元、滤子性质、经典二值真值，全是可以拆或更换的脚手架。拆完之后框架不塌——但多排序是另一回事，它不是一根可拆的柱子，而是地基少了一块。

给 L32 留下的三个问题
  1. 给定一类拓扑空间，它的逻辑是什么？反过来，给定一个逻辑，完备的空间类在哪里？（L23 Stone/Esakia 对偶的升级版。）
  2. 当空间复杂到 Borel 层级、可计算性、βω 这一带，代数化还能走多远？
  3. 三条线最终统一在什么之上？——回到 §0 的红线：闭包算子、Galois 连接、对偶性，还是「可编码为相等」这件事本身？

8三层例：典型 / 本质 / 边界 理解检验

典型 L∞ 的阈值实验：nice 与半 nice 的分界线

同一个 L∞，把有效性从 mnf(φ)=1 改成 mnf(φ)>0.9（练习 6.1.4(1) 甚至用 >0.9 的另一个版本：mnf(φ)>0.9），它就不再是 nice，却仍是半 nice（注 6.2.2）。为什么？因为「mnf(φ) > 0.9」不再是「意义等于最大元」这种能被主题变元整齐捕捉的等式，但仍可被 c(φ)=φ 的部分运算编码。这是理解「拆条件」最省力的例子：改动只在有效性一行，代价立刻反映在代数接口上。

本质 LP：无意义也能 nice

三值、无意义传染、强否定 N——从哥本哈根诠释来的语义，听起来比 L∞ 的阈值改动「怪」得多，可它是 nice 的（练习 6.2.7(1)：ε0(φ)=N(φ∧¬φ)、δ0(φ)=φ）。这个反差把判据钉死了：决定 nice 与否的是「有效性能否写成等式」，不是语义看起来多离谱。换句话说，框架关心的是翻译的结构，不是直觉的可接受性。这也解释了为什么 L27 里 LREL 会全盘失败——问题出在代入不保有效（结构坏了），不是出在语义「怪」。

边界 多排序：框架外的常客

把 L30 那个 S, P, R 三排序伪公理化再想一遍：作者得加脚注教读者「若不熟悉多排序模型，把它想成单排序 + 一元谓词」。这不是优雅的解决，而是绕行。L17 的排序缺口、L28 的 L′n 反例、L29 排序版与非排序版的分道扬镳，都是同一块地基缺口的症状。教材把它列为「最重要的缺失方向」，并且点明它恰是与 Halvorson、与「统一科学」副标题相连的那块。所有前面能拆的柱子都拆过了；这一块拆不掉，因为它根本还没立起来。
