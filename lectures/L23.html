2动机：为什么「点」偏偏是超滤子

它解决什么问题

抽象布尔代数 A = ⟨A, ∨, −, 0⟩ 的元素不是集合，里面根本没有「点」。可我们看命题逻辑时又非要有「可能世界」不可：一个公式在哪个世界成立？L06 给过一个答案——把超滤子当点，元素 a 对应含它的超滤子全体。当时只证明了这是嵌入。这一讲要追问两件更硬的事：为什么这个选择不是凑出来的，以及为什么它刚好把代数和拓扑变成同一个范畴的两面。

先看一个立场问题。给一个公式 φ，一个「可能世界」应当回答「φ 真不真」。但要算一个世界，你至少要满足三条朴素要求：

  1. 重言式必须真；矛盾式必须假。
  2. φ 真且 φ → ψ 真，则 ψ 真。
  3. φ 真且 ψ 真，则 φ ∧ ψ 真。

把这三条翻译成代数语言，就是「含 1、上闭、对 ∧ 封闭」——恰好是 UAL 引理 2.6.3(i) 的滤子定义。到这里还只是「立场」，不要求它决断一切：一个模棱两可的立场可以让 φ 和 −φ 都不置可否（这正是 L10 讲过的「既不可验证也不可证伪」）。

要得到一个世界，还得加一条：每个命题都得有个真值，不能骑墙。写成公式就是

φ ∈ F　当且仅当　−φ ∉ F.

这就是 UAL 引理 2.6.3(ii) 的超滤子刻画。所以超滤子不是从拓扑里借来的技术物件，它就是「一个不模棱两可的立场」的代数原文。再看 UAL 定义 2.6.2 怎么说：超滤子是「到二元代数 2 的满同态下 1 的同余类」。两种说法指的是同一个东西——一个世界就是一次取值，把每个元素判成 0 或 1，且保布尔运算。

这一步为什么值得慢慢走

「点 = 同态到 2」这句话后面 L24 还要再用一次：关系代数的表示，就是把抽象元素 ↦ 二元关系，也就是找一批「取值」。L26 的 locale 则走反方向——干脆不要点，只保留开集格。本讲是这两条路的岔口：我们先把点造出来、看清楚它靠什么成立，下一讲才知道「不要点」到底放弃了什么。

3超滤子与素理想定理 O1

定义 UAL 2.6.2 / 引理 2.6.3
  • A ∈ BA 的滤子是 1A 所在的同余类；超滤子是极大滤子，等价于某个满同态 A ↠ 2 下 1 的原像。
  • 等价刻画：F 是滤子当且仅当 1 ∈ F，且 a ∈ F, a ≤ b ⇒ b ∈ F，且 a, b ∈ F ⇒ a ∧ b ∈ F。
  • F 是超滤子当且仅当它是滤子且对每个 a：a ∈ F ⇔ −a ∉ F。
  • 理想是对偶概念：0 ∈ I、下闭、对 ∨ 封闭。I 素指 a ∧ b ∈ I ⇒ a ∈ I 或 b ∈ I。

在布尔代数里，「I 素」与「I 极大」等价，且 U = A − I 给出素理想与超滤子的一一对应。这是 Bergman 定义 2.40 前面那段话的核心，也是下面把「素理想」与「超滤子」混着用的依据。

定理 Bergman 2.41（素理想定理，L06 用过但没证）

设 L 是分配格，I 是理想，F 是滤子，且 I ∩ F = ∅。则存在素理想 P，使 I ⊆ P 且 P ∩ F = ∅。

证明（逐步，Zorn 引理）

第 1 步：摆出候选集。令 S = {J : J 是 L 的理想，I ⊆ J，J ∩ F = ∅}。显然 I ∈ S，所以 S ≠ ∅。按包含排序。

第 2 步：链有上界。取 S 中的一条链 C，令 J = ⋃C。理想三条逐条验：含 I 显然；若 x ∈ J、y ≤ x，则 x 落在链中某个 Jᵢ 里，故 y ∈ Jᵢ ⊆ J；若 x, y ∈ J，两者分别落在 Jᵢ, Jⱼ，由链的全序性可设 Jᵢ ⊆ Jⱼ，于是 x ∨ y ∈ Jⱼ ⊆ J。最后若 J ∩ F ≠ ∅，某个 Jᵢ 也交 F，矛盾。故 J ∈ S。

第 3 步：取极大元。Zorn 引理给 S 的极大元 P。它含 I、不交 F，只差证它素。

第 4 步：反证设素性失败。取 a, b ∉ P 而 a ∧ b ∈ P。造两个理想

J = {p ∨ x : p ∈ P, x ≤ a}　　K = {p ∨ y : p ∈ P, y ≤ b}.

第 5 步：它们真是理想，且真大于 P。以 J 为例：对 ∨ 封闭用分配律 (p∨x) ∨ (p′∨x′) = (p∨p′) ∨ (x∨x′)，其中 p∨p′ ∈ P、x∨x′ ≤ a；下闭性同样来自 p∨x = p ∨ (p ∧ x) 与 p ∧ x ∈ P。又对每个 p ∈ P 有 p = p ∨ (p ∧ a) ∈ J，故 P ⊆ J；而 a = (a ∧ p) ∨ a ∈ J − P（这里取任意 p ∈ P，若 P 空则显然），所以 J 严格包含 P。K 同理。

第 6 步：极大性逼出交点。由 P 在 S 中的极大性，J 和 K 都不在 S 里；它们仍是理想且含 I，所以只能是「交了 F」。取 p ∨ x ∈ J ∩ F、q ∨ y ∈ K ∩ F，其中 x ≤ a、y ≤ b、p, q ∈ P。

第 7 步：分配律收口。滤子对 ∧ 封闭，故 z = (p∨x) ∧ (q∨y) ∈ F。展开：

z = (p ∧ q) ∨ (p ∧ y) ∨ (q ∧ x) ∨ (x ∧ y).

前三项都 ≤ p 或 ≤ q，由下闭性落在 P；第四项 x ∧ y ≤ a ∧ b ∈ P，也落在 P。理想对 ∨ 封闭，所以 z ∈ P。于是 z ∈ P ∩ F，与 P ∩ F = ∅ 矛盾。∎

这一定理在干什么

「a ≠ b 就该有立场分开它们」不是自明的——它是素理想定理换来的。取 I = (b]、F = [a)（设 a ≰ b），I ∩ F = ∅ 成立，定理给的 P 含 b 不含 a。在 BA 里取补滤子 U = A − P，就是一个含 a 不含 b 的超滤子。L06 那句「存在超滤子分开它们」的欠账，到这里才还清。

4Stone 表示定理的完整证明 O1O1

定理 Stone 表示（UAL 定理 2.6.5 证明中给出 rep；Bergman 2.43 / 2.44；L06 定理 6.3）

设 A 是布尔代数，XA = Ult(A) 是它的超滤子全体。对 a ∈ A 定义

rep(a) = { U ∈ XA : a ∈ U }.

则 rep : A → 𝓟(XA) 是 BA 同态，且是到开闭集代数 Clop(XA) 的同构。

第 1 步：等式成立——rep 是同态

逐条直接来自超滤子的定义与刻画 2.6.3(ii)：

rep(a ∧ b) = rep(a) ∩ rep(b)　　rep(a ∨ b) = rep(a) ∪ rep(b) rep(−a) = XA − rep(a)　　rep(0) = ∅　　rep(1) = XA.

第三行值得停一下：它正是 a ∈ U ⇔ −a ∉ U 的集合论翻译。没有超滤子的「不骑墙」，补集就对不上。

第 2 步：像落在开闭集里，而且撑起一个基

给 XA 赋拓扑，以 {rep(a) : a ∈ A} 为基。第 1 步说明这些集合对有限交封闭，所以基条件成立。又 XA − rep(a) = rep(−a) 仍是基元素，故每个 rep(a) 既开又闭。「开闭」不是额外加的要求，是「不骑墙」的直接后果。

第 3 步：XA 是 Stone 空间

先证 Hausdorff：若 U ≠ V，取 a ∈ U − V，则 rep(a) 含 U 不含 V，而 rep(−a) 含 V 不含 U，两者不交且开。

再证紧致：把每个超滤子 U 看成 2A 中的点（特征函数）。成为超滤子的条件——含 1 不含 0、上闭、对 ∧ 封闭、a ∈ U ⇔ −a ∉ U——都能写成一族闭条件（每条只涉及有限个坐标）。由 Tychonoff 定理 2A 紧，闭子集 XA 紧。这就是 L13 的「紧致 = 超滤子收敛」在代数侧的翻版。

有开闭基 + 紧 + Hausdorff，按拓扑讲义引理 6.2.8，XA 是 Stone 空间。

第 4 步：单射——素理想定理上场

设 a ≠ b。若 a ≰ b，取 I = (b]、F = [a)，由 §3 得超滤子 U ∋ a、U ∌ b，故 U ∈ rep(a) − rep(b)。若 b ≰ a 同理。所以 rep 分开任意两点，是单射。

第 5 步：满射——这一步 L06 没做，靠紧致性

取任意开闭集 C ⊆ XA。它是开集，且是紧空间的闭子集，故紧。因 {rep(a)} 是基，对每个 U ∈ C 可取 aU 使 U ∈ rep(aU) ⊆ C；有限子覆盖给出

C = rep(a1) ∪ ⋯ ∪ rep(an) = rep(a1 ∨ ⋯ ∨ an).

令 a = a1 ∨ ⋯ ∨ an，则 C = rep(a)。「开闭集必是有限个基本开闭集之并」这一步，正是紧致性把无穷覆盖压成有限——和 L18 的用法同源。

别把「嵌入」和「同构」搞混

L06 只证到 rep 嵌入 𝓟(XA)；那还不够，因为像可能只是幂集的一小块。第 5 步说明：取对偶拓扑的开闭集作目标，像就恰好填满。目标选对了，嵌入自动升级成同构。这也解释了为什么 Stone 对偶必须带拓扑——只谈集合代数，对偶不成立。

来源：UAL 定理 2.6.5 证明（rep 的定义与同态验证）、定理 2.6.15、推论 2.6.12；Bergman 定理 2.41、2.43、2.44；拓扑讲义 引理 6.2.8。第 3、5 步的紧致性论证按 L13 的口径展开。

5范畴对偶：BAop ≃ Stone O2O2

从「一个代数」到「一整类代数」

§4 证明了单个代数 A 与单个空间 Ult A 同构。范畴对偶要的是连同映射一起对应：布尔代数之间的同态，对应 Stone 空间之间的连续映射，方向反过来。方向反转是「对偶」这个名字的由来，也是初学者最容易卡住的地方——多花十秒钟想清楚它为什么必须反。

定义 两个函数子
  • F : BA → Stoneop：对象 A ↦ Ult A；同态 f : A → B 送到
    F(f) = f* : Ult B → Ult A,　f*(V) = f−1(V) = { a ∈ A : f(a) ∈ V }.
  • G : Stoneop → BA：对象 X ↦ Clop X；连续映射 g : X → Y 送到
    G(g) = g−1 : Clop Y → Clop X.
验证一：f* 定义良好且连续

良定义。设 V 是 B 的超滤子。f−1(V) 含 1A（因 f(1)=1 ∈ V）、不含 0A、上闭、对 ∧ 封闭——逐条从 V 的滤子性质拉回即可。关键是超滤子性质也保住：若 a ∉ f−1(V)，则 f(a) ∉ V，故 f(−a) = −f(a) ∈ V，于是 −a ∈ f−1(V)。所以 f−1(V) 是 A 的超滤子。

连续。只需验基本开集的原像开。对 a ∈ A：

(f*)−1(rep(a)) = { V ∈ Ult B : f(a) ∈ V } = rep(f(a)),

右边是 Ult B 的基本开闭集。方向为什么反？因为同态 f 把 A 的元素送到 B，于是 B 上的取值自然拉回成 A 上的取值——映射跟着「取值」走，而取值是往回拉的。用 L02 的话说：这是同一个 Galois 连接的两极。

验证二：g−1 是布尔代数同态

集合的原像运算保 ∪, ∩, −, ∅, X，且开闭集的原像仍开闭（连续映射定义）。逐条对应 ∨, ∧, −, 0, 1，所以 g−1 : Clop Y → Clop X 是 BA 同态。这里方向不反：连续映射 X → Y 直接给出 Clop Y → Clop X，恰好与「BAop」中的箭头对齐。

定理 Stone 对偶（范畴版）

存在自然同构

ηA : A → Clop(Ult A)　　εX : X → Ult(Clop X),

使 G ∘ F ≃ IdBA、F ∘ G ≃ IdStone。因此 BAop 与 Stone 范畴等价。

验证三：ηA 就是 rep，已证是同构

§4 第 1、4、5 步合起来正是 A ≅ Clop(Ult A)。自然性检验：给定 f : A → B，两条路径

A ──f──→ B ──ηB──→ Clop(Ult B) A ──ηA──→ Clop(Ult A) ──(f*)−1──→ Clop(Ult B)

在 a ∈ A 上取值，第一条给 repB(f(a))；第二条给 (f*)−1(repA(a))，按验证一正是 repB(f(a))。两路相等，方框交换。

验证四：εX 是同胚——反向走一遍

设 X 是 Stone 空间。对 x ∈ X 令

εX(x) = { C ∈ Clop X : x ∈ C }.

是超滤子：含 X 不含 ∅、上闭、交封闭；C ∉ ε(x) 意味着 x ∈ X − C，而 X − C 开闭，故 −C ∈ ε(x)。

连续：基本开集 rep(C) 的原像是

εX−1(rep(C)) = { x : C ∈ ε(x) } = C,

开闭，故连续。

单射：x ≠ y 时，Stone 空间有开闭基且 Hausdorff（引理 6.2.8），取含 x 不含 y 的开闭集 C，则 C ∈ ε(x)、C ∉ ε(y)。

满射：取 U ∈ Ult(Clop X)。闭集族 {C : C ∈ U} 有有限交性质（U 对 ∧ 封闭且不含 ∅）；X 紧，故 K = ⋂C∈U C ≠ ∅。取 x ∈ K，则 U ⊆ ε(x)，两者都是超滤子，故相等。紧致性第二次登场，这次保证「点」不缺。

同胚：连续双射，定义域紧、值域 Hausdorff，故是同胚。∎

三个常见方向性错误
  • 把 F(f) 写成 V ↦ f(V)：V 是 B 的超滤子，f 从 A 出发，方向不对；必须取原像。
  • 以为 ηA 只在有限代数上满：满射对任意 BA 成立，代价是要用紧致性（选择公理藏在 Tychonoff 里）。
  • 以为 εX 的满射靠 Zorn：靠的是 X 的紧致性和有限交性质，不是超滤子扩张定理。

6对偶词典：理想、商、子代数 O3O3

范畴等价不只是「对象互换」，它把代数里的基本构造一个个翻成拓扑里的基本构造。下面四条逐条给证明，因为方向最容易记反，只有把定义摊开才不会再忘。

对照 四条对偶关系
代数侧拓扑侧（Ult A 中）用到的工具
理想 I ⊆ A开集 UI = ⋃a∈I rep(a)并；反向靠紧致
滤子 F ⊆ A闭集 KF = ⋂a∈F rep(a)有限交性质 + 紧致
商 A/I闭子空间 Ult A − UIq−1 与原像双射
子代数 B ≤ A连续满像 Ult A ↠ Ult B限制 U ↦ U ∩ B
① 理想 ↔ 开集（这条最漂亮，也最需要紧致）

给理想 I，令 UI = ⋃a∈I rep(a)，开。给开集 U，令 IU = {a : rep(a) ⊆ U}：含 0、下闭（b ≤ a 给 rep(b) ⊆ rep(a)）、对 ∨ 封闭（rep(a∨b)=rep(a)∪rep(b)），是理想。

证 IUI = I：若 rep(a) ⊆ UI，则紧集 rep(a) 被 {rep(b) : b∈I} 覆盖，取有限子覆盖得 rep(a) ⊆ rep(b1∨⋯∨bn)，故 a ≤ b1∨⋯∨bn ∈ I，由下闭性 a ∈ I。反向包含显然。

证 UIU = U：因 {rep(a)} 是基且 U 开，每个点所在的基本开闭集含于 U，故这些 rep(a) 覆盖 U，正是 UIU。

结论：Idl(A) ≅ Open(Ult A) 作为格同构。这是 L02「Galois 连接生闭包算子」的一个实例：关系就是「超滤子含元素」。

② 滤子 ↔ 闭集

对偶地，F ↦ KF = ⋂a∈F rep(a) 是闭集（任意交闭）；闭集 K ↦ FK = {a : K ⊆ rep(a)} 是滤子。有限交性质 + Ult A 紧致保证 KF ≠ ∅ 当 F 是真滤子；再用开闭基把 K ⊆ rep(a) 写成有限步，得 FKF = F。这与 ① 互为补：取补运算就把滤子翻成理想。

③ 商 ↔ 闭子空间

设 q : A → A/I 是商映射。一个超滤子 V ∈ Ult(A/I) 拉回成 q−1(V) ∈ Ult A，且不含 I 的任何元素（因为 q(a)=0 ∉ V）。反过来，若 U ∈ Ult A 且 U ∩ I = ∅，则 q(U) 生成 A/I 的真滤子，扩成超滤子 V，并且 q−1(V)=U（两者都是含 U 的超滤子，故相等）。于是

Ult(A/I) ≅ { U ∈ Ult A : U ∩ I = ∅ } = Ult A − ⋃a∈I rep(a),

右边开集的补，是闭子空间。注意方向：代数「缩小」（取商）对应空间「缩小」（取闭子集），不是商空间。

④ 子代数 ↔ 连续满像

设 B ≤ A。定义 r : Ult A → Ult B，r(U) = U ∩ B。它良定义（超滤子交子代数仍是子代数的超滤子：若 b ∈ B − U，则 −b ∈ U ∩ B），连续（r−1(repB(b)) = repA(b)），且满：给定 V ∈ Ult B，它在 A 中生成的滤子可扩成超滤子 U（超滤子引理），而 U ∩ B 真含 V 就会违背 V 的极大性，故 U ∩ B = V。

于是子代数对应连续满像（商空间），与 ③ 正好互补：商对应闭嵌入，子代数对应满射。这两条合起来说明范畴对偶把「子对象 / 商对象」也一并交换了。

有限积可以，无限积要小心

对有限积有 Ult(A × B) ≅ Ult A ⊔ Ult B（不交并）：每个超滤子恰落在一个分量上。对无限积 ∏i∈I Ai，除了各分量的拉回点，还有由 I 上非主超滤子产生的额外点——它是 ⨆i Ult Ai 的 Stone–Čech 紧致化（L13）。这不矛盾：不交并不紧，紧致化才对得上。

7三线汇合：Lindenbaum 代数的几何 O4O4O4

全课最重要的单一例子

给一个命题逻辑理论 T，L16 把公式按 T-等价商掉，得到 Lindenbaum–Tarski 代数 LT = F/∼T。现在把 A = LT 代进本节：Ult(LT) 是什么？就是 T 的所有完全理论（可能世界）组成的 Stone 空间。代数、拓扑、逻辑在这里不是类比，是同一对象的三层皮。

Γ 有限可满足，按定义是「每个有限子集有模型」，翻译成代数是「Γ 的每个有限子集生成真滤子」，翻译成拓扑是「{rep([φ]) : φ∈Γ} 有有限交性质」。因为 Ult LT 紧，这些闭集整体交非空（L13 命题 5.2.9），于是 Γ 有模型。L18 那座紧致桥，在这里变成了「闭集族交非空」一句话。

再看 L20 的可定义性

L20 说「语言能定义 ⟺ 语言能区分」，代数侧写成伴随同态满射，拓扑侧写成 T0 可分。用现在的语言重说一遍：两个世界不可区分，就是它们在所有开闭集上真假一致；商掉不可区分关系，就是把 Ult LT 压成 T0 空间（L12 的商空间泛性质）。三座桥在这里同时到场，而且各自的位置都能在图里指出来。

8推广与边界：Priestley、Esakia、反例 O5O5

推广 拿掉补运算，就要加序
  • Priestley 对偶。把布尔代数放宽成分配格，元素不再自带补，超滤子也不够用——要用素理想，而素理想全体自带包含序 ⟨Prm L, ⊆⟩（Bergman 定理 2.43 后那段明确指出这一点）。对偶对象从 Stone 空间换成 Priestley 空间：紧、Hausdorff、带偏序，且序闭集能被开闭上集分离。分配格 ≃ Priestley 空间的开闭上集格。Bergman 在定理 2.46 后明文说：有限情形的推广由 Stone（BA）与 Priestley（分配格）对偶提供。
  • Esakia 对偶（L26 预告）。再加一层 Heyting 代数（直觉主义逻辑的代数），对偶对象换成 Esakia 空间，即满足「每个点的开上邻域含一个开闭上集」条件的 Priestley 空间。这一条超出本次三本教材，是有意留的预告，到 L26 展开；这里只需记住方向：结构越弱，对偶空间上要补的序结构越多。
典型例子 有限情形可以对着看

A = 𝓟({1,2,3}) 的超滤子恰是三个主超滤子 ↑{1}, ↑{2}, ↑{3}，所以 Ult A 是离散三点空间，Clop(Ult A) = 𝓟(Ult A)，rep 就是恒等。有限 BA 上对偶退化成「集合 ⟷ 离散空间」，两个方向都能手算出来——这是检验定义的试验田，不是对偶真正厉害的地方。

本质例子 对偶真正干活的场合

A = 𝓟(ℕ)/fin（相差有限集即视为相等）。超滤子远不止自然数给出的那些：非主超滤子给 βℕ 中 ℕ 之外的点。「商掉有限误差」这个纯代数动作，翻译成拓扑就是「添上理想点」（L13）。此时 rep : A → Clop(βℕ) 是同构，却远不是到 𝓟(βℕ) 的同构——正说明开闭集这个目标选得多要紧。

边界例子 三个「以为对其实不对」
  • 余有限拓扑的无限集不是 Stone 空间。它紧致、T1，但不 Hausdorff；开闭集只有 ∅ 与 X，于是 Clop X ≅ 2，Ult(Clop X) 只有一个点。从 X 到对偶再回来，信息全丢了。可见「紧 + 开闭基」里的 Hausdorff 不能省（例 6.2.10 与 L14 已记下这个反例）。
  • ℝ 也不是。它连通，Clop ℝ 同样只有平凡两个元素。一般 Tychonoff 空间 X 与 Ult(Clop X) 不同胚，除非 X 本身就是 Stone 空间（0 维紧 Hausdorff）。范畴对偶只在 Stone 范畴里成立，不是对所有空间成立。
  • 无限积不是不交并。Ult(∏i Ai) 比 ⨆i Ult Ai 多出非主超滤子带来的点，前者是后者的 Stone–Čech 紧致化。有限积的直觉不能直接外推到无穷。

一处口径提醒

Stone 对偶里的「点」是超滤子，而 L14 定义 Stone 空间时用的是「紧 + Hausdorff + 全不连通」。两者等价，但靠的是引理 6.2.8（开闭基刻画）：Ult A 的开闭基 {rep(a)} 让第一定义自动成立。不要把「全不连通」直接当作「点 = 超滤子」的证据，中间必须经过开闭基和紧致性。
