2先看一个映射，它对不对？

本讲的主线

把实直线卷成圆：

π : ℝ → S¹,    π(t) = (cos 2πt, sin 2πt)

这一个映射，本讲要问的每个问题都能拿它来问一遍。先把它摊开看清楚：

  • 它是满射——圆上每一点都有原像。
  • 它不是单射——π(t) = π(t+n)，对每个整数 n。纤维恰好是 t + ℤ。
  • 它连续——坐标函数 cos, sin 都连续。
  • 它是开映射——这一点不那么显然，§6 再验。
  • 它不是同胚——因为它不是单射。
  • 它是商映射——§8 会把这条和「粘合」联系起来。

一个映射，六个身份，其中五个是「是」，两个是「不是」。本讲剩下的全部内容，就是把这几行判断逐个讲清楚，并回答一个更要紧的问题：这些性质里，哪些是 π 的，哪些是「ℝ 卷成圆」这件事本身的？

为什么从这里开始

教材的顺序是「定义 → 命题 → 例」。这个顺序对写书合适，对学不合适——先看定义再看例子，你永远不知道定义为什么长这样。反过来，先盯住一个具体的、够丰富、又够简单的映射，然后一路问「它凭什么算连续」「它有没有丢东西」，定义就会自己浮出来。

后面每一节，我都会回到 π。你只要盯住它，概念就不会散。

3连续：只查原像 O1

它解决什么问题

「连续」这个词被定义过三回：铅笔说（不断）、接近说（近的映到近的）、ε–δ 说。这三种都有个共同的毛病——它们都要用距离。一旦空间上没有距离（Kripke 框架、代数簇上的 Zariski 拓扑、抽象的逻辑论域），三种说法全部失声。

开集定义是把距离这个脚手架拆掉之后剩下的东西。它只说一句：可验证的东西，拉回去还可验证。

定义 3.1（拓扑讲义定义 3.0.1）

f : X → Y 连续，当且仅当 Y 中每个开集的原像在 X 中开：

∀U ⊆ Y  ( U ∈ τY ⟹ f−1[U] ∈ τX )

拿 π 验一遍：S¹ 的开集是开弧之并，而开弧的原像是若干开区间之并（π−1[弧] = ⋃n∈ℤ(a+n, b+n)），确实开。所以 π 连续。

注意分子里的方向：从 Y 拉回 X。原像这个运算天生是「逆向」的——它把一个关于值域的问题翻译成关于定义域的问题。

先拆掉一个错直觉

多数人第一次看到定义会想：「连续不是应该把开集映成开集吗？」

不是。看常值映射 c : ℝ → ℝ、c(x) ≡ 0。它是连续的——图像就是一条水平线，比什么都连续。但 c[(0,1)] = {0}，单点集在 ℝ 里不 open。把整条直线压成一个点，信息全没了，它依然叫连续。

这条裂缝是本讲的骨架：连续只管「不许凭空多出」，完全不管「丢了多少」。管丢不丢的是另一个概念，§6 见。

定理 3.2（命题 3.1.1）

f : X → Y 连续 ⟺ 对每个 S ⊆ X：

f[clX(S)] ⊆ clY(f[S])
证明

(⟹) 设 f 连续，x ∈ clX(S)。由 L10 命题 2.4.6，只需证 f(x) 的每个开邻域 V 都与 f[S] 相交。f−1[V] 是 x 的开邻域，故与 S 有交点 y；于是 f(y) ∈ V ∩ f[S]。

(⟸) 设 V ⊆ Y 开，令 S = f−1[Y − V]。用条件得 f[cl(S)] ⊆ cl(f[S]) ⊆ cl(Y−V) = Y−V，故 cl(S) ⊆ f−1[Y−V] = S，即 S 闭。取补得 f−1[V] 开。∎

这条定理其实在说人话

L10 把「x 接近 S」定义成 x ∈ cl(S)。定理说的是：x 接近 S，则 f(x) 接近 f[S]。这就是「接近说」的严格版本，而且只用 cl，不碰距离。

方向仍然是单向的：只有 ⊆，没有 ⊇。写成包含式，单向这件事就一目了然了——而它正是「允许坍缩」的精确表述。

定理 3.3（命题 3.1.2，四种等价）

设 ℬY 是 Y 的基或子基。连续 ⟺ 下列任一：

  1. 每个（子）基本开集的原像开；
  2. 每个闭集的原像闭；
  3. 对每个 x、每个 f(x) 的（基本）开邻域 V，存在 x 的开邻域 U 使 f[U] ⊆ V。

证第 1 条的基情形：任一开集 V = ⋃iVi，原像与并交换，f−1[V] = ⋃if−1[Vi]，仍是开集之并。子基情形：先取有限交成基（用 f−1 与交交换），再回到基情形。

典型例子

f(x) = x²。查基：开区间 (a,b) 的原像，解 a < x² < b——当 0 ≤ a < b 时是 (√a,√b) ∪ (−√b,−√a)，当 a < 0 < b 时是 (−√b,√b)，其余为空。全是开区间之并。注意这题的工作量：只解一个不等式，完全没碰「任意开集」。这就是查基的意义。

本质例子

连续性不是函数的性质，是三元组 (f, τX, τY) 的性质。取恒等映射 id : ℝ → ℝ。两边都用欧氏拓扑，连续。定义域离散、值域欧氏，仍连续（每个集合都开，原像自动开）。反过来定义域欧氏、值域离散，则 id−1[{0}] = {0} 不开，立刻不连续。同一个函数，同一个公式 f(x)=x，换个拓扑结论翻转。这是 L08「拓扑＝知识标准」最直接的一次兑现。

边界与误解

① 别记成「连续保开集」——常值映射是反例，见上面那个框。② 别以为「序列连续 ⟹ 连续」。连续确实保证 xn → x 时 f(xn) → f(x)（度量空间里），但反向需要第一可数性，一般拓扑空间里会失效。这类「反向不成立」的坑，本讲至少有四个，§6 的注会集中列。③ 等价说法里第 2 条是「闭集的原像闭」，不是「闭集的像闭」——后者叫闭映射，是另一个概念。

来源：拓扑讲义定义 3.0.1、命题 3.1.1 及证明、注 3.1.1、命题 3.1.2、例 3.1.3。

4不增、不丢、不变 O2

它解决什么问题

L08 把拓扑空间读成「论域 + 认识论框架 + 命题」，开集 = 可验证命题。那么两个论域之间的映射，读成什么？答案是翻译。于是「好翻译的标准是什么」这个问题，变成了「哪些映射连续」。

这个转换不是修辞。它让你能反过来用：如果某条翻译在现实中显然应当被允许，那它必须满足连续性条件，于是定义就不是人为规定了。

读法 4.1（注 3.1.2 / 3.1.4）

设 f : X → Y 是论域间的命题翻译。

映射开集条件读法允许发生什么
连续U 开 ⟹ f−1[U] 开不增加知识可以丢，不可以造
开映射U 开 ⟹ f[U] 开不丢失知识可以造，不可以丢
同胚双射 + 连续 + 开知识不增不减什么都不许

讲义还替「允许丢」说了句公道话：翻译可能丢失某些内容，是很合理的，因此允许信息损失的翻译本身仍然值得研究。要求每个翻译都保真（同胚）太苛刻——现实中绝大多数有用的映射都在丢东西。

用 π 验这三种读法

回到主线那个映射 π : ℝ → S¹。

  • 它不增知识吗？是。圆上一段弧若可验证，拉回成实直线上每隔 1 就出现一段的开集，仍可验证。
  • 它不丢知识吗？是。实直线上任一段开区间，卷上去是圆上的一段弧，仍可验证。这一点 π 和常值映射的关键区别——π 本地不坍缩，只是把同一条信息重复了无穷多次。
  • 它就是同胚吗？不是。它不增不丢，但不单射——它把 t 和 t+1 认同了。这不是「丢知识」，是「重复知识」。

「不增 + 不丢」仍不足以保证同胚，还差一个单射。这个区分很重要，多数讲义一笔带过。几何上：π 是覆叠，局部看是同胚，全局看是 ℤ 重的。

典型例子

常值映射 c(x) ≡ 0。连续（不增：没什么可造），不开（丢光：c[(0,1)] = {0} 不开）。读法：一种语言把所有事情说成同一句话——可靠，但零分辨率。

本质例子

例 3.1.5 的折线：

f(x) = x (x ≤ 0)，   f(x) = 0 (x > 0)

连续但不开：f[(−1,1)] = (−1,0]，半开区间不开。读法：正半轴那一整段分辨率被压进了单点 0。注意 0 这个端点的角色——它是压扁的痕迹，把右侧全部信息收进了自己。这个例子比常值映射更本质，因为它只在一个方向上坍缩，其余地方完好：翻译在某些话题上精确，在另一些话题上只能说「不是负的」。

边界与误解

① 「不增加」不等于「一定减少」——恒等映射一点不丢，它的开性也成立。连续与开是两个独立条件，四种组合都存在（§6 摆全）。② 别把 f−1[U] 当逆映射。这里 f 不必可逆，f−1 只是「取原像」这个集合运算，f−1[U] 读作「U 在 f 下的原像」。③ 「不丢」不能理解成「f 是满射」。满射是集合层面的事；开映射是拓扑层面的事，两者互不推出——π 两者都有，常值映射两者都无，但也有很多映射只有其中一个。

来源：拓扑讲义注 3.1.2、注 3.1.4、例 3.1.5。

5点连续与 ε–δ O3

它解决什么问题

整体连续是个全局断言。但动手验的时候，你总是一点一点验的。能不能把全局条件拆成「每点各管一段」？能，这就是点连续。而它的邻域形式，正是 ε–δ 定义剥掉度量外套之后的样子。

定义 5.1（命题 3.1.2 第 3 条、注 3.1.3）

f 在 x 连续，若对 f(x) 的每个（基本）开邻域 V，存在 x 的开邻域 U 使 f[U] ⊆ V。等价地：

∀S ⊆ X,   x ∈ cl(S) ⟹ f(x) ∈ cl(f[S])

整体连续 ⟺ 处处点连续。

定理 5.2（习题 3.8）

在 ℝ 上，f 在 a 连续 ⟺

∀ε > 0 ∃δ > 0 ∀x  ( |x−a| < δ ⟹ |f(x)−f(a)| < ε )
两套语言逐词对照
ε–δ拓扑
|x−a| < δx ∈ U，U 是 a 的开邻域
|f(x)−f(a)| < εf(x) ∈ V，V 是 f(a) 的开邻域
开区间 (a−δ,a+δ) 够小开邻域可以是任意形状，不必是区间
「对每个 ε 找 δ」「对每个 V 找 U」

ε–δ 里每一个「小」都被换成「开邻域」。换掉之后，第三行那个差别就露出来了：拓扑版本允许邻域奇形怪状，不必是区间。这不是放宽，是去掉了一个不该有的假设——距离结构本来就只是拓扑结构的一个特例。

典型例子

f(x) = x² 在 a = 3：取 δ = min(1, ε/7)。当 |x−3| < 1 时 |x+3| < 7，于是 |x²−9| < 7δ ≤ ε。套路是先把变量框进一个有界范围，把因子估成常数。拓扑语言里这一步对应「先用一个基本开邻域把点圈住」——同一件事的两种说法。

本质例子

f(x) = 0（x ≠ 0）、f(0) = 1。处处连续，恰在 0 处断。0 处为什么断？取 V = (1/2, 3/2)，原像是 {0}，而 {0} 不是 0 的邻域。你找不到 0 附近的一小块，保证它整个映进 V。这个例子证明点连续是真正局部的：可以只在一点崩坏，其余全好。

边界与误解

① 「处处点连续」确实等价于整体连续，这是定理不是反例——但注意每个点的邻域 U 可以随点剧烈变化，不能以为同一个 U 管所有点。② 方向别搞反：定义里从「f(x) 的邻域」出发，回头找「x 的邻域」。这与 L10 闭包刻画的顺序一致，也和 ε–δ（先给 ε，再找 δ）一致。③ 连续点集未必开——它只是 Gδ 集，可以相当怪。上面那个例子恰好是开集，属于运气好，别当定理用。

来源：拓扑讲义命题 3.1.2 第 4 条、注 3.1.3、习题 3.8。

6四格表：连续 × 开 O4O4

它解决什么问题

「连续」和「开」是两个独立条件。既然是独立的，就该有四种组合，而且四种都该存在。这一节就是把这四格填满——填满之后，你就再也不会把两者混为一谈。

先把定义摆出来，然后一次性填表，最后用模态逻辑解释其中一格为什么在逻辑里也有名字。

定义 6.1（定义 3.1.4、3.2.2）

f 开，若每个开集的像开；f 闭，若每个闭集的像闭。

开：U ∈ τX ⟹ f[U] ∈ τY     闭：F 闭 ⟹ f[F] 闭

开与闭也是两回事，互不推出——和 L10 里「开集与闭集」的四分完全同构。原因也相同：开只对开集说话，闭只对闭集说话，而集合可以只开、只闭、两者皆是、两者皆非。

填满这张表

开映射不开
连续π : ℝ → S¹（§2 列的五条性质，开性 §6 末补证）常值映射 c(x) ≡ 0；折线 f(x)=x (x≤0), 0 (x>0)
不连续id : (ℝ, 平凡) → (ℝ, 离散)1ℚ : ℝ → ℝ（有理点取 1，其余 0）
四格逐个交代

左上（连续 + 开）：π。这是本讲主线，§2 已列。补一句开性为什么成立：ℝ 的任一开集是开区间之并，而 π 把开区间 (a,b) 映成一段弧——只要 b−a ≤ 1 就是真弧（不自重叠），而长区间可切成小段。关键是定义域没有端点，这一点 §7 会用它做 A/B 对照。

右上（连续 + 不开）：常值映射与折线，§4 已讲。它们的共同点是坍缩：某个非空开集被压成低维的东西。

左下（不连续 + 开）：id : (ℝ, 平凡) → (ℝ, 离散)。平凡拓扑只有 ∅, ℝ 两个开集，它们的像是 ∅, ℝ，在离散拓扑里都开——所以它开。但 {0} 在离散侧开，原像是 {0}，在平凡侧不开——不连续。这一格最反直觉，但它说明：「不丢」比「不增」弱得多，因为定义域的拓扑太粗时，能让原像失败的开集在定义域里根本不存在。

右下（都不）：1ℚ。它处处不连续（每点的邻域都同时含有理与无理点，像在 {0,1} 里跳）。也不开：任一非空开集都含有理与无理点，像是 {0,1}，在 ℝ 里不开。这一格证明两个条件确实互不蕴含。

定理 6.2（命题 3.1.7，forth / back）

设 𝔉 = (W,R)、𝔉′ = (W′,R′) 为 Kripke 框架。f : W → W′ 满足

  • forth：xRy ⟹ f(x)R′f(y)；
  • back：f(x)R′y′ ⟹ ∃y ( xRy 且 f(y)=y′ )。

若两框架自反传递、赋 Alexandroff 拓扑（上集为开），则

forth ⟺ 连续      back ⟺ 开映射

证明（forth 一侧）。 设 forth 成立，U′ 为 R′-上集，x ∈ f−1[U′] 且 xRy。则 f(x)R′f(y)，由 f(x) ∈ U′ 与上集性得 f(y) ∈ U′，即 y ∈ f−1[U′]。故原像是上集。
反向：取上集 ↑f(x) = {z′ : f(x)R′z′}，其原像是上集（由连续性）且含 x（自反），故含所有 y 满足 xRy；于是 f(y) ∈ ↑f(x)，即 f(x)R′f(y)。
back 一侧完全对偶：把「原像是上集」换成「像是上集」，自反性负责让 x ∈ ↑x 落回像里。∎

这一格为什么在逻辑里有名字

forth + back 合起来，在模态逻辑里叫有界态射（p-态射）。它是模态逻辑的「同态」，作用是双向保持模态公式的真值：w ⊨ φ ⟺ f(w) ⊨ φ。

定理 6.2 说的是：这个逻辑概念，在拓扑里恰好切成「连续 + 开」。于是四格表里的「左上」这一格，正好是「逻辑上完全保真」的那些映射。这条对应不是巧合：L06 讲过 Alexandroff 拓扑与预序的对应，而模态框架就是预序加标注。拓朴说「不增不丢」，逻辑说「双向保真」，代数说「同态且像」，三句话是一句话。

典型例子

最小的 forth / back 实验：W = {0,1}，0R1（自反传递），上集为 ∅, {1}, {0,1}。取 f(0)=0、f(1)=0。0R1 需 f(0)Rf(1) 即 0R0，由自反成立——forth 有，故连续。但 f(1)=0，取 y′=1，需 y 使 1Ry 且 f(y)=1，即 y=1 而 f(1)=0——back 无，故不开。这个映射把世界 1 抹掉了，是坍缩的极小模型。

本质例子

为什么 forth 只要求「前向」，back 要求「后向满」？用一个生活化的框架看：W 是时刻，R 是「未来于」。forth 说「x 在 y 之前，则 f(x) 在 f(y) 之前」——这是保序，即不颠倒时间。back 说「f(x) 之后有 y′，则 x 之后有个 y 映过去」——这是满性，即不遗漏未来的分支。保序 + 不遗漏 = 时间结构完全保持，恰好对应连续 + 开。这个读法比抽象定义好记。

边界与误解

① 「开 ⟹ 闭」错。折线 f(x)=x (x≤0), 0 (x>0) 两样都不是：f[[0,∞)) = {0} 闭但 f[(−∞,0]] = (−∞,0] 不闭。开集与闭集的四分，在「映射」这一层原样重演了一遍。② 「连续 + 双射 ⟹ 开」错，§7 有标准反例。③ forth / back 依赖框架关系，不是任意空间的通用判据——换拓扑就换说法。④ 别把「开映射」和「开集」搞混：前者是映射的性质，后者是子集的性质，同名不同类。

来源：拓扑讲义定义 3.1.4、注 3.1.4、例 3.1.5、定义 3.1.6、命题 3.1.7、定义 3.2.2、图 3.1。

7同胚与嵌入 O5O5

它解决什么问题

四格表左上那一格还不够。要「两个空间是同一个」，得再加一条：不许重复（单射）。加上之后得到同胚——拓扑空间的同构。这一节的主线例子会给出一个漂亮的 A/B 对照：同一个圆，从 ℝ 卷出来是同胚意义上的「覆叠」，从 [0,1) 卷出来却连开映射都不是。差别只在定义域有没有端点。

定义 7.1（定义 3.2.1）
  • 商映射：f 满射，且 U 开 ⟺ f−1[U] 开（§8 详说）；
  • 同胚：f 双射、连续、开；
  • 嵌入：把陪域缩到像得到的 f′ : X → f[X] 是同胚（f[X] 取子空间拓扑）。

同胚的等价说法（习题 3.6）：f 同胚 ⟺ 存在连续的 g : Y → X 使 f∘g = idY、g∘f = idX。「g 连续」这四个字不能省——集合论逆总是存在，拓扑逆才要条件。

定理 7.2（引理 3.2.3）

商映射 ⟺ 满射且「U 闭 ⟺ f−1[U] 闭」；商映射必满射连续；满射 + 连续 + 开（或闭）⟹ 商映射。
嵌入必单射连续；单射 + 连续 + 开（或闭）⟹ 嵌入。

但都只是部分逆命题（注 3.2.1）：商映射可以不开不闭，嵌入也可以不开不闭。

嵌入的两个方向

(1.e) 嵌入 ⟹ 单射 + 连续。 f′ : X → f[X] 同胚故单射，于是 f 单射。取 V ⊆ Y 开，V ∩ f[X] 在子空间中开，由 f′ 连续得 (f′)−1[V ∩ f[X]] = f−1[V] 在 X 中开。

(2.e) 单射 + 连续 + 开 ⟹ 嵌入。 f′ 是双射。对 Y 中开集 V，(f′)−1[V ∩ f[X]] = f−1[V] 开，故 f′ 连续。又对 X 中开集 U，f′[U] = f[U] ∩ f[X]，其中 f[U] 在 Y 中开，故此像在 f[X] 中开。∎

两个证明共用同一个动作：把「Y 中的开集」换成「f[X] 中的开集」，即与 f[X] 取交。这就是 L09 子空间拓扑的定义在干活——嵌入的本质是「先缩到像上，再谈同胚」。

A/B 对照：同一个圆，两种卷法

π : ℝ → S¹ , t ↦ e^{2πit} [0,1) → S¹ , t ↦ e^{2πit} ├ 满射 ✓ ├ 满射 ✓ ├ 单射 ✗（t ≡ t+n） ├ 单射 ✓ ├ 连续 ✓ ├ 连续 ✓ ├ 开 ✓ ├ 开 ✗ ← 差别只在这里 └ 商映射 ✓（§8） └ 商映射 ✗

定义域有没有「端点」，决定了卷出来的映射是否开

典型例子

(−1,1) ≅ ℝ，同胚 f(x) = tan(πx/2)。由此对任意 a<b 有 (a,b) ≅ ℝ。这正是注 3.3.1 说的「拓扑空间可以伸展」：长度、直径这些度量概念在同胚下全部失效，留下的只有「断没断、有没有洞」这类结构信息。甜甜圈与咖啡杯的笑话讲的其实是这件事。

本质例子

连续双射不必是同胚，标准反例就在上面那张图的右侧：

f : [0,1) → S¹,   t ↦ (cos 2πt, sin 2πt)

连续、双射。但不是同胚。看开性：[0, 1/2) 是 [0,1) 的开集（子空间拓扑），而它的像是一段「有起点、没有终点」的弧——在 S¹ 里不含起点的小邻域，故不开。读法：起点 0 这一端被「剪断」了，剪口在像里留下一个缺口。而 π 的定义域是无端点的直线，每个点两侧都有余地，所以卷起来处处干净。

这个对照是本节最值得记住的东西：它不是「找到某个性质不满足」的技巧题，而是让你看见端点是拓扑结构的真实内容，不是一个可以随便去掉的技术细节。

边界与误解

① 「单射 + 连续 = 嵌入」错。取 id : (ℝ, 离散) → (ℝ, 欧氏)：单射、连续（离散定义域），但不是嵌入——逆（欧氏 → 离散）不连续。缺的正是「开」这一半。② 「同胚是等价关系」对（习题 3.5），所以「同胚于」可以传递使用，这是后文「沿同胚搬运性质」的许可证。③ 嵌入 ≠ 包含映射：习题 3.7 说明 U ⊆ X 开时 U ↪ X 连续且开（故是嵌入）；U 不开时只连续不开，一般不是嵌入。「U 在 X 中开」这件事，决定了它作为子空间是否与自身嵌入一致——这和本节 A/B 对照是同一个道理。④ 同胚不必「形状像」，可以极其奇异，讲义那句提醒是认真的。

来源：拓扑讲义定义 3.2.1、引理 3.2.3 及证明、注 3.2.1、例 3.2.4、注 3.3.1、习题 3.4/3.5/3.6/3.7。

8商映射与泛性质 O6O6

它解决什么问题

前面都是「给定两空间，问映射好不好」。商映射反过来：把条件当定义，用它造空间。这是 L03 商代数的拓扑版，动作一模一样——把某些点认同成一类，然后要求新空间的结构恰好是使投影保持结构的那个。

而 §2 那个 π 在这里终于找到自己的位置：它不是「恰好也是」商映射，它就是一个商映射，商掉的是 ℤ 作用。

定义 8.1（定义 3.2.5）

设 ∼ 是 X 上的等价关系，q : X → X/∼ 为自然投影。商拓扑定义为

U ⊆ X/∼ 开  ⟺  q−1[U] 在 X 中开

这确实是拓扑，且 q 确为商映射。

注意方向：条件「q−1[U] 开」越容易满足，能放进来的 U 就越多，所以商拓扑是使 q 连续的最细拓扑。再细一点，q 就不连续了。

与 L03 商代数逐条对照
商代数 A/θ商拓扑 X/∼
元素等价类 [a]θ等价类 [x]∼
良定义问题要验证 aiθbi ⟹ f(a⃗)θf(b⃗)用原像定义，免验
投影π 是满同态q 是商映射
极值方向θ 取最大同余取最细拓扑
泛性质在 θ 上常值的同态唯一分解在类上常值的连续映射唯一分解

为什么一个「最大」一个「最细」？因为代数的条件是等式（「f(a⃗) = f(b⃗)」，认同得越少越容易满足，故取最大），拓扑的条件是包含（「q−1[U] 开」，开集越少越容易满足，故取最细）。这是两者之间唯一的实质差别，其余处处同构。

定理 8.2（习题 3.9.3，泛性质）

每个在等价类上常值的连续映射 f : X → Y，唯一诱导 f̃ : X/∼ → Y 使 f = f̃ ∘ q；且

f̃ 连续 ⟺ f 连续

这条才是「为什么要这样定义商拓扑」的真正答案。它说：要在商空间上构造连续映射，只需在 X 上构造，再检查它尊重认同。「尊重认同」是集合条件，「连续」是拓扑条件，两者被这条定理彻底解耦——这就是商空间所有实际用法的技术基础。

典型例子

端点粘合：I = [0,1]，x ∼ y ⟺ x=y 或 {x,y} = {0,1}。商空间 [0,1]/∼ ≅ S¹。「取商＝粘合」的字面意思：0 和 1 认同成一类，区间卷成圆。
更狠的是 Möbius 带（例 3.2.7）：I² 上令 (x,y) ∼ (x′,y′) 当 (x,y)=(x′,y′) 或 [x = 1−x′ ∈ {0,1}, y = 1−y′]——一条边翻转后粘到对边。三步构造：[0,1] 子空间 → 积 → 商，全是 L09 讲过的东西，组合起来正好给出该几何对象应有的拓扑。

本质例子

连续满射不一定是商映射（习题 3.9.2）。取 X = (ℝ, 欧氏)、Y = (ℝ, 离散)、f = id。它满射、连续（从粗到细）。但 {0} 在 Y 中开，原像 {0} 在 X 中不开——若 f 是商映射，Y 的开集必须恰好是那些拉回后开的集合，而 {0} 不符合。失败原因：Y 的拓扑比商拓扑更细。商映射的定义是「Y 的拓扑恰好是商拓扑」，多一个开集都不行。这是引理 3.2.3 只说「部分逆命题」的根本原因。

边界与误解

① 「商映射 = 连续满射」错，上例即是；正确配方是「满射 + 连续 + 开（或闭）」。② 「商空间继承原空间的好性质」错：分离性、紧致性都可能崩塌——认同两个点，Hausdorff 就可能失去。这是 L12 的题目。③ 「商拓扑是使 q 连续的最粗拓扑」错，是最细。混淆来自「商＝取最小」的直觉——这里的「最小」是指认同得多，而非开集少。④ 泛性质里的「唯一」是集合层面唯一（f̃ 的值完全由 f 决定），连续性要另验；但由「f̃ 连续 ⟺ f 连续」这条，验起来很省事。

来源：拓扑讲义定义 3.2.5、例 3.2.6/3.2.7、习题 3.9、注 3.2.1。

收束

整讲其实只有两句话。第一句：连续是单向的，只禁止凭空造知识，允许坍缩。所以高分答案永远不会是「连续保开集」。第二句：同胚是两个单向条件的交集——不增 + 不丢 + 不重复。有了它，拓扑学第一次有了判断「两个空间是否同一个」的尺子，也有了「沿同胚搬运性质」的许可证。
