0动机：一个动作，三个名字

先不谈定义。请你回想三种再熟悉不过的动作：

三个场景

代数。给群 G 里两个元素 a,b，问「它们生成的子群是什么」。你得把 a⁻¹, b², ab, ba, … 全部加进去，直到对乘法和逆封闭才停手。这个「补到封闭」的动作叫 Sg（subgroup/subalgebra generated by）。

逻辑。给一组前提 Γ，问「能推出什么」。你得把所有逻辑后承都加进来，直到再也推不出新句子。这个「补到封闭」的动作叫 Cn（consequence）。

拓扑。给实数集里一个点集 A，问「它的闭包是什么」。你得把所有极限点加进去，直到包含所有聚点。这个「补到封闭」的动作叫 cl（closure）。

三个动作来自三门完全不同的课，教科书也各写各的。但把它们剥到骨头，是同一个动作：给定一个不完整的集合，补上「被迫一起来的东西」，得到一个自足的整体。而且这个动作服从同样的三条规律。

这就是全课第一个融合点

本讲要做的，就是把这三条规律抽象出来，命名为闭包算子，然后证明：代数的 Sg、逻辑的 Cn、拓扑的 cl 都是它的实例。一旦看穿这一点，后面五座桥定理（L18–L22）就不再是魔术——它们只是在问「这个闭包算子多快能补全」「补全过程和什么结构对偶」。

为什么这一讲值得花 2–3 学时？因为它是唯一一个三条线在同一页纸上相遇的地方。后面你会反复回到这里：L03 的同余生成是闭包算子，L04 的超积是闭包系统的极限，L10 的紧致性是闭包算子的「有限性」，L21 的 Stone 对偶是 Galois 连接的一个实例。

1偏序与格：三个视角

闭包算子的自然栖息地是幂集的包含序，但它在任意偏序集上都能定义。先把序的语言铺好。

定义 2.1（Bergman 2.1）

偏序集 ⟨P, ≤⟩：自反、反对称、传递。a ≺ b（覆盖）指 a<b 且不存在中间元。

对 S⊆P：⋁S（join、上确界）是最小上界，⋀S（meet、下确界）是最大下界。注意「上确界」和「极大元」不是一回事：偏序里可能有多个不可比的极大元，但上确界至多一个。

格的两个视角 —— 这是理解后面所有对偶的钥匙

视角 A：格是一个偏序集，其中每对元素都有唯一的最小上界 a∨b 和最大下界 a∧b。读作「a∨b 是同时包含两者的最小整体」。

视角 B：格是一个代数 ⟨L, ∨, ∧⟩，满足交换律、结合律、吸收律 a∨(a∧b)=a。读作「有两种运算」。

这两个视角等价，但用途不同。做拓扑、做逻辑，你用视角 A（开集按包含排序、公式按可推出排序）；做泛代数、做同余格，你用视角 B（要对运算封闭、要谈子格同态）。本课程在两者之间来回切换，请都熟悉。

定义 2.2

格 L 分配，若 a∧(b∨c)=(a∧b)∨(a∧c) 对全部元素成立；模，若 a≤c ⇒ a∨(b∧c)=(a∨b)∧c。

完全格：任意子集（不只是有限集，也不只是二元集）都有上下确界。

例 · 三个务必记住的完全格
  1. ⟨𝒫(H), ⊆⟩：⋁ = ⋃，⋀ = ⋂，顶元 H，底元 ∅。分配。
  2. ⟨Sub(A), ⊆⟩：A 的子代数全体。⋀ 是 ordinary 交，⋁ 是「生成子代数」而非 ordinary 并（两个子代数的并一般不封闭）。这就是闭包算子的影子。
  3. ⟨Con(A), ⊆⟩：A 的同余关系全体（Bergman 推论 2.15 保证它是完全格）。同余格是 L03 的主角。
为什么完全格重要

因为它保证「任意多个闭集的交还是闭集」这件事有地方安放。L02 的下半场会证明一个漂亮的互反结论：闭包算子和完全格是同一枚硬币的两面（Bergman 定理 2.25 / 2.26）。

来源：Bergman §2.1–2.3（命题 2.14、推论 2.15）；UAL §1.3。

2闭包算子：三条公理的来由

定义 2.3（UAL 1.7.1；Bergman 2.23）

集合 H 上的闭包算子是映射 c : 𝒫(H) → 𝒫(H)，满足对任意 X,Y ⊆ H：

(i)  X ⊆ c(X)    （扩张性 extensive）
(ii)  X ⊆ Y ⟹ c(X) ⊆ c(Y)    （单调性 monotone）
(iii)  c(c(X)) = c(X)    （幂等性 idempotent）

c(X) 称为 X 的 c-闭包；若 X = c(X)，称 X 是闭集。

逐条拆开：为什么偏偏是这三条？

(i) 扩张性：补全只加不减。你无法在「生成一个子群」时把原来的元素弄丢。X ⊆ c(X) 是对「补全过程」的最低要求。

(ii) 单调性：起点越大，终点越大。给的前提越多，能推出的越多；给的种子越多，生成的子代数越大。形式上 X⊆Y ⇒ c(X)⊆c(Y)。这一条常常是三条里最容易被验证也最容易被忽略的。

(iii) 幂等性：补一次就够了。这是「封闭」这个词的精确含义：已经封闭的东西再补也不会变。c(c(X))=c(X)。注意它和两个条件一起蕴含：X 闭当且仅当它是某个集合的闭包，即 X = c(Y)（Bergman 定理 2.25(1)）。

常见误区

闭包算子不要求 c(X∪Y)=c(X)∪c(Y)。代数里这条几乎从不成立：两个子群并集的闭包严格大于两个子群之并。UAL 把满足有限并可加（c(X1∪⋯∪Xn) = c(X1)∪⋯∪c(Xn)，n=0 时给出 c(∅)=∅）的叫拓扑闭包算子（定义 1.7.3）。名字的来历正是：拓扑空间的闭包算子恰好满足这条（Kuratowski 公理之一，L10 详讲），所以它是闭包算子的一个真子类，而不是与拓扑闭包对立的东西。

但要注意「有限」二字：拓扑闭包只对有限并可加，对无穷并一般不可加，只有 cl(⋃iXi) ⊇ ⋃icl(Xi)。反例：取 Xn = {1/n} ⊆ ℝ，则 cl(⋃nXn) = {0} ∪ {1/n : n∈ℕ} 含 0，而 ⋃ncl(Xn) = {1/n : n∈ℕ} 不含 0。这个「有限可加、无穷不可加」的差别在 L10 与 L18 紧致性里会反复出现。

例 · 天花板函数（UAL 1.7.7，一个非幂集的例子）

把闭包算子定义搬到任意偏序集 ⟨P,≤⟩：只需把 ⊆ 换成 ≤。取 P = ℝ 通常序，ce(r) = 不小于 r 的最小整数。

ce ... ────●─────●─────●─────●─────●──── → ℝ -2 -1 0 1 2 r ──ce(r) （r 被抬到右边的整数格点）

天花板是把实数「补」到整数格点上的闭包算子

验证：r ≤ ce(r)（扩张）；r≤s ⇒ ce(r)≤ce(s)（单调）；ce(ce(r))=ce(r)（幂等，因为整数天花板是自己）。这个例子提醒我们：闭包算子的本质是「把东西抬到一族特殊的点上」，这族点就是闭元——不必真的是集合的包含。

来源：UAL 定义 1.7.1、1.7.3、1.7.7 及图 1.8、1.9；Bergman 定义 2.23。

3三副面孔：Sg / Cn / cl

现在把 §0 的三个场景严格化，逐条核对三条公理。

闭包算子定义在「闭集」是什么直观：补的是什么
SgA 代数 𝒫(A)，A 一个代数 子代数的载体（subuniverse） 把运算结果补进来，直到对全部基本运算封闭
CgA 代数 𝒫(A×A) A 上的同余关系 把「必须同等对待」的对补进来，直到成为等价关系且相容于运算
Cn 逻辑 𝒫(Form)，公式集 理论（对后承封闭的句子集） 把能推出的句子补进来，直到 Γ ⊨ φ ⇒ φ∈Γ
cl 拓扑 𝒫(X)，X 拓扑空间 闭集 把极限点补进来，直到包含所有聚点
Mod∘Th 逻辑 𝒫(Str)，模型类 基本初等类（可公理化的模型类） 把满足同一理论的所有模型补进来
例 · Mod∘Th 是闭包算子（UAL 练习 1.7 末）

对模型类 K，令 Th(K) = {φ : 𝔐⊨φ 对所有 𝔐∈K}（理论），Mod(T) = {𝔐 : 𝔐⊨T}（模型类）。则 c(K)=Mod(Th(K)) 满足三条公理。

这一对算子就是 L02 下半场 Galois 连接的原型：Th 与 Mod 互相「极化」，把「公式集」和「模型类」两个世界对偶起来。UAL 把它放在闭包系统一节当练习，不是随便放的。

深沉一点：所谓「代数化」，第一步就是在做这件事

UAL 的核心操作是给逻辑 L 造代数对应物 Alg⊨(L)。它的原材料正是：公式代数（一个自由代数）＋ Cn（一个闭包算子）。把闭包看成同余、把理论看成理想/滤子，Lindenbaum–Tarski 代数就出来了（L21）。你现在掌握的 Cn，就是 L18–L22 五座桥的桥墩。

来源：Bergman 定义 2.23 后说明、定义 2.24 后说明；UAL §1.7 练习；UAL §3.3（预告）。

4代数闭包与「有限」的分量

这是本讲最重要的一个区分，也是通向紧致性的暗门。

定义 2.4（UAL 1.7.3；Bergman 2.27）

闭包算子 c 称为代数的（algebraic，UAL 也叫 finitary），若对任意 X ⊆ H：

c(X) = ⋃ { c(Z) : Z ⊆ X 且 Z 有限 }

即：任给元素在 c(X) 里，只用到 X 的某个有限子集就能把它补出来。

直观 · 「有限 witness」原则

代数的生成是逐步的：一个元素之所以进了子代数，是因为它在有限步运算里由有限个种子造出来的。没有任何元素需要「无穷多步」才能出现。逻辑的后承也一样：证明是有限长的，只用有限个前提（这是紧致性的证明论版本）。

拓扑的闭包不是这样：一个点可能是某个无穷点列的极限，却不属于任何有限子集的闭包。需要「无穷信息」才能到达它。这一个技术差别，就是拓扑和代数在紧致性上分道扬镳的根源。

定理 2.5（Bergman 2.28）

对任意代数 A，SgA 与 CgA 都是代数闭包算子。

反例 · 拓扑闭包一般不代数

在 ℝ 中取 X = {1/n : n≥1}。则 0 ∈ cl(X)（因为 1/n → 0），但对任何有限 Z ⊆ X，0 ∉ cl(Z)（有限集在 T₁ 空间里是闭的）。所以

cl(X) ≠ ⋃{ cl(Z) : Z ⊆ X 有限 }。

这解释了为什么 Bergman 说 "the closure operator from topology fails to be algebraic"（定义 2.27 后）。

紧致性的三副面孔，第一次照面
领域「有限 witness」的说法正式名字
代数元素由有限种子生成闭包算子代数性（finitary）
逻辑结论由有限前提推出逻辑紧致性 / 证明有限性
拓扑覆盖有有限子覆盖空间紧致性

三处「有限」是同一件事的三个侧面。L10 会把它们严格连成一条等价链：L 紧致 ⟺ Alg⊨(L) 对超积封闭 ⟺ 相应空间紧致。你现在看到的，是这条链的种子。

来源：UAL 定义 1.7.3；Bergman 定义 2.27、定理 2.28 及其后说明。

5闭包系统：换个视角看同一件事

闭包算子是「操作」视角：给你集合，我补。闭包系统是「结果」视角：直接告诉你哪些集合是封闭的。二者一一对应。

定义 2.6（UAL 1.7.4；Bergman 2.24）

二元组 ⟨H, 𝒟⟩ 是闭包系统，若 𝒟 ⊆ 𝒫(H) 对任意交封闭：

(∀ℒ ⊆ 𝒟)   ⋂ℒ ∈ 𝒟

𝒟 的元素叫闭集。约定空族的交为 H，故 H ∈ 𝒟。

为什么「交封闭」和三条公理是一回事

如果知道哪些集合封闭，那么「X 的闭包」自然该是包含 X 的最小闭集，即所有包含 X 的闭集之交：

c(X) = ⋂ { Y ∈ 𝒟 : X ⊆ Y }

反过来，若 c 是闭包算子，取 𝒟 = {X : c(X)=X}，那么任意一族闭集的交仍满足 c(Y)=Y（用单调性和幂等性验证）。两个方向互为逆。

引理 2.7（UAL 1.7.5）

(1) 闭包算子 c 给出闭包系统 c* = ⟨H, {X⊆H : c(X)=X}⟩。

(2) 闭包系统 ⟨H,𝒟⟩ 给出闭包算子 ⟨H,𝒟⟩*(X) = ⋂{Y∈𝒟 : X⊆Y}。

(3) 于是 c** = c，⟨H,𝒟⟩** = ⟨H,𝒟⟩：这是一一对应。

UAL 把证明留作练习——请你真的做一遍（见本讲习题 2），这是检验你是否吃透三条公理的最好方式。

两种视角各有用处

说「拓扑空间」时，我们给的就是一个闭包系统（开集族 τ，闭集是其补）；说「子代数格」时，我们给的是闭包算子 Sg。同一个数学对象，两种呈现。以后看到「闭包系统」不要慌，它只是把闭包算子的结果先摆出来而已。

来源：UAL 定义 1.7.4、引理 1.7.5；Bergman 定义 2.24。

6闭集格与代数格

Bergman 把闭包算子推到深处：闭集构成一个完全格，而且闭包算子与完全格在某种意义上是同一个东西。再加一条「有限性」，就得到代数格。

定理 2.8（Bergman 2.25）

设 C 是 A 上的闭包算子，LC 为全体闭集。则

  1. LC = { C(Y) : Y ⊆ A }；
  2. 非空闭集族的交仍闭；
  3. ⟨LC, ⊆⟩ 是完全格，其中非空族的 meet 就是交，而对 𝒳 ⊆ LC：
    ⋁𝒳 = C( ⋃𝒳 )
注意 join 的形状

在幂集格 𝒫(A) 里，⋁ 就是并。但在闭集格里，⋁ 是「先并再补」：C(⋃𝒳)。两个子代数的「和」不是它们的并，而是它们生成子代数。这正说明 ⟨LC,⊆⟩ 是 𝒫(A) 的一个子格但不是完全子格——L01 里埋的伏笔在这里兑现。

定理 2.9（Bergman 2.26）

逆命题：对任意完全格 M，存在集合 A 与闭包算子 C，使 M ≅ LC。

合起来的口号：闭包算子与完全格是同一枚硬币的两面；研究其一等价于研究其二。

紧致元与代数格

定义 2.10（Bergman 2.29）

完全格 L 的元素 a 称为紧致，若

a ≤ ⋁X ⟹ (∃Z ⊆ω X)   a ≤ ⋁Z

即「被任意并压住，只需被某个有限子并压住」。若 L 的每个元素都是紧致元的 join，称 L 为代数格。

紧凑，还是很像「有限 witness」

把定义里的「⋁X」读成「由无穷多信息补全的结果」，「有限 Z」读成「有限 witness」——你就认出来了：紧致元就是自身只携带有限信息的元素。有限生成子代数、有限可证的句子，都是紧致元。

定理 2.11（Bergman 2.30）

设 C 是 A 上的代数闭包算子，则 LC 是代数格，且其紧致元恰为 C(Y)（Y 有限子集）。反之每个代数格都如此得到（Bergman 2.32）。

这条链把本讲的名字串起来了
闭包算子 C ──§5── 闭包系统 ⟨H,𝒟⟩ │ │ │ 取闭集 │ 取闭集 ▼ ▼ 完全格 L_C ←──────────→ 完全格（定理 2.25/2.26） │ │ + 代数性（有限 witness） ▼ 代数格（紧致元 = 有限生成对象） ←──→ Sg_A, Cg_A, Cn（若紧致） ↑ ↑ L03 同余格 L10 紧致性桥 / L21 Stone 对偶

7Galois 连接：闭包算子的制造机

至此还有一个问题：闭包算子从哪来？每次手工验证三条公理很累。Bergman 说得好：有一个「简单而普遍的方法……几乎藏在本学科的每个角落」。它就是 Galois 连接。

动机 · 从「配对关系」自动造出闭包

设想两类对象，集合 A（比如多项式）和集合 B（比如零点），它们之间有一个关系 φ ⊆ A×B（「a 在 b 处为零」）。

给定 A 的一批元素 X，去看所有「和 X 中每个都配对」的 B 元素；再回来看「和这些 B 元素全都配对」的 A 元素。这一去一回，就把 X 补全了。补全的结果自动满足闭包算子三条公理，无需逐条验证。这就是 Galois 连接。

定义 2.12（Bergman 2.5 式 (2–4)；UAL 1.7.6）

设 φ ⊆ A×B。对 X⊆A、Y⊆B 定义极性（polarities）：

X◮ = { b∈B : (∀x∈X) ⟨x,b⟩∈φ }
Y◭ = { a∈A : (∀y∈Y) ⟨a,y⟩∈φ }

UAL 用方括号记同一件事：X] 与 Y[（练习 1.7.6）。记号不同，结构相同：X◮ = X]，Y◭ = Y[。

命题 2.13（极性的四条性质）
(1)  X ⊆ X◮◭           (1′)  Y ⊆ Y◭◮
(2)  X₁ ⊆ X₂ ⟹ X₁◮ ⊇ X₂◮    (2′)  Y₁ ⊆ Y₂ ⟹ Y₁◭ ⊇ Y₂◭
(3)  X◮ = X◮◭◮         (3′)  Y◭ = Y◭◮◭

注意 (2) 中方向的反转：这是 Galois 连接的标志性特征——反序。(1)(2)(3) 直接说明 C(X)=X◮◭ 是 A 上的闭包算子（扩张、单调、幂等）；D(Y)=Y◭◮ 是 B 上的闭包算子。(3)(3′) 其实由前四条推出。

定理 2.14（Bergman 2.35）

映射 X ↦ X◮ 给出 LC 与 LD∂（LD 的对偶格，即序反转）之间的格同构，其逆为 Y ↦ Y◭。

而且 LC = { Y◭ : Y⊆B }：一边闭集恰好是另一边某集合的极性。

为什么叫「制造机」

你只要随便给一个关系 φ，就免费得到两个闭包算子和一对对偶同构。反过来，任何闭包算子都能由某个 Galois 连接产生吗？是的——取 A = H，B = Lc（闭集族），φ = {⟨x,Y⟩ : x∈Y}（「点属于闭集」）。于是「点—闭集」的属于关系生成了原来的闭包。这个构造正是 Stone 对偶的婴儿版：把点看成「闭集上的某个对象」，用关系把它们对偶起来（L23、L26）。

四个例子：同一个定理反复出现

例 1 · 经典 Galois 理论（Bergman 2.36(1)）

A = 多项式 p(x) 的分裂域，B = 自同构群 Autℚ(A)，φ = {⟨a,f⟩ : f(a)=a}。B 子集的极性是其固定域，A 子集的极性是其自同构子群。定理 2.14 给出的同构，就是伽罗瓦理论基本定理：子群 ↔ 伽罗瓦子扩张，且序反转（群越大，固定域越小）。

例 2 · Hilbert 零点定理（Bergman 2.36(2)）

A = ℂⁿ，B = 多项式环，φ = {⟨a,f⟩ : f(a)=0}。B 的闭集恰是根理想（radical ideals）。「代数集的理想 ↔ 代数集」的对偶，就是 Nullstellensatz。

例 3 · 正交补（Bergman 2.36(3)）

V 内积空间，A = B = V，φ = {⟨v,w⟩ : ⟨v,w⟩=0}。极性就是正交补 X⊥，闭集是子空间（有限维时每个子空间都闭）。这里 X ↦ X⊥ 是对合。

例 4 · 普通序本身（Bergman 2.36(4)）

M 是格，A = B = M，φ = {⟨x,y⟩ : x≤y}。此时 X◮ 是 X 的所有上界。Pollack 等人研究过这个特例；它是把 Galois 连接和序论直接焊在一起的样例。

例 5（本课程的主角）· Th 与 Mod

A = 公式集，B = 模型类，φ = {⟨φ,𝔐⟩ : 𝔐⊨φ}。则

X◮ = Th(X) = {𝔐 : 𝔐⊨X 全部},    Y◭ = Mod(Y) = {φ : 所有 𝔐∈Y 满足 φ}

而 Mod∘Th 与 Th∘Mod 正是 §3 表中的两个闭包算子。你在 §3 见到的逻辑后承闭包，原来一直是 Galois 连接的产物。L21 的 Stone 对偶、L26 的 locale 理论，都是这一对极性的不同装束。

来源：Bergman §2.5（式 2–4、定理 2.35、例 2.36）；UAL 练习 1.7.6；UAL §1.7 末段「更抽象地说」。

带走三句话

一、「补全」这件事在三条线上是同一个结构（闭包算子），别被名字骗了。

二、「有限 witness」这个技术差别，是紧致性在三个领域的共同源头（§4 表）。

三、对偶不是玄学：给定一个关系，极性就自动造出一对闭包算子和一对反序同构（§7）。Stone 对偶只是这套机制的一个好例子。

9习题

  1. 代数 验证天花板函数 ce : ℝ→ℝ 满足闭包算子的三条公理，并写出它的「闭元」集合。（UAL 1.7.7）
  2. 代数 证明引理 2.7：闭包算子与闭包系统一一对应。提示：验证 c(X)=⋂{Y∈𝒟 : X⊆Y} 的三条公理，并说明两次转换回到原对象。
  3. 代数 证明 Bergman 定理 2.25(2)：非空闭集族的交仍闭。再用它推出 ⟨LC,⊆⟩ 是完全格，并验证 ⋁𝒳 = C(⋃𝒳)。
  4. 拓扑逻辑 在 ℝ 中找 X 使 cl(X) ⊋ ⋃{cl(Z):Z⊆X 有限}；再说明为什么逻辑的 Cn 不会有这种现象（提示：证明有穷长度）。
  5. 逻辑 对 φ = {⟨φ,𝔐⟩ : 𝔐⊨φ} 逐条验证极性的性质 (1)(2)(3)，从而 Mod∘Th 是闭包算子。写出「闭集」分别是什么。（UAL §1.7 练习末项）
